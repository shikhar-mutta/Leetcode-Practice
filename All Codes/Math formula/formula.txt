[3] Area of Triangle (Shoelace Formula)
    Given 3 points: A(x1,y1), B(x2,y2), C(x3,y3)

    Area = |x1*(y2 - y3) + x2*(y3 - y1) + x3*(y1 - y2)| / 2

----------------------------------------

[4] 2D Cross Product — Collinearity Check (LeetCode 1037)
    Given 3 points: p1(x1,y1), p2(x2,y2), p3(x3,y3)
    Build vectors from p1:
        v1 = p2 - p1 = (x2-x1, y2-y1)
        v2 = p3 - p1 = (x3-x1, y3-y1)

    Cross product: v1 × v2 = (x2-x1)*(y3-y1) - (x3-x1)*(y2-y1)

    = 0   → collinear (same line)
    ≠ 0   → form a triangle

    Code: return (x2-x1)*(y3-y1) != (x3-x1)*(y2-y1);
