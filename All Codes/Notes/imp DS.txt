2. Matrix Reshaping (index mapping)
   - c = num of cols in new matrix, n = num of cols in old matrix
   - Formula: ans[i / c][i % c] = mat[i / n][i % n]

   for (int i = 0; i < m * n; i++)
       ans[i / c][i % c] = mat[i / n][i % n];

3. reverse_iterator::base()
   - Converts a reverse_iterator to its underlying forward iterator.
   - find(...rbegin(), rend(), val) returns a reverse_iterator.
   - You can't subtract a reverse_iterator from a forward iterator directly — different types.
   - .base() gives you the equivalent forward iterator so you can do arithmetic on it.

4. Erase-Remove Idiom
   - Standard C++ way to delete all occurrences of a value from a vector.

   vec.erase(std::remove(vec.begin(), vec.end(), key), vec.end());

   - std::remove  : shifts non-matching elements to the front; returns iterator to start of "garbage". Does NOT shrink the vector.
   - vec.erase    : erases from that iterator to the end, actually shrinking the vector.

5. std::map::operator[]
   - If the key does NOT exist, operator[] inserts it with a default value (0 for int) and returns a reference to it.
   - Side effect: mp[key] on a missing key silently adds {key, 0} to the map.
   - Prefer mp.find(key) to avoid unwanted insertions:

   auto it = mp.find(key);
   return it != mp.end() ? it->second : -1;

6. std::string::find(char, pos)
   - Searches for the first occurrence of a character starting at index pos.
   - Returns the index if found, or std::string::npos if not found.

   string email = "user+tag@example.com";
   size_t plus = email.find('+', 0);   // returns 4
   if (plus != string::npos) {
       local = email.substr(0, plus);  // local = "user"  (drops "+tag")
   }

   - The second argument (pos) is the start position; find('+') == find('+', 0).
   - npos is a sentinel value (usually SIZE_MAX) meaning "not found".

7. unordered_set::count(val)
   - Returns 1 if val exists in the set, 0 if it does not.
   - Since sets have no duplicates, it's always 0 or 1 — effectively a boolean existence check.
   - Equivalent to: occurrences.find(val) != occurrences.end()

   unordered_set<int> occurrences;
   if (occurrences.count(val)) { /* val exists */ }

8. vector (sort+unique) vs set for deduplication
   - Both are O(n log n), but vector is faster in practice.
   - set (red-black tree): nodes scattered in heap → pointer chasing → cache misses.
   - vector: contiguous memory → cache-friendly iteration and sort.
   - Also gives free indexed access: rank = i + 1 (no loop counter needed).

   // Preferred:
   sort(v.begin(), v.end());
   v.erase(unique(v.begin(), v.end()), v.end());

9. __builtin_popcount(n)
   - GCC built-in that counts the number of set bits (1s) in the binary representation of n.
   - O(1) — maps to a single hardware instruction (POPCNT) on modern CPUs.
   - Works on unsigned int; use __builtin_popcountll for long long.

   __builtin_popcount(7)        // 0b0111 → 3
   __builtin_popcount(8)        // 0b1000 → 1
   __builtin_popcountll(1LL << 40)  // 1

   - Common use: group/sort numbers by number of set bits (LC 1356).

   // Sort by bit count, break ties by value — single pass, in-place:
   sort(arr.begin(), arr.end(), [](int a, int b) {
       int ca = __builtin_popcount(a), cb = __builtin_popcount(b);
       return ca != cb ? ca < cb : a < b;
   });

10. lower_bound — count of elements smaller than x
    - lower_bound(begin, end, x) returns an iterator to the first element >= x in a sorted range.
    - Subtracting begin gives the index of that element = number of elements strictly less than x.

    vector<int> sorted = nums;
    sort(sorted.begin(), sorted.end());
    ans[i] = lower_bound(sorted.begin(), sorted.end(), nums[i]) - sorted.begin();

    - Use case: "how many numbers in the array are smaller than nums[i]?" (LC 1365)
      Sort a copy, then for each element binary-search its position in the sorted copy.
    - O(n log n) overall vs O(n²) brute force.
    - upper_bound gives the first element > x; use it to count elements <= x.

11. std::none_of / any_of / all_of
    - Range algorithms that test a predicate against every element; short-circuit on first match.
    - none_of : returns true if predicate is false for ALL elements.   TC: O(n) worst, O(1) best
    - any_of  : returns true if predicate is true for AT LEAST ONE element. TC: O(n) worst, O(1) best
    - all_of  : returns true if predicate is true for ALL elements.    TC: O(n) worst, O(1) best

    // LC 1385 — Approach 1: none_of  |  TC: O(n * m)
    if (none_of(arr2.begin(), arr2.end(), [&](int y) { return abs(x - y) <= d; }))
        cnt++;

    // LC 1385 — Approach 2: nested loops with manual break  |  TC: O(n * m)
    for (auto a2 : arr2)
        if (abs(a1 - a2) <= d) { res = false; break; }

    - Both approaches are O(n * m) worst case; early-stop makes best case O(n).
    - Replaces a bool flag + inner loop + break — reads exactly like the problem statement.

12. std::string::find(substr) — substring search
    - Searches for the first occurrence of substr appearing consecutively inside the string.
    - Returns the starting index if found, or string::npos if not found.
    - Matches the full substring, NOT just the first character.

    string s = "leetcoder";
    s.find("leet")  // → 0  (found at index 0)
    s.find("code")  // → 4  (found at index 4)
    s.find("leer")  // → string::npos  (not found)

    // Use case: check if words[i] is a substring of words[j] (LC 1408):
    if (words[j].find(words[i]) != string::npos)
        ans.push_back(words[i]);

    - find(substr, pos): optional second arg to start search from index pos.
    - TC: O(n * m) where n = s.size(), m = substr.size().

13. max / min  vs  max_element / min_element
    - max(a, b)            : compares two VALUES, returns the larger value.
    - max_element(beg,end) : scans a RANGE, returns an ITERATOR to the largest element.

    max(3, 7)                          // → 7
    *max_element(v.begin(), v.end())   // → largest value in vector  ✓

    // COMMON MISTAKE — passing iterators to max/min:
    *max(v.begin(), v.end())           // compares pointer addresses → returns end() → UB ✗

    - Always dereference max_element: *max_element(...).
    - Use min_element the same way for minimum.

14. Rounding double to n decimal places (inline)
    - You cannot return a formatted value from a function — double has no precision metadata.
    - To round the value itself before returning:

    return round(val * 1e5) / 1e5;   // 5 decimal places
    return round(val * 1e2) / 1e2;   // 2 decimal places

    - For output formatting at cout instead:
    cout << fixed << setprecision(5) << val;

15. vec.insert(vec.end(), count, value)
    - Appends 'value' exactly 'count' times to the end of the vector.

    res.insert(res.end(), f, x);   // inserts x repeated f times

    - Useful when building result vectors from frequency maps:
      for each (value x, frequency f), expand directly into result.
    - More concise than a manual for loop: for (int i = 0; i < f; i++) res.push_back(x);
