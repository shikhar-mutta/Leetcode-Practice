3. reverse_iterator::base()
   - Converts a reverse_iterator to its underlying forward iterator.
   - find(...rbegin(), rend(), val) returns a reverse_iterator.
   - You can't subtract a reverse_iterator from a forward iterator directly — different types.
   - .base() gives you the equivalent forward iterator so you can do arithmetic on it.

4. Erase-Remove Idiom
   - Standard C++ way to delete all occurrences of a value from a vector.

   vec.erase(std::remove(vec.begin(), vec.end(), key), vec.end());

   - std::remove  : shifts non-matching elements to the front; returns iterator to start of "garbage". Does NOT shrink the vector.
   - vec.erase    : erases from that iterator to the end, actually shrinking the vector.

5. std::map::operator[]
   - If the key does NOT exist, operator[] inserts it with a default value (0 for int) and returns a reference to it.
   - Side effect: mp[key] on a missing key silently adds {key, 0} to the map.
   - Prefer mp.find(key) to avoid unwanted insertions:

   auto it = mp.find(key);
   return it != mp.end() ? it->second : -1;

6. std::string::find(char, pos)
   - Searches for the first occurrence of a character starting at index pos.
   - Returns the index if found, or std::string::npos if not found.

   string email = "user+tag@example.com";
   size_t plus = email.find('+', 0);   // returns 4
   if (plus != string::npos) {
       local = email.substr(0, plus);  // local = "user"  (drops "+tag")
   }

   - The second argument (pos) is the start position; find('+') == find('+', 0).
   - npos is a sentinel value (usually SIZE_MAX) meaning "not found".

7. unordered_set::count(val)
   - Returns 1 if val exists in the set, 0 if it does not.
   - Since sets have no duplicates, it's always 0 or 1 — effectively a boolean existence check.
   - Equivalent to: occurrences.find(val) != occurrences.end()

   unordered_set<int> occurrences;
   if (occurrences.count(val)) { /* val exists */ }

8. vector (sort+unique) vs set for deduplication
   - Both are O(n log n), but vector is faster in practice.
   - set (red-black tree): nodes scattered in heap → pointer chasing → cache misses.
   - vector: contiguous memory → cache-friendly iteration and sort.
   - Also gives free indexed access: rank = i + 1 (no loop counter needed).

   // Preferred:
   sort(v.begin(), v.end());
   v.erase(unique(v.begin(), v.end()), v.end());

9. __builtin_popcount(n)
   - GCC built-in that counts the number of set bits (1s) in the binary representation of n.
   - O(1) — maps to a single hardware instruction (POPCNT) on modern CPUs.
   - Works on unsigned int; use __builtin_popcountll for long long.

   __builtin_popcount(7)        // 0b0111 → 3
   __builtin_popcount(8)        // 0b1000 → 1
   __builtin_popcountll(1LL << 40)  // 1

   - Common use: group/sort numbers by number of set bits (LC 1356).

   // Sort by bit count, break ties by value — single pass, in-place:
   sort(arr.begin(), arr.end(), [](int a, int b) {
       int ca = __builtin_popcount(a), cb = __builtin_popcount(b);
       return ca != cb ? ca < cb : a < b;
   });

10. lower_bound — count of elements smaller than x
    - lower_bound(begin, end, x) returns an iterator to the first element >= x in a sorted range.
    - Subtracting begin gives the index of that element = number of elements strictly less than x.

    vector<int> sorted = nums;
    sort(sorted.begin(), sorted.end());
    ans[i] = lower_bound(sorted.begin(), sorted.end(), nums[i]) - sorted.begin();

    - Use case: "how many numbers in the array are smaller than nums[i]?" (LC 1365)
      Sort a copy, then for each element binary-search its position in the sorted copy.
    - O(n log n) overall vs O(n²) brute force.
    - upper_bound gives the first element > x; use it to count elements <= x.

11. std::none_of / any_of / all_of
    - Range algorithms that test a predicate against every element; short-circuit on first match.
    - none_of : returns true if predicate is false for ALL elements.   TC: O(n) worst, O(1) best
    - any_of  : returns true if predicate is true for AT LEAST ONE element. TC: O(n) worst, O(1) best
    - all_of  : returns true if predicate is true for ALL elements.    TC: O(n) worst, O(1) best

    // LC 1385 — Approach 1: none_of  |  TC: O(n * m)
    if (none_of(arr2.begin(), arr2.end(), [&](int y) { return abs(x - y) <= d; }))
        cnt++;

    // LC 1385 — Approach 2: nested loops with manual break  |  TC: O(n * m)
    for (auto a2 : arr2)
        if (abs(a1 - a2) <= d) { res = false; break; }

    - Both approaches are O(n * m) worst case; early-stop makes best case O(n).
    - Replaces a bool flag + inner loop + break — reads exactly like the problem statement.

12. std::string::find(substr) — substring search
    - Searches for the first occurrence of substr appearing consecutively inside the string.
    - Returns the starting index if found, or string::npos if not found.
    - Matches the full substring, NOT just the first character.

    string s = "leetcoder";
    s.find("leet")  // → 0  (found at index 0)
    s.find("code")  // → 4  (found at index 4)
    s.find("leer")  // → string::npos  (not found)

    // Use case: check if words[i] is a substring of words[j] (LC 1408):
    if (words[j].find(words[i]) != string::npos)
        ans.push_back(words[i]);

    - find(substr, pos): optional second arg to start search from index pos.
    - TC: O(n * m) where n = s.size(), m = substr.size().

13. max / min  vs  max_element / min_element
    - max(a, b)            : compares two VALUES, returns the larger value.
    - max_element(beg,end) : scans a RANGE, returns an ITERATOR to the largest element.

    max(3, 7)                          // → 7
    *max_element(v.begin(), v.end())   // → largest value in vector  ✓

    // COMMON MISTAKE — passing iterators to max/min:
    *max(v.begin(), v.end())           // compares pointer addresses → returns end() → UB ✗

    - Always dereference max_element: *max_element(...).
    - Use min_element the same way for minimum.

14. Rounding double to n decimal places (inline)

16. priority_queue tie-breaking with -index
    - {val, i} max-heap: for equal values, LARGER index wins (lexicographic) — breaks original order.
    - Fix: store {val, -i}; larger -i = smaller original index = preferred among ties.

    // Two-heap pattern (LC 2099): top-k by value, restore original order  TC: O(n log n)
    priority_queue<pair<int,int>> maxheap;                                   // {value, -index}
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> minheap; // {index,  value}

    for (int i = 0; i < n; i++) maxheap.push({nums[i], -i});
    for (int cnt = 0; cnt < k; cnt++) {
        minheap.push({-maxheap.top().second, maxheap.top().first});
        maxheap.pop();
    }
    while (!minheap.empty()) { ans.push_back(minheap.top().second); minheap.pop(); }

17. Lambda Function (C++)
    auto funcName = [capture](params) { body; };

    - [&]  : capture all local variables by reference
    - [=]  : capture all by value
    - [&x] : capture only x by reference
    - []   : capture nothing

    Example — rotate matrix 90° clockwise:
        auto rotate90 = [&](vector<vector<int>> &m) {
            vector<vector<int>> tmp(n, vector<int>(n));
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                    tmp[j][n - 1 - i] = m[i][j];
            m = tmp;
        };
        rotate90(cur);  // called like a normal function

    - Defined inline inside a function; can close over local variables (e.g. n above)
    - Useful for short, one-off helpers scoped to the enclosing function

    Benefits:
    - Inline helper: no need to write a separate function for small logic.
    - Captures local vars: use n, grid, vis etc. directly via [&], no extra params.
    - Custom comparator: clean sorting with sort(v.begin(), v.end(), [](auto& a, auto& b){ ... });
    - Recursive DFS/BFS: use function<void(int)> dfs = [&](int u){ dfs(v); }; inline.

18. Prefix check via substr
    - word.substr(0, pref.size()) == pref checks if word starts with pref.
    - Extracts the first pref.size() characters of word and compares directly.

    // Count words starting with prefix (LC 2185):
    int prefixCount(vector<string>& words, string pref) {
        int cnt = 0;
        for (auto& word : words)
            if (word.substr(0, pref.size()) == pref) cnt++;
        return cnt;
    }

    - TC: O(n * m) where n = words.size(), m = pref.size().
    - Alternative: word.find(pref) == 0  (same cost, slightly less explicit).

19. Max array size in CP (256 MB memory limit, stack ~8 MB)

    | Type          | Bytes | Global/Static | Global Mem | Local (Stack 8MB) |
    |---------------|-------|---------------|------------|-------------------|
    | char          | 1     | 10^8          | 100 MB     | 10^6              |
    | int           | 4     | 10^7          |  40 MB     | 10^6              |
    | float         | 4     | 10^7          |  40 MB     | 10^6              |
    | long long     | 8     | 10^7          |  80 MB     | 10^6              |
    | double        | 8     | 10^7          |  80 MB     | 10^6              |
    | pair<int,int> | 8     | 10^7          |  80 MB     | 10^6              |
    Note: Local limits are theoretical max; in practice keep local arrays
          under 10^5 since stack is shared with function frames.

    256 MB = CP judge memory limit (not hardware). Exceed it → MLE.
             Most problems: 256 MB default; some: 64/512 MB — always check.

    Quick rule:
    - int global       → safe up to 10^7  (conservative; actual ~6 × 10^7)
    - long long global → safe up to 10^7  (conservative; actual ~3 × 10^7)
    - Always declare large arrays globally, never locally.

20. Early Stopping (very important for optimized code)
    - Break as soon as result is determined — don't waste iterations.
    - Saves time when best/worst case is decided before loop ends.
    - If remaining elements can't change the answer → break immediately.
    - Turns O(n) inner work into O(1) best case on already-decided iterations.
    - Example: count + (m - j - 1) <= best → remaining 1s can't beat best → break.
    - any_of / none_of / all_of use early stopping internally — prefer them when possible.

21. std::bitset<N>
    - Fixed-size sequence of N bits. N must be a compile-time constant.
    - Memory: N/8 bytes. 1000 bits = 125 bytes vs 1000 ints = 4000 bytes.
    - All operations below are O(N/64) — word-level parallel, very fast.

    Declaration:
        bitset<101> bs;           // all bits 0 by default
        bitset<8>   bs("10110");  // from binary string → 00010110

    ── Single bit operations ──────────────────────────────────
        bs.set(3)       // 00001000  — set bit 3 to 1
        bs.reset(3)     // 00000000  — set bit 3 to 0
        bs.flip(2)      // 00000100  — toggle bit 2
        bs.test(3)      // → true    — bounds-checked read (throws if out of range)
        bs[3]           // → true    — unchecked read, prefer in loops

    ── Whole-bitset operations ────────────────────────────────
        bs.set()        // 11111111  — set ALL bits to 1
        bs.reset()      // 00000000  — set ALL bits to 0
        bs.flip()       // toggle ALL bits

    ── Query functions ────────────────────────────────────────
        // bitset<4> bs("1010");
        bs.count()      // → 2      — number of set bits (use instead of counting loop)
        bs.size()       // → 4      — total bits (always N)
        bs.any()        // → true   — at least one bit is 1
        bs.none()       // → false  — true only if all bits are 0
        bs.all()        // → false  — true only if all bits are 1

    ── Bitwise operators ──────────────────────────────────────
        // bitset<4> a("1100"), b("1010");
        a & b           // → 1000  — AND
        a | b           // → 1110  — OR
        a ^ b           // → 0110  — XOR
        ~a              // → 0011  — NOT (flip all)
        a << 1          // → 1000  — left shift
        a >> 1          // → 0110  — right shift

    ── Conversion ────────────────────────────────────────────
        bs.to_string()  // → "1010"  — binary string, MSB first
        bs.to_ulong()   // → unsigned long  (throws if bits exceed 32)
        bs.to_ullong()  // → unsigned long long

        // int → bitset: pass integer to constructor
        bitset<8> bs(13);           // 13 = 0b00001101 → "00001101"

        // bitset → int:
        int x = (int)bs.to_ulong(); // → 13
        long long y = bs.to_ullong(); // for large values

        // Re-assign from int (constructor required — direct = not allowed):
        bs = bitset<8>(42);         // ✓  re-construct
        // bs = 42;                 // ✗  does not compile

    ── No range-set ──────────────────────────────────────────
        // No bs.set(l, r) — use difference array for multiple intervals:
        int diff[N+2] = {};
        for (auto& seg : segs) { diff[seg[0]]++; diff[seg[1]+1]--; }
        int cur = 0;
        for (int i = 0; i < N; i++) { cur += diff[i]; bs[i] = cur > 0; }

    ── Common use cases ──────────────────────────────────────
        // Count distinct covered points (LC 2848):
        bitset<101> bs;
        for (auto& s : nums) for (int i = s[0]; i <= s[1]; i++) bs[i] = 1;
        return (int)bs.count();

        // 0/1 knapsack reachability — O(N * capacity / 64):
        bitset<100001> dp; dp[0] = 1;
        for (int x : nums) dp |= dp << x;

22. std::count_if
    - Counts elements in a range for which a predicate returns true.
    - TC: O(n) — single pass, no early stopping.
    - Returns ptrdiff_t (signed) → cast to int when assigning to int.

    count_if(begin, end, predicate)

    // Count even numbers:
    count_if(v.begin(), v.end(), [](int x){ return x % 2 == 0; });

    // Count nums1 elements that exist in a set (LC 2956):
    (int)count_if(nums1.begin(), nums1.end(), [&](int x){ return s2.count(x); });

    - Cleaner than a manual loop with a counter variable.
    - Use when you need a count; use any_of/none_of when you only need a bool.

23. pair<int,int> comparison (lexicographic)
    - C++ compares pairs lexicographically by default:
      (a1, a2) > (b1, b2)  →  a1 > b1, OR (a1 == b1 AND a2 > b2)

    // Example:
    pair<int,int> a = {2, 1}, b = {2, 0};
    a > b   // → true  (values tie at 2, index 1 > 0)
    a < b   // → false

    - Use case: sorting/bubbling {value, original_index} pairs where ties in
      value should be broken by smaller index coming first.

    // Bubble-up after multiplying minimum in sorted array (LC 3264):
    while (j + 1 < n && temp[j] > temp[j + 1])   // ✓ correct: handles tie-break
        swap(temp[j], temp[j + 1]), j++;

    // WRONG — only checks value, misses index tie-break:
    while (j + 1 < n && temp[j].first > temp[j + 1].first)   // ✗

    - Same rule applies to sort, priority_queue, min/max on pairs.
    - sort(v.begin(), v.end()) on vector<pair<int,int>> sorts by .first first,
      then .second — no custom comparator needed for this common case.

24. map → vector<pair<int,int>> conversion
    - A map<K,V> can be directly converted to vector<pair<K,V>> via range constructor.

    map<int,int> freq;
    vector<pair<int,int>> v(freq.begin(), freq.end());

    - Copies all {key, value} entries into the vector in ascending key order (map is sorted).
    - Use when you need to sort entries by value (or custom criterion) — map doesn't support that directly.

    // Sort by frequency desc, break ties by value desc (LC 3318 x-sum pattern):
    sort(v.begin(), v.end(), [](auto& a, auto& b) {
        return a.second != b.second ? a.second > b.second : a.first > b.first;
    });

    // Then take top-x entries:
    for (int i = 0; i < min(x, (int)v.size()); i++)
        sum += v[i].first * v[i].second;

    - TC: O(n) for conversion + O(n log n) for sort.
    - Alternative for unordered_map: same syntax works — but iteration order is arbitrary,
      so the resulting vector won't be key-sorted (doesn't matter if you sort afterwards).

25. std::binary_search / lower_bound / upper_bound — cheat sheet

    REQUIRES sorted range. All are O(log n).

    ┌─────────────────────────────────────────────────────────────────┐
    │ Function          │ Returns  │ Meaning                          │
    ├─────────────────────────────────────────────────────────────────┤
    │ binary_search     │ bool     │ does val exist in range?         │
    │ lower_bound       │ iterator │ first element >= val             │
    │ upper_bound       │ iterator │ first element >  val             │
    └─────────────────────────────────────────────────────────────────┘

    binary_search(v.begin(), v.end(), x)         // true if x exists
    lower_bound(v.begin(), v.end(), x)           // ptr to first >= x
    upper_bound(v.begin(), v.end(), x)           // ptr to first >  x

    ── Derived queries (index = iterator - begin) ────────────────────
    lower_bound(..., x) - v.begin()              // count of elements < x
    upper_bound(..., x) - v.begin()              // count of elements <= x
    upper_bound(...,x) - lower_bound(...,x)      // count of elements == x

    ── Custom comparator ─────────────────────────────────────────────
    // Works the same for all three; comp must be consistent with sort order
    binary_search(v.begin(), v.end(), x, cmp);
    lower_bound(v.begin(), v.end(), x, cmp);

    ── Common mistake ────────────────────────────────────────────────
    // binary_search on UNSORTED vector → undefined behavior, wrong answers
    // Always sort first, or use an unordered_set for O(1) lookup instead:
    unordered_set<int> s(v.begin(), v.end());
    if (s.count(x)) { ... }   // O(1) avg, no sort needed

26. stringstream — split sentence into words
    - Treats a string like an input stream; >> reads one whitespace-delimited token at a time.
    - Cleanest way to split a sentence into words without manually scanning for spaces.

    string sentence = "dog cat cat dog";
    stringstream ss(sentence);
    string w;
    vector<string> words;
    while (ss >> w) words.push_back(w);
    // words = ["dog", "cat", "cat", "dog"]

    - ss >> w returns false at end of stream → loop exits automatically.
    - Handles multiple spaces between words (like cin >> skips all whitespace).
    - Use case: word-pattern matching, anagram checks, any problem where input
      is a space-separated list of words inside a string.

27. Bit Masking & Arithmetic Right Shift

    num & 0xf    // extract lowest 4 bits (0..15) — one hex digit
    num >>= 4    // shift right by 4, expose next group

    signed >> k  → arithmetic shift: fills top with sign bit (negative stays negative forever)
    unsigned >> k → logical shift: fills top with 0s

    Negative nums (two's complement): -1 = 0xFFFFFFFF, so & 0xf extracts correctly.
    But -1 >> 4 = -1 (never reaches 0) → ALWAYS cap with res.size() < 8 guard.
