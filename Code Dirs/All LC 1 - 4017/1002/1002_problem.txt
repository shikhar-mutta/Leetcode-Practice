 1002. Find Common Characters
 Easy  |  Tags: Array, Hash Table, String
 https://leetcode.com/problems/find-common-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string array words, return an array of all characters that show
  up in all strings within the words (including duplicates). You may
  return the answer in any order.

CONSTRAINTS
  1 <= words.length <= 100
  1 <= words[i].length <= 100
  words[i] consists of lowercase English letters.

TEST CASES
  [1] Input    : words = ["bella","label","roller"]
      Expected : ["e","l","l"]

  [2] Input    : words = ["cool","lock","cook"]
      Expected : ["c","o"]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<string> commonChars(vector<string>& words);

FILES
  edit : 1002.cpp
  test : lc run 1002
