 1003. Check If Word Is Valid After Substitutions
 Medium  |  Tags: String, Stack
 https://leetcode.com/problems/check-if-word-is-valid-after-substitutions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, determine if it is valid.

  A string s is valid if, starting with an empty string t = "", you can
  transform t into s after performing the following operation any number
  of times:

  - Insert string "abc" into any position in t. More formally, t becomes
    tleft + "abc" + tright, where t == tleft + tright. Note that tleft and
    tright may be empty.

  Return true if s is a valid string, otherwise, return false.

CONSTRAINTS
  1 <= s.length <= 2 * 10^4
  s consists of letters 'a', 'b', and 'c'

TEST CASES
  [1] Input    : s = "aabcbc"
      Expected : true
      Why      : "" -> "abc" -> "aabcbc"
                 Thus, "aabcbc" is valid.

  [2] Input    : s = "abcabcababcc"
      Expected : true
      Why      : "" -> "abc" -> "abcabc" -> "abcabcabc" -> "abcabcababcc"
                 Thus, "abcabcababcc" is valid.

  [3] Input    : s = "abccba"
      Expected : false
      Why      : It is impossible to get "abccba" using the operation.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isValid(string s);
