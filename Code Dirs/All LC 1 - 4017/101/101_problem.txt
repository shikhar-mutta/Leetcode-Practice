 101. Symmetric Tree
 Easy  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/symmetric-tree/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, check whether it is a mirror of itself
  (i.e., symmetric around its center).

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 1000].
  -100 <= Node.val <= 100

TEST CASES
  [1] Input    : root = [1,2,2,3,4,4,3]
      Expected : true

  [2] Input    : root = [1,2,2,null,3,null,3]
      Expected : false

FOLLOW UP
  Could you solve it both recursively and iteratively?

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  bool isSymmetric(TreeNode* root);

FILES
  edit : 101.cpp
  test : lc run 101
