 1013. Partition Array Into Three Parts With Equal Sum
 Easy  |  Tags: Array, Greedy
 https://leetcode.com/problems/partition-array-into-three-parts-with-equal-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers arr, return true if we can partition the
  array into three non-empty parts with equal sums.

  Formally, we can partition the array if we can find indexes i + 1 < j
  with (arr[0] + arr[1] + ... + arr[i] == arr[i + 1] + arr[i + 2] + ... +
  arr[j - 1] == arr[j] + arr[j + 1] + ... + arr[arr.length - 1])

CONSTRAINTS
  3 <= arr.length <= 5 * 10^4
  -10^4 <= arr[i] <= 10^4

TEST CASES
  [1] Input    : arr = [0,2,1,-6,6,-7,9,1,2,0,1]
      Expected : true
      Why      : 0 + 2 + 1 = -6 + 6 - 7 + 9 + 1 = 2 + 0 + 1

  [2] Input    : arr = [0,2,1,-6,6,7,9,-1,2,0,1]
      Expected : false

  [3] Input    : arr = [3,3,6,5,-2,2,5,1,-9,4]
      Expected : true
      Why      : 3 + 3 = 6 = 5 - 2 + 2 + 5 + 1 - 9 + 4

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canThreePartsEqualSum(vector<int>& arr);
