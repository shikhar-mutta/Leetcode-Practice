 1015. Smallest Integer Divisible by K
 Medium  |  Tags: Hash Table, Math, Pigeonhole Principle
 https://leetcode.com/problems/smallest-integer-divisible-by-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a positive integer k, you need to find the length of the smallest
  positive integer n such that n is divisible by k, and n only contains
  the digit 1.

  Return the length of n. If there is no such n, return -1.

  Note: n may not fit in a 64-bit signed integer.

CONSTRAINTS
  1 <= k <= 10^5

TEST CASES
  [1] Input    : k = 1
      Expected : 1
      Why      : The smallest answer is n = 1, which has length 1.

  [2] Input    : k = 2
      Expected : -1
      Why      : There is no such positive integer n divisible by 2.

  [3] Input    : k = 3
      Expected : 3
      Why      : The smallest answer is n = 111, which has length 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int smallestRepunitDivByK(int k);
