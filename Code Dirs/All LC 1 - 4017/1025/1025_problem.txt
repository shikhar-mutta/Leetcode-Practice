 1025. Divisor Game
 Easy  |  Tags: Math, Dynamic Programming, Brainteaser, Game Theory, Impartial Game
 https://leetcode.com/problems/divisor-game/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Alice and Bob take turns playing a game, with Alice starting first.

  Initially, there is a number n on the chalkboard. On each player's turn,
  that player makes a move consisting of:

  - Choosing any integer x with 0 < x < n and n % x == 0.

  - Replacing the number n on the chalkboard with n - x.

  Also, if a player cannot make a move, they lose the game.

  Return true if and only if Alice wins the game, assuming both players
  play optimally.

CONSTRAINTS
  1 <= n <= 1000

TEST CASES
  [1] Input    : n = 2
      Expected : true
      Why      : Alice chooses 1, and Bob has no more moves.

  [2] Input    : n = 3
      Expected : false
      Why      : Alice chooses 1, Bob chooses 1, and Alice has no more moves.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool divisorGame(int n);
