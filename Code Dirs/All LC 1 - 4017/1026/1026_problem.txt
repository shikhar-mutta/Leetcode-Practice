 1026. Maximum Difference Between Node and Ancestor
 Medium  |  Tags: Tree, Depth-First Search, Binary Tree
 https://leetcode.com/problems/maximum-difference-between-node-and-ancestor/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, find the maximum value v for which
  there exist different nodes a and b where v = |a.val - b.val| and a is
  an ancestor of b.

  A node a is an ancestor of b if either: any child of a is equal to b or
  any child of a is an ancestor of b.

CONSTRAINTS
  The number of nodes in the tree is in the range [2, 5000].
  0 <= Node.val <= 10^5

TEST CASES
  [1] Input    : root = [8,3,10,1,6,null,14,null,null,4,7,13]
      Expected : 7
      Why      : We have various ancestor-node differences, some of which are given below :
                 |8 - 3| = 5
                 |3 - 7| = 4
                 … (3 more)

  [2] Input    : root = [1,null,2,null,0,3]
      Expected : 3

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int maxAncestorDiff(TreeNode* root);
