 1027. Longest Arithmetic Subsequence
 Medium  |  Tags: Array, Hash Table, Binary Search, Dynamic Programming
 https://leetcode.com/problems/longest-arithmetic-subsequence/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array nums of integers, return the length of the longest
  arithmetic subsequence in nums.

  Note that:

  - A subsequence is an array that can be derived from another array by
    deleting some or no elements without changing the order of the
    remaining elements.

  - A sequence seq is arithmetic if seq[i + 1] - seq[i] are all the same
    value (for 0 <= i < seq.length - 1).

CONSTRAINTS
  2 <= nums.length <= 1000
  0 <= nums[i] <= 500

TEST CASES
  [1] Input    : nums = [3,6,9,12]
      Expected : 4
      Why      : The whole array is an arithmetic sequence with steps of length = 3.

  [2] Input    : nums = [9,4,7,2,10]
      Expected : 3
      Why      : The longest arithmetic subsequence is [4,7,10].

  [3] Input    : nums = [20,1,15,3,10,5,8]
      Expected : 4
      Why      : The longest arithmetic subsequence is [20,15,10,5].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestArithSeqLength(vector<int>& nums);
