 1042. Flower Planting With No Adjacent
 Medium  |  Tags: Depth-First Search, Breadth-First Search, Graph Theory, Graph Coloring
 https://leetcode.com/problems/flower-planting-with-no-adjacent/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You have n gardens, labeled from 1 to n, and an array paths where
  paths[i] = [xi, yi] describes a bidirectional path between garden xi to
  garden yi. In each garden, you want to plant one of 4 types of flowers.

  All gardens have at most 3 paths coming into or leaving it.

  Your task is to choose a flower type for each garden such that, for any
  two gardens connected by a path, they have different types of flowers.

  Return any such a choice as an array answer, where answer[i] is the type
  of flower planted in the (i+1)^th garden. The flower types are denoted
  1, 2, 3, or 4. It is guaranteed an answer exists.

CONSTRAINTS
  1 <= n <= 10^4
  0 <= paths.length <= 2 * 10^4
  paths[i].length == 2
  1 <= xi, yi <= n
  xi != yi
  Every garden has at most 3 paths coming into or leaving it.

TEST CASES
  [1] Input    : n = 3, paths = [[1,2],[2,3],[3,1]]
      Expected : [1,2,3]
      Why      : Gardens 1 and 2 have different types.
                 Gardens 2 and 3 have different types.
                 Gardens 3 and 1 have different types.
                 … (1 more)

  [2] Input    : n = 4, paths = [[1,2],[3,4]]
      Expected : [1,2,1,2]

  [3] Input    : n = 4, paths = [[1,2],[2,3],[3,4],[4,1],[1,3],[2,4]]
      Expected : [1,2,3,4]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> gardenNoAdj(int n, vector<vector<int>>& paths);
