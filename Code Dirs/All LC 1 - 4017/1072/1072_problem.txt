 1072. Flip Columns For Maximum Number of Equal Rows
 Medium  |  Tags: Array, Hash Table, Matrix
 https://leetcode.com/problems/flip-columns-for-maximum-number-of-equal-rows/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an m x n binary matrix matrix.

  You can choose any number of columns in the matrix and flip every cell
  in that column (i.e., Change the value of the cell from 0 to 1 or vice
  versa).

  Return the maximum number of rows that have all values equal after some
  number of flips.

CONSTRAINTS
  m == matrix.length
  n == matrix[i].length
  1 <= m, n <= 300
  matrix[i][j] is either 0 or 1.

TEST CASES
  [1] Input    : matrix = [[0,1],[1,1]]
      Expected : 1
      Why      : After flipping no values, 1 row has all values equal.

  [2] Input    : matrix = [[0,1],[1,0]]
      Expected : 2
      Why      : After flipping values in the first column, both rows have equal values.

  [3] Input    : matrix = [[0,0,0],[0,0,1],[1,1,0]]
      Expected : 2
      Why      : After flipping values in the first two columns, the last two rows have equal values.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxEqualRowsAfterFlips(vector<vector<int>>& matrix);
