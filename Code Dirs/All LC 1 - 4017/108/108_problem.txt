 108. Convert Sorted Array to Binary Search Tree
 Easy  |  Tags: Array, Divide and Conquer, Tree, Binary Search Tree, Binary Tree
 https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums where the elements are sorted in ascending
  order, convert it to a height-balanced binary search tree.

CONSTRAINTS
  1 <= nums.length <= 10^4
  -10^4 <= nums[i] <= 10^4
  nums is sorted in a strictly increasing order.

TEST CASES
  [1] Input    : nums = [-10,-3,0,5,9]
      Expected : [0,-3,9,-10,null,5]
      Why      : [0,-10,5,null,-3,null,9] is also accepted:

  [2] Input    : nums = [1,3]
      Expected : [3,1]
      Why      : [1,null,3] and [3,1] are both height-balanced BSTs.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  TreeNode* sortedArrayToBST(vector<int>& nums);
