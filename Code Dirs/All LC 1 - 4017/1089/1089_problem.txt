 1089. Duplicate Zeros
 Easy  |  Tags: Array, Two Pointers
 https://leetcode.com/problems/duplicate-zeros/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a fixed-length integer array arr, duplicate each occurrence of
  zero, shifting the remaining elements to the right.

  Note that elements beyond the length of the original array are not
  written. Do the above modifications to the input array in place and do
  not return anything.

CONSTRAINTS
  1 <= arr.length <= 10^4
  0 <= arr[i] <= 9

TEST CASES
  [1] Input    : arr = [1,0,2,3,0,4,5,0]
      Expected : [1,0,0,2,3,0,0,4]
      Why      : After calling your function, the input array is modified to: [1,0,0,2,3,0,0,4]

  [2] Input    : arr = [1,2,3]
      Expected : [1,2,3]
      Why      : After calling your function, the input array is modified to: [1,2,3]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  void duplicateZeros(vector<int>& arr);
