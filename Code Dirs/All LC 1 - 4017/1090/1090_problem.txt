 1090. Largest Values From Labels
 Medium  |  Tags: Array, Hash Table, Greedy, Sorting, Counting
 https://leetcode.com/problems/largest-values-from-labels/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given n item's value and label as two integer arrays values and
  labels. You are also given two integers numWanted and useLimit.

  Your task is to find a subset of items with the maximum sum of their
  values such that:

  - The number of items is at most numWanted.

  - The number of items with the same label is at most useLimit.

  Return the maximum sum.

CONSTRAINTS
  n == values.length == labels.length
  1 <= n <= 2 * 10^4
  0 <= values[i], labels[i] <= 2 * 10^4
  1 <= numWanted, useLimit <= n

TEST CASES
  [1] Input    : values = [5,4,3,2,1], labels = [1,1,2,2,3], numWanted = 3, useLimit = 1
      Expected : 9
      Why      : The subset chosen is the first, third, and fifth items with the sum of values 5 + 3 + 1.

  [2] Input    : values = [5,4,3,2,1], labels = [1,3,3,3,2], numWanted = 3, useLimit = 2
      Expected : 12
      Why      : The subset chosen is the first, second, and third items with the sum of values 5 + 4 + 3.

  [3] Input    : values = [9,8,8,7,6], labels = [0,0,0,1,1], numWanted = 3, useLimit = 1
      Expected : 16
      Why      : The subset chosen is the first and fourth items with the sum of values 9 + 7.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestValsFromLabels(vector<int>& values, vector<int>& labels, int numWanted, int useLimit);
