 112. Path Sum
 Easy  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/path-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree and an integer targetSum, return true if
  the tree has a root-to-leaf path such that adding up all the values
  along the path equals targetSum.

  A leaf is a node with no children.

CONSTRAINTS
  The number of nodes in the tree is in the range [0, 5000].
  -1000 <= Node.val <= 1000
  -1000 <= targetSum <= 1000

TEST CASES
  [1] Input    : root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22
      Expected : true
      Why      : The root-to-leaf path with the target sum is shown.

  [2] Input    : root = [1,2,3], targetSum = 5
      Expected : false
      Why      : There are two root-to-leaf paths in the tree:
                 (1 --> 2): The sum is 3.
                 (1 --> 3): The sum is 4.
                 … (1 more)

  [3] Input    : root = [], targetSum = 0
      Expected : false
      Why      : Since the tree is empty, there are no root-to-leaf paths.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  bool hasPathSum(TreeNode* root, int targetSum);
