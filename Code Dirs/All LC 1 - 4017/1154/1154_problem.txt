 1154. Day of the Year
 Easy  |  Tags: Math, String
 https://leetcode.com/problems/day-of-the-year/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string date representing a Gregorian calendar date formatted as
  YYYY-MM-DD, return the day number of the year.

CONSTRAINTS
  date.length == 10
  date[4] == date[7] == '-', and all other date[i]'s are digits
  date represents a calendar date between Jan 1^st, 1900 and Dec 31^st, 2019.

TEST CASES
  [1] Input    : date = "2019-01-09"
      Expected : 9
      Why      : Given date is the 9th day of the year in 2019.

  [2] Input    : date = "2019-02-10"
      Expected : 41

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int dayOfYear(string date);

FILES
  edit : 1154.cpp
  test : lc run 1154
