 1163. Last Substring in Lexicographical Order
 Hard  |  Tags: Two Pointers, String, Lyndon Factorization
 https://leetcode.com/problems/last-substring-in-lexicographical-order/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, return the last substring of s in lexicographical
  order.

CONSTRAINTS
  1 <= s.length <= 4 * 10^5
  s contains only lowercase English letters.

TEST CASES
  [1] Input    : s = "abab"
      Expected : "bab"
      Why      : The substrings are ["a", "ab", "aba", "abab", "b", "ba", "bab"]. The lexicographically maximum substring is "bab".

  [2] Input    : s = "leetcode"
      Expected : "tcode"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string lastSubstring(string s);
