 1185. Day of the Week
 Easy  |  Tags: Math
 https://leetcode.com/problems/day-of-the-week/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a date, return the corresponding day of the week for that date.

  The input is given as three integers representing the day, month and
  year respectively.

  Return the answer as one of the following values {"Sunday", "Monday",
  "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"}.

  Note: January 1, 1971 was a Friday.

CONSTRAINTS
  The given dates are valid dates between the years 1971 and 2100.

TEST CASES
  [1] Input    : day = 31, month = 8, year = 2019
      Expected : "Saturday"

  [2] Input    : day = 18, month = 7, year = 1999
      Expected : "Sunday"

  [3] Input    : day = 15, month = 8, year = 1993
      Expected : "Sunday"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string dayOfTheWeek(int day, int month, int year);
