 1191. K-Concatenation Maximum Sum
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/k-concatenation-maximum-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array arr and an integer k, modify the array by
  repeating it k times.

  For example, if arr = [1, 2] and k = 3 then the modified array will be
  [1, 2, 1, 2, 1, 2].

  Return the maximum sub-array sum in the modified array. Note that the
  length of the sub-array can be 0 and its sum in that case is 0.

  As the answer can be very large, return the answer modulo 10^9 + 7.

CONSTRAINTS
  1 <= arr.length <= 10^5
  1 <= k <= 10^5
  -10^4 <= arr[i] <= 10^4

TEST CASES
  [1] Input    : arr = [1,2], k = 3
      Expected : 9

  [2] Input    : arr = [1,-2,1], k = 5
      Expected : 2

  [3] Input    : arr = [-1,-2], k = 7
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int kConcatenationMaxSum(vector<int>& arr, int k);
