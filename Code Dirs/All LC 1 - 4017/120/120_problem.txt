 120. Triangle
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/triangle/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a triangle array, return the minimum path sum from top to bottom.

  For each step, you may move to an adjacent number of the row below. More
  formally, if you are on index i on the current row, you may move to
  either index i or index i + 1 on the next row.

CONSTRAINTS
  1 <= triangle.length <= 200
  triangle[0].length == 1
  triangle[i].length == triangle[i - 1].length + 1
  -10^4 <= triangle[i][j] <= 10^4

TEST CASES
  [1] Input    : triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
      Expected : 11
      Why      : The triangle looks like:
                 2
                 3 4
                 … (3 more)

  [2] Input    : triangle = [[-10]]
      Expected : -10

FOLLOW UP
  Could you do this using only O(n) extra space, where n is the total
  number of rows in the triangle?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumTotal(vector<vector<int>>& triangle);

FILES
  edit : 120.cpp
  test : lc run 120
