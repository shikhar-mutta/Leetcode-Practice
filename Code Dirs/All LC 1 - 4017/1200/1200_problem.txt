 1200. Minimum Absolute Difference
 Easy  |  Tags: Array, Sorting
 https://leetcode.com/problems/minimum-absolute-difference/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of distinct integers arr, find all pairs of elements with
  the minimum absolute difference of any two elements.

  Return a list of pairs in ascending order(with respect to pairs), each
  pair [a, b] follows

  - a, b are from arr

  - a < b

  - b - a equals to the minimum absolute difference of any two elements in
    arr

CONSTRAINTS
  2 <= arr.length <= 10^5
  -10^6 <= arr[i] <= 10^6

TEST CASES
  [1] Input    : arr = [4,2,1,3]
      Expected : [[1,2],[2,3],[3,4]]
      Why      : The minimum absolute difference is 1. List all pairs with difference equal to 1 in ascending order.

  [2] Input    : arr = [1,3,6,10,15]
      Expected : [[1,3]]

  [3] Input    : arr = [3,8,-10,23,19,-4,-14,27]
      Expected : [[-14,-10],[19,23],[23,27]]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> minimumAbsDifference(vector<int>& arr);

FILES
