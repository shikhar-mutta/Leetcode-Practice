 1201. Ugly Number III
 Medium  |  Tags: Math, Binary Search, Combinatorics, Number Theory, Least Common Multiple, Euclidean Algorithm, Greatest Common Divisor, Inclusion-Exclusion Principle
 https://leetcode.com/problems/ugly-number-iii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An ugly number is a positive integer that is divisible by a, b, or c.

  Given four integers n, a, b, and c, return the n^th ugly number.

CONSTRAINTS
  1 <= n, a, b, c <= 10^9
  1 <= a * b * c <= 10^18
  It is guaranteed that the result will be in range [1, 2 * 10^9].

TEST CASES
  [1] Input    : n = 3, a = 2, b = 3, c = 5
      Expected : 4
      Why      : The ugly numbers are 2, 3, 4, 5, 6, 8, 9, 10... The 3^rd is 4.

  [2] Input    : n = 4, a = 2, b = 3, c = 4
      Expected : 6
      Why      : The ugly numbers are 2, 3, 4, 6, 8, 9, 10, 12... The 4^th is 6.

  [3] Input    : n = 5, a = 2, b = 11, c = 13
      Expected : 10
      Why      : The ugly numbers are 2, 4, 6, 8, 10, 11, 12, 13... The 5^th is 10.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int nthUglyNumber(int n, int a, int b, int c);
