 1221. Split a String in Balanced Strings
 Easy  |  Tags: String, Greedy, Counting
 https://leetcode.com/problems/split-a-string-in-balanced-strings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Balanced strings are those that have an equal quantity of 'L' and 'R'
  characters.

  Given a balanced string s, split it into some number of substrings such
  that:

  - Each substring is balanced.

  Return the maximum number of balanced strings you can obtain.

CONSTRAINTS
  2 <= s.length <= 1000
  s[i] is either 'L' or 'R'.
  s is a balanced string.

TEST CASES
  [1] Input    : s = "RLRRLLRLRL"
      Expected : 4
      Why      : s can be split into "RL", "RRLL", "RL", "RL", each substring contains same number of 'L' and 'R'.

  [2] Input    : s = "RLRRRLLRLL"
      Expected : 2
      Why      : s can be split into "RL", "RRRLLRLL", each substring contains same number of 'L' and 'R'.
                 Note that s cannot be split into "RL", "RR", "RL", "LR", "LL", because the 2^nd and 5^th substrings are not balanced.

  [3] Input    : s = "LLLLRRRR"
      Expected : 1
      Why      : s can be split into "LLLLRRRR".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int balancedStringSplit(string s);
