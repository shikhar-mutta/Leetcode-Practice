 1227. Airplane Seat Assignment Probability
 Medium  |  Tags: Math, Dynamic Programming, Brainteaser, Probability and Statistics
 https://leetcode.com/problems/airplane-seat-assignment-probability/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  n passengers board an airplane with exactly n seats. The first passenger
  has lost the ticket and picks a seat randomly. But after that, the rest
  of the passengers will:

  - Take their own seat if it is still available, and

  - Pick other seats randomly when they find their seat occupied

  Return the probability that the n^th person gets his own seat.

CONSTRAINTS
  1 <= n <= 10^5

TEST CASES
  [1] Input    : n = 1
      Expected : 1.00000
      Why      : The first person can only get the first seat.

  [2] Input    : n = 2
      Expected : 0.50000
      Why      : The second person has a probability of 0.5 to get the second seat (when first person gets the first seat).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  double nthPersonGetsNthSeat(int n);

FILES
  edit : 1227.cpp
  test : lc run 1227
