 1240. Tiling a Rectangle with the Fewest Squares
 Hard  |  Tags: Backtracking
 https://leetcode.com/problems/tiling-a-rectangle-with-the-fewest-squares/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a rectangle of size n x m, return the minimum number of integer-
  sided squares that tile the rectangle.

CONSTRAINTS
  1 <= n, m <= 13

TEST CASES
  [1] Input    : n = 2, m = 3
      Expected : 3
      Why      : 3 squares are necessary to cover the rectangle.
                 2 (squares of 1x1)
                 1 (square of 2x2)

  [2] Input    : n = 5, m = 8
      Expected : 5

  [3] Input    : n = 11, m = 13
      Expected : 6

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int tilingRectangle(int n, int m);

  edit : 1240.cpp
