 1248. Count Number of Nice Subarrays
 Medium  |  Tags: Array, Hash Table, Math, Sliding Window, Prefix Sum
 https://leetcode.com/problems/count-number-of-nice-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers nums and an integer k. A continuous subarray
  is called nice if there are k odd numbers on it.

  Return the number of nice sub-arrays.

CONSTRAINTS
  1 <= nums.length <= 50000
  1 <= nums[i] <= 10^5
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [1,1,2,1,1], k = 3
      Expected : 2
      Why      : The only sub-arrays with 3 odd numbers are [1,1,2,1] and [1,2,1,1].

  [2] Input    : nums = [2,4,6], k = 1
      Expected : 0
      Why      : There are no odd numbers in the array.

  [3] Input    : nums = [2,2,2,1,2,2,1,2,2,2], k = 2
      Expected : 16

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfSubarrays(vector<int>& nums, int k);
