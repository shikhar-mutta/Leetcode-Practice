 1262. Greatest Sum Divisible by Three
 Medium  |  Tags: Array, Dynamic Programming, Greedy, Sorting
 https://leetcode.com/problems/greatest-sum-divisible-by-three/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the maximum possible sum of elements
  of the array such that it is divisible by three.

CONSTRAINTS
  1 <= nums.length <= 4 * 10^4
  1 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [3,6,5,1,8]
      Expected : 18
      Why      : Pick numbers 3, 6, 1 and 8 their sum is 18 (maximum sum divisible by 3).

  [2] Input    : nums = [4]
      Expected : 0
      Why      : Since 4 is not divisible by 3, do not pick any number.

  [3] Input    : nums = [1,2,3,4,4]
      Expected : 12
      Why      : Pick numbers 1, 3, 4 and 4 their sum is 12 (maximum sum divisible by 3).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSumDivThree(vector<int>& nums);
