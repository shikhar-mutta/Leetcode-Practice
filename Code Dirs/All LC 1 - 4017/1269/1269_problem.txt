 1269. Number of Ways to Stay in the Same Place After Some Steps
 Hard  |  Tags: Dynamic Programming
 https://leetcode.com/problems/number-of-ways-to-stay-in-the-same-place-after-some-steps/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You have a pointer at index 0 in an array of size arrLen. At each step,
  you can move 1 position to the left, 1 position to the right in the
  array, or stay in the same place (The pointer should not be placed
  outside the array at any time).

  Given two integers steps and arrLen, return the number of ways such that
  your pointer is still at index 0 after exactly steps steps. Since the
  answer may be too large, return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= steps <= 500
  1 <= arrLen <= 10^6

TEST CASES
  [1] Input    : steps = 3, arrLen = 2
      Expected : 4
      Why      : There are 4 differents ways to stay at index 0 after 3 steps.
                 Right, Left, Stay
                 Stay, Right, Left
                 … (2 more)

  [2] Input    : steps = 2, arrLen = 4
      Expected : 2
      Why      : There are 2 differents ways to stay at index 0 after 2 steps
                 Right, Left
                 Stay, Stay

  [3] Input    : steps = 4, arrLen = 2
      Expected : 8

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numWays(int steps, int arrLen);
