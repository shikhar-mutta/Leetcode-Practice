 1281. Subtract the Product and Sum of Digits of an Integer
 Easy  |  Tags: Math
 https://leetcode.com/problems/subtract-the-product-and-sum-of-digits-of-an-integer/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer number n, return the difference between the product of
  its digits and the sum of its digits.

CONSTRAINTS
  1 <= n <= 10^5

TEST CASES
  [1] Input    : n = 234
      Expected : 15
      Why      : Product of digits = 2 * 3 * 4 = 24
                 Sum of digits = 2 + 3 + 4 = 9
                 Result = 24 - 9 = 15

  [2] Input    : n = 4421
      Expected : 21
      Why      : Product of digits = 4 * 4 * 2 * 1 = 32
                 Sum of digits = 4 + 4 + 2 + 1 = 11
                 Result = 32 - 11 = 21

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int subtractProductAndSum(int n);
