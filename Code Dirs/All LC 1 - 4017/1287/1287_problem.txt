 1287. Element Appearing More Than 25% In Sorted Array
 Easy  |  Tags: Array
 https://leetcode.com/problems/element-appearing-more-than-25-in-sorted-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array sorted in non-decreasing order, there is exactly
  one integer in the array that occurs more than 25% of the time, return
  that integer.

CONSTRAINTS
  1 <= arr.length <= 10^4
  0 <= arr[i] <= 10^5

TEST CASES
  [1] Input    : arr = [1,2,2,6,6,6,6,7,10]
      Expected : 6

  [2] Input    : arr = [1,1]
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findSpecialInteger(vector<int>& arr);
