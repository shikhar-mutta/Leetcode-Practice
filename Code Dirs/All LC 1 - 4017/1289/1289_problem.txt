 1289. Minimum Falling Path Sum II
 Hard  |  Tags: Array, Dynamic Programming, Matrix
 https://leetcode.com/problems/minimum-falling-path-sum-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an n x n integer matrix grid, return the minimum sum of a falling
  path with non-zero shifts.

  A falling path with non-zero shifts is a choice of exactly one element
  from each row of grid such that no two elements chosen in adjacent rows
  are in the same column.

CONSTRAINTS
  n == grid.length == grid[i].length
  1 <= n <= 200
  -99 <= grid[i][j] <= 99

TEST CASES
  [1] Input    : grid = [[1,2,3],[4,5,6],[7,8,9]]
      Expected : 13
      Why      : The possible falling paths are:
                 [1,5,9], [1,5,7], [1,6,7], [1,6,8],
                 [2,4,8], [2,4,9], [2,6,7], [2,6,8],
                 … (2 more)

  [2] Input    : grid = [[7]]
      Expected : 7

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minFallingPathSum(vector<vector<int>>& grid);
