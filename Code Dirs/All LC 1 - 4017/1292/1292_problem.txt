 1292. Maximum Side Length of a Square with Sum Less than or Equal to Threshold
 Medium  |  Tags: Array, Binary Search, Matrix, Prefix Sum
 https://leetcode.com/problems/maximum-side-length-of-a-square-with-sum-less-than-or-equal-to-threshold/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a m x n matrix mat and an integer threshold, return the maximum
  side-length of a square with a sum less than or equal to threshold or
  return 0 if there is no such square.

CONSTRAINTS
  m == mat.length
  n == mat[i].length
  1 <= m, n <= 300
  0 <= mat[i][j] <= 10^4
  0 <= threshold <= 10^5

TEST CASES
  [1] Input    : mat = [[1,1,3,2,4,3,2],[1,1,3,2,4,3,2],[1,1,3,2,4,3,2]], threshold = 4
      Expected : 2
      Why      : The maximum side length of square with sum less than or equal to 4 is 2 as shown.

  [2] Input    : mat = [[2,2,2,2,2],[2,2,2,2,2],[2,2,2,2,2],[2,2,2,2,2],[2,2,2,2,2]], threshold = 1
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSideLength(vector<vector<int>>& mat, int threshold);
