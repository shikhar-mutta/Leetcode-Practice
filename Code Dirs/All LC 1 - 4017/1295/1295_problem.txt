 1295. Find Numbers with Even Number of Digits
 Easy  |  Tags: Array, Math
 https://leetcode.com/problems/find-numbers-with-even-number-of-digits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array nums of integers, return how many of them contain an even
  number of digits.

CONSTRAINTS
  1 <= nums.length <= 500
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [12,345,2,6,7896]
      Expected : 2
      Why      : 12 contains 2 digits (even number of digits).
                 345 contains 3 digits (odd number of digits).
                 2 contains 1 digit (odd number of digits).
                 … (3 more)

  [2] Input    : nums = [555,901,482,1771]
      Expected : 1
      Why      : Only 1771 contains an even number of digits.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findNumbers(vector<int>& nums);

FILES
  edit : 1295.cpp
  test : lc run 1295
