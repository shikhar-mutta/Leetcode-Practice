 1299. Replace Elements with Greatest Element on Right Side
 Easy  |  Tags: Array
 https://leetcode.com/problems/replace-elements-with-greatest-element-on-right-side/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array arr, replace every element in that array with the
  greatest element among the elements to its right, and replace the last
  element with -1.

  After doing so, return the array.

CONSTRAINTS
  1 <= arr.length <= 10^4
  1 <= arr[i] <= 10^5

TEST CASES
  [1] Input    : arr = [17,18,5,4,6,1]
      Expected : [18,6,6,6,1,-1]
      Why      : - index 0 --> the greatest element to the right of index 0 is index 1 (18).
                 - index 1 --> the greatest element to the right of index 1 is index 4 (6).
                 - index 2 --> the greatest element to the right of index 2 is index 4 (6).
                 … (3 more)

  [2] Input    : arr = [400]
      Expected : [-1]
      Why      : There are no elements to the right of index 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> replaceElements(vector<int>& arr);
