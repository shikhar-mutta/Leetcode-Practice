 1302. Deepest Leaves Sum
 Medium  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/deepest-leaves-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, return the sum of values of its deepest
  leaves.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 10^4].
  1 <= Node.val <= 100

TEST CASES
  [1] Input    : root = [1,2,3,4,5,null,6,7,null,null,null,null,8]
      Expected : 15

  [2] Input    : root = [6,7,8,2,7,1,3,9,null,1,4,null,null,null,5]
      Expected : 19

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int deepestLeavesSum(TreeNode* root);
