 1304. Find N Unique Integers Sum up to Zero
 Easy  |  Tags: Array, Math
 https://leetcode.com/problems/find-n-unique-integers-sum-up-to-zero/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, return any array containing n unique integers such
  that they add up to 0.

CONSTRAINTS
  1 <= n <= 1000

TEST CASES
  [1] Input    : n = 5
      Expected : [-7,-1,1,3,4]
      Why      : These arrays also are accepted [-5,-1,1,2,3] , [-3,-1,2,-2,4].

  [2] Input    : n = 3
      Expected : [-1,0,1]

  [3] Input    : n = 1
      Expected : [0]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> sumZero(int n);

FILES
  edit : 1304.cpp
  test : lc run 1304
