 1310. XOR Queries of a Subarray
 Medium  |  Tags: Array, Bit Manipulation, Prefix Sum
 https://leetcode.com/problems/xor-queries-of-a-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array arr of positive integers. You are also given the
  array queries where queries[i] = [lefti,righti].

  For each query i compute the XOR of elements from lefti to righti (that
  is, arr[lefti] XOR arr[lefti + 1] XOR ... XOR arr[righti] ).

  Return an array answer where answer[i] is the answer to the i^th query.

CONSTRAINTS
  1 <= arr.length, queries.length <= 3 * 10^4
  1 <= arr[i] <= 10^9
  queries[i].length == 2
  0 <= lefti <= righti < arr.length

TEST CASES
  [1] Input    : arr = [1,3,4,8], queries = [[0,1],[1,2],[0,3],[3,3]]
      Expected : [2,7,14,8]
      Why      : The binary representation of the elements in the array are:
                 1 = 0001
                 3 = 0011
                 … (7 more)

  [2] Input    : arr = [4,8,2,10], queries = [[2,3],[1,3],[0,0],[0,3]]
      Expected : [8,0,4,4]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> xorQueries(vector<int>& arr, vector<vector<int>>& queries);
