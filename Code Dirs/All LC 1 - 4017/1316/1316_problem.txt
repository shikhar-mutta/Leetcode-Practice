 1316. Distinct Echo Substrings
 Hard  |  Tags: String, Trie, Rolling Hash, Suffix Array, Hash Function, Suffix Automaton, Suffix Tree
 https://leetcode.com/problems/distinct-echo-substrings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Return the number of distinct non-empty substrings of text that can be
  written as the concatenation of some string with itself (i.e. it can be
  written as a + a where a is some string).

CONSTRAINTS
  1 <= text.length <= 2000
  text has only lowercase English letters.

TEST CASES
  [1] Input    : text = "abcabcabc"
      Expected : 3
      Why      : The 3 substrings are "abcabc", "bcabca" and "cabcab".

  [2] Input    : text = "leetcodeleetcode"
      Expected : 2
      Why      : The 2 substrings are "ee" and "leetcodeleetcode".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int distinctEchoSubstrings(string text);

FILES
  edit : 1316.cpp
  test : lc run 1316
