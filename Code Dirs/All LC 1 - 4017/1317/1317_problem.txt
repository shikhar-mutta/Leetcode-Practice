 1317. Convert Integer to the Sum of Two No-Zero Integers
 Easy  |  Tags: Math
 https://leetcode.com/problems/convert-integer-to-the-sum-of-two-no-zero-integers/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  No-Zero integer is a positive integer that does not contain any 0 in its
  decimal representation.

  Given an integer n, return a list of two integers [a, b] where:

  - a and b are No-Zero integers.

  - a + b = n

  The test cases are generated so that there is at least one valid
  solution. If there are many valid solutions, you can return any of them.

CONSTRAINTS
  2 <= n <= 10^4

TEST CASES
  [1] Input    : n = 2
      Expected : [1,1]
      Why      : Let a = 1 and b = 1.
                 Both a and b are no-zero integers, and a + b = 2 = n.

  [2] Input    : n = 11
      Expected : [2,9]
      Why      : Let a = 2 and b = 9.
                 Both a and b are no-zero integers, and a + b = 11 = n.
                 Note that there are other valid answers as [8, 3] that can be accepted.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> getNoZeroIntegers(int n);

FILES
  edit : 1317.cpp
