 1318. Minimum Flips to Make a OR b Equal to c
 Medium  |  Tags: Bit Manipulation
 https://leetcode.com/problems/minimum-flips-to-make-a-or-b-equal-to-c/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given 3 positives numbers a, b and c. Return the minimum flips required
  in some bits of a and b to make ( a OR b == c ). (bitwise OR operation).

  Flip operation consists of change any single bit 1 to 0 or change the
  bit 0 to 1 in their binary representation.

CONSTRAINTS
  1 <= a <= 10^9
  1 <= b <= 10^9
  1 <= c <= 10^9

TEST CASES
  [1] Input    : a = 2, b = 6, c = 5
      Expected : 3
      Why      : After flips a = 1 , b = 4 , c = 5 such that (a OR b == c)

  [2] Input    : a = 4, b = 2, c = 7
      Expected : 1

  [3] Input    : a = 1, b = 2, c = 3
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minFlips(int a, int b, int c);
