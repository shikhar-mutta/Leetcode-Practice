 1323. Maximum 69 Number
 Easy  |  Tags: Math, Greedy
 https://leetcode.com/problems/maximum-69-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer num consisting only of digits 6 and 9.

  Return the maximum number you can get by changing at most one digit (6
  becomes 9, and 9 becomes 6).

CONSTRAINTS
  1 <= num <= 10^4
  num consists of only 6 and 9 digits.

TEST CASES
  [1] Input    : num = 9669
      Expected : 9969
      Why      : Changing the first digit results in 6669.
                 Changing the second digit results in 9969.
                 Changing the third digit results in 9699.
                 … (2 more)

  [2] Input    : num = 9996
      Expected : 9999
      Why      : Changing the last digit 6 to 9 results in the maximum number.

  [3] Input    : num = 9999
      Expected : 9999
      Why      : It is better not to apply any change.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximum69Number (int num);
