 1330. Reverse Subarray To Maximize Array Value
 Hard  |  Tags: Array, Math, Greedy
 https://leetcode.com/problems/reverse-subarray-to-maximize-array-value/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. The value of this array is defined
  as the sum of |nums[i] - nums[i + 1]| for all 0 <= i < nums.length - 1.

  You are allowed to select any subarray of the given array and reverse
  it. You can perform this operation only once.

  Find maximum possible value of the final array.

CONSTRAINTS
  2 <= nums.length <= 3 * 10^4
  -10^5 <= nums[i] <= 10^5
  The answer is guaranteed to fit in a 32-bit integer.

TEST CASES
  [1] Input    : nums = [2,3,1,5,4]
      Expected : 10
      Why      : By reversing the subarray [3,1,5] the array becomes [2,5,1,3,4] whose value is 10.

  [2] Input    : nums = [2,4,9,24,2,1,10]
      Expected : 68

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxValueAfterReverse(vector<int>& nums);
