 1344. Angle Between Hands of a Clock
 Medium  |  Tags: Math
 https://leetcode.com/problems/angle-between-hands-of-a-clock/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two numbers, hour and minutes, return the smaller angle (in
  degrees) formed between the hour and the minute hand.

  Answers within 10^-5 of the actual value will be accepted as correct.

CONSTRAINTS
  1 <= hour <= 12
  0 <= minutes <= 59

TEST CASES
  [1] Input    : hour = 12, minutes = 30
      Expected : 165

  [2] Input    : hour = 3, minutes = 30
      Expected : 75

  [3] Input    : hour = 3, minutes = 15
      Expected : 7.5

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  double angleClock(int hour, int minutes);

FILES
  edit : 1344.cpp
  test : lc run 1344
