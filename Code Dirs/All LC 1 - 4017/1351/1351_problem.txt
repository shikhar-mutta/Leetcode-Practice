 1351. Count Negative Numbers in a Sorted Matrix
 Easy  |  Tags: Array, Binary Search, Matrix
 https://leetcode.com/problems/count-negative-numbers-in-a-sorted-matrix/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a m x n matrix grid which is sorted in non-increasing order both
  row-wise and column-wise, return the number of negative numbers in grid.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  1 <= m, n <= 100
  -100 <= grid[i][j] <= 100

TEST CASES
  [1] Input    : grid = [[4,3,2,-1],[3,2,1,-1],[1,1,-1,-2],[-1,-1,-2,-3]]
      Expected : 8
      Why      : There are 8 negatives number in the matrix.

  [2] Input    : grid = [[3,2],[1,0]]
      Expected : 0

FOLLOW UP
  Could you find an O(n + m) solution?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countNegatives(vector<vector<int>>& grid);
