 1354. Construct Target Array With Multiple Sums
 Hard  |  Tags: Array, Heap (Priority Queue)
 https://leetcode.com/problems/construct-target-array-with-multiple-sums/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array target of n integers. From a starting array arr
  consisting of n 1's, you may perform the following procedure :

  - let x be the sum of all elements currently in your array.

  - choose index i, such that 0 <= i < n and set the value of arr at index
    i to x.

  - You may repeat this procedure as many times as needed.

  Return true if it is possible to construct the target array from arr,
  otherwise, return false.

CONSTRAINTS
  n == target.length
  1 <= n <= 5 * 10^4
  1 <= target[i] <= 10^9

TEST CASES
  [1] Input    : target = [9,3,5]
      Expected : true
      Why      : Start with arr = [1, 1, 1]
                 [1, 1, 1], sum = 3 choose index 1
                 [1, 3, 1], sum = 5 choose index 2
                 … (2 more)

  [2] Input    : target = [1,1,1,2]
      Expected : false
      Why      : Impossible to create target array from [1,1,1,1].

  [3] Input    : target = [8,5]
      Expected : true

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isPossible(vector<int>& target);
