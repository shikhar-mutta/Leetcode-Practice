 1359. Count All Valid Pickup and Delivery Options
 Hard  |  Tags: Math, Dynamic Programming, Combinatorics
 https://leetcode.com/problems/count-all-valid-pickup-and-delivery-options/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given n orders, each order consists of a pickup and a delivery service.

  Count all valid pickup/delivery possible sequences such that delivery(i)
  is always after of pickup(i).

  Since the answer may be too large, return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= n <= 500

TEST CASES
  [1] Input    : n = 1
      Expected : 1
      Why      : Unique order (P1, D1), Delivery 1 always is after of Pickup 1.

  [2] Input    : n = 2
      Expected : 6
      Why      : All possible orders:
                 (P1,P2,D1,D2), (P1,P2,D2,D1), (P1,D1,P2,D2), (P2,P1,D1,D2), (P2,P1,D2,D1) and (P2,D2,P1,D1).
                 This is an invalid order (P1,D2,P2,D1) because Pickup 2 is after of Delivery 2.

  [3] Input    : n = 3
      Expected : 90

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countOrders(int n);
