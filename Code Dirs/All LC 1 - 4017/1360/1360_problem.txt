 1360. Number of Days Between Two Dates
 Easy  |  Tags: Math, String
 https://leetcode.com/problems/number-of-days-between-two-dates/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Write a program to count the number of days between two dates.

  The two dates are given as strings, their format is YYYY-MM-DD as shown
  in the examples.

CONSTRAINTS
  The given dates are valid dates between the years 1971 and 2100.

TEST CASES
  [1] Input    : date1 = "2019-06-29", date2 = "2019-06-30"
      Expected : 1

  [2] Input    : date1 = "2020-01-15", date2 = "2019-12-31"
      Expected : 15

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int daysBetweenDates(string date1, string date2);

FILES
  edit : 1360.cpp
  test : lc run 1360
