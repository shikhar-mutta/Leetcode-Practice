 1361. Validate Binary Tree Nodes
 Medium  |  Tags: Tree, Depth-First Search, Breadth-First Search, Union-Find, Graph Theory, Binary Tree
 https://leetcode.com/problems/validate-binary-tree-nodes/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You have n binary tree nodes numbered from 0 to n - 1 where node i has
  two children leftChild[i] and rightChild[i], return true if and only if
  all the given nodes form exactly one valid binary tree.

  If node i has no left child then leftChild[i] will equal -1, similarly
  for the right child.

  Note that the nodes have no values and that we only use the node numbers
  in this problem.

CONSTRAINTS
  n == leftChild.length == rightChild.length
  1 <= n <= 10^4
  -1 <= leftChild[i], rightChild[i] <= n - 1

TEST CASES
  [1] Input    : n = 4, leftChild = [1,-1,3,-1], rightChild = [2,-1,-1,-1]
      Expected : true

  [2] Input    : n = 4, leftChild = [1,-1,3,-1], rightChild = [2,3,-1,-1]
      Expected : false

  [3] Input    : n = 2, leftChild = [1,0], rightChild = [-1,-1]
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool validateBinaryTreeNodes(int n, vector<int>& leftChild, vector<int>& rightChild);
