 1362. Closest Divisors
 Medium  |  Tags: Math, Prime Factorization
 https://leetcode.com/problems/closest-divisors/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer num, find the closest two integers in absolute
  difference whose product equals num + 1 or num + 2.

  Return the two integers in any order.

CONSTRAINTS
  1 <= num <= 10^9

TEST CASES
  [1] Input    : num = 8
      Expected : [3,3]
      Why      : For num + 1 = 9, the closest divisors are 3 & 3, for num + 2 = 10, the closest divisors are 2 & 5, hence 3 & 3 is chosen.

  [2] Input    : num = 123
      Expected : [5,25]

  [3] Input    : num = 999
      Expected : [40,25]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> closestDivisors(int num);

FILES
  edit : 1362.cpp
  test : lc run 1362
