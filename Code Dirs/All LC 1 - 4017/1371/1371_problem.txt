 1371. Find the Longest Substring Containing Vowels in Even Counts
 Medium  |  Tags: Hash Table, String, Bit Manipulation, Prefix Sum
 https://leetcode.com/problems/find-the-longest-substring-containing-vowels-in-even-counts/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the string s, return the size of the longest substring containing
  each vowel an even number of times. That is, 'a', 'e', 'i', 'o', and 'u'
  must appear an even number of times.

CONSTRAINTS
  1 <= s.length <= 5 x 10^5
  s contains only lowercase English letters.

TEST CASES
  [1] Input    : s = "eleetminicoworoep"
      Expected : 13
      Why      : The longest substring is "leetminicowor" which contains two each of the vowels: e, i and o and zero of the vowels: a and u.

  [2] Input    : s = "leetcodeisgreat"
      Expected : 5
      Why      : The longest substring is "leetc" which contains two e's.

  [3] Input    : s = "bcbcbc"
      Expected : 6
      Why      : In this case, the given string "bcbcbc" is the longest because all vowels: a, e, i, o and u appear zero times.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findTheLongestSubstring(string s);
