 1380. Lucky Numbers in a Matrix
 Easy  |  Tags: Array, Matrix
 https://leetcode.com/problems/lucky-numbers-in-a-matrix/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an m x n matrix of distinct numbers, return all lucky numbers in
  the matrix in any order.

  A lucky number is an element of the matrix such that it is the minimum
  element in its row and maximum in its column.

CONSTRAINTS
  m == mat.length
  n == mat[i].length
  1 <= n, m <= 50
  1 <= matrix[i][j] <= 10^5.
  All elements in the matrix are distinct.

TEST CASES
  [1] Input    : matrix = [[3,7,8],[9,11,13],[15,16,17]]
      Expected : [15]
      Why      : 15 is the only lucky number since it is the minimum in its row and the maximum in its column.

  [2] Input    : matrix = [[1,10,4,2],[9,3,8,7],[15,16,17,12]]
      Expected : [12]
      Why      : 12 is the only lucky number since it is the minimum in its row and the maximum in its column.

  [3] Input    : matrix = [[7,8],[1,2]]
      Expected : [7]
      Why      : 7 is the only lucky number since it is the minimum in its row and the maximum in its column.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> luckyNumbers(vector<vector<int>>& matrix);
