 1382. Balance a Binary Search Tree
 Medium  |  Tags: Divide and Conquer, Greedy, Tree, Depth-First Search, Binary Search Tree, Binary Tree
 https://leetcode.com/problems/balance-a-binary-search-tree/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary search tree, return a balanced binary search
  tree with the same node values. If there is more than one answer, return
  any of them.

  A binary search tree is balanced if the depth of the two subtrees of
  every node never differs by more than 1.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 10^4].
  1 <= Node.val <= 10^5

TEST CASES
  [1] Input    : root = [1,null,2,null,3,null,4,null,null]
      Expected : [2,1,3,null,null,null,4]
      Why      : This is not the only correct answer, [3,1,4,null,2] is also correct.

  [2] Input    : root = [2,1,3]
      Expected : [2,1,3]

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  TreeNode* balanceBST(TreeNode* root);
