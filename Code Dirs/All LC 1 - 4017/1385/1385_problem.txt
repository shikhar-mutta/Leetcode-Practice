 1385. Find the Distance Value Between Two Arrays
 Easy  |  Tags: Array, Two Pointers, Binary Search, Sorting
 https://leetcode.com/problems/find-the-distance-value-between-two-arrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integer arrays arr1 and arr2, and the integer d, return the
  distance value between the two arrays.

  The distance value is defined as the number of elements arr1[i] such
  that there is not any element arr2[j] where |arr1[i]-arr2[j]| <= d.

CONSTRAINTS
  1 <= arr1.length, arr2.length <= 500
  -1000 <= arr1[i], arr2[j] <= 1000
  0 <= d <= 100

TEST CASES
  [1] Input    : arr1 = [4,5,8], arr2 = [10,9,1,8], d = 2
      Expected : 2
      Why      : For arr1[0]=4 we have:
                 |4-10|=6 > d=2
                 |4-9|=5 > d=2
                 … (12 more)

  [2] Input    : arr1 = [1,4,2,3], arr2 = [-4,-3,6,10,20,30], d = 3
      Expected : 2

  [3] Input    : arr1 = [2,1,100,3], arr2 = [-5,-2,10,-3,7], d = 6
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findTheDistanceValue(vector<int>& arr1, vector<int>& arr2, int d);
