 1389. Create Target Array in the Given Order
 Easy  |  Tags: Array, Simulation
 https://leetcode.com/problems/create-target-array-in-the-given-order/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two arrays of integers nums and index. Your task is to create
  target array under the following rules:

  - Initially target array is empty.

  - From left to right read nums[i] and index[i], insert at index index[i]
    the value nums[i] in target array.

  - Repeat the previous step until there are no elements to read in nums
    and index.

  Return the target array.

  It is guaranteed that the insertion operations will be valid.

CONSTRAINTS
  1 <= nums.length, index.length <= 100
  nums.length == index.length
  0 <= nums[i] <= 100
  0 <= index[i] <= i

TEST CASES
  [1] Input    : nums = [0,1,2,3,4], index = [0,1,2,2,1]
      Expected : [0,4,1,3,2]
      Why      : nums index target
                 0 0 [0]
                 1 1 [0,1]
                 … (3 more)

  [2] Input    : nums = [1,2,3,4,0], index = [0,1,2,3,0]
      Expected : [0,1,2,3,4]
      Why      : nums index target
                 1 0 [1]
                 2 1 [1,2]
                 … (3 more)

  [3] Input    : nums = [1], index = [0]
      Expected : [1]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> createTargetArray(vector<int>& nums, vector<int>& index);
