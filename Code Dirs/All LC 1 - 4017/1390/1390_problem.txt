 1390. Four Divisors
 Medium  |  Tags: Array, Math, Prime Factorization, Sieve Theory
 https://leetcode.com/problems/four-divisors/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the sum of divisors of the integers
  in that array that have exactly four divisors. If there is no such
  integer in the array, return 0.

CONSTRAINTS
  1 <= nums.length <= 10^4
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [21,4,7]
      Expected : 32
      Why      : 21 has 4 divisors: 1, 3, 7, 21
                 4 has 3 divisors: 1, 2, 4
                 7 has 2 divisors: 1, 7
                 … (1 more)

  [2] Input    : nums = [21,21]
      Expected : 64

  [3] Input    : nums = [1,2,3,4,5]
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumFourDivisors(vector<int>& nums);
