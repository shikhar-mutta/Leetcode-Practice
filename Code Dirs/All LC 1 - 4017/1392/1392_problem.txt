 1392. Longest Happy Prefix
 Hard  |  Tags: String, Rolling Hash, String Matching, Hash Function, Z Algorithm, Knuth–Morris–Pratt Algorithm
 https://leetcode.com/problems/longest-happy-prefix/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A string is called a happy prefix if it is a non-empty prefix which is
  also a suffix (excluding itself).

  Given a string s, return the longest happy prefix of s. Return an empty
  string "" if no such prefix exists.

CONSTRAINTS
  1 <= s.length <= 10^5
  s contains only lowercase English letters.

TEST CASES
  [1] Input    : s = "level"
      Expected : "l"
      Why      : s contains 4 prefix excluding itself ("l", "le", "lev", "leve"), and suffix ("l", "el", "vel", "evel"). The largest prefix which is also suffix is given by "l".

  [2] Input    : s = "ababab"
      Expected : "abab"
      Why      : "abab" is the largest prefix which is also suffix. They can overlap in the original string.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string longestPrefix(string s);
