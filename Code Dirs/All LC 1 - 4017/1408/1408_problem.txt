 1408. String Matching in an Array
 Easy  |  Tags: Array, String, String Matching
 https://leetcode.com/problems/string-matching-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of string words, return all strings in words that are a
  substring of another word. You can return the answer in any order.

CONSTRAINTS
  1 <= words.length <= 100
  1 <= words[i].length <= 30
  words[i] contains only lowercase English letters.
  All the strings of words are unique.

TEST CASES
  [1] Input    : words = ["mass","as","hero","superhero"]
      Expected : ["as","hero"]
      Why      : "as" is substring of "mass" and "hero" is substring of "superhero".
                 ["hero","as"] is also a valid answer.

  [2] Input    : words = ["leetcode","et","code"]
      Expected : ["et","code"]
      Why      : "et", "code" are substring of "leetcode".

  [3] Input    : words = ["blue","green","bu"]
      Expected : []
      Why      : No string of words is substring of another string.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<string> stringMatching(vector<string>& words);

FILES
  edit : 1408.cpp
