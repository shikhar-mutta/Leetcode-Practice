 1414. Find the Minimum Number of Fibonacci Numbers Whose Sum Is K
 Medium  |  Tags: Math, Greedy
 https://leetcode.com/problems/find-the-minimum-number-of-fibonacci-numbers-whose-sum-is-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer k, return the minimum number of Fibonacci numbers whose
  sum is equal to k. The same Fibonacci number can be used multiple times.

  The Fibonacci numbers are defined as:

  - F1 = 1

  - F2 = 1

  - Fn = Fn-1 + Fn-2 for n > 2.

  It is guaranteed that for the given constraints we can always find such
  Fibonacci numbers that sum up to k.

CONSTRAINTS
  1 <= k <= 10^9

TEST CASES
  [1] Input    : k = 7
      Expected : 2
      Why      : The Fibonacci numbers are: 1, 1, 2, 3, 5, 8, 13, ...
                 For k = 7 we can use 2 + 5 = 7.

  [2] Input    : k = 10
      Expected : 2
      Why      : For k = 10 we can use 2 + 8 = 10.

  [3] Input    : k = 19
      Expected : 3
      Why      : For k = 19 we can use 1 + 5 + 13 = 19.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findMinFibonacciNumbers(int k);

FILES
  edit : 1414.cpp
