 143. Reorder List
 Medium  |  Tags: Linked List, Two Pointers, Stack, Recursion
 https://leetcode.com/problems/reorder-list/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the head of a singly linked-list. The list can be
  represented as:

  L0 → L1 → … → Ln - 1 → Ln

  Reorder the list to be on the following form:

  L0 → Ln → L1 → Ln - 1 → L2 → Ln - 2 → …

  You may not modify the values in the list's nodes. Only nodes themselves
  may be changed.

CONSTRAINTS
  The number of nodes in the list is in the range [1, 5 * 10^4].
  1 <= Node.val <= 1000

TEST CASES
  [1] Input    : head = [1,2,3,4]
      Expected : [1,4,2,3]

  [2] Input    : head = [1,2,3,4,5]
      Expected : [1,5,2,4,3]

CODE TYPE
  function · linked list
    driver: one Solution call per test case
    linked list: ListNode* — values in order, e.g. [1,2,3,4]

SIGNATURE
  void reorderList(ListNode* head);
