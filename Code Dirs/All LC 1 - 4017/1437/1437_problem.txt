 1437. Check If All 1's Are at Least Length K Places Away
 Easy  |  Tags: Array
 https://leetcode.com/problems/check-if-all-1s-are-at-least-length-k-places-away/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an binary array nums and an integer k, return true if all 1's are
  at least k places away from each other, otherwise return false.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= k <= nums.length
  nums[i] is 0 or 1

TEST CASES
  [1] Input    : nums = [1,0,0,0,1,0,0,1], k = 2
      Expected : true
      Why      : Each of the 1s are at least 2 places away from each other.

  [2] Input    : nums = [1,0,0,1,0,1], k = 2
      Expected : false
      Why      : The second 1 and third 1 are only one apart from each other.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool kLengthApart(vector<int>& nums, int k);
