 1438. Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit
 Medium  |  Tags: Array, Queue, Sliding Window, Heap (Priority Queue), Ordered Set, Monotonic Queue
 https://leetcode.com/problems/longest-continuous-subarray-with-absolute-diff-less-than-or-equal-to-limit/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers nums and an integer limit, return the size of
  the longest non-empty subarray such that the absolute difference between
  any two elements of this subarray is less than or equal to limit.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9
  0 <= limit <= 10^9

TEST CASES
  [1] Input    : nums = [8,2,4,7], limit = 4
      Expected : 2
      Why      : All subarrays are:
                 [8] with maximum absolute diff |8-8| = 0 <= 4.
                 [8,2] with maximum absolute diff |8-2| = 6 > 4.
                 … (9 more)

  [2] Input    : nums = [10,1,2,4,7,2], limit = 5
      Expected : 4
      Why      : The subarray [2,4,7,2] is the longest since the maximum absolute diff is |2-7| = 5 <= 5.

  [3] Input    : nums = [4,2,2,2,4,4,2,2], limit = 0
      Expected : 3

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestSubarray(vector<int>& nums, int limit);
