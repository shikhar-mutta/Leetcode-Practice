 1447. Simplified Fractions
 Medium  |  Tags: Math, String, Number Theory, Euclidean Algorithm, Greatest Common Divisor
 https://leetcode.com/problems/simplified-fractions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, return a list of all simplified fractions between 0
  and 1 (exclusive) such that the denominator is less-than-or-equal-to n.
  You can return the answer in any order.

CONSTRAINTS
  1 <= n <= 100

TEST CASES
  [1] Input    : n = 2
      Expected : ["1/2"]
      Why      : "1/2" is the only unique fraction with a denominator less-than-or-equal-to 2.

  [2] Input    : n = 3
      Expected : ["1/2","1/3","2/3"]

  [3] Input    : n = 4
      Expected : ["1/2","1/3","1/4","2/3","3/4"]
      Why      : "2/4" is not a simplified fraction because it can be simplified to "1/2".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<string> simplifiedFractions(int n);

FILES
  edit : 1447.cpp
  test : lc run 1447
