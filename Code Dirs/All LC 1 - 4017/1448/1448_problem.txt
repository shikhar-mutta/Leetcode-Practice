 1448. Count Good Nodes in Binary Tree
 Medium  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/count-good-nodes-in-binary-tree/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a binary tree root, a node X in the tree is named good if in the
  path from root to X there are no nodes with a value greater than X.


  Return the number of good nodes in the binary tree.

CONSTRAINTS
  The number of nodes in the binary tree is in the range [1, 10^5].
  Each node's value is between [-10^4, 10^4].

TEST CASES
  [1] Input    : root = [3,1,4,3,null,1,5]
      Expected : 4
      Why      : Nodes in blue are good.
                 Root Node (3) is always a good node.
                 Node 4 -> (3,4) is the maximum value in the path starting from the root.
                 … (2 more)

  [2] Input    : root = [3,3,null,4,2]
      Expected : 3
      Why      : Node 2 -> (3, 3, 2) is not good, because "3" is higher than it.

  [3] Input    : root = [1]
      Expected : 1
      Why      : Root is considered as good.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int goodNodes(TreeNode* root);
