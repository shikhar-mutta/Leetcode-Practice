 1451. Rearrange Words in a Sentence
 Medium  |  Tags: String, Sorting
 https://leetcode.com/problems/rearrange-words-in-a-sentence/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a sentence text (A sentence is a string of space-separated words)
  in the following format:

  - First letter is in upper case.

  - Each word in text are separated by a single space.

  Your task is to rearrange the words in text such that all words are
  rearranged in an increasing order of their lengths. If two words have
  the same length, arrange them in their original order.

  Return the new text following the format shown above.

CONSTRAINTS
  text begins with a capital letter and then contains lowercase letters and single space between words.
  1 <= text.length <= 10^5

TEST CASES
  [1] Input    : text = "Leetcode is cool"
      Expected : is ordered by length and the new first word starts with capital letter.
      Why      : There are 3 words, "Leetcode" of length 8, "is" of length 2 and "cool" of length 4.

  [2] Input    : text = "Keep calm and code on"
      Expected : "On and keep calm code"
      Why      : Output is ordered as follows:
                 "On" 2 letters.
                 "and" 3 letters.
                 … (3 more)

  [3] Input    : text = "To be or not to be"
      Expected : "To be or to be not"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string arrangeWords(string text);
