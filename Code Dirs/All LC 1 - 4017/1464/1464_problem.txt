 1464. Maximum Product of Two Elements in an Array
 Easy  |  Tags: Array, Sorting, Heap (Priority Queue)
 https://leetcode.com/problems/maximum-product-of-two-elements-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of integers nums.

  Choose two different indices i and j of that array.

  Return the maximum value of (nums[i] - 1) * (nums[j] - 1).

CONSTRAINTS
  2 <= nums.length <= 500
  1 <= nums[i] <= 10^3

TEST CASES
  [1] Input    : nums = [3,4,5,2]
      Expected : 12
      Why      : If you choose the indices i=1 and j=2 (indexed from 0), you will get the maximum value, that is, (nums[1]-1)*(nums[2]-1) = (4-1)*(5-1) = 3*4 = 12.

  [2] Input    : nums = [1,5,4,5]
      Expected : 16
      Why      : Choosing the indices i=1 and j=3 (indexed from 0), you will get the maximum value of (5-1)*(5-1) = 16.

  [3] Input    : nums = [3,7]
      Expected : 12

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxProduct(vector<int>& nums);
