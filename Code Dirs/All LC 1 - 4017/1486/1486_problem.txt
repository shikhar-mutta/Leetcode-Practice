 1486. XOR Operation in an Array
 Easy  |  Tags: Math, Bit Manipulation
 https://leetcode.com/problems/xor-operation-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n and an integer start.

  Define an array nums where nums[i] = start + 2 * i (0-indexed) and n ==
  nums.length.

  Return the bitwise XOR of all elements of nums.

CONSTRAINTS
  1 <= n <= 1000
  0 <= start <= 1000
  n == nums.length

TEST CASES
  [1] Input    : n = 5, start = 0
      Expected : 8
      Why      : Array nums is equal to [0, 2, 4, 6, 8] where (0 ^ 2 ^ 4 ^ 6 ^ 8) = 8.
                 Where "^" corresponds to bitwise XOR operator.

  [2] Input    : n = 4, start = 3
      Expected : 8
      Why      : Array nums is equal to [3, 5, 7, 9] where (3 ^ 5 ^ 7 ^ 9) = 8.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int xorOperation(int n, int start);
