 1492. The kth Factor of n
 Medium  |  Tags: Math, Number Theory, Prime Factorization
 https://leetcode.com/problems/the-kth-factor-of-n/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two positive integers n and k. A factor of an integer n is
  defined as an integer i where n % i == 0.

  Consider a list of all factors of n sorted in ascending order, return
  the k^th factor in this list or return -1 if n has less than k factors.

CONSTRAINTS
  1 <= k <= n <= 1000

TEST CASES
  [1] Input    : n = 12, k = 3
      Expected : 3
      Why      : Factors list is [1, 2, 3, 4, 6, 12], the 3^rd factor is 3.

  [2] Input    : n = 7, k = 2
      Expected : 7
      Why      : Factors list is [1, 7], the 2^nd factor is 7.

  [3] Input    : n = 4, k = 4
      Expected : -1
      Why      : Factors list is [1, 2, 4], there is only 3 factors. We should return -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int kthFactor(int n, int k);
