 1496. Path Crossing
 Easy  |  Tags: Hash Table, String
 https://leetcode.com/problems/path-crossing/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string path, where path[i] = 'N', 'S', 'E' or 'W', each
  representing moving one unit north, south, east, or west, respectively.
  You start at the origin (0, 0) on a 2D plane and walk on the path
  specified by path.

  Return true if the path crosses itself at any point, that is, if at any
  time you are on a location you have previously visited. Return false
  otherwise.

CONSTRAINTS
  1 <= path.length <= 10^4
  path[i] is either 'N', 'S', 'E', or 'W'.

TEST CASES
  [1] Input    : path = "NES"
      Expected : false
      Why      : Notice that the path doesn't cross any point more than once.

  [2] Input    : path = "NESWW"
      Expected : true
      Why      : Notice that the path visits the origin twice.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isPathCrossing(string path);
