 15. 3Sum
 Medium  |  Tags: Array, Two Pointers, Sorting
 https://leetcode.com/problems/3sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return all the triplets [nums[i], nums[j],
  nums[k]] such that i != j, i != k, and j != k, and nums[i] + nums[j] +
  nums[k] == 0.

  Notice that the solution set must not contain duplicate triplets.

CONSTRAINTS
  3 <= nums.length <= 3000
  -10^5 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [-1,0,1,2,-1,-4]
      Expected : [[-1,-1,2],[-1,0,1]]
      Why      : nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0.
                 nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0.
                 nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0.
                 … (2 more)

  [2] Input    : nums = [0,1,1]
      Expected : []
      Why      : The only possible triplet does not sum up to 0.

  [3] Input    : nums = [0,0,0]
      Expected : [[0,0,0]]
      Why      : The only possible triplet sums up to 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> threeSum(vector<int>& nums);

FILES
  edit : 15.cpp
  test : lc run 15
