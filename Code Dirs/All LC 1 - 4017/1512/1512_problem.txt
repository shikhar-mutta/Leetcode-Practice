 1512. Number of Good Pairs
 Easy  |  Tags: Array, Hash Table, Math, Counting
 https://leetcode.com/problems/number-of-good-pairs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers nums, return the number of good pairs.

  A pair (i, j) is called good if nums[i] == nums[j] and i < j.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,3,1,1,3]
      Expected : 4
      Why      : There are 4 good pairs (0,3), (0,4), (3,4), (2,5) 0-indexed.

  [2] Input    : nums = [1,1,1,1]
      Expected : 6
      Why      : Each pair in the array are good.

  [3] Input    : nums = [1,2,3]
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numIdenticalPairs(vector<int>& nums);
