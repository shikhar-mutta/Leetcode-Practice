 1513. Number of Substrings With Only 1s
 Medium  |  Tags: Math, String
 https://leetcode.com/problems/number-of-substrings-with-only-1s/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a binary string s, return the number of substrings with all
  characters 1's. Since the answer may be too large, return it modulo 10^9
  + 7.

CONSTRAINTS
  1 <= s.length <= 10^5
  s[i] is either '0' or '1'.

TEST CASES
  [1] Input    : s = "0110111"
      Expected : 9
      Why      : There are 9 substring in total with only 1's characters.
                 "1" -> 5 times.
                 "11" -> 3 times.
                 … (1 more)

  [2] Input    : s = "101"
      Expected : 2
      Why      : Substring "1" is shown 2 times in s.

  [3] Input    : s = "111111"
      Expected : 21
      Why      : Each substring contains only 1's characters.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numSub(string s);
