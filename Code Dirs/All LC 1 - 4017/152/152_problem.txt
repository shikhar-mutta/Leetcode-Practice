 152. Maximum Product Subarray
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/maximum-product-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, find a subarray that has the largest
  product, and return the product.

  The test cases are generated so that the answer will fit in a 32-bit
  integer.

  Note that the product of an array with a single element is the value of
  that element.

CONSTRAINTS
  1 <= nums.length <= 2 * 10^4
  -10 <= nums[i] <= 10
  The product of any subarray of nums is guaranteed to fit in a 32-bit integer.

TEST CASES
  [1] Input    : nums = [2,3,-2,4]
      Expected : 6
      Why      : [2,3] has the largest product 6.

  [2] Input    : nums = [-2,0,-1]
      Expected : 0
      Why      : The result cannot be 2, because [-2,-1] is not a subarray.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxProduct(vector<int>& nums);

FILES
  edit : 152.cpp
  test : lc run 152
