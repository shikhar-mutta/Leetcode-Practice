 1523. Count Odd Numbers in an Interval Range
 Easy  |  Tags: Math
 https://leetcode.com/problems/count-odd-numbers-in-an-interval-range/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two non-negative integers low and high. Return the count of odd
  numbers between low and high (inclusive).

CONSTRAINTS
  0 <= low <= high <= 10^9

TEST CASES
  [1] Input    : low = 3, high = 7
      Expected : 3
      Why      : The odd numbers between 3 and 7 are [3,5,7].

  [2] Input    : low = 8, high = 10
      Expected : 1
      Why      : The odd numbers between 8 and 10 are [9].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countOdds(int low, int high);

  edit : 1523.cpp
