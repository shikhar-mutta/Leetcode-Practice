 1528. Shuffle String
 Easy  |  Tags: Array, String
 https://leetcode.com/problems/shuffle-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s and an integer array indices of the same
  length. The string s will be shuffled such that the character at the
  i^th position moves to indices[i] in the shuffled string.

  Return the shuffled string.

CONSTRAINTS
  s.length == indices.length == n
  1 <= n <= 100
  s consists of only lowercase English letters.
  0 <= indices[i] < n
  All values of indices are unique.

TEST CASES
  [1] Input    : s = "codeleet", indices = [4,5,6,7,0,2,1,3]
      Expected : "leetcode"
      Why      : As shown, "codeleet" becomes "leetcode" after shuffling.

  [2] Input    : s = "abc", indices = [0,1,2]
      Expected : "abc"
      Why      : After shuffling, each character remains in its position.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string restoreString(string s, vector<int>& indices);
