 1529. Minimum Suffix Flips
 Medium  |  Tags: String, Greedy
 https://leetcode.com/problems/minimum-suffix-flips/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed binary string target of length n. You have
  another binary string s of length n that is initially set to all zeros.
  You want to make s equal to target.

  In one operation, you can pick an index i where 0 <= i < n and flip all
  bits in the inclusive range [i, n - 1]. Flip means changing '0' to '1'
  and '1' to '0'.

  Return the minimum number of operations needed to make s equal to
  target.

CONSTRAINTS
  n == target.length
  1 <= n <= 10^5
  target[i] is either '0' or '1'.

TEST CASES
  [1] Input    : target = "10111"
      Expected : 3
      Why      : Initially, s = "00000".
                 Choose index i = 2: "00000" -> "00111"
                 Choose index i = 0: "00111" -> "11000"
                 … (2 more)

  [2] Input    : target = "101"
      Expected : 3
      Why      : Initially, s = "000".
                 Choose index i = 0: "000" -> "111"
                 Choose index i = 1: "111" -> "100"
                 … (2 more)

  [3] Input    : target = "00000"
      Expected : 0
      Why      : We do not need any operations since the initial s already equals target.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minFlips(string target);
