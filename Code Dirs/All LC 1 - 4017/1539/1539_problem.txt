 1539. Kth Missing Positive Number
 Easy  |  Tags: Array, Binary Search
 https://leetcode.com/problems/kth-missing-positive-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array arr of positive integers sorted in a strictly increasing
  order, and an integer k.

  Return the k^th positive integer that is missing from this array.

CONSTRAINTS
  1 <= arr.length <= 1000
  1 <= arr[i] <= 1000
  1 <= k <= 1000
  arr[i] < arr[j] for 1 <= i < j <= arr.length

TEST CASES
  [1] Input    : arr = [2,3,4,7,11], k = 5
      Expected : 9
      Why      : The missing positive integers are [1,5,6,8,9,10,12,13,...]. The 5^th missing positive integer is 9.

  [2] Input    : arr = [1,2,3,4], k = 2
      Expected : 6
      Why      : The missing positive integers are [5,6,7,...]. The 2^nd missing positive integer is 6.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findKthPositive(vector<int>& arr, int k);
