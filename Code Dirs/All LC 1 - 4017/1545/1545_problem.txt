 1545. Find Kth Bit in Nth Binary String
 Medium  |  Tags: String, Recursion, Simulation
 https://leetcode.com/problems/find-kth-bit-in-nth-binary-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two positive integers n and k, the binary string Sn is formed as
  follows:

  - S1 = "0"

  - Si = Si - 1 + "1" + reverse(invert(Si - 1)) for i > 1

  Where + denotes the concatenation operation, reverse(x) returns the
  reversed string x, and invert(x) inverts all the bits in x (0 changes to
  1 and 1 changes to 0).

  For example, the first four strings in the above sequence are:

  - S1= "0"

  - S2= "011"

  - S3= "0111001"

  - S4 = "011100110110001"

  Return the k^th bit in Sn. It is guaranteed that k is valid for the
  given n.

CONSTRAINTS
  1 <= n <= 20
  1 <= k <= 2^n - 1

TEST CASES
  [1] Input    : n = 3, k = 1
      Expected : "0"
      Why      : S3 is "0111001".
                 The 1^st bit is "0".

  [2] Input    : n = 4, k = 11
      Expected : "1"
      Why      : S4 is "011100110110001".
                 The 11^th bit is "1".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  char findKthBit(int n, int k);
