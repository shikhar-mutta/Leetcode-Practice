 1546. Maximum Number of Non-Overlapping Subarrays With Sum Equals Target
 Medium  |  Tags: Array, Hash Table, Greedy, Prefix Sum
 https://leetcode.com/problems/maximum-number-of-non-overlapping-subarrays-with-sum-equals-target/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array nums and an integer target, return the maximum number of
  non-empty non-overlapping subarrays such that the sum of values in each
  subarray is equal to target.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^4 <= nums[i] <= 10^4
  0 <= target <= 10^6

TEST CASES
  [1] Input    : nums = [1,1,1,1,1], target = 2
      Expected : 2
      Why      : There are 2 non-overlapping subarrays [1,1,1,1,1] with sum equals to target(2).

  [2] Input    : nums = [-1,3,5,1,4,2,-9], target = 6
      Expected : 2
      Why      : There are 3 subarrays with sum equal to 6.
                 ([5,1], [4,2], [3,5,1,4,2,-9]) but only the first 2 are non-overlapping.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxNonOverlapping(vector<int>& nums, int target);
