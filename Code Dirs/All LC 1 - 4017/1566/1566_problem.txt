 1566. Detect Pattern of Length M Repeated K or More Times
 Easy  |  Tags: Array, Enumeration
 https://leetcode.com/problems/detect-pattern-of-length-m-repeated-k-or-more-times/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of positive integers arr, find a pattern of length m that
  is repeated k or more times.

  A pattern is a subarray (consecutive sub-sequence) that consists of one
  or more values, repeated multiple times consecutively without
  overlapping. A pattern is defined by its length and the number of
  repetitions.

  Return true if there exists a pattern of length m that is repeated k or
  more times, otherwise return false.

CONSTRAINTS
  2 <= arr.length <= 100
  1 <= arr[i] <= 100
  1 <= m <= 100
  2 <= k <= 100

TEST CASES
  [1] Input    : arr = [1,2,4,4,4,4], m = 1, k = 3
      Expected : true
      Why      : The pattern (4) of length 1 is repeated 4 consecutive times. Notice that pattern can be repeated k or more times but not less.

  [2] Input    : arr = [1,2,1,2,1,1,1,3], m = 2, k = 2
      Expected : true
      Why      : The pattern (1,2) of length 2 is repeated 2 consecutive times. Another valid pattern (2,1) is also repeated 2 times.

  [3] Input    : arr = [1,2,1,2,1,3], m = 2, k = 3
      Expected : false
      Why      : The pattern (1,2) is of length 2 but is repeated only 2 times. There is no pattern of length 2 that is repeated 3 or more times.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool containsPattern(vector<int>& arr, int m, int k);
