 1573. Number of Ways to Split a String
 Medium  |  Tags: Math, String
 https://leetcode.com/problems/number-of-ways-to-split-a-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a binary string s, you can split s into 3 non-empty strings s1,
  s2, and s3 where s1 + s2 + s3 = s.

  Return the number of ways s can be split such that the number of ones is
  the same in s1, s2, and s3. Since the answer may be too large, return it
  modulo 10^9 + 7.

CONSTRAINTS
  3 <= s.length <= 10^5
  s[i] is either '0' or '1'.

TEST CASES
  [1] Input    : s = "10101"
      Expected : 4
      Why      : There are four ways to split s in 3 parts where each part contain the same number of letters '1'.
                 "1|010|1"
                 "1|01|01"
                 … (2 more)

  [2] Input    : s = "1001"
      Expected : 0

  [3] Input    : s = "0000"
      Expected : 3
      Why      : There are three ways to split s in 3 parts.
                 "0|0|00"
                 "0|00|0"
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numWays(string s);
