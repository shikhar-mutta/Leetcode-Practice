 1588. Sum of All Odd Length Subarrays
 Easy  |  Tags: Array, Math, Prefix Sum
 https://leetcode.com/problems/sum-of-all-odd-length-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of positive integers arr, return the sum of all possible
  odd-length subarrays of arr.

  A subarray is a contiguous subsequence of the array.

CONSTRAINTS
  1 <= arr.length <= 100
  1 <= arr[i] <= 1000

TEST CASES
  [1] Input    : arr = [1,4,2,5,3]
      Expected : 58
      Why      : The odd-length subarrays of arr and their sums are:
                 [1] = 1
                 [4] = 4
                 … (8 more)

  [2] Input    : arr = [1,2]
      Expected : 3
      Why      : There are only 2 subarrays of odd length, [1] and [2]. Their sum is 3.

  [3] Input    : arr = [10,11,12]
      Expected : 66

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumOddLengthSubarrays(vector<int>& arr);
