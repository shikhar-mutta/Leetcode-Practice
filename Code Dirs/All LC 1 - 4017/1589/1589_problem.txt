 1589. Maximum Sum Obtained of Any Permutation
 Medium  |  Tags: Array, Greedy, Sorting, Prefix Sum
 https://leetcode.com/problems/maximum-sum-obtained-of-any-permutation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  We have an array of integers, nums, and an array of requests where
  requests[i] = [starti, endi]. The i^th request asks for the sum of
  nums[starti] + nums[starti + 1] + ... + nums[endi - 1] + nums[endi].
  Both starti and endi are 0-indexed.

  Return the maximum total sum of all requests among all permutations of
  nums.

  Since the answer may be too large, return it modulo 10^9 + 7.

CONSTRAINTS
  n == nums.length
  1 <= n <= 10^5
  0 <= nums[i] <= 10^5
  1 <= requests.length <= 10^5
  requests[i].length == 2
  0 <= starti <= endi < n

TEST CASES
  [1] Input    : nums = [1,2,3,4,5], requests = [[1,3],[0,1]]
      Expected : 19
      Why      : One permutation of nums is [2,1,3,4,5] with the following result:
                 requests[0] -> nums[1] + nums[2] + nums[3] = 1 + 3 + 4 = 8
                 requests[1] -> nums[0] + nums[1] = 2 + 1 = 3
                 … (5 more)

  [2] Input    : nums = [1,2,3,4,5,6], requests = [[0,1]]
      Expected : 11
      Why      : A permutation with the max total sum is [6,5,4,3,2,1] with request sums [11].

  [3] Input    : nums = [1,2,3,4,5,10], requests = [[0,2],[1,3],[1,1]]
      Expected : 47
      Why      : A permutation with the max total sum is [4,10,5,3,2,1] with request sums [19,18,10].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSumRangeQuery(vector<int>& nums, vector<vector<int>>& requests);
