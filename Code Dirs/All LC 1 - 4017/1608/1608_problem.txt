 1608. Special Array With X Elements Greater Than or Equal X
 Easy  |  Tags: Array, Binary Search, Sorting
 https://leetcode.com/problems/special-array-with-x-elements-greater-than-or-equal-x/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums of non-negative integers. nums is considered
  special if there exists a number x such that there are exactly x numbers
  in nums that are greater than or equal to x.

  Notice that x does not have to be an element in nums.

  Return x if the array is special, otherwise, return -1. It can be proven
  that if nums is special, the value for x is unique.

CONSTRAINTS
  1 <= nums.length <= 100
  0 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [3,5]
      Expected : 2
      Why      : There are 2 values (3 and 5) that are greater than or equal to 2.

  [2] Input    : nums = [0,0]
      Expected : -1
      Why      : No numbers fit the criteria for x.
                 If x = 0, there should be 0 numbers >= x, but there are 2.
                 If x = 1, there should be 1 number >= x, but there are 0.
                 … (2 more)

  [3] Input    : nums = [0,4,3,0,4]
      Expected : 3
      Why      : There are 3 values that are greater than or equal to 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int specialArray(vector<int>& nums);
