 1622. Fancy Sequence
 Hard  |  Tags: Math, Design, Segment Tree, Number Theory, Fermat's Little Theorem
 https://leetcode.com/problems/fancy-sequence/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Write an API that generates fancy sequences using the append, addAll,
  and multAll operations.

  Implement the Fancy class:

  - Fancy() Initializes the object with an empty sequence.

  - void append(val) Appends an integer val to the end of the sequence.

  - void addAll(inc) Increments all existing values in the sequence by an
    integer inc.

  - void multAll(m) Multiplies all existing values in the sequence by an
    integer m.

  - int getIndex(idx) Gets the current value at index idx (0-indexed) of
    the sequence modulo 10^9 + 7. If the index is greater or equal than
    the length of the sequence, return -1.

CONSTRAINTS
  1 <= val, inc, m <= 100
  0 <= idx <= 10^5
  At most 10^5 calls total will be made to append, addAll, multAll, and getIndex.
