 1624. Largest Substring Between Two Equal Characters
 Easy  |  Tags: Hash Table, String
 https://leetcode.com/problems/largest-substring-between-two-equal-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, return the length of the longest substring between two
  equal characters, excluding the two characters. If there is no such
  substring return -1.

  A substring is a contiguous sequence of characters within a string.

CONSTRAINTS
  1 <= s.length <= 300
  s contains only lowercase English letters.

TEST CASES
  [1] Input    : s = "aa"
      Expected : 0
      Why      : The optimal substring here is an empty substring between the two 'a's.

  [2] Input    : s = "abca"
      Expected : 2
      Why      : The optimal substring here is "bc".

  [3] Input    : s = "cbzxy"
      Expected : -1
      Why      : There are no characters that appear twice in s.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxLengthBetweenEqualCharacters(string s);
