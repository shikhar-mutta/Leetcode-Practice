 1638. Count Substrings That Differ by One Character
 Medium  |  Tags: Hash Table, String, Dynamic Programming, Enumeration
 https://leetcode.com/problems/count-substrings-that-differ-by-one-character/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two strings s and t, find the number of ways you can choose a non-
  empty substring of s and replace a single character by a different
  character such that the resulting substring is a substring of t. In
  other words, find the number of substrings in s that differ from some
  substring in t by exactly one character.

  For example, the underlined substrings in "computer" and "computation"
  only differ by the 'e'/'a', so this is a valid way.

  Return the number of substrings that satisfy the condition above.

  A substring is a contiguous sequence of characters within a string.

CONSTRAINTS
  1 <= s.length, t.length <= 100
  s and t consist of lowercase English letters only.

TEST CASES
  [1] Input    : s = "aba", t = "baba"
      Expected : 6
      Why      : The following are the pairs of substrings from s and t that differ by exactly 1 character:
                 ("aba", "baba")
                 ("aba", "baba")
                 … (5 more)

  [2] Input    : s = "ab", t = "bb"
      Expected : 3
      Why      : The following are the pairs of substrings from s and t that differ by 1 character:
                 ("ab", "bb")
                 ("ab", "bb")
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countSubstrings(string s, string t);
