 164. Maximum Gap
 Medium  |  Tags: Array, Sorting, Bucket Sort, Radix Sort, Pigeonhole Principle
 https://leetcode.com/problems/maximum-gap/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the maximum difference between two
  successive elements in its sorted form. If the array contains less than
  two elements, return 0.

  You must write an algorithm that runs in linear time and uses linear
  extra space.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [3,6,9,1]
      Expected : 3
      Why      : The sorted form of the array is [1,3,6,9], either (3,6) or (6,9) has the maximum difference 3.

  [2] Input    : nums = [10]
      Expected : 0
      Why      : The array contains less than 2 elements, therefore return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumGap(vector<int>& nums);

FILES
  edit : 164.cpp
  test : lc run 164
