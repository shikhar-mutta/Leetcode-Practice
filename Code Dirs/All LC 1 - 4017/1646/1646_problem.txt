 1646. Get Maximum in Generated Array
 Easy  |  Tags: Array, Simulation
 https://leetcode.com/problems/get-maximum-in-generated-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n. A 0-indexed integer array nums of length n +
  1 is generated in the following way:

  - nums[0] = 0

  - nums[1] = 1

  - nums[2 * i] = nums[i] when 2 <= 2 * i <= n

  - nums[2 * i + 1] = nums[i] + nums[i + 1] when 2 <= 2 * i + 1 <= n

  Return the maximum integer in the array nums.

CONSTRAINTS
  0 <= n <= 100

TEST CASES
  [1] Input    : n = 7
      Expected : 3
      Why      : According to the given rules:
                 nums[0] = 0
                 nums[1] = 1
                 … (7 more)

  [2] Input    : n = 2
      Expected : 1
      Why      : According to the given rules, nums = [0,1,1]. The maximum is max(0,1,1) = 1.

  [3] Input    : n = 3
      Expected : 2
      Why      : According to the given rules, nums = [0,1,1,2]. The maximum is max(0,1,1,2) = 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int getMaximumGenerated(int n);
