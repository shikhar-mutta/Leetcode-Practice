 165. Compare Version Numbers
 Medium  |  Tags: Two Pointers, String
 https://leetcode.com/problems/compare-version-numbers/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two version strings, version1 and version2, compare them. A
  version string consists of revisions separated by dots '.'. The value of
  the revision is its integer conversion ignoring leading zeros.

  To compare version strings, compare their revision values in left-to-
  right order. If one of the version strings has fewer revisions, treat
  the missing revision values as 0.

  Return the following:

  - If version1 < version2, return -1.

  - If version1 > version2, return 1.

  - Otherwise, return 0.

CONSTRAINTS
  1 <= version1.length, version2.length <= 500
  version1 and version2 only contain digits and '.'.
  version1 and version2 are valid version numbers.
  All the given revisions in version1 and version2 can be stored in a 32-bit integer.

TEST CASES
  [1] Input    : version1 = "1.2", version2 = "1.10"
      Expected : -1
      Why      : version1's second revision is "2" and version2's second revision is "10": 2 < 10, so version1 < version2.

  [2] Input    : version1 = "1.01", version2 = "1.001"
      Expected : 0
      Why      : Ignoring leading zeroes, both "01" and "001" represent the same integer "1".

  [3] Input    : version1 = "1.0", version2 = "1.0.0.0"
      Expected : 0
      Why      : version1 has less revisions, which means every missing revision are treated as "0".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int compareVersion(string version1, string version2);
