 1664. Ways to Make a Fair Array
 Medium  |  Tags: Array, Prefix Sum
 https://leetcode.com/problems/ways-to-make-a-fair-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. You can choose exactly one index
  (0-indexed) and remove the element. Notice that the index of the
  elements may change after the removal.

  For example, if nums = [6,1,7,4,1]:

  - Choosing to remove index 1 results in nums = [6,7,4,1].

  - Choosing to remove index 2 results in nums = [6,1,4,1].

  - Choosing to remove index 4 results in nums = [6,1,7,4].

  An array is fair if the sum of the odd-indexed values equals the sum of
  the even-indexed values.

  Return the number of indices that you could choose such that after the
  removal, nums is fair.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [2,1,6,4]
      Expected : 1
      Why      : Remove index 0: [1,6,4] -> Even sum: 1 + 4 = 5. Odd sum: 6. Not fair.
                 Remove index 1: [2,6,4] -> Even sum: 2 + 4 = 6. Odd sum: 6. Fair.
                 Remove index 2: [2,1,4] -> Even sum: 2 + 4 = 6. Odd sum: 1. Not fair.
                 … (2 more)

  [2] Input    : nums = [1,1,1]
      Expected : 3
      Why      : You can remove any index and the remaining array is fair.

  [3] Input    : nums = [1,2,3]
      Expected : 0
      Why      : You cannot make a fair array after removing any index.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int waysToMakeFair(vector<int>& nums);
