 1672. Richest Customer Wealth
 Easy  |  Tags: Array, Matrix
 https://leetcode.com/problems/richest-customer-wealth/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an m x n integer grid accounts where accounts[i][j] is the
  amount of money the i^th customer has in the j^th bank. Return the
  wealth that the richest customer has.

  A customer's wealth is the amount of money they have in all their bank
  accounts. The richest customer is the customer that has the maximum
  wealth.

CONSTRAINTS
  m == accounts.length
  n == accounts[i].length
  1 <= m, n <= 50
  1 <= accounts[i][j] <= 100

TEST CASES
  [1] Input    : accounts = [[1,2,3],[3,2,1]]
      Expected : 6
      Why      : 1st customer has wealth = 1 + 2 + 3 = 6
                 2nd customer has wealth = 3 + 2 + 1 = 6
                 Both customers are considered the richest with a wealth of 6 each, so return 6.

  [2] Input    : accounts = [[1,5],[7,3],[3,5]]
      Expected : 10
      Why      : 1st customer has wealth = 6
                 2nd customer has wealth = 10
                 3rd customer has wealth = 8
                 … (1 more)

  [3] Input    : accounts = [[2,8,7],[7,1,3],[1,9,5]]
      Expected : 17

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumWealth(vector<vector<int>>& accounts);
