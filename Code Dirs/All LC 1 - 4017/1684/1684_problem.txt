 1684. Count the Number of Consistent Strings
 Easy  |  Tags: Array, Hash Table, String, Bit Manipulation, Counting
 https://leetcode.com/problems/count-the-number-of-consistent-strings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string allowed consisting of distinct characters and an
  array of strings words. A string is consistent if all characters in the
  string appear in the string allowed.

  Return the number of consistent strings in the array words.

CONSTRAINTS
  1 <= words.length <= 10^4
  1 <= allowed.length <=^26
  1 <= words[i].length <= 10
  The characters in allowed are distinct.
  words[i] and allowed contain only lowercase English letters.

TEST CASES
  [1] Input    : allowed = "ab", words = ["ad","bd","aaab","baa","badab"]
      Expected : 2
      Why      : Strings "aaab" and "baa" are consistent since they only contain characters 'a' and 'b'.

  [2] Input    : allowed = "abc", words = ["a","b","c","ab","ac","bc","abc"]
      Expected : 7
      Why      : All strings are consistent.

  [3] Input    : allowed = "cad", words = ["cc","acd","b","ba","bac","bad","ac","d"]
      Expected : 4
      Why      : Strings "cc", "acd", "ac", and "d" are consistent.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countConsistentStrings(string allowed, vector<string>& words);
