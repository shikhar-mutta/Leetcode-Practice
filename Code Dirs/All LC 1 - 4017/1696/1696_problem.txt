 1696. Jump Game VI
 Medium  |  Tags: Array, Dynamic Programming, Queue, Heap (Priority Queue), Monotonic Queue
 https://leetcode.com/problems/jump-game-vi/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums and an integer k.

  You are initially standing at index 0. In one move, you can jump at most
  k steps forward without going outside the boundaries of the array. That
  is, you can jump from index i to any index in the range [i + 1, min(n -
  1, i + k)] inclusive.

  You want to reach the last index of the array (index n - 1). Your score
  is the sum of all nums[j] for each index j you visited in the array.

  Return the maximum score you can get.

CONSTRAINTS
  1 <= nums.length, k <= 10^5
  -10^4 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [1,-1,-2,4,-7,3], k = 2
      Expected : 7
      Why      : You can choose your jumps forming the subsequence [1,-1,4,3] (underlined above). The sum is 7.

  [2] Input    : nums = [10,-5,-2,4,0,3], k = 3
      Expected : 17
      Why      : You can choose your jumps forming the subsequence [10,4,3] (underlined above). The sum is 17.

  [3] Input    : nums = [1,-5,-20,4,-1,3,-6,-3], k = 2
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxResult(vector<int>& nums, int k);
