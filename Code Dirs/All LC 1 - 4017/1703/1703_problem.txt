 1703. Minimum Adjacent Swaps for K Consecutive Ones
 Hard  |  Tags: Array, Greedy, Sliding Window, Prefix Sum
 https://leetcode.com/problems/minimum-adjacent-swaps-for-k-consecutive-ones/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array, nums, and an integer k. nums comprises
  of only 0's and 1's. In one move, you can choose two adjacent indices
  and swap their values.

  Return the minimum number of moves required so that nums has k
  consecutive 1's.

CONSTRAINTS
  1 <= nums.length <= 10^5
  nums[i] is 0 or 1.
  1 <= k <= sum(nums)

TEST CASES
  [1] Input    : nums = [1,0,0,1,0,1], k = 2
      Expected : 1
      Why      : In 1 move, nums could be [1,0,0,0,1,1] and have 2 consecutive 1's.

  [2] Input    : nums = [1,0,0,0,0,0,1,1], k = 3
      Expected : 5
      Why      : In 5 moves, the leftmost 1 can be shifted right until nums = [0,0,0,0,0,1,1,1].

  [3] Input    : nums = [1,1,0,1], k = 2
      Expected : 0
      Why      : nums already has 2 consecutive 1's.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minMoves(vector<int>& nums, int k);
