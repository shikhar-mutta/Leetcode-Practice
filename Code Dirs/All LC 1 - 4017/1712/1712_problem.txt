 1712. Ways to Split Array Into Three Subarrays
 Medium  |  Tags: Array, Two Pointers, Binary Search, Prefix Sum
 https://leetcode.com/problems/ways-to-split-array-into-three-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A split of an integer array is good if:

  - The array is split into three non-empty contiguous subarrays - named
    left, mid, right respectively from left to right.

  - The sum of the elements in left is less than or equal to the sum of
    the elements in mid, and the sum of the elements in mid is less than
    or equal to the sum of the elements in right.

  Given nums, an array of non-negative integers, return the number of good
  ways to split nums. As the number may be too large, return it modulo
  10^9+ 7.

CONSTRAINTS
  3 <= nums.length <= 10^5
  0 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [1,1,1]
      Expected : 1
      Why      : The only good way to split nums is [1] [1] [1].

  [2] Input    : nums = [1,2,2,2,5,0]
      Expected : 3
      Why      : There are three good ways of splitting nums:
                 [1] [2] [2,2,5,0]
                 [1] [2,2] [2,5,0]
                 … (1 more)

  [3] Input    : nums = [3,2,1]
      Expected : 0
      Why      : There is no good way to split nums.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int waysToSplit(vector<int>& nums);
