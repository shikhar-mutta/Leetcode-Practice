 1721. Swapping Nodes in a Linked List
 Medium  |  Tags: Linked List, Two Pointers
 https://leetcode.com/problems/swapping-nodes-in-a-linked-list/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the head of a linked list, and an integer k.

  Return the head of the linked list after swapping the values of the k^th
  node from the beginning and the k^th node from the end (the list is
  1-indexed).

CONSTRAINTS
  The number of nodes in the list is n.
  1 <= k <= n <= 10^5
  0 <= Node.val <= 100

TEST CASES
  [1] Input    : head = [1,2,3,4,5], k = 2
      Expected : [1,4,3,2,5]

  [2] Input    : head = [7,9,6,6,7,8,3,0,9,5], k = 5
      Expected : [7,9,6,6,8,7,3,0,9,5]

CODE TYPE
  function · linked list
    driver: one Solution call per test case
    linked list: ListNode* — values in order, e.g. [1,2,3,4]

SIGNATURE
  ListNode* swapNodes(ListNode* head, int k);
