 1726. Tuple with Same Product
 Medium  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/tuple-with-same-product/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array nums of distinct positive integers, return the number of
  tuples (a, b, c, d) such that a * b = c * d where a, b, c, and d are
  elements of nums, and a != b != c != d.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 10^4
  All elements in nums are distinct.

TEST CASES
  [1] Input    : nums = [2,3,4,6]
      Expected : 8
      Why      : There are 8 valid tuples:
                 (2,6,3,4) , (2,6,4,3) , (6,2,3,4) , (6,2,4,3)
                 (3,4,2,6) , (4,3,2,6) , (3,4,6,2) , (4,3,6,2)

  [2] Input    : nums = [1,2,4,5,10]
      Expected : 16
      Why      : There are 16 valid tuples:
                 (1,10,2,5) , (1,10,5,2) , (10,1,2,5) , (10,1,5,2)
                 (2,5,1,10) , (2,5,10,1) , (5,2,1,10) , (5,2,10,1)
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int tupleSameProduct(vector<int>& nums);
