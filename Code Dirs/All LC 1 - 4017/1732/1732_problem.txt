 1732. Find the Highest Altitude
 Easy  |  Tags: Array, Prefix Sum
 https://leetcode.com/problems/find-the-highest-altitude/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is a biker going on a road trip. The road trip consists of n + 1
  points at various altitudes. The biker starts his trip on point 0 with
  altitude equal 0.

  You are given an integer array gain of length n where gain[i] is the net
  gain in altitude between points i and i + 1 for all (0 <= i < n). Return
  the highest altitude of a point.

CONSTRAINTS
  n == gain.length
  1 <= n <= 100
  -100 <= gain[i] <= 100

TEST CASES
  [1] Input    : gain = [-5,1,5,0,-7]
      Expected : 1
      Why      : The altitudes are [0,-5,-4,1,1,-6]. The highest is 1.

  [2] Input    : gain = [-4,-3,-2,-1,4,3,2]
      Expected : 0
      Why      : The altitudes are [0,-4,-7,-9,-10,-6,-3,-1]. The highest is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestAltitude(vector<int>& gain);
