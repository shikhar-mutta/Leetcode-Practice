 1736. Latest Time by Replacing Hidden Digits
 Easy  |  Tags: String, Greedy
 https://leetcode.com/problems/latest-time-by-replacing-hidden-digits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string time in the form of hh:mm, where some of the
  digits in the string are hidden (represented by ?).

  The valid times are those inclusively between 00:00 and 23:59.

  Return the latest valid time you can get from time by replacing the
  hidden digits.

CONSTRAINTS
  time is in the format hh:mm.
  It is guaranteed that you can produce a valid time from the given string.

TEST CASES
  [1] Input    : time = "2?:?0"
      Expected : "23:50"
      Why      : The latest hour beginning with the digit '2' is 23 and the latest minute ending with the digit '0' is 50.

  [2] Input    : time = "0?:3?"
      Expected : "09:39"

  [3] Input    : time = "1?:22"
      Expected : "19:22"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string maximumTime(string time);
