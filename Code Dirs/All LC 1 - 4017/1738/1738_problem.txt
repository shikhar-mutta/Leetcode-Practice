 1738. Find Kth Largest XOR Coordinate Value
 Medium  |  Tags: Array, Divide and Conquer, Bit Manipulation, Sorting, Heap (Priority Queue), Matrix, Prefix Sum, Quickselect
 https://leetcode.com/problems/find-kth-largest-xor-coordinate-value/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D matrix of size m x n, consisting of non-negative
  integers. You are also given an integer k.

  The value of coordinate (a, b) of the matrix is the XOR of all
  matrix[i][j] where 0 <= i <= a < m and 0 <= j <= b < n (0-indexed).

  Find the k^th largest value (1-indexed) of all the coordinates of
  matrix.

CONSTRAINTS
  m == matrix.length
  n == matrix[i].length
  1 <= m, n <= 1000
  0 <= matrix[i][j] <= 10^6
  1 <= k <= m * n

TEST CASES
  [1] Input    : matrix = [[5,2],[1,6]], k = 1
      Expected : 7
      Why      : The value of coordinate (0,1) is 5 XOR 2 = 7, which is the largest value.

  [2] Input    : matrix = [[5,2],[1,6]], k = 2
      Expected : 5
      Why      : The value of coordinate (0,0) is 5 = 5, which is the 2nd largest value.

  [3] Input    : matrix = [[5,2],[1,6]], k = 3
      Expected : 4
      Why      : The value of coordinate (1,0) is 5 XOR 1 = 4, which is the 3rd largest value.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int kthLargestValue(vector<vector<int>>& matrix, int k);
