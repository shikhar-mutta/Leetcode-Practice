 1745. Palindrome Partitioning IV
 Hard  |  Tags: String, Dynamic Programming
 https://leetcode.com/problems/palindrome-partitioning-iv/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, return true if it is possible to split the string s
  into three non-empty palindromic substrings. Otherwise, return false.

  A string is said to be palindrome if it the same string when reversed.

CONSTRAINTS
  3 <= s.length <= 2000
  s consists only of lowercase English letters.

TEST CASES
  [1] Input    : s = "abcbdd"
      Expected : true
      Why      : "abcbdd" = "a" + "bcb" + "dd", and all three substrings are palindromes.

  [2] Input    : s = "bcbddxy"
      Expected : false
      Why      : s cannot be split into 3 palindromes.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool checkPartitioning(string s);
