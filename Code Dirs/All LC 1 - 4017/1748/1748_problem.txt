 1748. Sum of Unique Elements
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/sum-of-unique-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. The unique elements of an array are
  the elements that appear exactly once in the array.

  Return the sum of all the unique elements of nums.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,3,2]
      Expected : 4
      Why      : The unique elements are [1,3], and the sum is 4.

  [2] Input    : nums = [1,1,1,1,1]
      Expected : 0
      Why      : There are no unique elements, and the sum is 0.

  [3] Input    : nums = [1,2,3,4,5]
      Expected : 15
      Why      : The unique elements are [1,2,3,4,5], and the sum is 15.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumOfUnique(vector<int>& nums);
