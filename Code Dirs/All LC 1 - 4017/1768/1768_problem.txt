 1768. Merge Strings Alternately
 Easy  |  Tags: Two Pointers, String
 https://leetcode.com/problems/merge-strings-alternately/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two strings word1 and word2. Merge the strings by adding
  letters in alternating order, starting with word1. If a string is longer
  than the other, append the additional letters onto the end of the merged
  string.


  Return the merged string.

CONSTRAINTS
  1 <= word1.length, word2.length <= 100
  word1 and word2 consist of lowercase English letters.

TEST CASES
  [1] Input    : word1 = "abc", word2 = "pqr"
      Expected : "apbqcr"
      Why      : The merged string will be merged as so:
                 word1: a b c
                 word2: p q r
                 … (1 more)

  [2] Input    : word1 = "ab", word2 = "pqrs"
      Expected : "apbqrs"
      Why      : Notice that as word2 is longer, "rs" is appended to the end.
                 word1: a b
                 word2: p q r s
                 … (1 more)

  [3] Input    : word1 = "abcd", word2 = "pq"
      Expected : "apbqcd"
      Why      : Notice that as word1 is longer, "cd" is appended to the end.
                 word1: a b c d
                 word2: p q
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string mergeAlternately(string word1, string word2);
