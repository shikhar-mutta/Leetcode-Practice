 1793. Maximum Score of a Good Subarray
 Hard  |  Tags: Array, Two Pointers, Binary Search, Stack, Monotonic Stack, Cartesian Tree
 https://leetcode.com/problems/maximum-score-of-a-good-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of integers nums (0-indexed) and an integer k.

  The score of a subarray (i, j) is defined as min(nums[i], nums[i+1],
  ..., nums[j]) * (j - i + 1). A good subarray is a subarray where i <= k
  <= j.

  Return the maximum possible score of a good subarray.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 2 * 10^4
  0 <= k < nums.length

TEST CASES
  [1] Input    : nums = [1,4,3,7,4,5], k = 3
      Expected : 15
      Why      : The optimal subarray is (1, 5) with a score of min(4,3,7,4,5) * (5-1+1) = 3 * 5 = 15.

  [2] Input    : nums = [5,5,4,5,4,1,1,1], k = 0
      Expected : 20
      Why      : The optimal subarray is (0, 4) with a score of min(5,5,4,5,4) * (4-0+1) = 4 * 5 = 20.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumScore(vector<int>& nums, int k);
