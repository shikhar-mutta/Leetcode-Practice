 1798. Maximum Number of Consecutive Values You Can Make
 Medium  |  Tags: Array, Greedy, Sorting
 https://leetcode.com/problems/maximum-number-of-consecutive-values-you-can-make/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array coins of length n which represents the n
  coins that you own. The value of the i^th coin is coins[i]. You can make
  some value x if you can choose some of your n coins such that their
  values sum up to x.

  Return the maximum number of consecutive integer values that you can
  make with your coins starting from and including 0.

  Note that you may have multiple coins of the same value.

CONSTRAINTS
  coins.length == n
  1 <= n <= 4 * 10^4
  1 <= coins[i] <= 4 * 10^4

TEST CASES
  [1] Input    : coins = [1,3]
      Expected : 2
      Why      : You can make the following values:
                 - 0: take []
                 - 1: take [1]
                 … (1 more)

  [2] Input    : coins = [1,1,1,4]
      Expected : 8
      Why      : You can make the following values:
                 - 0: take []
                 - 1: take [1]
                 … (7 more)

  [3] Input    : coins = [1,4,10,3,1]
      Expected : 20

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int getMaximumConsecutive(vector<int>& coins);
