 1800. Maximum Ascending Subarray Sum
 Easy  |  Tags: Array
 https://leetcode.com/problems/maximum-ascending-subarray-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of positive integers nums, return the maximum possible
  sum of an strictly increasing subarray in nums.

  A subarray is defined as a contiguous sequence of numbers in an array.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [10,20,30,5,10,50]
      Expected : 65
      Why      : [5,10,50] is the ascending subarray with the maximum sum of 65.

  [2] Input    : nums = [10,20,30,40,50]
      Expected : 150
      Why      : [10,20,30,40,50] is the ascending subarray with the maximum sum of 150.

  [3] Input    : nums = [12,17,15,13,10,11,12]
      Expected : 33
      Why      : [10,11,12] is the ascending subarray with the maximum sum of 33.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxAscendingSum(vector<int>& nums);
