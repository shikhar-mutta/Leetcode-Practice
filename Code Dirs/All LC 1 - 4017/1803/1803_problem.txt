 1803. Count Pairs With XOR in a Range
 Hard  |  Tags: Array, Bit Manipulation, Trie
 https://leetcode.com/problems/count-pairs-with-xor-in-a-range/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a (0-indexed) integer array nums and two integers low and high,
  return the number of nice pairs.


  A nice pair is a pair (i, j) where 0 <= i < j < nums.length and low <=
  (nums[i] XOR nums[j]) <= high.

CONSTRAINTS
  1 <= nums.length <= 2 * 10^4
  1 <= nums[i] <= 2 * 10^4
  1 <= low <= high <= 2 * 10^4

TEST CASES
  [1] Input    : nums = [1,4,2,7], low = 2, high = 6
      Expected : 6
      Why      : All nice pairs (i, j) are as follows:
                 - (0, 1): nums[0] XOR nums[1] = 5
                 - (0, 2): nums[0] XOR nums[2] = 3
                 … (4 more)

  [2] Input    : nums = [9,8,4,2,1], low = 5, high = 14
      Expected : 8
      Why      : All nice pairs (i, j) are as follows:
                 - (0, 2): nums[0] XOR nums[2] = 13
                 - (0, 3): nums[0] XOR nums[3] = 11
                 … (6 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPairs(vector<int>& nums, int low, int high);
