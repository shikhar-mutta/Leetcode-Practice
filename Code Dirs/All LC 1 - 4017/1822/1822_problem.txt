 1822. Sign of the Product of an Array
 Easy  |  Tags: Array, Math
 https://leetcode.com/problems/sign-of-the-product-of-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Implement a function signFunc(x) that returns:

  - 1 if x is positive.

  - -1 if x is negative.

  - 0 if x is equal to 0.

  You are given an integer array nums. Let product be the product of all
  values in the array nums.

  Return signFunc(product).

CONSTRAINTS
  1 <= nums.length <= 1000
  -100 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [-1,-2,-3,-4,3,2,1]
      Expected : 1
      Why      : The product of all values in the array is 144, and signFunc(144) = 1

  [2] Input    : nums = [1,5,0,2,-3]
      Expected : 0
      Why      : The product of all values in the array is 0, and signFunc(0) = 0

  [3] Input    : nums = [-1,1,-1,1,-1]
      Expected : -1
      Why      : The product of all values in the array is -1, and signFunc(-1) = -1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int arraySign(vector<int>& nums);
