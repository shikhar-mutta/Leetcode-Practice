 1832. Check if the Sentence Is Pangram
 Easy  |  Tags: Hash Table, String
 https://leetcode.com/problems/check-if-the-sentence-is-pangram/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A pangram is a sentence where every letter of the English alphabet
  appears at least once.

  Given a string sentence containing only lowercase English letters,
  return true if sentence is a pangram, or false otherwise.

CONSTRAINTS
  1 <= sentence.length <= 1000
  sentence consists of lowercase English letters.

TEST CASES
  [1] Input    : sentence = "thequickbrownfoxjumpsoverthelazydog"
      Expected : true
      Why      : sentence contains at least one of every letter of the English alphabet.

  [2] Input    : sentence = "leetcode"
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool checkIfPangram(string sentence);

FILES
  edit : 1832.cpp
  test : lc run 1832
