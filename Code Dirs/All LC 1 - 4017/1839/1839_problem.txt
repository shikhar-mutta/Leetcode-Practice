 1839. Longest Substring Of All Vowels in Order
 Medium  |  Tags: String, Sliding Window
 https://leetcode.com/problems/longest-substring-of-all-vowels-in-order/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A string is considered beautiful if it satisfies the following
  conditions:

  - Each of the 5 English vowels ('a', 'e', 'i', 'o', 'u') must appear at
    least once in it.

  - The letters must be sorted in alphabetical order (i.e. all 'a's before
    'e's, all 'e's before 'i's, etc.).

  For example, strings "aeiou" and "aaaaaaeiiiioou" are considered
  beautiful, but "uaeio", "aeoiu", and "aaaeeeooo" are not beautiful.

  Given a string word consisting of English vowels, return the length of
  the longest beautiful substring of word. If no such substring exists,
  return 0.

  A substring is a contiguous sequence of characters in a string.

CONSTRAINTS
  1 <= word.length <= 5 * 10^5
  word consists of characters 'a', 'e', 'i', 'o', and 'u'.

TEST CASES
  [1] Input    : word = "aeiaaioaaaaeiiiiouuuooaauuaeiu"
      Expected : 13
      Why      : The longest beautiful substring in word is "aaaaeiiiiouuu" of length 13.

  [2] Input    : word = "aeeeiiiioooauuuaeiou"
      Expected : 5
      Why      : The longest beautiful substring in word is "aeiou" of length 5.

  [3] Input    : word = "a"
      Expected : 0
      Why      : There is no beautiful substring, so return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestBeautifulSubstring(string word);
