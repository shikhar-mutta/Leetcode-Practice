 1844. Replace All Digits with Characters
 Easy  |  Tags: String
 https://leetcode.com/problems/replace-all-digits-with-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed string s that has lowercase English letters in
  its even indices and digits in its odd indices.

  You must perform an operation shift(c, x), where c is a character and x
  is a digit, that returns the x^th character after c.

  - For example, shift('a', 5) = 'f' and shift('x', 0) = 'x'.

  For every odd index i, you want to replace the digit s[i] with the
  result of the shift(s[i-1], s[i]) operation.

  Return s after replacing all digits. It is guaranteed that shift(s[i-1],
  s[i]) will never exceed 'z'.

  Note that shift(c, x) is not a preloaded function, but an operation to
  be implemented as part of the solution.

CONSTRAINTS
  1 <= s.length <= 100
  s consists only of lowercase English letters and digits.
  shift(s[i-1], s[i]) <= 'z' for all odd indices i.

TEST CASES
  [1] Input    : s = "a1c1e1"
      Expected : "abcdef"
      Why      : The digits are replaced as follows:
                 - s[1] -> shift('a',1) = 'b'
                 - s[3] -> shift('c',1) = 'd'
                 … (1 more)

  [2] Input    : s = "a1b2c3d4e"
      Expected : "abbdcfdhe"
      Why      : The digits are replaced as follows:
                 - s[1] -> shift('a',1) = 'b'
                 - s[3] -> shift('b',2) = 'd'
                 … (2 more)
