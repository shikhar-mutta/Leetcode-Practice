 1854. Maximum Population Year
 Easy  |  Tags: Array, Counting, Prefix Sum
 https://leetcode.com/problems/maximum-population-year/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array logs where each logs[i] = [birthi,
  deathi] indicates the birth and death years of the i^th person.

  The population of some year x is the number of people alive during that
  year. The i^th person is counted in year x's population if x is in the
  inclusive range [birthi, deathi - 1]. Note that the person is not
  counted in the year that they die.

  Return the earliest year with the maximum population.

CONSTRAINTS
  1 <= logs.length <= 100
  1950 <= birthi < deathi <= 2050

TEST CASES
  [1] Input    : logs = [[1993,1999],[2000,2010]]
      Expected : 1993
      Why      : The maximum population is 1, and 1993 is the earliest year with this population.

  [2] Input    : logs = [[1950,1961],[1960,1971],[1970,1981]]
      Expected : 1960
      Why      : The maximum population is 2, and it had happened in years 1960 and 1970.
                 The earlier year between them is 1960.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumPopulation(vector<vector<int>>& logs);
