 1856. Maximum Subarray Min-Product
 Medium  |  Tags: Array, Stack, Monotonic Stack, Prefix Sum, Cartesian Tree
 https://leetcode.com/problems/maximum-subarray-min-product/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The min-product of an array is equal to the minimum value in the array
  multiplied by the array's sum.

  - For example, the array [3,2,5] (minimum value is 2) has a min-product
    of 2 * (3+2+5) = 2 * 10 = 20.

  Given an array of integers nums, return the maximum min-product of any
  non-empty subarray of nums. Since the answer may be large, return it
  modulo 10^9 + 7.

  Note that the min-product should be maximized before performing the
  modulo operation. Testcases are generated such that the maximum min-
  product without modulo will fit in a 64-bit signed integer.

  A subarray is a contiguous part of an array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^7

TEST CASES
  [1] Input    : nums = [1,2,3,2]
      Expected : 14
      Why      : The maximum min-product is achieved with the subarray [2,3,2] (minimum value is 2).
                 2 * (2+3+2) = 2 * 7 = 14.

  [2] Input    : nums = [2,3,3,1,2]
      Expected : 18
      Why      : The maximum min-product is achieved with the subarray [3,3] (minimum value is 3).
                 3 * (3+3) = 3 * 6 = 18.

  [3] Input    : nums = [3,1,5,6,4,2]
      Expected : 60
      Why      : The maximum min-product is achieved with the subarray [5,6,4] (minimum value is 4).
                 4 * (5+6+4) = 4 * 15 = 60.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSumMinProduct(vector<int>& nums);
