 1862. Sum of Floored Pairs
 Hard  |  Tags: Array, Math, Binary Search, Counting, Enumeration, Prefix Sum
 https://leetcode.com/problems/sum-of-floored-pairs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the sum of floor(nums[i] / nums[j])
  for all pairs of indices 0 <= i, j < nums.length in the array. Since the
  answer may be too large, return it modulo 10^9 + 7.

  The floor() function returns the integer part of the division.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [2,5,9]
      Expected : 10
      Why      : floor(2 / 5) = floor(2 / 9) = floor(5 / 9) = 0
                 floor(2 / 2) = floor(5 / 5) = floor(9 / 9) = 1
                 floor(5 / 2) = 2
                 … (3 more)

  [2] Input    : nums = [7,7,7,7,7,7,7]
      Expected : 49

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumOfFlooredPairs(vector<int>& nums);

FILES
  edit : 1862.cpp
  test : lc run 1862
