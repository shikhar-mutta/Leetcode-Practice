 1863. Sum of All Subset XOR Totals
 Easy  |  Tags: Array, Math, Backtracking, Bit Manipulation, Combinatorics, Enumeration
 https://leetcode.com/problems/sum-of-all-subset-xor-totals/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The XOR total of an array is defined as the bitwise XOR of all its
  elements, or 0 if the array is empty.

  - For example, the XOR total of the array [2,5,6] is 2 XOR 5 XOR 6 = 1.

  Given an array nums, return the sum of all XOR totals for every subset
  of nums.

  Note: Subsets with the same elements should be counted multiple times.

  An array a is a subset of an array b if a can be obtained from b by
  deleting some (possibly zero) elements of b.

CONSTRAINTS
  1 <= nums.length <= 12
  1 <= nums[i] <= 20

TEST CASES
  [1] Input    : nums = [1,3]
      Expected : 6
      Why      : The 4 subsets of [1,3] are:
                 - The empty subset has an XOR total of 0.
                 - [1] has an XOR total of 1.
                 … (3 more)

  [2] Input    : nums = [5,1,6]
      Expected : 28
      Why      : The 8 subsets of [5,1,6] are:
                 - The empty subset has an XOR total of 0.
                 - [5] has an XOR total of 5.
                 … (7 more)

  [3] Input    : nums = [3,4,5,6,7,8]
      Expected : 480
      Why      : The sum of all XOR totals for every subset is 480.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int subsetXORSum(vector<int>& nums);
