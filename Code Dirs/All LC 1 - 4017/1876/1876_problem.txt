 1876. Substrings of Size Three with Distinct Characters
 Easy  |  Tags: Hash Table, String, Sliding Window, Counting
 https://leetcode.com/problems/substrings-of-size-three-with-distinct-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A string is good if there are no repeated characters.

  Given a string s, return the number of good substrings of length three
  in s.

  Note that if there are multiple occurrences of the same substring, every
  occurrence should be counted.

  A substring is a contiguous sequence of characters in a string.

CONSTRAINTS
  1 <= s.length <= 100
  s consists of lowercase English letters.

TEST CASES
  [1] Input    : s = "xyzzaz"
      Expected : 1
      Why      : There are 4 substrings of size 3: "xyz", "yzz", "zza", and "zaz".
                 The only good substring of length 3 is "xyz".

  [2] Input    : s = "aababcabc"
      Expected : 4
      Why      : There are 7 substrings of size 3: "aab", "aba", "bab", "abc", "bca", "cab", and "abc".
                 The good substrings are "abc", "bca", "cab", and "abc".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countGoodSubstrings(string s);

  edit : 1876.cpp
  test : lc run 1876
