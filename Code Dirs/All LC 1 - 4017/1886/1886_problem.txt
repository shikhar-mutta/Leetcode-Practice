 1886. Determine Whether Matrix Can Be Obtained By Rotation
 Easy  |  Tags: Array, Matrix
 https://leetcode.com/problems/determine-whether-matrix-can-be-obtained-by-rotation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two n x n binary matrices mat and target, return true if it is
  possible to make mat equal to target by rotating mat in 90-degree
  increments, or false otherwise.

CONSTRAINTS
  n == mat.length == target.length
  n == mat[i].length == target[i].length
  1 <= n <= 10
  mat[i][j] and target[i][j] are either 0 or 1.

TEST CASES
  [1] Input    : mat = [[0,1],[1,0]], target = [[1,0],[0,1]]
      Expected : true
      Why      : We can rotate mat 90 degrees clockwise to make mat equal target.

  [2] Input    : mat = [[0,1],[1,1]], target = [[1,0],[0,1]]
      Expected : false
      Why      : It is impossible to make mat equal to target by rotating mat.

  [3] Input    : mat = [[0,0,0],[0,1,0],[1,1,1]], target = [[1,1,1],[0,1,0],[0,0,0]]
      Expected : true
      Why      : We can rotate mat 90 degrees clockwise two times to make mat equal target.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool findRotation(vector<vector<int>>& mat, vector<vector<int>>& target);

  edit : 1886.cpp
