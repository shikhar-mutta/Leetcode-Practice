 1893. Check if All the Integers in a Range Are Covered
 Easy  |  Tags: Array, Hash Table, Prefix Sum
 https://leetcode.com/problems/check-if-all-the-integers-in-a-range-are-covered/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array ranges and two integers left and right.
  Each ranges[i] = [starti, endi] represents an inclusive interval between
  starti and endi.

  Return true if each integer in the inclusive range [left, right] is
  covered by at least one interval in ranges. Return false otherwise.

  An integer x is covered by an interval ranges[i] = [starti, endi] if
  starti <= x <= endi.

CONSTRAINTS
  1 <= ranges.length <= 50
  1 <= starti <= endi <= 50
  1 <= left <= right <= 50

TEST CASES
  [1] Input    : ranges = [[1,2],[3,4],[5,6]], left = 2, right = 5
      Expected : true
      Why      : Every integer between 2 and 5 is covered:
                 - 2 is covered by the first range.
                 - 3 and 4 are covered by the second range.
                 … (1 more)

  [2] Input    : ranges = [[1,10],[10,20]], left = 21, right = 21
      Expected : false
      Why      : 21 is not covered by any range.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isCovered(vector<vector<int>>& ranges, int left, int right);

FILES
  edit : 1893.cpp
