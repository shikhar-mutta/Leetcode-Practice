 1895. Largest Magic Square
 Medium  |  Tags: Array, Matrix, Prefix Sum
 https://leetcode.com/problems/largest-magic-square/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A k x k magic square is a k x k grid filled with integers such that
  every row sum, every column sum, and both diagonal sums are all equal.
  The integers in the magic square do not have to be distinct. Every 1 x 1
  grid is trivially a magic square.

  Given an m x n integer grid, return the size (i.e., the side length k)
  of the largest magic square that can be found within this grid.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  1 <= m, n <= 50
  1 <= grid[i][j] <= 10^6

TEST CASES
  [1] Input    : grid = [[7,1,4,5,6],[2,5,1,6,4],[1,5,4,3,2],[1,2,7,3,4]]
      Expected : 3
      Why      : The largest magic square has a size of 3.
                 Every row sum, column sum, and diagonal sum of this magic square is equal to 12.
                 - Row sums: 5+1+6 = 5+4+3 = 2+7+3 = 12
                 … (2 more)

  [2] Input    : grid = [[5,1,3,1],[9,3,3,1],[1,3,3,8]]
      Expected : 2

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestMagicSquare(vector<vector<int>>& grid);
