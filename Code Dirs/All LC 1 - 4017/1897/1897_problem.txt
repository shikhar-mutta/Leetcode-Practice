 1897. Redistribute Characters to Make All Strings Equal
 Easy  |  Tags: Hash Table, String, Counting
 https://leetcode.com/problems/redistribute-characters-to-make-all-strings-equal/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of strings words (0-indexed).

  In one operation, pick two distinct indices i and j, where words[i] is a
  non-empty string, and move any character from words[i] to any position
  in words[j].

  Return true if you can make every string in words equal using any number
  of operations, and false otherwise.

CONSTRAINTS
  1 <= words.length <= 100
  1 <= words[i].length <= 100
  words[i] consists of lowercase English letters.

TEST CASES
  [1] Input    : words = ["abc","aabc","bc"]
      Expected : true
      Why      : Move the first 'a' in words[1] to the front of words[2],
                 to make words[1] = "abc" and words[2] = "abc".
                 All the strings are now equal to "abc", so return true.

  [2] Input    : words = ["ab","a"]
      Expected : false
      Why      : It is impossible to make all the strings equal using the operation.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool makeEqual(vector<string>& words);
