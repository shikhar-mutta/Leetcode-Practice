 1909. Remove One Element to Make the Array Strictly Increasing
 Easy  |  Tags: Array
 https://leetcode.com/problems/remove-one-element-to-make-the-array-strictly-increasing/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed integer array nums, return true if it can be made
  strictly increasing after removing exactly one element, or false
  otherwise. If the array is already strictly increasing, return true.

  The array nums is strictly increasing if nums[i - 1] < nums[i] for each
  index (1 <= i < nums.length).

CONSTRAINTS
  2 <= nums.length <= 1000
  1 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [1,2,10,5,7]
      Expected : true
      Why      : By removing 10 at index 2 from nums, it becomes [1,2,5,7].
                 [1,2,5,7] is strictly increasing, so return true.

  [2] Input    : nums = [2,3,1,2]
      Expected : false
      Why      : [3,1,2] is the result of removing the element at index 0.
                 [2,1,2] is the result of removing the element at index 1.
                 [2,3,2] is the result of removing the element at index 2.
                 … (2 more)

  [3] Input    : nums = [1,1,1]
      Expected : false
      Why      : The result of removing any element is [1,1].
                 [1,1] is not strictly increasing, so return false.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canBeIncreasing(vector<int>& nums);
