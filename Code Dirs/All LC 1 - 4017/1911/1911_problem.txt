 1911. Maximum Alternating Subsequence Sum
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/maximum-alternating-subsequence-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The alternating sum of a 0-indexed array is defined as the sum of the
  elements at even indices minus the sum of the elements at odd indices.



  - For example, the alternating sum of [4,2,5,3] is (4 + 5) - (2 + 3) =
    4.




  Given an array nums, return the maximum alternating sum of any
  subsequence of nums (after reindexing the elements of the subsequence).






  A subsequence of an array is a new array generated from the original
  array by deleting some elements (possibly none) without changing the
  remaining elements' relative order. For example, [2,7,4] is a
  subsequence of [4,2,3,7,2,1,4] (the underlined elements), while [2,4,2]
  is not.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [4,2,5,3]
      Expected : 7
      Why      : It is optimal to choose the subsequence [4,2,5] with alternating sum (4 + 5) - 2 = 7.

  [2] Input    : nums = [5,6,7,8]
      Expected : 8
      Why      : It is optimal to choose the subsequence [8] with alternating sum 8.

  [3] Input    : nums = [6,2,1,2,4,5]
      Expected : 10
      Why      : It is optimal to choose the subsequence [6,1,5] with alternating sum (6 + 5) - 1 = 10.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maxAlternatingSum(vector<int>& nums);
