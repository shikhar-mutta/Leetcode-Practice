 1925. Count Square Sum Triples
 Easy  |  Tags: Math, Enumeration
 https://leetcode.com/problems/count-square-sum-triples/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A square triple (a,b,c) is a triple where a, b, and c are integers and
  a^2 + b^2 = c^2.

  Given an integer n, return the number of square triples such that 1 <=
  a, b, c <= n.

CONSTRAINTS
  1 <= n <= 250

TEST CASES
  [1] Input    : n = 5
      Expected : 2
      Why      : The square triples are (3,4,5) and (4,3,5).

  [2] Input    : n = 10
      Expected : 4
      Why      : The square triples are (3,4,5), (4,3,5), (6,8,10), and (8,6,10).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countTriples(int n);

  test : lc run 1925
