 1957. Delete Characters to Make Fancy String
 Easy  |  Tags: String
 https://leetcode.com/problems/delete-characters-to-make-fancy-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A fancy string is a string where no three consecutive characters are
  equal.

  Given a string s, delete the minimum possible number of characters from
  s to make it fancy.

  Return the final string after the deletion. It can be shown that the
  answer will always be unique.

CONSTRAINTS
  1 <= s.length <= 10^5
  s consists only of lowercase English letters.

TEST CASES
  [1] Input    : s = "leeetcode"
      Expected : "leetcode"
      Why      : Remove an 'e' from the first group of 'e's to create "leetcode".
                 No three consecutive characters are equal, so return "leetcode".

  [2] Input    : s = "aaabaaaa"
      Expected : "aabaa"
      Why      : Remove an 'a' from the first group of 'a's to create "aabaaaa".
                 Remove two 'a's from the second group of 'a's to create "aabaa".
                 No three consecutive characters are equal, so return "aabaa".

  [3] Input    : s = "aab"
      Expected : "aab"
      Why      : No three consecutive characters are equal, so return "aab".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string makeFancyString(string s);

  edit : 1957.cpp
