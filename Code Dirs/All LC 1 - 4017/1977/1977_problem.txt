 1977. Number of Ways to Separate Numbers
 Hard  |  Tags: String, Dynamic Programming, Prefix Sum
 https://leetcode.com/problems/number-of-ways-to-separate-numbers/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You wrote down many positive integers in a string called num. However,
  you realized that you forgot to add commas to seperate the different
  numbers. You remember that the list of integers was non-decreasing and
  that no integer had leading zeros.

  Return the number of possible lists of integers that you could have
  written down to get the string num. Since the answer may be large,
  return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= num.length <= 3500
  num consists of digits '0' through '9'.

TEST CASES
  [1] Input    : num = "327"
      Expected : 2
      Why      : You could have written down the numbers:
                 3, 27
                 327

  [2] Input    : num = "094"
      Expected : 0
      Why      : No numbers can have leading zeros and all numbers must be positive.

  [3] Input    : num = "0"
      Expected : 0
      Why      : No numbers can have leading zeros and all numbers must be positive.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfCombinations(string num);

FILES
  edit : 1977.cpp
  test : lc run 1977
