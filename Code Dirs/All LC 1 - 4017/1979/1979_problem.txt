 1979. Find Greatest Common Divisor of Array
 Easy  |  Tags: Array, Math, Number Theory, Euclidean Algorithm, Greatest Common Divisor
 https://leetcode.com/problems/find-greatest-common-divisor-of-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the greatest common divisor of the
  smallest number and largest number in nums.

  The greatest common divisor of two numbers is the largest positive
  integer that evenly divides both numbers.

CONSTRAINTS
  2 <= nums.length <= 1000
  1 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [2,5,6,9,10]
      Expected : 2
      Why      : The smallest number in nums is 2.
                 The largest number in nums is 10.
                 The greatest common divisor of 2 and 10 is 2.

  [2] Input    : nums = [7,5,6,8,3]
      Expected : 1
      Why      : The smallest number in nums is 3.
                 The largest number in nums is 8.
                 The greatest common divisor of 3 and 8 is 1.

  [3] Input    : nums = [3,3]
      Expected : 3
      Why      : The smallest number in nums is 3.
                 The largest number in nums is 3.
                 The greatest common divisor of 3 and 3 is 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findGCD(vector<int>& nums);

  edit : 1979.cpp
  test : lc run 1979
