 198. House Robber
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/house-robber/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are a professional robber planning to rob houses along a street.
  Each house has a certain amount of money stashed, the only constraint
  stopping you from robbing each of them is that adjacent houses have
  security systems connected and it will automatically contact the police
  if two adjacent houses were broken into on the same night.

  Given an integer array nums representing the amount of money of each
  house, return the maximum amount of money you can rob tonight without
  alerting the police.

CONSTRAINTS
  1 <= nums.length <= 100
  0 <= nums[i] <= 400

TEST CASES
  [1] Input    : nums = [1,2,3,1]
      Expected : 4
      Why      : Rob house 1 (money = 1) and then rob house 3 (money = 3).
                 Total amount you can rob = 1 + 3 = 4.

  [2] Input    : nums = [2,7,9,3,1]
      Expected : 12
      Why      : Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1).
                 Total amount you can rob = 2 + 9 + 1 = 12.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int rob(vector<int>& nums);

FILES
  edit : 198.cpp
  test : lc run 198
