 1980. Find Unique Binary String
 Medium  |  Tags: Array, Hash Table, String, Backtracking
 https://leetcode.com/problems/find-unique-binary-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of strings nums containing n unique binary strings each
  of length n, return a binary string of length n that does not appear in
  nums. If there are multiple answers, you may return any of them.

CONSTRAINTS
  n == nums.length
  1 <= n <= 16
  nums[i].length == n
  nums[i] is either '0' or '1'.
  All the strings of nums are unique.

TEST CASES
  [1] Input    : nums = ["01","10"]
      Expected : "11"
      Why      : "11" does not appear in nums. "00" would also be correct.

  [2] Input    : nums = ["00","01"]
      Expected : "11"
      Why      : "11" does not appear in nums. "10" would also be correct.

  [3] Input    : nums = ["111","011","001"]
      Expected : "101"
      Why      : "101" does not appear in nums. "000", "010", "100", and "110" would also be correct.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string findDifferentBinaryString(vector<string>& nums);
