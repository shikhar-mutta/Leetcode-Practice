 1991. Find the Middle Index in Array
 Easy  |  Tags: Array, Prefix Sum
 https://leetcode.com/problems/find-the-middle-index-in-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed integer array nums, find the leftmost middleIndex
  (i.e., the smallest amongst all the possible ones).

  A middleIndex is an index where nums[0] + nums[1] + ... +
  nums[middleIndex-1] == nums[middleIndex+1] + nums[middleIndex+2] + ... +
  nums[nums.length-1].

  If middleIndex == 0, the left side sum is considered to be 0. Similarly,
  if middleIndex == nums.length - 1, the right side sum is considered to
  be 0.

  Return the leftmost middleIndex that satisfies the condition, or -1 if
  there is no such index.

CONSTRAINTS
  1 <= nums.length <= 100
  -1000 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [2,3,-1,8,4]
      Expected : 3
      Why      : The sum of the numbers before index 3 is: 2 + 3 + -1 = 4
                 The sum of the numbers after index 3 is: 4 = 4

  [2] Input    : nums = [1,-1,4]
      Expected : 2
      Why      : The sum of the numbers before index 2 is: 1 + -1 = 0
                 The sum of the numbers after index 2 is: 0

  [3] Input    : nums = [2,5]
      Expected : -1
      Why      : There is no valid middleIndex.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findMiddleIndex(vector<int>& nums);
