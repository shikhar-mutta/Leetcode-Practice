 1996. The Number of Weak Characters in the Game
 Medium  |  Tags: Array, Stack, Greedy, Sorting, Monotonic Stack
 https://leetcode.com/problems/the-number-of-weak-characters-in-the-game/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are playing a game that contains multiple characters, and each of
  the characters has two main properties: attack and defense. You are
  given a 2D integer array properties where properties[i] = [attacki,
  defensei] represents the properties of the i^th character in the game.

  A character is said to be weak if any other character has both attack
  and defense levels strictly greater than this character's attack and
  defense levels. More formally, a character i is said to be weak if there
  exists another character j where attackj > attacki and defensej >
  defensei.

  Return the number of weak characters.

CONSTRAINTS
  2 <= properties.length <= 10^5
  properties[i].length == 2
  1 <= attacki, defensei <= 10^5

TEST CASES
  [1] Input    : properties = [[5,5],[6,3],[3,6]]
      Expected : 0
      Why      : No character has strictly greater attack and defense than the other.

  [2] Input    : properties = [[2,2],[3,3]]
      Expected : 1
      Why      : The first character is weak because the second character has a strictly greater attack and defense.

  [3] Input    : properties = [[1,5],[10,4],[4,3]]
      Expected : 1
      Why      : The third character is weak because the second character has a strictly greater attack and defense.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfWeakCharacters(vector<vector<int>>& properties);
