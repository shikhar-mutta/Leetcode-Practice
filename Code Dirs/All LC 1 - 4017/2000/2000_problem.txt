 2000. Reverse Prefix of Word
 Easy  |  Tags: Two Pointers, String, Stack
 https://leetcode.com/problems/reverse-prefix-of-word/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed string word and a character ch, reverse the segment of
  word that starts at index 0 and ends at the index of the first
  occurrence of ch (inclusive). If the character ch does not exist in
  word, do nothing.

  - For example, if word = "abcdefd" and ch = "d", then you should reverse
    the segment that starts at 0 and ends at 3 (inclusive). The resulting
    string will be "dcbaefd".

  Return the resulting string.

CONSTRAINTS
  1 <= word.length <= 250
  word consists of lowercase English letters.
  ch is a lowercase English letter.

TEST CASES
  [1] Input    : word = "abcdefd", ch = "d"
      Expected : "dcbaefd"
      Why      : The first occurrence of "d" is at index 3.
                 Reverse the part of word from 0 to 3 (inclusive), the resulting string is "dcbaefd".

  [2] Input    : word = "xyxzxe", ch = "z"
      Expected : "zxyxxe"
      Why      : The first and only occurrence of "z" is at index 3.
                 Reverse the part of word from 0 to 3 (inclusive), the resulting string is "zxyxxe".

  [3] Input    : word = "abcd", ch = "z"
      Expected : "abcd"
      Why      : "z" does not exist in word.
                 You should not do any reverse operation, the resulting string is "abcd".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string reversePrefix(string word, char ch);
