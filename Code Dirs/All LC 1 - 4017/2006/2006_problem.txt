 2006. Count Number of Pairs With Absolute Difference K
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/count-number-of-pairs-with-absolute-difference-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums and an integer k, return the number of pairs
  (i, j) where i < j such that |nums[i] - nums[j]| == k.

  The value of |x| is defined as:

  - x if x >= 0.

  - -x if x < 0.

CONSTRAINTS
  1 <= nums.length <= 200
  1 <= nums[i] <= 100
  1 <= k <= 99

TEST CASES
  [1] Input    : nums = [1,2,2,1], k = 1
      Expected : 4
      Why      : The pairs with an absolute difference of 1 are:
                 - [1,2,2,1]
                 - [1,2,2,1]
                 … (2 more)

  [2] Input    : nums = [1,3], k = 3
      Expected : 0
      Why      : There are no pairs with an absolute difference of 3.

  [3] Input    : nums = [3,2,1,5,4], k = 2
      Expected : 3
      Why      : The pairs with an absolute difference of 2 are:
                 - [3,2,1,5,4]
                 - [3,2,1,5,4]
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countKDifference(vector<int>& nums, int k);

  edit : 2006.cpp
