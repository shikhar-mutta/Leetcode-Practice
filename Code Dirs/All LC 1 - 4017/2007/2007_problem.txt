 2007. Find Original Array From Doubled Array
 Medium  |  Tags: Array, Hash Table, Greedy, Sorting
 https://leetcode.com/problems/find-original-array-from-doubled-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An integer array original is transformed into a doubled array changed by
  appending twice the value of every element in original, and then
  randomly shuffling the resulting array.

  Given an array changed, return original if changed is a doubled array.
  If changed is not a doubled array, return an empty array. The elements
  in original may be returned in any order.

CONSTRAINTS
  1 <= changed.length <= 10^5
  0 <= changed[i] <= 10^5

TEST CASES
  [1] Input    : changed = [1,3,4,2,6,8]
      Expected : [1,3,4]
      Why      : One possible original array could be [1,3,4]:
                 - Twice the value of 1 is 1 * 2 = 2.
                 - Twice the value of 3 is 3 * 2 = 6.
                 … (2 more)

  [2] Input    : changed = [6,3,0,1]
      Expected : []
      Why      : changed is not a doubled array.

  [3] Input    : changed = [1]
      Expected : []
      Why      : changed is not a doubled array.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> findOriginalArray(vector<int>& changed);

FILES
  edit : 2007.cpp
  test : lc run 2007
