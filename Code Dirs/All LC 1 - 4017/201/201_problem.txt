 201. Bitwise AND of Numbers Range
 Medium  |  Tags: Bit Manipulation
 https://leetcode.com/problems/bitwise-and-of-numbers-range/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integers left and right that represent the range [left,
  right], return the bitwise AND of all numbers in this range, inclusive.

CONSTRAINTS
  0 <= left <= right <= 2^31 - 1

TEST CASES
  [1] Input    : left = 5, right = 7
      Expected : 4

  [2] Input    : left = 0, right = 0
      Expected : 0

  [3] Input    : left = 1, right = 2147483647
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int rangeBitwiseAnd(int left, int right);

FILES
  edit : 201.cpp
  test : lc run 201
