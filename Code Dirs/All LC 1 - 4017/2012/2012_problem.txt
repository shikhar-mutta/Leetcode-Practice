 2012. Sum of Beauty in the Array
 Medium  |  Tags: Array
 https://leetcode.com/problems/sum-of-beauty-in-the-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums. For each index i (1 <= i
  <= nums.length - 2) the beauty of nums[i] equals:

  - 2, if nums[j] < nums[i] < nums[k], for all 0 <= j < i and for all i <
    k <= nums.length - 1.

  - 1, if nums[i - 1] < nums[i] < nums[i + 1], and the previous condition
    is not satisfied.

  - 0, if none of the previous conditions holds.

  Return the sum of beauty of all nums[i] where 1 <= i <= nums.length - 2.

CONSTRAINTS
  3 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [1,2,3]
      Expected : 2
      Why      : For each index i in the range 1 <= i <= 1:
                 - The beauty of nums[1] equals 2.

  [2] Input    : nums = [2,4,6,4]
      Expected : 1
      Why      : For each index i in the range 1 <= i <= 2:
                 - The beauty of nums[1] equals 1.
                 - The beauty of nums[2] equals 0.

  [3] Input    : nums = [3,2,1]
      Expected : 0
      Why      : For each index i in the range 1 <= i <= 1:
                 - The beauty of nums[1] equals 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumOfBeauties(vector<int>& nums);
