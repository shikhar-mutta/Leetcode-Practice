 203. Remove Linked List Elements
 Easy  |  Tags: Linked List, Recursion
 https://leetcode.com/problems/remove-linked-list-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the head of a linked list and an integer val, remove all the nodes
  of the linked list that has Node.val == val, and return the new head.

CONSTRAINTS
  The number of nodes in the list is in the range [0, 10^4].
  1 <= Node.val <= 50
  0 <= val <= 50

TEST CASES
  [1] Input    : head = [1,2,6,3,4,5,6], val = 6
      Expected : [1,2,3,4,5]

  [2] Input    : head = [], val = 1
      Expected : []

  [3] Input    : head = [7,7,7,7], val = 7
      Expected : []

CODE TYPE
  function · linked list
    driver: one Solution call per test case
    linked list: ListNode* — values in order, e.g. [1,2,3,4]

SIGNATURE
  ListNode* removeElements(ListNode* head, int val);

FILES
  edit : 203.cpp
  test : lc run 203
