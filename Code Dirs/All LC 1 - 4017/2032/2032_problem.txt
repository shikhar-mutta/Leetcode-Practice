 2032. Two Out of Three
 Easy  |  Tags: Array, Hash Table, Bit Manipulation
 https://leetcode.com/problems/two-out-of-three/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given three integer arrays nums1, nums2, and nums3, return a distinct
  array containing all the values that are present in at least two out of
  the three arrays. You may return the values in any order.

CONSTRAINTS
  1 <= nums1.length, nums2.length, nums3.length <= 100
  1 <= nums1[i], nums2[j], nums3[k] <= 100

TEST CASES
  [1] Input    : nums1 = [1,1,3,2], nums2 = [2,3], nums3 = [3]
      Expected : [3,2]
      Why      : The values that are present in at least two arrays are:
                 - 3, in all three arrays.
                 - 2, in nums1 and nums2.

  [2] Input    : nums1 = [3,1], nums2 = [2,3], nums3 = [1,2]
      Expected : [2,3,1]
      Why      : The values that are present in at least two arrays are:
                 - 2, in nums2 and nums3.
                 - 3, in nums1 and nums2.
                 … (1 more)

  [3] Input    : nums1 = [1,2,2], nums2 = [4,3,3], nums3 = [5]
      Expected : []
      Why      : No value is present in at least two arrays.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> twoOutOfThree(vector<int>& nums1, vector<int>& nums2, vector<int>& nums3);

FILES
  edit : 2032.cpp
  test : lc run 2032
