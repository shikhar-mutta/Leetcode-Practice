 2040. Kth Smallest Product of Two Sorted Arrays
 Hard  |  Tags: Array, Binary Search
 https://leetcode.com/problems/kth-smallest-product-of-two-sorted-arrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two sorted 0-indexed integer arrays nums1 and nums2 as well as an
  integer k, return the k^th (1-based) smallest product of nums1[i] *
  nums2[j] where 0 <= i < nums1.length and 0 <= j < nums2.length.

CONSTRAINTS
  1 <= nums1.length, nums2.length <= 5 * 10^4
  -10^5 <= nums1[i], nums2[j] <= 10^5
  1 <= k <= nums1.length * nums2.length
  nums1 and nums2 are sorted.

TEST CASES
  [1] Input    : nums1 = [2,5], nums2 = [3,4], k = 2
      Expected : 8
      Why      : The 2 smallest products are:
                 - nums1[0] * nums2[0] = 2 * 3 = 6
                 - nums1[0] * nums2[1] = 2 * 4 = 8
                 … (1 more)

  [2] Input    : nums1 = [-4,-2,0,3], nums2 = [2,4], k = 6
      Expected : 0
      Why      : The 6 smallest products are:
                 - nums1[0] * nums2[1] = (-4) * 4 = -16
                 - nums1[0] * nums2[0] = (-4) * 2 = -8
                 … (5 more)

  [3] Input    : nums1 = [-2,-1,0,1,2], nums2 = [-3,-1,2,4,5], k = 3
      Expected : -6
      Why      : The 3 smallest products are:
                 - nums1[0] * nums2[4] = (-2) * 5 = -10
                 - nums1[0] * nums2[3] = (-2) * 4 = -8
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long kthSmallestProduct(vector<int>& nums1, vector<int>& nums2, long long k);
