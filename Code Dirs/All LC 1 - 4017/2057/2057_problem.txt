 2057. Smallest Index With Equal Value
 Easy  |  Tags: Array
 https://leetcode.com/problems/smallest-index-with-equal-value/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed integer array nums, return the smallest index i of
  nums such that i mod 10 == nums[i], or -1 if such index does not exist.

  x mod y denotes the remainder when x is divided by y.

CONSTRAINTS
  1 <= nums.length <= 100
  0 <= nums[i] <= 9

TEST CASES
  [1] Input    : nums = [0,1,2]
      Expected : 0
      Why      : i=0: 0 mod 10 = 0 == nums[0].
                 i=1: 1 mod 10 = 1 == nums[1].
                 i=2: 2 mod 10 = 2 == nums[2].
                 … (1 more)

  [2] Input    : nums = [4,3,2,1]
      Expected : 2
      Why      : i=0: 0 mod 10 = 0 != nums[0].
                 i=1: 1 mod 10 = 1 != nums[1].
                 i=2: 2 mod 10 = 2 == nums[2].
                 … (2 more)

  [3] Input    : nums = [1,2,3,4,5,6,7,8,9,0]
      Expected : -1
      Why      : No index satisfies i mod 10 == nums[i].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int smallestEqual(vector<int>& nums);
