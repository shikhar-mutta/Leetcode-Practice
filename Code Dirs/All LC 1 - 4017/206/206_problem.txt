 206. Reverse Linked List
 Easy  |  Tags: Linked List, Recursion
 https://leetcode.com/problems/reverse-linked-list/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the head of a singly linked list, reverse the list, and return the
  reversed list.

CONSTRAINTS
  The number of nodes in the list is the range [0, 5000].
  -5000 <= Node.val <= 5000

TEST CASES
  [1] Input    : head = [1,2,3,4,5]
      Expected : [5,4,3,2,1]

  [2] Input    : head = [1,2]
      Expected : [2,1]

  [3] Input    : head = []
      Expected : []

FOLLOW UP
  A linked list can be reversed either iteratively or recursively. Could
  you implement both?

CODE TYPE
  function · linked list
    driver: one Solution call per test case
    linked list: ListNode* — values in order, e.g. [1,2,3,4]

SIGNATURE
  ListNode* reverseList(ListNode* head);
