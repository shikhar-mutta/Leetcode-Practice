 2085. Count Common Words With One Occurrence
 Easy  |  Tags: Array, Hash Table, String, Counting
 https://leetcode.com/problems/count-common-words-with-one-occurrence/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two string arrays words1 and words2, return the number of strings
  that appear exactly once in each of the two arrays.

CONSTRAINTS
  1 <= words1.length, words2.length <= 1000
  1 <= words1[i].length, words2[j].length <= 30
  words1[i] and words2[j] consists only of lowercase English letters.

TEST CASES
  [1] Input    : words1 = ["leetcode","is","amazing","as","is"], words2 = ["amazing","leetcode","is"]
      Expected : 2
      Why      : - "leetcode" appears exactly once in each of the two arrays. We count this string.
                 - "amazing" appears exactly once in each of the two arrays. We count this string.
                 - "is" appears in each of the two arrays, but there are 2 occurrences of it in words1. We do not count this string.
                 … (2 more)

  [2] Input    : words1 = ["b","bb","bbb"], words2 = ["a","aa","aaa"]
      Expected : 0
      Why      : There are no strings that appear in each of the two arrays.

  [3] Input    : words1 = ["a","ab"], words2 = ["a","a","a","ab"]
      Expected : 1
      Why      : The only string that appears exactly once in each of the two arrays is "ab".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countWords(vector<string>& words1, vector<string>& words2);
