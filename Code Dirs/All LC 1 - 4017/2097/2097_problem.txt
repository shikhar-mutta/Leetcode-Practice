 2097. Valid Arrangement of Pairs
 Hard  |  Tags: Array, Depth-First Search, Graph Theory, Eulerian Circuit, Eulerian Path, Semi-Eulerian Graph
 https://leetcode.com/problems/valid-arrangement-of-pairs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed 2D integer array pairs where pairs[i] =
  [starti, endi]. An arrangement of pairs is valid if for every index i
  where 1 <= i < pairs.length, we have endi-1 == starti.

  Return any valid arrangement of pairs.

  Note: The inputs will be generated such that there exists a valid
  arrangement of pairs.

CONSTRAINTS
  1 <= pairs.length <= 10^5
  pairs[i].length == 2
  0 <= starti, endi <= 10^9
  starti != endi
  No two pairs are exactly the same.
  There exists a valid arrangement of pairs.

TEST CASES
  [1] Input    : pairs = [[5,1],[4,5],[11,9],[9,4]]
      Expected : [[11,9],[9,4],[4,5],[5,1]]
      Why      : This is a valid arrangement since endi-1 always equals starti.
                 end0 = 9 == 9 = start1
                 end1 = 4 == 4 = start2
                 … (1 more)

  [2] Input    : pairs = [[1,3],[3,2],[2,1]]
      Expected : [[1,3],[3,2],[2,1]]
      Why      : This is a valid arrangement since endi-1 always equals starti.
                 end0 = 3 == 3 = start1
                 end1 = 2 == 2 = start2
                 … (1 more)

  [3] Input    : pairs = [[1,2],[1,3],[2,1]]
      Expected : [[1,2],[2,1],[1,3]]
      Why      : This is a valid arrangement since endi-1 always equals starti.
                 end0 = 2 == 2 = start1
                 end1 = 1 == 1 = start2

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> validArrangement(vector<vector<int>>& pairs);
