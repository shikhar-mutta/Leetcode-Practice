 2104. Sum of Subarray Ranges
 Medium  |  Tags: Array, Stack, Monotonic Stack
 https://leetcode.com/problems/sum-of-subarray-ranges/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. The range of a subarray of nums is
  the difference between the largest and smallest element in the subarray.

  Return the sum of all subarray ranges of nums.

  A subarray is a contiguous non-empty sequence of elements within an
  array.

CONSTRAINTS
  1 <= nums.length <= 1000
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,2,3]
      Expected : 4
      Why      : The 6 subarrays of nums are the following:
                 [1], range = largest - smallest = 1 - 1 = 0
                 [2], range = 2 - 2 = 0
                 … (5 more)

  [2] Input    : nums = [1,3,3]
      Expected : 4
      Why      : The 6 subarrays of nums are the following:
                 [1], range = largest - smallest = 1 - 1 = 0
                 [3], range = 3 - 3 = 0
                 … (5 more)

  [3] Input    : nums = [4,-2,-3,4,1]
      Expected : 59
      Why      : The sum of all subarray ranges of nums is 59.

FOLLOW UP
  Could you find a solution with O(n) time complexity?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long subArrayRanges(vector<int>& nums);
