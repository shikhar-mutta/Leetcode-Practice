 2116. Check if a Parentheses String Can Be Valid
 Medium  |  Tags: String, Stack, Greedy, Bracket Sequences
 https://leetcode.com/problems/check-if-a-parentheses-string-can-be-valid/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A parentheses string is a non-empty string consisting only of '(' and
  ')'. It is valid if any of the following conditions is true:

  - It is ().

  - It can be written as AB (A concatenated with B), where A and B are
    valid parentheses strings.

  - It can be written as (A), where A is a valid parentheses string.

  You are given a parentheses string s and a string locked, both of length
  n. locked is a binary string consisting only of '0's and '1's. For each
  index i of locked,

  - If locked[i] is '1', you cannot change s[i].

  - But if locked[i] is '0', you can change s[i] to either '(' or ')'.

  Return true if you can make s a valid parentheses string. Otherwise,
  return false.

CONSTRAINTS
  n == s.length == locked.length
  1 <= n <= 10^5
  s[i] is either '(' or ')'.
  locked[i] is either '0' or '1'.

TEST CASES
  [1] Input    : s = "))()))", locked = "010100"
      Expected : true
      Why      : locked[1] == '1' and locked[3] == '1', so we cannot change s[1] or s[3].
                 We change s[0] and s[4] to '(' while leaving s[2] and s[5] unchanged to make s valid.

  [2] Input    : s = "()()", locked = "0000"
      Expected : true
      Why      : We do not need to make any changes because s is already valid.

  [3] Input    : s = ")", locked = "0"
      Expected : false
      Why      : locked permits us to change s[0].
                 Changing s[0] to either '(' or ')' will not make s valid.

  [4] Input    : s = "(((())(((())", locked = "111111010111"
      Expected : true
      Why      : locked permits us to change s[6] and s[8].
                 We change s[6] and s[8] to ')' to make s valid.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canBeValid(string s, string locked);
