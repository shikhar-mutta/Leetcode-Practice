 2124. Check if All A's Appears Before All B's
 Easy  |  Tags: String
 https://leetcode.com/problems/check-if-all-as-appears-before-all-bs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s consisting of only the characters 'a' and 'b', return
  true if every 'a' appears before every 'b' in the string. Otherwise,
  return false.

CONSTRAINTS
  1 <= s.length <= 100
  s[i] is either 'a' or 'b'.

TEST CASES
  [1] Input    : s = "aaabbb"
      Expected : true
      Why      : The 'a's are at indices 0, 1, and 2, while the 'b's are at indices 3, 4, and 5.
                 Hence, every 'a' appears before every 'b' and we return true.

  [2] Input    : s = "abab"
      Expected : false
      Why      : There is an 'a' at index 2 and a 'b' at index 1.
                 Hence, not every 'a' appears before every 'b' and we return false.

  [3] Input    : s = "bbb"
      Expected : true
      Why      : There are no 'a's, hence, every 'a' appears before every 'b' and we return true.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool checkString(string s);
