 214. Shortest Palindrome
 Hard  |  Tags: String, Rolling Hash, String Matching, Hash Function, Manacher, Z Algorithm, Knuth–Morris–Pratt Algorithm
 https://leetcode.com/problems/shortest-palindrome/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s. You can convert s to a palindrome by adding
  characters in front of it.

  Return the shortest palindrome you can find by performing this
  transformation.

CONSTRAINTS
  0 <= s.length <= 5 * 10^4
  s consists of lowercase English letters only.

TEST CASES
  [1] Input    : s = "aacecaaa"
      Expected : "aaacecaaa"

  [2] Input    : s = "abcd"
      Expected : "dcbabcd"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string shortestPalindrome(string s);

FILES
  edit : 214.cpp
  test : lc run 214
