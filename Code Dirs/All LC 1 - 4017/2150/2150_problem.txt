 2150. Find All Lonely Numbers in the Array
 Medium  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/find-all-lonely-numbers-in-the-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. A number x is lonely when it
  appears only once, and no adjacent numbers (i.e. x + 1 and x - 1) appear
  in the array.

  Return all lonely numbers in nums. You may return the answer in any
  order.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= nums[i] <= 10^6

TEST CASES
  [1] Input    : nums = [10,6,5,8]
      Expected : [10,8]
      Why      : - 10 is a lonely number since it appears exactly once and 9 and 11 does not appear in nums.
                 - 8 is a lonely number since it appears exactly once and 7 and 9 does not appear in nums.
                 - 5 is not a lonely number since 6 appears in nums and vice versa.
                 … (2 more)

  [2] Input    : nums = [1,3,5,3]
      Expected : [1,5]
      Why      : - 1 is a lonely number since it appears exactly once and 0 and 2 does not appear in nums.
                 - 5 is a lonely number since it appears exactly once and 4 and 6 does not appear in nums.
                 - 3 is not a lonely number since it appears twice.
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> findLonely(vector<int>& nums);
