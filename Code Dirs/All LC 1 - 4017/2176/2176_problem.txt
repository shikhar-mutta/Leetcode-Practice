 2176. Count Equal and Divisible Pairs in an Array
 Easy  |  Tags: Array
 https://leetcode.com/problems/count-equal-and-divisible-pairs-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed integer array nums of length n and an integer k,
  return the number of pairs (i, j) where 0 <= i < j < n, such that
  nums[i] == nums[j] and (i * j) is divisible by k.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i], k <= 100

TEST CASES
  [1] Input    : nums = [3,1,2,2,2,1,3], k = 2
      Expected : 4
      Why      : There are 4 pairs that meet all the requirements:
                 - nums[0] == nums[6], and 0 * 6 == 0, which is divisible by 2.
                 - nums[2] == nums[3], and 2 * 3 == 6, which is divisible by 2.
                 … (2 more)

  [2] Input    : nums = [1,2,3,4], k = 1
      Expected : 0
      Why      : Since no value in nums is repeated, there are no pairs (i,j) that meet all the requirements.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPairs(vector<int>& nums, int k);
