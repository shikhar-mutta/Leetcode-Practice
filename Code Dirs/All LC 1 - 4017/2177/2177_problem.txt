 2177. Find Three Consecutive Integers That Sum to a Given Number
 Medium  |  Tags: Math, Simulation
 https://leetcode.com/problems/find-three-consecutive-integers-that-sum-to-a-given-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer num, return three consecutive integers (as a sorted
  array) that sum to num. If num cannot be expressed as the sum of three
  consecutive integers, return an empty array.

CONSTRAINTS
  0 <= num <= 10^15

TEST CASES
  [1] Input    : num = 33
      Expected : [10,11,12]
      Why      : 33 can be expressed as 10 + 11 + 12 = 33.
                 10, 11, 12 are 3 consecutive integers, so we return [10, 11, 12].

  [2] Input    : num = 4
      Expected : []
      Why      : There is no way to express 4 as the sum of 3 consecutive integers.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<long long> sumOfThree(long long num);

FILES
  edit : 2177.cpp
  test : lc run 2177
