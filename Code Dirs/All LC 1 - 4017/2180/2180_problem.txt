 2180. Count Integers With Even Digit Sum
 Easy  |  Tags: Math, Simulation
 https://leetcode.com/problems/count-integers-with-even-digit-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a positive integer num, return the number of positive integers
  less than or equal to num whose digit sums are even.

  The digit sum of a positive integer is the sum of all its digits.

CONSTRAINTS
  1 <= num <= 1000

TEST CASES
  [1] Input    : num = 4
      Expected : 2
      Why      : The only integers less than or equal to 4 whose digit sums are even are 2 and 4.

  [2] Input    : num = 30
      Expected : 14
      Why      : The 14 integers less than or equal to 30 whose digit sums are even are
                 2, 4, 6, 8, 11, 13, 15, 17, 19, 20, 22, 24, 26, and 28.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countEven(int num);

FILES
  edit : 2180.cpp
  test : lc run 2180
