 2183. Count Array Pairs Divisible by K
 Hard  |  Tags: Array, Hash Table, Math, Counting, Number Theory, Euclidean Algorithm, Greatest Common Divisor
 https://leetcode.com/problems/count-array-pairs-divisible-by-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed integer array nums of length n and an integer k,
  return the number of pairs (i, j) such that:

  - 0 <= i < j <= n - 1 and

  - nums[i] * nums[j] is divisible by k.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i], k <= 10^5

TEST CASES
  [1] Input    : nums = [1,2,3,4,5], k = 2
      Expected : 7
      Why      : The 7 pairs of indices whose corresponding products are divisible by 2 are
                 (0, 1), (0, 3), (1, 2), (1, 3), (1, 4), (2, 3), and (3, 4).
                 Their products are 2, 4, 6, 8, 10, 12, and 20 respectively.
                 … (1 more)

  [2] Input    : nums = [1,2,3,4], k = 5
      Expected : 0
      Why      : There does not exist any pair of indices whose corresponding product is divisible by 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countPairs(vector<int>& nums, int k);
