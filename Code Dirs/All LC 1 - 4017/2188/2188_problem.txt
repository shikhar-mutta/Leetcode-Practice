 2188. Minimum Time to Finish the Race
 Hard  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/minimum-time-to-finish-the-race/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed 2D integer array tires where tires[i] = [fi,
  ri] indicates that the i^th tire can finish its x^th successive lap in
  fi * ri^(x-1) seconds.

  - For example, if fi = 3 and ri = 2, then the tire would finish its 1^st
    lap in 3 seconds, its 2^nd lap in 3 * 2 = 6 seconds, its 3^rd lap in 3
    * 2^2 = 12 seconds, etc.

  You are also given an integer changeTime and an integer numLaps.

  The race consists of numLaps laps and you may start the race with any
  tire. You have an unlimited supply of each tire and after every lap, you
  may change to any given tire (including the current tire type) if you
  wait changeTime seconds.

  Return the minimum time to finish the race.

CONSTRAINTS
  1 <= tires.length <= 10^5
  tires[i].length == 2
  1 <= fi, changeTime <= 10^5
  2 <= ri <= 10^5
  1 <= numLaps <= 1000

TEST CASES
  [1] Input    : tires = [[2,3],[3,4]], changeTime = 5, numLaps = 4
      Expected : 21
      Why      : Lap 1: Start with tire 0 and finish the lap in 2 seconds.
                 Lap 2: Continue with tire 0 and finish the lap in 2 * 3 = 6 seconds.
                 Lap 3: Change tires to a new tire 0 for 5 seconds and then finish the lap in another 2 seconds.
                 … (3 more)

  [2] Input    : tires = [[1,10],[2,2],[3,4]], changeTime = 6, numLaps = 5
      Expected : 25
      Why      : Lap 1: Start with tire 1 and finish the lap in 2 seconds.
                 Lap 2: Continue with tire 1 and finish the lap in 2 * 2 = 4 seconds.
                 Lap 3: Change tires to a new tire 1 for 6 seconds and then finish the lap in another 2 seconds.
                 … (4 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumFinishTime(vector<vector<int>>& tires, int changeTime, int numLaps);
