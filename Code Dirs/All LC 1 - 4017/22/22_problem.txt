 22. Generate Parentheses
 Medium  |  Tags: String, Dynamic Programming, Backtracking, Bracket Sequences
 https://leetcode.com/problems/generate-parentheses/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given n pairs of parentheses, write a function to generate all
  combinations of well-formed parentheses.

CONSTRAINTS
  1 <= n <= 8

TEST CASES
  [1] Input    : n = 3
      Expected : ["((()))","(()())","(())()","()(())","()()()"]

  [2] Input    : n = 1
      Expected : ["()"]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<string> generateParenthesis(int n);

FILES
  edit : 22.cpp
  test : lc run 22
