 2200. Find All K-Distant Indices in an Array
 Easy  |  Tags: Array, Two Pointers
 https://leetcode.com/problems/find-all-k-distant-indices-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums and two integers key and k.
  A k-distant index is an index i of nums for which there exists at least
  one index j such that |i - j| <= k and nums[j] == key.

  Return a list of all k-distant indices sorted in increasing order.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 1000
  key is an integer from the array nums.
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [3,4,9,1,3,9,5], key = 9, k = 1
      Expected : [1,2,3,4,5,6]
      Why      : Here, nums[2] == key and nums[5] == key.
                 - For index 0, |0 - 2| > k and |0 - 5| > k, so there is no j where |0 - j| <= k and nums[j] == key. Thus, 0 is not a k-distant index.
                 - For index 1, |1 - 2| <= k and nums[2] == key, so 1 is a k-distant index.
                 … (6 more)

  [2] Input    : nums = [2,2,2,2,2], key = 2, k = 2
      Expected : [0,1,2,3,4]
      Why      : For all indices i in nums, there exists some index j such that |i - j| <= k and nums[j] == key, so every index is a k-distant index.
                 Hence, we return [0,1,2,3,4].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> findKDistantIndices(vector<int>& nums, int key, int k);
