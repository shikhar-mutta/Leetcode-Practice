 2236. Root Equals Sum of Children
 Easy  |  Tags: Tree, Binary Tree
 https://leetcode.com/problems/root-equals-sum-of-children/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the root of a binary tree that consists of exactly 3
  nodes: the root, its left child, and its right child.

  Return true if the value of the root is equal to the sum of the values
  of its two children, or false otherwise.

CONSTRAINTS
  The tree consists only of the root, its left child, and its right child.
  -100 <= Node.val <= 100

TEST CASES
  [1] Input    : root = [10,4,6]
      Expected : true
      Why      : The values of the root, its left child, and its right child are 10, 4, and 6, respectively.
                 10 is equal to 4 + 6, so we return true.

  [2] Input    : root = [5,3,1]
      Expected : false
      Why      : The values of the root, its left child, and its right child are 5, 3, and 1, respectively.
                 5 is not equal to 3 + 1, so we return false.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  bool checkTree(TreeNode* root);
