 2239. Find Closest Number to Zero
 Easy  |  Tags: Array
 https://leetcode.com/problems/find-closest-number-to-zero/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums of size n, return the number with the value
  closest to 0 in nums. If there are multiple answers, return the number
  with the largest value.

CONSTRAINTS
  1 <= n <= 1000
  -10^5 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [-4,-2,1,4,8]
      Expected : 1
      Why      : The distance from -4 to 0 is |-4| = 4.
                 The distance from -2 to 0 is |-2| = 2.
                 The distance from 1 to 0 is |1| = 1.
                 … (3 more)

  [2] Input    : nums = [2,-1,1]
      Expected : 1
      Why      : 1 and -1 are both the closest numbers to 0, so 1 being larger is returned.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findClosestNumber(vector<int>& nums);
