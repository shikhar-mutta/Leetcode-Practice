 2259. Remove Digit From Number to Maximize Result
 Easy  |  Tags: String, Greedy, Enumeration
 https://leetcode.com/problems/remove-digit-from-number-to-maximize-result/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string number representing a positive integer and a
  character digit.

  Return the resulting string after removing exactly one occurrence of
  digit from number such that the value of the resulting string in decimal
  form is maximized. The test cases are generated such that digit occurs
  at least once in number.

CONSTRAINTS
  2 <= number.length <= 100
  number consists of digits from '1' to '9'.
  digit is a digit from '1' to '9'.
  digit occurs at least once in number.

TEST CASES
  [1] Input    : number = "123", digit = "3"
      Expected : "12"
      Why      : There is only one '3' in "123". After removing '3', the result is "12".

  [2] Input    : number = "1231", digit = "1"
      Expected : "231"
      Why      : We can remove the first '1' to get "231" or remove the second '1' to get "123".
                 Since 231 > 123, we return "231".

  [3] Input    : number = "551", digit = "5"
      Expected : "51"
      Why      : We can remove either the first or second '5' from "551".
                 Both result in the string "51".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string removeDigit(string number, char digit);
