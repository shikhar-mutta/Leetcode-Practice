 2260. Minimum Consecutive Cards to Pick Up
 Medium  |  Tags: Array, Hash Table, Sliding Window
 https://leetcode.com/problems/minimum-consecutive-cards-to-pick-up/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array cards where cards[i] represents the value
  of the i^th card. A pair of cards are matching if the cards have the
  same value.

  Return the minimum number of consecutive cards you have to pick up to
  have a pair of matching cards among the picked cards. If it is
  impossible to have matching cards, return -1.

CONSTRAINTS
  1 <= cards.length <= 10^5
  0 <= cards[i] <= 10^6

TEST CASES
  [1] Input    : cards = [3,4,2,3,4,7]
      Expected : 4
      Why      : We can pick up the cards [3,4,2,3] which contain a matching pair of cards with value 3. Note that picking up the cards [4,2,3,4] is also optimal.

  [2] Input    : cards = [1,0,5,3]
      Expected : -1
      Why      : There is no way to pick up a set of consecutive cards that contain a pair of matching cards.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumCardPickup(vector<int>& cards);
