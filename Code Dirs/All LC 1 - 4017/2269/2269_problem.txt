 2269. Find the K-Beauty of a Number
 Easy  |  Tags: Math, String, Sliding Window
 https://leetcode.com/problems/find-the-k-beauty-of-a-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The k-beauty of an integer num is defined as the number of substrings of
  num when it is read as a string that meet the following conditions:

  - It has a length of k.

  - It is a divisor of num.

  Given integers num and k, return the k-beauty of num.

  Note:

  - Leading zeros are allowed.

  - 0 is not a divisor of any value.

  A substring is a contiguous sequence of characters in a string.

CONSTRAINTS
  1 <= num <= 10^9
  1 <= k <= num.length (taking num as a string)

TEST CASES
  [1] Input    : num = 240, k = 2
      Expected : 2
      Why      : The following are the substrings of num of length k:
                 - "24" from "240": 24 is a divisor of 240.
                 - "40" from "240": 40 is a divisor of 240.
                 … (1 more)

  [2] Input    : num = 430043, k = 2
      Expected : 2
      Why      : The following are the substrings of num of length k:
                 - "43" from "430043": 43 is a divisor of 430043.
                 - "30" from "430043": 30 is not a divisor of 430043.
                 … (4 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int divisorSubstrings(int num, int k);
