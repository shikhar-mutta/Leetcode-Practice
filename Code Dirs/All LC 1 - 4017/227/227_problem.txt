 227. Basic Calculator II
 Medium  |  Tags: Math, String, Stack
 https://leetcode.com/problems/basic-calculator-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s which represents an expression, evaluate this
  expression and return its value.

  The integer division should truncate toward zero.

  You may assume that the given expression is always valid. All
  intermediate results will be in the range of [-2^31, 2^31 - 1].

  Note: You are not allowed to use any built-in function which evaluates
  strings as mathematical expressions, such as eval().

CONSTRAINTS
  1 <= s.length <= 3 * 10^5
  s consists of integers and operators ('+', '-', '*', '/') separated by some number of spaces.
  s represents a valid expression.
  All the integers in the expression are non-negative integers in the range [0, 2^31 - 1].
  The answer is guaranteed to fit in a 32-bit integer.

TEST CASES
  [1] Input    : s = "3+2*2"
      Expected : 7

  [2] Input    : s = " 3/2 "
      Expected : 1

  [3] Input    : s = " 3+5 / 2 "
      Expected : 5

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int calculate(string s);

FILES
  edit : 227.cpp
  test : lc run 227
