 2289. Steps to Make Array Non-decreasing
 Medium  |  Tags: Array, Linked List, Dynamic Programming, Stack, Monotonic Stack, Simulation
 https://leetcode.com/problems/steps-to-make-array-non-decreasing/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums. In one step, remove all
  elements nums[i] where nums[i - 1] > nums[i] for all 0 < i <
  nums.length.

  Return the number of steps performed until nums becomes a non-decreasing
  array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [5,3,4,4,7,3,6,11,8,5,11]
      Expected : 3
      Why      : The following are the steps performed:
                 - Step 1: [5,3,4,4,7,3,6,11,8,5,11] becomes [5,4,4,7,6,11,11]
                 - Step 2: [5,4,4,7,6,11,11] becomes [5,4,7,11,11]
                 … (2 more)

  [2] Input    : nums = [4,5,7,7,13]
      Expected : 0
      Why      : nums is already a non-decreasing array. Therefore, we return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int totalSteps(vector<int>& nums);
