 229. Majority Element II
 Medium  |  Tags: Array, Hash Table, Sorting, Counting, Boyer–Moore Majority Vote Algorithm
 https://leetcode.com/problems/majority-element-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array of size n, find all elements that appear more
  than ⌊n / 3⌋ times.

CONSTRAINTS
  1 <= nums.length <= 5 * 10^4
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [3,2,3]
      Expected : [3]

  [2] Input    : nums = [1]
      Expected : [1]

  [3] Input    : nums = [1,2]
      Expected : [1,2]

FOLLOW UP
  Could you solve the problem in linear time and in O(1) space?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> majorityElement(vector<int>& nums);

FILES
  edit : 229.cpp
  test : lc run 229
