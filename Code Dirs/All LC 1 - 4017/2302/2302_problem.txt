 2302. Count Subarrays With Score Less Than K
 Hard  |  Tags: Array, Binary Search, Sliding Window, Prefix Sum
 https://leetcode.com/problems/count-subarrays-with-score-less-than-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The score of an array is defined as the product of its sum and its
  length.

  - For example, the score of [1, 2, 3, 4, 5] is (1 + 2 + 3 + 4 + 5) * 5 =
    75.

  Given a positive integer array nums and an integer k, return the number
  of non-empty subarrays of nums whose score is strictly less than k.

  A subarray is a contiguous sequence of elements within an array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5
  1 <= k <= 10^15

TEST CASES
  [1] Input    : nums = [2,1,4,3,5], k = 10
      Expected : 6
      Why      : The 6 subarrays having scores less than 10 are:
                 - [2] with score 2 * 1 = 2.
                 - [1] with score 1 * 1 = 1.
                 … (5 more)

  [2] Input    : nums = [1,1,1], k = 5
      Expected : 5
      Why      : Every subarray except [1,1,1] has a score less than 5.
                 [1,1,1] has a score (1 + 1 + 1) * 3 = 9, which is greater than 5.
                 Thus, there are 5 subarrays having scores less than 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countSubarrays(vector<int>& nums, long long k);
