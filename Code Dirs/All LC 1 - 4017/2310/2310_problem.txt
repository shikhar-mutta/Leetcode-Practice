 2310. Sum of Numbers With Units Digit K
 Medium  |  Tags: Math, Dynamic Programming, Greedy, Enumeration
 https://leetcode.com/problems/sum-of-numbers-with-units-digit-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integers num and k, consider a set of positive integers with
  the following properties:

  - The units digit of each integer is k.

  - The sum of the integers is num.

  Return the minimum possible size of such a set, or -1 if no such set
  exists.

  Note:

  - The set can contain multiple instances of the same integer, and the
    sum of an empty set is considered 0.

  - The units digit of a number is the rightmost digit of the number.

CONSTRAINTS
  0 <= num <= 3000
  0 <= k <= 9

TEST CASES
  [1] Input    : num = 58, k = 9
      Expected : 2
      Why      : One valid set is [9,49], as the sum is 58 and each integer has a units digit of 9.
                 Another valid set is [19,39].
                 It can be shown that 2 is the minimum possible size of a valid set.

  [2] Input    : num = 37, k = 2
      Expected : -1
      Why      : It is not possible to obtain a sum of 37 using only integers that have a units digit of 2.

  [3] Input    : num = 0, k = 7
      Expected : 0
      Why      : The sum of an empty set is considered 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumNumbers(int num, int k);
