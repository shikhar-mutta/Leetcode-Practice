 2315. Count Asterisks
 Easy  |  Tags: String
 https://leetcode.com/problems/count-asterisks/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s, where every two consecutive vertical bars '|'
  are grouped into a pair. In other words, the 1^st and 2^nd '|' make a
  pair, the 3^rd and 4^th '|' make a pair, and so forth.

  Return the number of '*' in s, excluding the '*' between each pair of
  '|'.

  Note that each '|' will belong to exactly one pair.

CONSTRAINTS
  1 <= s.length <= 1000
  s consists of lowercase English letters, vertical bars '|', and asterisks '*'.
  s contains an even number of vertical bars '|'.

TEST CASES
  [1] Input    : s = "l|*e*et|c**o|*de|"
      Expected : 2
      Why      : The considered characters are underlined: "l|*e*et|c**o|*de|".
                 The characters between the first and second '|' are excluded from the answer.
                 Also, the characters between the third and fourth '|' are excluded from the answer.
                 … (1 more)

  [2] Input    : s = "iamprogrammer"
      Expected : 0
      Why      : In this example, there are no asterisks in s. Therefore, we return 0.

  [3] Input    : s = "yo|uar|e**|b|e***au|tifu|l"
      Expected : 5
      Why      : The considered characters are underlined: "yo|uar|e**|b|e***au|tifu|l". There are 5 asterisks considered. Therefore, we return 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countAsterisks(string s);
