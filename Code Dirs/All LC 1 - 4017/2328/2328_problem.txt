 2328. Number of Increasing Paths in a Grid
 Hard  |  Tags: Array, Dynamic Programming, Depth-First Search, Breadth-First Search, Graph Theory, Topological Sort, Memoization, Matrix
 https://leetcode.com/problems/number-of-increasing-paths-in-a-grid/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an m x n integer matrix grid, where you can move from a
  cell to any adjacent cell in all 4 directions.

  Return the number of strictly increasing paths in the grid such that you
  can start from any cell and end at any cell. Since the answer may be
  very large, return it modulo 10^9 + 7.

  Two paths are considered different if they do not have exactly the same
  sequence of visited cells.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  1 <= m, n <= 1000
  1 <= m * n <= 10^5
  1 <= grid[i][j] <= 10^5

TEST CASES
  [1] Input    : grid = [[1,1],[3,4]]
      Expected : 8
      Why      : The strictly increasing paths are:
                 - Paths with length 1: [1], [1], [3], [4].
                 - Paths with length 2: [1 -> 3], [1 -> 4], [3 -> 4].
                 … (2 more)

  [2] Input    : grid = [[1],[2]]
      Expected : 3
      Why      : The strictly increasing paths are:
                 - Paths with length 1: [1], [2].
                 - Paths with length 2: [1 -> 2].
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPaths(vector<vector<int>>& grid);
