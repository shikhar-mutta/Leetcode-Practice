 2335. Minimum Amount of Time to Fill Cups
 Easy  |  Tags: Array, Greedy, Sorting, Heap (Priority Queue)
 https://leetcode.com/problems/minimum-amount-of-time-to-fill-cups/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You have a water dispenser that can dispense cold, warm, and hot water.
  Every second, you can either fill up 2 cups with different types of
  water, or 1 cup of any type of water.

  You are given a 0-indexed integer array amount of length 3 where
  amount[0], amount[1], and amount[2] denote the number of cold, warm, and
  hot water cups you need to fill respectively. Return the minimum number
  of seconds needed to fill up all the cups.

CONSTRAINTS
  amount.length == 3
  0 <= amount[i] <= 100

TEST CASES
  [1] Input    : amount = [1,4,2]
      Expected : 4
      Why      : One way to fill up the cups is:
                 Second 1: Fill up a cold cup and a warm cup.
                 Second 2: Fill up a warm cup and a hot cup.
                 … (3 more)

  [2] Input    : amount = [5,4,4]
      Expected : 7
      Why      : One way to fill up the cups is:
                 Second 1: Fill up a cold cup, and a hot cup.
                 Second 2: Fill up a cold cup, and a warm cup.
                 … (5 more)

  [3] Input    : amount = [5,0,0]
      Expected : 5
      Why      : Every second, we fill up a cold cup.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int fillCups(vector<int>& amount);
