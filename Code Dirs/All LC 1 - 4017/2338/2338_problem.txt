 2338. Count the Number of Ideal Arrays
 Hard  |  Tags: Math, Dynamic Programming, Combinatorics, Number Theory, Prime Factorization, Fermat's Little Theorem
 https://leetcode.com/problems/count-the-number-of-ideal-arrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integers n and maxValue, which are used to describe an
  ideal array.

  A 0-indexed integer array arr of length n is considered ideal if the
  following conditions hold:

  - Every arr[i] is a value from 1 to maxValue, for 0 <= i < n.

  - Every arr[i] is divisible by arr[i - 1], for 0 < i < n.

  Return the number of distinct ideal arrays of length n. Since the answer
  may be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  2 <= n <= 10^4
  1 <= maxValue <= 10^4

TEST CASES
  [1] Input    : n = 2, maxValue = 5
      Expected : 10
      Why      : The following are the possible ideal arrays:
                 - Arrays starting with the value 1 (5 arrays): [1,1], [1,2], [1,3], [1,4], [1,5]
                 - Arrays starting with the value 2 (2 arrays): [2,2], [2,4]
                 … (4 more)

  [2] Input    : n = 5, maxValue = 3
      Expected : 11
      Why      : The following are the possible ideal arrays:
                 - Arrays starting with the value 1 (9 arrays):
                 - With no other distinct values (1 array): [1,1,1,1,1]
                 … (5 more)

CODE TYPE

SIGNATURE
