 2348. Number of Zero-Filled Subarrays
 Medium  |  Tags: Array, Math
 https://leetcode.com/problems/number-of-zero-filled-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the number of subarrays filled with
  0.

  A subarray is a contiguous non-empty sequence of elements within an
  array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,3,0,0,2,0,0,4]
      Expected : 6
      Why      : There are 4 occurrences of [0] as a subarray.
                 There are 2 occurrences of [0,0] as a subarray.
                 There is no occurrence of a subarray with a size more than 2 filled with 0. Therefore, we return 6.

  [2] Input    : nums = [0,0,0,2,0,0]
      Expected : 9
      Why      : There are 5 occurrences of [0] as a subarray.
                 There are 3 occurrences of [0,0] as a subarray.
                 There is 1 occurrence of [0,0,0] as a subarray.
                 … (1 more)

  [3] Input    : nums = [2,10,2019]
      Expected : 0
      Why      : There is no subarray filled with 0. Therefore, we return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long zeroFilledSubarray(vector<int>& nums);
