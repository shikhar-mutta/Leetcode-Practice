 2364. Count Number of Bad Pairs
 Medium  |  Tags: Array, Hash Table, Math, Counting
 https://leetcode.com/problems/count-number-of-bad-pairs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums. A pair of indices (i, j)
  is a bad pair if i < j and j - i != nums[j] - nums[i].

  Return the total number of bad pairs in nums.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [4,1,3,3]
      Expected : 5
      Why      : The pair (0, 1) is a bad pair since 1 - 0 != 1 - 4.
                 The pair (0, 2) is a bad pair since 2 - 0 != 3 - 4, 2 != -1.
                 The pair (0, 3) is a bad pair since 3 - 0 != 3 - 4, 3 != -1.
                 … (3 more)

  [2] Input    : nums = [1,2,3,4,5]
      Expected : 0
      Why      : There are no bad pairs.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countBadPairs(vector<int>& nums);
