 2368. Reachable Nodes With Restrictions
 Medium  |  Tags: Array, Hash Table, Tree, Depth-First Search, Breadth-First Search, Union-Find, Graph Theory
 https://leetcode.com/problems/reachable-nodes-with-restrictions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is an undirected tree with n nodes labeled from 0 to n - 1 and n -
  1 edges.

  You are given a 2D integer array edges of length n - 1 where edges[i] =
  [ai, bi] indicates that there is an edge between nodes ai and bi in the
  tree. You are also given an integer array restricted which represents
  restricted nodes.

  Return the maximum number of nodes you can reach from node 0 without
  visiting a restricted node.

  Note that node 0 will not be a restricted node.

CONSTRAINTS
  2 <= n <= 10^5
  edges.length == n - 1
  edges[i].length == 2
  0 <= ai, bi < n
  ai != bi
  edges represents a valid tree.
  1 <= restricted.length < n
  1 <= restricted[i] < n
  All the values of restricted are unique.

TEST CASES
  [1] Input    : n = 7, edges = [[0,1],[1,2],[3,1],[4,0],[0,5],[5,6]], restricted = [4,5]
      Expected : 4
      Why      : The diagram above shows the tree.
                 We have that [0,1,2,3] are the only nodes that can be reached from node 0 without visiting a restricted node.

  [2] Input    : n = 7, edges = [[0,1],[0,2],[0,5],[0,4],[3,2],[6,5]], restricted = [4,2,1]
      Expected : 3
      Why      : The diagram above shows the tree.
                 We have that [0,5,6] are the only nodes that can be reached from node 0 without visiting a restricted node.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int reachableNodes(int n, vector<vector<int>>& edges, vector<int>& restricted);
