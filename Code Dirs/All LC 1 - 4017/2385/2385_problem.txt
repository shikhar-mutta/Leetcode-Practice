 2385. Amount of Time for Binary Tree to Be Infected
 Medium  |  Tags: Hash Table, Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/amount-of-time-for-binary-tree-to-be-infected/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the root of a binary tree with unique values, and an
  integer start. At minute 0, an infection starts from the node with value
  start.

  Each minute, a node becomes infected if:

  - The node is currently uninfected.

  - The node is adjacent to an infected node.

  Return the number of minutes needed for the entire tree to be infected.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 10^5].
  1 <= Node.val <= 10^5
  Each node has a unique value.
  A node with a value of start exists in the tree.

TEST CASES
  [1] Input    : root = [1,5,3,null,4,10,6,9,2], start = 3
      Expected : 4
      Why      : The following nodes are infected during:
                 - Minute 0: Node 3
                 - Minute 1: Nodes 1, 10 and 6
                 … (4 more)

  [2] Input    : root = [1], start = 1
      Expected : 0
      Why      : At minute 0, the only node in the tree is infected so we return 0.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int amountOfTime(TreeNode* root, int start);
