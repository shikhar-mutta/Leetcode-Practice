 239. Sliding Window Maximum
 Hard  |  Tags: Array, Queue, Sliding Window, Heap (Priority Queue), Monotonic Queue, Range Minimum/Maximum Query
 https://leetcode.com/problems/sliding-window-maximum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of integers nums, there is a sliding window of
  size k which is moving from the very left of the array to the very
  right. You can only see the k numbers in the window. Each time the
  sliding window moves right by one position.

  Return the max sliding window.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^4 <= nums[i] <= 10^4
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [1,3,-1,-3,5,3,6,7], k = 3
      Expected : [3,3,5,5,6,7]
      Why      : Window position Max
                 --------------- -----
                 [1 3 -1] -3 5 3 6 7 3
                 … (5 more)

  [2] Input    : nums = [1], k = 1
      Expected : [1]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> maxSlidingWindow(vector<int>& nums, int k);

FILES
  edit : 239.cpp
  test : lc run 239
