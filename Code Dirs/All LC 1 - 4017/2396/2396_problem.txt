 2396. Strictly Palindromic Number
 Medium  |  Tags: Math, Two Pointers, Brainteaser
 https://leetcode.com/problems/strictly-palindromic-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An integer n is strictly palindromic if, for every base b between 2 and
  n - 2 (inclusive), the string representation of the integer n in base b
  is palindromic.

  Given an integer n, return true if n is strictly palindromic and false
  otherwise.

  A string is palindromic if it reads the same forward and backward.

CONSTRAINTS
  4 <= n <= 10^5

TEST CASES
  [1] Input    : n = 9
      Expected : false
      Why      : In base 2: 9 = 1001 (base 2), which is palindromic.
                 In base 3: 9 = 100 (base 3), which is not palindromic.
                 Therefore, 9 is not strictly palindromic so we return false.
                 … (1 more)

  [2] Input    : n = 4
      Expected : false
      Why      : We only consider base 2: 4 = 100 (base 2), which is not palindromic.
                 Therefore, we return false.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isStrictlyPalindromic(int n);
