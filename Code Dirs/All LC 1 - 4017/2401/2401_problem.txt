 2401. Longest Nice Subarray
 Medium  |  Tags: Array, Bit Manipulation, Sliding Window
 https://leetcode.com/problems/longest-nice-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums consisting of positive integers.

  We call a subarray of nums nice if the bitwise AND of every pair of
  elements that are in different positions in the subarray is equal to 0.

  Return the length of the longest nice subarray.

  A subarray is a contiguous part of an array.

  Note that subarrays of length 1 are always considered nice.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,3,8,48,10]
      Expected : 3
      Why      : The longest nice subarray is [3,8,48]. This subarray satisfies the conditions:
                 - 3 AND 8 = 0.
                 - 3 AND 48 = 0.
                 … (2 more)

  [2] Input    : nums = [3,1,5,11,13]
      Expected : 1
      Why      : The length of the longest nice subarray is 1. Any subarray of length 1 can be chosen.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestNiceSubarray(vector<int>& nums);
