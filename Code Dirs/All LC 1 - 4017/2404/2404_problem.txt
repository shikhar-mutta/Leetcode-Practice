 2404. Most Frequent Even Element
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/most-frequent-even-element/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the most frequent even element.

  If there is a tie, return the smallest one. If there is no such element,
  return -1.

CONSTRAINTS
  1 <= nums.length <= 2000
  0 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [0,1,2,2,4,4,1]
      Expected : 2
      Why      : The even elements are 0, 2, and 4. Of these, 2 and 4 appear the most.
                 We return the smallest one, which is 2.

  [2] Input    : nums = [4,4,4,9,2,4]
      Expected : 4
      Why      : 4 is the even element appears the most.

  [3] Input    : nums = [29,47,21,41,13,37,25,7]
      Expected : -1
      Why      : There is no even element.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int mostFrequentEven(vector<int>& nums);
