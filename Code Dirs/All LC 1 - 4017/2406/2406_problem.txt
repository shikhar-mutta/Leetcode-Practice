 2406. Divide Intervals Into Minimum Number of Groups
 Medium  |  Tags: Array, Two Pointers, Greedy, Sorting, Heap (Priority Queue), Prefix Sum
 https://leetcode.com/problems/divide-intervals-into-minimum-number-of-groups/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array intervals where intervals[i] = [lefti,
  righti] represents the inclusive interval [lefti, righti].

  You have to divide the intervals into one or more groups such that each
  interval is in exactly one group, and no two intervals that are in the
  same group intersect each other.

  Return the minimum number of groups you need to make.

  Two intervals intersect if there is at least one common number between
  them. For example, the intervals [1, 5] and [5, 8] intersect.

CONSTRAINTS
  1 <= intervals.length <= 10^5
  intervals[i].length == 2
  1 <= lefti <= righti <= 10^6

TEST CASES
  [1] Input    : intervals = [[5,10],[6,8],[1,5],[2,3],[1,10]]
      Expected : 3
      Why      : We can divide the intervals into the following groups:
                 - Group 1: [1, 5], [6, 8].
                 - Group 2: [2, 3], [5, 10].
                 … (2 more)

  [2] Input    : intervals = [[1,3],[5,6],[8,10],[11,13]]
      Expected : 1
      Why      : None of the intervals overlap, so we can put all of them in one group.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minGroups(vector<vector<int>>& intervals);
