 241. Different Ways to Add Parentheses
 Medium  |  Tags: Math, String, Dynamic Programming, Recursion, Memoization, Bracket Sequences
 https://leetcode.com/problems/different-ways-to-add-parentheses/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string expression of numbers and operators, return all possible
  results from computing all the different possible ways to group numbers
  and operators. You may return the answer in any order.

  The test cases are generated such that the output values fit in a 32-bit
  integer and the number of different results does not exceed 10^4.

CONSTRAINTS
  1 <= expression.length <= 20
  expression consists of digits and the operator '+', '-', and '*'.
  All the integer values in the input expression are in the range [0, 99].
  The integer values in the input expression do not have a leading '-' or '+' denoting the sign.

TEST CASES
  [1] Input    : expression = "2-1-1"
      Expected : [0,2]
      Why      : ((2-1)-1) = 0
                 (2-(1-1)) = 2

  [2] Input    : expression = "2*3-4*5"
      Expected : [-34,-14,-10,-10,10]
      Why      : (2*(3-(4*5))) = -34
                 ((2*3)-(4*5)) = -14
                 ((2*(3-4))*5) = -10
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> diffWaysToCompute(string expression);

FILES
  edit : 241.cpp
  test : lc run 241
