 2419. Longest Subarray With Maximum Bitwise AND
 Medium  |  Tags: Array, Bit Manipulation, Brainteaser
 https://leetcode.com/problems/longest-subarray-with-maximum-bitwise-and/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of size n.

  Consider a non-empty subarray from nums that has the maximum possible
  bitwise AND.

  - In other words, let k be the maximum value of the bitwise AND of any
    subarray of nums. Then, only subarrays with a bitwise AND equal to k
    should be considered.

  Return the length of the longest such subarray.

  The bitwise AND of an array is the bitwise AND of all the numbers in it.

  A subarray is a contiguous sequence of elements within an array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^6

TEST CASES
  [1] Input    : nums = [1,2,3,3,2,2]
      Expected : 2
      Why      : The maximum possible bitwise AND of a subarray is 3.
                 The longest subarray with that value is [3,3], so we return 2.

  [2] Input    : nums = [1,2,3,4]
      Expected : 1
      Why      : The maximum possible bitwise AND of a subarray is 4.
                 The longest subarray with that value is [4], so we return 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestSubarray(vector<int>& nums);
