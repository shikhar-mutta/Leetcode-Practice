 2427. Number of Common Factors
 Easy  |  Tags: Math, Enumeration, Number Theory, Euclidean Algorithm, Greatest Common Divisor
 https://leetcode.com/problems/number-of-common-factors/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two positive integers a and b, return the number of common factors
  of a and b.

  An integer x is a common factor of a and b if x divides both a and b.

CONSTRAINTS
  1 <= a, b <= 1000

TEST CASES
  [1] Input    : a = 12, b = 6
      Expected : 4
      Why      : The common factors of 12 and 6 are 1, 2, 3, 6.

  [2] Input    : a = 25, b = 30
      Expected : 2
      Why      : The common factors of 25 and 30 are 1, 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int commonFactors(int a, int b);
