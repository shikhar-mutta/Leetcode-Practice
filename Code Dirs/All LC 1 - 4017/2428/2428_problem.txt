 2428. Maximum Sum of an Hourglass
 Medium  |  Tags: Array, Matrix, Prefix Sum
 https://leetcode.com/problems/maximum-sum-of-an-hourglass/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an m x n integer matrix grid.

  We define an hourglass as a part of the matrix with the following form:

  Return the maximum sum of the elements of an hourglass.

  Note that an hourglass cannot be rotated and must be entirely contained
  within the matrix.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  3 <= m, n <= 150
  0 <= grid[i][j] <= 10^6

TEST CASES
  [1] Input    : grid = [[6,2,1,3],[4,2,1,5],[9,2,8,7],[4,1,2,9]]
      Expected : 30
      Why      : The cells shown above represent the hourglass with the maximum sum: 6 + 2 + 1 + 2 + 9 + 2 + 8 = 30.

  [2] Input    : grid = [[1,2,3],[4,5,6],[7,8,9]]
      Expected : 35
      Why      : There is only one hourglass in the matrix, with the sum: 1 + 2 + 3 + 5 + 7 + 8 + 9 = 35.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSum(vector<vector<int>>& grid);
