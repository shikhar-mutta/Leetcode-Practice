 2442. Count Number of Distinct Integers After Reverse Operations
 Medium  |  Tags: Array, Hash Table, Math, Counting
 https://leetcode.com/problems/count-number-of-distinct-integers-after-reverse-operations/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums consisting of positive integers.

  You have to take each integer in the array, reverse its digits, and add
  it to the end of the array. You should apply this operation to the
  original integers in nums.

  Return the number of distinct integers in the final array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^6

TEST CASES
  [1] Input    : nums = [1,13,10,12,31]
      Expected : 6
      Why      : After including the reverse of each number, the resulting array is [1,13,10,12,31,1,31,1,21,13].
                 The reversed integers that were added to the end of the array are underlined. Note that for the integer 10, after reversing it, it becomes 01 which is just 1.
                 The number of distinct integers in this array is 6 (The numbers 1, 10, 12, 13, 21, and 31).

  [2] Input    : nums = [2,2,2]
      Expected : 1
      Why      : After including the reverse of each number, the resulting array is [2,2,2,2,2,2].
                 The number of distinct integers in this array is 1 (The number 2).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countDistinctIntegers(vector<int>& nums);
