 2444. Count Subarrays With Fixed Bounds
 Hard  |  Tags: Array, Queue, Sliding Window, Monotonic Queue
 https://leetcode.com/problems/count-subarrays-with-fixed-bounds/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and two integers minK and maxK.

  A fixed-bound subarray of nums is a subarray that satisfies the
  following conditions:

  - The minimum value in the subarray is equal to minK.

  - The maximum value in the subarray is equal to maxK.

  Return the number of fixed-bound subarrays.

  A subarray is a contiguous part of an array.

CONSTRAINTS
  2 <= nums.length <= 10^5
  1 <= nums[i], minK, maxK <= 10^6

TEST CASES
  [1] Input    : nums = [1,3,5,2,7,5], minK = 1, maxK = 5
      Expected : 2
      Why      : The fixed-bound subarrays are [1,3,5] and [1,3,5,2].

  [2] Input    : nums = [1,1,1,1], minK = 1, maxK = 1
      Expected : 10
      Why      : Every subarray of nums is a fixed-bound subarray. There are 10 possible subarrays.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countSubarrays(vector<int>& nums, int minK, int maxK);
