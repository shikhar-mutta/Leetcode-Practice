 2455. Average Value of Even Numbers That Are Divisible by Three
 Easy  |  Tags: Array, Math
 https://leetcode.com/problems/average-value-of-even-numbers-that-are-divisible-by-three/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums of positive integers, return the average
  value of all even integers that are divisible by 3.

  Note that the average of n elements is the sum of the n elements divided
  by n and rounded down to the nearest integer.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [1,3,6,10,12,15]
      Expected : 9
      Why      : 6 and 12 are even numbers that are divisible by 3. (6 + 12) / 2 = 9.

  [2] Input    : nums = [1,2,4,7,10]
      Expected : 0
      Why      : There is no single number that satisfies the requirement, so return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int averageValue(vector<int>& nums);
