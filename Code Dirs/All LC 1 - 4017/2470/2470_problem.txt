 2470. Number of Subarrays With LCM Equal to K
 Medium  |  Tags: Array, Math, Number Theory
 https://leetcode.com/problems/number-of-subarrays-with-lcm-equal-to-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums and an integer k, return the number of
  subarrays of nums where the least common multiple of the subarray's
  elements is k.

  A subarray is a contiguous non-empty sequence of elements within an
  array.

  The least common multiple of an array is the smallest positive integer
  that is divisible by all the array elements.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i], k <= 1000

TEST CASES
  [1] Input    : nums = [3,6,2,7,1], k = 6
      Expected : 4
      Why      : The subarrays of nums where 6 is the least common multiple of all the subarray's elements are:
                 - [3,6,2,7,1]
                 - [3,6,2,7,1]
                 … (2 more)

  [2] Input    : nums = [3], k = 2
      Expected : 0
      Why      : There are no subarrays of nums where 2 is the least common multiple of all the subarray's elements.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int subarrayLCM(vector<int>& nums, int k);
