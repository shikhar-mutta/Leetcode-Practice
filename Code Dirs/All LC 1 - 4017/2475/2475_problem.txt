 2475. Number of Unequal Triplets in Array
 Easy  |  Tags: Array, Hash Table, Sorting
 https://leetcode.com/problems/number-of-unequal-triplets-in-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array of positive integers nums. Find the
  number of triplets (i, j, k) that meet the following conditions:

  - 0 <= i < j < k < nums.length

  - nums[i], nums[j], and nums[k] are pairwise distinct.

  - In other words, nums[i] != nums[j], nums[i] != nums[k], and nums[j] !=
    nums[k].





  Return the number of triplets that meet the conditions.

CONSTRAINTS
  3 <= nums.length <= 100
  1 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [4,4,2,4,3]
      Expected : 3
      Why      : The following triplets meet the conditions:
                 - (0, 2, 4) because 4 != 2 != 3
                 - (1, 2, 4) because 4 != 2 != 3
                 … (3 more)

  [2] Input    : nums = [1,1,1,1,1]
      Expected : 0
      Why      : No triplets meet the conditions so we return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int unequalTriplets(vector<int>& nums);
