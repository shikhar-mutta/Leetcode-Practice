 2483. Minimum Penalty for a Shop
 Medium  |  Tags: String, Prefix Sum
 https://leetcode.com/problems/minimum-penalty-for-a-shop/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the customer visit log of a shop represented by a
  0-indexed string customers consisting only of characters 'N' and 'Y':

  - if the i^th character is 'Y', it means that customers come at the i^th
    hour

  - whereas 'N' indicates that no customers come at the i^th hour.

  If the shop closes at the j^th hour (0 <= j <= n), the penalty is
  calculated as follows:

  - For every hour when the shop is open and no customers come, the
    penalty increases by 1.

  - For every hour when the shop is closed and customers come, the penalty
    increases by 1.

  Return the earliest hour at which the shop must be closed to incur a
  minimum penalty.

  Note that if a shop closes at the j^th hour, it means the shop is closed
  at the hour j.

CONSTRAINTS
  1 <= customers.length <= 10^5
  customers consists only of characters 'Y' and 'N'.

TEST CASES
  [1] Input    : customers = "YYNY"
      Expected : 2
      Why      : - Closing the shop at the 0^th hour incurs in 1+1+0+1 = 3 penalty.
                 - Closing the shop at the 1^st hour incurs in 0+1+0+1 = 2 penalty.
                 - Closing the shop at the 2^nd hour incurs in 0+0+0+1 = 1 penalty.
                 … (3 more)

  [2] Input    : customers = "NNNNN"
      Expected : 0
      Why      : It is best to close the shop at the 0^th hour as no customers arrive.

  [3] Input    : customers = "YYYY"
      Expected : 4
      Why      : It is best to close the shop at the 4^th hour as customers arrive at each hour.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int bestClosingTime(string customers);
