 2485. Find the Pivot Integer
 Easy  |  Tags: Math, Prefix Sum
 https://leetcode.com/problems/find-the-pivot-integer/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a positive integer n, find the pivot integer x such that:

  - The sum of all elements between 1 and x inclusively equals the sum of
    all elements between x and n inclusively.

  Return the pivot integer x. If no such integer exists, return -1. It is
  guaranteed that there will be at most one pivot index for the given
  input.

CONSTRAINTS
  1 <= n <= 1000

TEST CASES
  [1] Input    : n = 8
      Expected : 6
      Why      : 6 is the pivot integer since: 1 + 2 + 3 + 4 + 5 + 6 = 6 + 7 + 8 = 21.

  [2] Input    : n = 1
      Expected : 1
      Why      : 1 is the pivot integer since: 1 = 1.

  [3] Input    : n = 4
      Expected : -1
      Why      : It can be proved that no such integer exist.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int pivotInteger(int n);
