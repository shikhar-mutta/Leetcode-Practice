 2506. Count Pairs Of Similar Strings
 Easy  |  Tags: Array, Hash Table, String, Bit Manipulation, Counting
 https://leetcode.com/problems/count-pairs-of-similar-strings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed string array words.

  Two strings are similar if they consist of the same characters.

  - For example, "abca" and "cba" are similar since both consist of
    characters 'a', 'b', and 'c'.

  - However, "abacba" and "bcfd" are not similar since they do not consist
    of the same characters.

  Return the number of pairs (i, j) such that 0 <= i < j <= word.length -
  1 and the two strings words[i] and words[j] are similar.

CONSTRAINTS
  1 <= words.length <= 100
  1 <= words[i].length <= 100
  words[i] consist of only lowercase English letters.

TEST CASES
  [1] Input    : words = ["aba","aabb","abcd","bac","aabc"]
      Expected : 2
      Why      : There are 2 pairs that satisfy the conditions:
                 - i = 0 and j = 1 : both words[0] and words[1] only consist of characters 'a' and 'b'.
                 - i = 3 and j = 4 : both words[3] and words[4] only consist of characters 'a', 'b', and 'c'.

  [2] Input    : words = ["aabb","ab","ba"]
      Expected : 3
      Why      : There are 3 pairs that satisfy the conditions:
                 - i = 0 and j = 1 : both words[0] and words[1] only consist of characters 'a' and 'b'.
                 - i = 0 and j = 2 : both words[0] and words[2] only consist of characters 'a' and 'b'.
                 … (1 more)

  [3] Input    : words = ["nba","cba","dba"]
      Expected : 0
      Why      : Since there does not exist any pair that satisfies the conditions, we return 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int similarPairs(vector<string>& words);
