 2508. Add Edges to Make Degrees of All Nodes Even
 Hard  |  Tags: Hash Table, Graph Theory
 https://leetcode.com/problems/add-edges-to-make-degrees-of-all-nodes-even/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is an undirected graph consisting of n nodes numbered from 1 to n.
  You are given the integer n and a 2D array edges where edges[i] = [ai,
  bi] indicates that there is an edge between nodes ai and bi. The graph
  can be disconnected.

  You can add at most two additional edges (possibly none) to this graph
  so that there are no repeated edges and no self-loops.

  Return true if it is possible to make the degree of each node in the
  graph even, otherwise return false.

  The degree of a node is the number of edges connected to it.

CONSTRAINTS
  3 <= n <= 10^5
  2 <= edges.length <= 10^5
  edges[i].length == 2
  1 <= ai, bi <= n
  ai != bi
  There are no repeated edges.

TEST CASES
  [1] Input    : n = 5, edges = [[1,2],[2,3],[3,4],[4,2],[1,4],[2,5]]
      Expected : true
      Why      : The above diagram shows a valid way of adding an edge.
                 Every node in the resulting graph is connected to an even number of edges.

  [2] Input    : n = 4, edges = [[1,2],[3,4]]
      Expected : true
      Why      : The above diagram shows a valid way of adding two edges.

  [3] Input    : n = 4, edges = [[1,2],[1,3],[1,4]]
      Expected : false
      Why      : It is not possible to obtain a valid graph with adding at most 2 edges.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isPossible(int n, vector<vector<int>>& edges);
