 2518. Number of Great Partitions
 Hard  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/number-of-great-partitions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums consisting of positive integers and an
  integer k.

  Partition the array into two ordered groups such that each element is in
  exactly one group. A partition is called great if the sum of elements of
  each group is greater than or equal to k.

  Return the number of distinct great partitions. Since the answer may be
  too large, return it modulo 10^9 + 7.

  Two partitions are considered distinct if some element nums[i] is in
  different groups in the two partitions.

CONSTRAINTS
  1 <= nums.length, k <= 1000
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,2,3,4], k = 4
      Expected : 6
      Why      : The great partitions are: ([1,2,3], [4]), ([1,3], [2,4]), ([1,4], [2,3]), ([2,3], [1,4]), ([2,4], [1,3]) and ([4], [1,2,3]).

  [2] Input    : nums = [3,3,3], k = 4
      Expected : 0
      Why      : There are no great partitions for this array.

  [3] Input    : nums = [6,6], k = 2
      Expected : 2
      Why      : We can either put nums[0] in the first partition or in the second partition.
                 The great partitions will be ([6], [6]) and ([6], [6]).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPartitions(vector<int>& nums, int k);
