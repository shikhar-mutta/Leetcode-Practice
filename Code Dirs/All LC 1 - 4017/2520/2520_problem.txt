 2520. Count the Digits That Divide a Number
 Easy  |  Tags: Math
 https://leetcode.com/problems/count-the-digits-that-divide-a-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer num, return the number of digits in num that divide
  num.

  An integer val divides nums if nums % val == 0.

CONSTRAINTS
  1 <= num <= 10^9
  num does not contain 0 as one of its digits.

TEST CASES
  [1] Input    : num = 7
      Expected : 1
      Why      : 7 divides itself, hence the answer is 1.

  [2] Input    : num = 121
      Expected : 2
      Why      : 121 is divisible by 1, but not 2. Since 1 occurs twice as a digit, we return 2.

  [3] Input    : num = 1248
      Expected : 4
      Why      : 1248 is divisible by all of its digits, hence the answer is 4.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countDigits(int num);

  edit : 2520.cpp
