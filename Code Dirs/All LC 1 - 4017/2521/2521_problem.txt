 2521. Distinct Prime Factors of Product of Array
 Medium  |  Tags: Array, Hash Table, Math, Number Theory, Prime Factorization, Euclidean Algorithm, Primality Test, Greatest Common Divisor, Sieve Theory, Prime Number Sieve
 https://leetcode.com/problems/distinct-prime-factors-of-product-of-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of positive integers nums, return the number of distinct
  prime factors in the product of the elements of nums.

  Note that:

  - A number greater than 1 is called prime if it is divisible by only 1
    and itself.

  - An integer val1 is a factor of another integer val2 if val2 / val1 is
    an integer.

CONSTRAINTS
  1 <= nums.length <= 10^4
  2 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [2,4,3,7,10,6]
      Expected : 4
      Why      : The product of all the elements in nums is: 2 * 4 * 3 * 7 * 10 * 6 = 10080 = 2^5 * 3^2 * 5 * 7.
                 There are 4 distinct prime factors so we return 4.

  [2] Input    : nums = [2,4,8,16]
      Expected : 1
      Why      : The product of all the elements in nums is: 2 * 4 * 8 * 16 = 1024 = 2^10.
                 There is 1 distinct prime factor so we return 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int distinctPrimeFactors(vector<int>& nums);
