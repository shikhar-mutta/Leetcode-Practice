 2537. Count the Number of Good Subarrays
 Medium  |  Tags: Array, Hash Table, Sliding Window
 https://leetcode.com/problems/count-the-number-of-good-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums and an integer k, return the number of good
  subarrays of nums.

  A subarray arr is good if there are at least k pairs of indices (i, j)
  such that i < j and arr[i] == arr[j].

  A subarray is a contiguous non-empty sequence of elements within an
  array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i], k <= 10^9

TEST CASES
  [1] Input    : nums = [1,1,1,1,1], k = 10
      Expected : 1
      Why      : The only good subarray is the array nums itself.

  [2] Input    : nums = [3,1,4,3,2,2,4], k = 2
      Expected : 4
      Why      : There are 4 different good subarrays:
                 - [3,1,4,3,2,2] that has 2 pairs.
                 - [3,1,4,3,2,2,4] that has 3 pairs.
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countGood(vector<int>& nums, int k);
