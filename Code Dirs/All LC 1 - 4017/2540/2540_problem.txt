 2540. Minimum Common Value
 Easy  |  Tags: Array, Hash Table, Two Pointers, Binary Search
 https://leetcode.com/problems/minimum-common-value/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integer arrays nums1 and nums2, sorted in non-decreasing
  order, return the minimum integer common to both arrays. If there is no
  common integer amongst nums1 and nums2, return -1.

  Note that an integer is said to be common to nums1 and nums2 if both
  arrays have at least one occurrence of that integer.

CONSTRAINTS
  1 <= nums1.length, nums2.length <= 10^5
  1 <= nums1[i], nums2[j] <= 10^9
  Both nums1 and nums2 are sorted in non-decreasing order.

TEST CASES
  [1] Input    : nums1 = [1,2,3], nums2 = [2,4]
      Expected : 2
      Why      : The smallest element common to both arrays is 2, so we return 2.

  [2] Input    : nums1 = [1,2,3,6], nums2 = [2,3,4,5]
      Expected : 2
      Why      : There are two common elements in the array 2 and 3 out of which 2 is the smallest, so 2 is returned.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int getCommon(vector<int>& nums1, vector<int>& nums2);
