 2553. Separate the Digits in an Array
 Easy  |  Tags: Array, Simulation
 https://leetcode.com/problems/separate-the-digits-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of positive integers nums, return an array answer that
  consists of the digits of each integer in nums after separating them in
  the same order they appear in nums.

  To separate the digits of an integer is to get all the digits it has in
  the same order.

  - For example, for the integer 10921, the separation of its digits is
    [1,0,9,2,1].

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [13,25,83,77]
      Expected : [1,3,2,5,8,3,7,7]
      Why      : - The separation of 13 is [1,3].
                 - The separation of 25 is [2,5].
                 - The separation of 83 is [8,3].
                 … (2 more)

  [2] Input    : nums = [7,1,3,9]
      Expected : [7,1,3,9]
      Why      : The separation of each integer in nums is itself.
                 answer = [7,1,3,9].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> separateDigits(vector<int>& nums);
