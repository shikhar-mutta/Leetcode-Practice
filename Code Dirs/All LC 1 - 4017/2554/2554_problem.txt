 2554. Maximum Number of Integers to Choose From a Range I
 Medium  |  Tags: Array, Hash Table, Binary Search, Greedy, Sorting
 https://leetcode.com/problems/maximum-number-of-integers-to-choose-from-a-range-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array banned and two integers n and maxSum. You
  are choosing some number of integers following the below rules:

  - The chosen integers have to be in the range [1, n].

  - Each integer can be chosen at most once.

  - The chosen integers should not be in the array banned.

  - The sum of the chosen integers should not exceed maxSum.

  Return the maximum number of integers you can choose following the
  mentioned rules.

CONSTRAINTS
  1 <= banned.length <= 10^4
  1 <= banned[i], n <= 10^4
  1 <= maxSum <= 10^9

TEST CASES
  [1] Input    : banned = [1,6,5], n = 5, maxSum = 6
      Expected : 2
      Why      : You can choose the integers 2 and 4.
                 2 and 4 are from the range [1, 5], both did not appear in banned, and their sum is 6, which did not exceed maxSum.

  [2] Input    : banned = [1,2,3,4,5,6,7], n = 8, maxSum = 1
      Expected : 0
      Why      : You cannot choose any integer while following the mentioned conditions.

  [3] Input    : banned = [11], n = 7, maxSum = 50
      Expected : 7
      Why      : You can choose the integers 1, 2, 3, 4, 5, 6, and 7.
                 They are from the range [1, 7], all did not appear in banned, and their sum is 28, which did not exceed maxSum.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxCount(vector<int>& banned, int n, int maxSum);
