 2558. Take Gifts From the Richest Pile
 Easy  |  Tags: Array, Heap (Priority Queue), Simulation
 https://leetcode.com/problems/take-gifts-from-the-richest-pile/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array gifts denoting the number of gifts in
  various piles. Every second, you do the following:

  - Choose the pile with the maximum number of gifts.

  - If there is more than one pile with the maximum number of gifts,
    choose any.

  - Reduce the number of gifts in the pile to the floor of the square root
    of the original number of gifts in the pile.

  Return the number of gifts remaining after k seconds.

CONSTRAINTS
  1 <= gifts.length <= 10^3
  1 <= gifts[i] <= 10^9
  1 <= k <= 10^3

TEST CASES
  [1] Input    : gifts = [25,64,9,4,100], k = 4
      Expected : 29
      Why      : The gifts are taken in the following way:
                 - In the first second, the last pile is chosen and 10 gifts are left behind.
                 - Then the second pile is chosen and 8 gifts are left behind.
                 … (3 more)

  [2] Input    : gifts = [1,1,1,1], k = 4
      Expected : 4
      Why      : In this case, regardless which pile you choose, you have to leave behind 1 gift in each pile.
                 That is, you can't take any pile with you.
                 So, the total gifts remaining are 4.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long pickGifts(vector<int>& gifts, int k);
