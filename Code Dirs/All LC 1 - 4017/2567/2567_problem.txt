 2567. Minimum Score by Changing Two Elements
 Medium  |  Tags: Array, Greedy, Sorting
 https://leetcode.com/problems/minimum-score-by-changing-two-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  - The low score of nums is the minimum absolute difference between any
    two integers.

  - The high score of nums is the maximum absolute difference between any
    two integers.

  - The score of nums is the sum of the high and low scores.

  Return the minimum score after changing two elements of nums.

CONSTRAINTS
  3 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,4,7,8,5]
      Expected : 3
      Why      : - Change nums[0] and nums[1] to be 6 so that nums becomes [6,6,7,8,5].
                 - The low score is the minimum absolute difference: |6 - 6| = 0.
                 - The high score is the maximum absolute difference: |8 - 5| = 3.
                 … (1 more)

  [2] Input    : nums = [1,4,3]
      Expected : 0
      Why      : - Change nums[1] and nums[2] to 1 so that nums becomes [1,1,1].
                 - The sum of maximum absolute difference and minimum absolute difference is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimizeSum(vector<int>& nums);
