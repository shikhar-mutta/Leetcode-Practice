 2568. Minimum Impossible OR
 Medium  |  Tags: Array, Bit Manipulation, Brainteaser
 https://leetcode.com/problems/minimum-impossible-or/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums.

  We say that an integer x is expressible from nums if there exist some
  integers 0 <= index1 < index2 < ... < indexk < nums.length for which
  nums[index1] | nums[index2] | ... | nums[indexk] = x. In other words, an
  integer is expressible if it can be written as the bitwise OR of some
  subsequence of nums.

  Return the minimum positive non-zero integer that is not expressible
  from nums.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [2,1]
      Expected : 4
      Why      : 1 and 2 are already present in the array. We know that 3 is expressible, since nums[0] | nums[1] = 2 | 1 = 3. Since 4 is not expressible, we return 4.

  [2] Input    : nums = [5,3,2]
      Expected : 1
      Why      : We can show that 1 is the smallest number that is not expressible.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minImpossibleOR(vector<int>& nums);
