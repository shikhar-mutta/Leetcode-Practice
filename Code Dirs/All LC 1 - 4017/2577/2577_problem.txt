 2577. Minimum Time to Visit a Cell In a Grid
 Hard  |  Tags: Array, Breadth-First Search, Graph Theory, Heap (Priority Queue), Matrix, Shortest Path
 https://leetcode.com/problems/minimum-time-to-visit-a-cell-in-a-grid/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a m x n matrix grid consisting of non-negative integers
  where grid[row][col] represents the minimum time required to be able to
  visit the cell (row, col), which means you can visit the cell (row, col)
  only when the time you visit it is greater than or equal to
  grid[row][col].

  You are standing in the top-left cell of the matrix in the 0^th second,
  and you must move to any adjacent cell in the four directions: up, down,
  left, and right. Each move you make takes 1 second.

  Return the minimum time required in which you can visit the bottom-right
  cell of the matrix. If you cannot visit the bottom-right cell, then
  return -1.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  2 <= m, n <= 1000
  4 <= m * n <= 10^5
  0 <= grid[i][j] <= 10^5
  grid[0][0] == 0

TEST CASES
  [1] Input    : grid = [[0,1,3,2],[5,1,2,5],[4,3,8,6]]
      Expected : 7
      Why      : One of the paths that we can take is the following:
                 - at t = 0, we are on the cell (0,0).
                 - at t = 1, we move to the cell (0,1). It is possible because grid[0][1] <= 1.
                 … (7 more)

  [2] Input    : grid = [[0,2,4],[3,2,1],[1,0,4]]
      Expected : -1
      Why      : There is no path from the top left to the bottom-right cell.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumTime(vector<vector<int>>& grid);
