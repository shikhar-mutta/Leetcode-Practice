 258. Add Digits
 Easy  |  Tags: Math, Simulation, Number Theory
 https://leetcode.com/problems/add-digits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer num, repeatedly add all its digits until the result has
  only one digit, and return it.

CONSTRAINTS
  0 <= num <= 2^31 - 1

TEST CASES
  [1] Input    : num = 38
      Expected : 2
      Why      : The process is
                 38 --> 3 + 8 --> 11
                 11 --> 1 + 1 --> 2
                 … (1 more)

  [2] Input    : num = 0
      Expected : 0

FOLLOW UP
  Could you do it without any loop/recursion in O(1) runtime?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int addDigits(int num);

FILES
  edit : 258.cpp
  test : lc run 258
