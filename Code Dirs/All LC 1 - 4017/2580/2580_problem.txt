 2580. Count Ways to Group Overlapping Ranges
 Medium  |  Tags: Array, Sorting
 https://leetcode.com/problems/count-ways-to-group-overlapping-ranges/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array ranges where ranges[i] = [starti, endi]
  denotes that all integers between starti and endi (both inclusive) are
  contained in the i^th range.

  You are to split ranges into two (possibly empty) groups such that:

  - Each range belongs to exactly one group.

  - Any two overlapping ranges must belong to the same group.

  Two ranges are said to be overlapping if there exists at least one
  integer that is present in both ranges.

  - For example, [1, 3] and [2, 5] are overlapping because 2 and 3 occur
    in both ranges.

  Return the total number of ways to split ranges into two groups. Since
  the answer may be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= ranges.length <= 10^5
  ranges[i].length == 2
  0 <= starti <= endi <= 10^9

TEST CASES
  [1] Input    : ranges = [[6,10],[5,15]]
      Expected : 2
      Why      : The two ranges are overlapping, so they must be in the same group.
                 Thus, there are two possible ways:
                 - Put both the ranges together in group 1.
                 … (1 more)

      Expected : 4
      Why      : Ranges [1,3], and [2,5] are overlapping. So, they must be in the same group.
                 Again, ranges [2,5] and [4,8] are also overlapping. So, they must also be in the same group.
                 Thus, there are four possible ways to group them:
                 … (4 more)
