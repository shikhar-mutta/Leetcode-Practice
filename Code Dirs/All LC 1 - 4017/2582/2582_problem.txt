 2582. Pass the Pillow
 Easy  |  Tags: Math, Simulation
 https://leetcode.com/problems/pass-the-pillow/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There are n people standing in a line labeled from 1 to n. The first
  person in the line is holding a pillow initially. Every second, the
  person holding the pillow passes it to the next person standing in the
  line. Once the pillow reaches the end of the line, the direction
  changes, and people continue passing the pillow in the opposite
  direction.

  - For example, once the pillow reaches the n^th person they pass it to
    the n - 1^th person, then to the n - 2^th person and so on.

  Given the two positive integers n and time, return the index of the
  person holding the pillow after time seconds.

CONSTRAINTS
  2 <= n <= 1000
  1 <= time <= 1000

TEST CASES
  [1] Input    : n = 4, time = 5
      Expected : 2
      Why      : People pass the pillow in the following way: 1 -> 2 -> 3 -> 4 -> 3 -> 2.
                 After five seconds, the 2^nd person is holding the pillow.

  [2] Input    : n = 3, time = 2
      Expected : 3
      Why      : People pass the pillow in the following way: 1 -> 2 -> 3.
                 After two seconds, the 3^r^d person is holding the pillow.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int passThePillow(int n, int time);
