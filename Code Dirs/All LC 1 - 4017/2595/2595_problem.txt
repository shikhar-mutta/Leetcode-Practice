 2595. Number of Even and Odd Bits
 Easy  |  Tags: Bit Manipulation
 https://leetcode.com/problems/number-of-even-and-odd-bits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer n.

  Let even denote the number of even indices in the binary representation
  of n with value 1.

  Let odd denote the number of odd indices in the binary representation of
  n with value 1.

  Note that bits are indexed from right to left in the binary
  representation of a number.

  Return the array [even, odd].

CONSTRAINTS
  1 <= n <= 1000

TEST CASES
  [1] Input    : n = 50
      Expected : [1,2]
      Why      : The binary representation of 50 is 110010.
                 It contains 1 on indices 1, 4, and 5.

  [2] Input    : n = 2
      Expected : [0,1]
      Why      : The binary representation of 2 is 10.
                 It contains 1 only on index 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> evenOddBit(int n);
