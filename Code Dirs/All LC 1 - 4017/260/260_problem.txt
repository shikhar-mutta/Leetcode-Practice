 260. Single Number III
 Medium  |  Tags: Array, Bit Manipulation
 https://leetcode.com/problems/single-number-iii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, in which exactly two elements appear only
  once and all the other elements appear exactly twice. Find the two
  elements that appear only once. You can return the answer in any order.

  You must write an algorithm that runs in linear runtime complexity and
  uses only constant extra space.

CONSTRAINTS
  2 <= nums.length <= 3 * 10^4
  -2^31 <= nums[i] <= 2^31 - 1
  Each integer in nums will appear twice, only two integers will appear once.

TEST CASES
  [1] Input    : nums = [1,2,1,3,2,5]
      Expected : [3,5]
      Why      : [5, 3] is also a valid answer.

  [2] Input    : nums = [-1,0]
      Expected : [-1,0]

  [3] Input    : nums = [0,1]
      Expected : [1,0]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> singleNumber(vector<int>& nums);

FILES
  edit : 260.cpp
  test : lc run 260
