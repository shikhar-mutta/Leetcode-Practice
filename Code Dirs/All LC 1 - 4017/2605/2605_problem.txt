 2605. Form Smallest Number From Two Digit Arrays
 Easy  |  Tags: Array, Hash Table, Enumeration
 https://leetcode.com/problems/form-smallest-number-from-two-digit-arrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two arrays of unique digits nums1 and nums2, return the smallest
  number that contains at least one digit from each array.

CONSTRAINTS
  1 <= nums1.length, nums2.length <= 9
  1 <= nums1[i], nums2[i] <= 9
  All digits in each array are unique.

TEST CASES
  [1] Input    : nums1 = [4,1,3], nums2 = [5,7]
      Expected : 15
      Why      : The number 15 contains the digit 1 from nums1 and the digit 5 from nums2. It can be proven that 15 is the smallest number we can have.

  [2] Input    : nums1 = [3,5,2,6], nums2 = [3,1,7]
      Expected : 3
      Why      : The number 3 contains the digit 3 which exists in both arrays.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minNumber(vector<int>& nums1, vector<int>& nums2);
