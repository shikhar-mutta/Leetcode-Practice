 2643. Row With Maximum Ones
 Easy  |  Tags: Array, Matrix
 https://leetcode.com/problems/row-with-maximum-ones/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a m x n binary matrix mat, find the 0-indexed position of the row
  that contains the maximum count of ones, and the number of ones in that
  row.

  In case there are multiple rows that have the maximum count of ones, the
  row with the smallest row number should be selected.

  Return an array containing the index of the row, and the number of ones
  in it.

CONSTRAINTS
  m == mat.length
  n == mat[i].length
  1 <= m, n <= 100
  mat[i][j] is either 0 or 1.

TEST CASES
  [1] Input    : mat = [[0,1],[1,0]]
      Expected : [0,1]
      Why      : Both rows have the same number of 1's. So we return the index of the smaller row, 0, and the maximum count of ones (1). So, the answer is [0,1].

  [2] Input    : mat = [[0,0,0],[0,1,1]]
      Expected : [1,2]
      Why      : The row indexed 1 has the maximum count of ones (2). So we return its index, 1, and the count. So, the answer is [1,2].

  [3] Input    : mat = [[0,0],[1,1],[0,0]]
      Expected : [1,2]
      Why      : The row indexed 1 has the maximum count of ones (2). So the answer is [1,2].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> rowAndMaximumOnes(vector<vector<int>>& mat);
