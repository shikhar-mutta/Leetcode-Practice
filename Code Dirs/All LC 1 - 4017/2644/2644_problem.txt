 2644. Find the Maximum Divisibility Score
 Easy  |  Tags: Array
 https://leetcode.com/problems/find-the-maximum-divisibility-score/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integer arrays nums and divisors.

  The divisibility score of divisors[i] is the number of indices j such
  that nums[j] is divisible by divisors[i].

  Return the integer divisors[i] with the maximum divisibility score. If
  multiple integers have the maximum score, return the smallest one.

CONSTRAINTS
  1 <= nums.length, divisors.length <= 1000
  1 <= nums[i], divisors[i] <= 10^9

TEST CASES
  [1] Input    : nums = [2,9,15,50], divisors = [5,3,7,2]
      Expected : 2
      Why      : The divisibility score of divisors[0] is 2 since nums[2] and nums[3] are divisible by 5.
                 The divisibility score of divisors[1] is 2 since nums[1] and nums[2] are divisible by 3.
                 The divisibility score of divisors[2] is 0 since none of the numbers in nums is divisible by 7.
                 … (2 more)

  [2] Input    : nums = [4,7,9,3,9], divisors = [5,2,3]
      Expected : 3
      Why      : The divisibility score of divisors[0] is 0 since none of numbers in nums is divisible by 5.
                 The divisibility score of divisors[1] is 1 since only nums[0] is divisible by 2.
                 The divisibility score of divisors[2] is 3 since nums[2], nums[3] and nums[4] are divisible by 3.

  [3] Input    : nums = [20,14,21,10], divisors = [10,16,20]
      Expected : 10
      Why      : The divisibility score of divisors[0] is 2 since nums[0] and nums[3] are divisible by 10.
                 The divisibility score of divisors[1] is 0 since none of the numbers in nums is divisible by 16.
                 The divisibility score of divisors[2] is 1 since nums[0] is divisible by 20.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxDivScore(vector<int>& nums, vector<int>& divisors);
