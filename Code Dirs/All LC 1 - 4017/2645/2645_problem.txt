 2645. Minimum Additions to Make Valid String
 Medium  |  Tags: String, Dynamic Programming, Stack, Greedy
 https://leetcode.com/problems/minimum-additions-to-make-valid-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string word to which you can insert letters "a", "b" or "c"
  anywhere and any number of times, return the minimum number of letters
  that must be inserted so that word becomes valid.

  A string is called valid if it can be formed by concatenating the string
  "abc" several times.

CONSTRAINTS
  1 <= word.length <= 50
  word consists of letters "a", "b" and "c" only.

TEST CASES
  [1] Input    : word = "b"
      Expected : 2
      Why      : Insert the letter "a" right before "b", and the letter "c" right next to "b" to obtain the valid string "abc".

  [2] Input    : word = "aaa"
      Expected : 6
      Why      : Insert letters "b" and "c" next to each "a" to obtain the valid string "abcabcabc".

  [3] Input    : word = "abc"
      Expected : 0
      Why      : word is already valid. No modifications are needed.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int addMinimum(string word);
