 2661. First Completely Painted Row or Column
 Medium  |  Tags: Array, Hash Table, Matrix
 https://leetcode.com/problems/first-completely-painted-row-or-column/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array arr, and an m x n integer matrix
  mat. arr and mat both contain all the integers in the range [1, m * n].

  Go through each index i in arr starting from index 0 and paint the cell
  in mat containing the integer arr[i].

  Return the smallest index i at which either a row or a column will be
  completely painted in mat.

CONSTRAINTS
  m == mat.length
  n = mat[i].length
  arr.length == m * n
  1 <= m, n <= 10^5
  1 <= m * n <= 10^5
  1 <= arr[i], mat[r][c] <= m * n
  All the integers of arr are unique.
  All the integers of mat are unique.

TEST CASES
  [1] Input    : arr = [1,3,4,2], mat = [[1,4],[2,3]]
      Expected : 2
      Why      : The moves are shown in order, and both the first row and second column of the matrix become fully painted at arr[2].

  [2] Input    : arr = [2,8,7,4,1,3,5,6,9], mat = [[3,2,5],[1,4,6],[8,7,9]]
      Expected : 3
      Why      : The second column becomes fully painted at arr[3].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int firstCompleteIndex(vector<int>& arr, vector<vector<int>>& mat);
