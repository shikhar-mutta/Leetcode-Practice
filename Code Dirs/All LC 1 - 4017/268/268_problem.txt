 268. Missing Number
 Easy  |  Tags: Array, Hash Table, Math, Binary Search, Bit Manipulation, Sorting
 https://leetcode.com/problems/missing-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array nums containing n distinct numbers in the range [0, n],
  return the only number in the range that is missing from the array.

CONSTRAINTS
  n == nums.length
  1 <= n <= 10^4
  0 <= nums[i] <= n
  All the numbers of nums are unique.

TEST CASES
  [1] Input    : nums = [3,0,1]
      Expected : 2
      Why      : n = 3 since there are 3 numbers, so all numbers are in the range [0,3]. 2 is the missing number in the range since it does not appear in nums.

  [2] Input    : nums = [0,1]
      Expected : 2
      Why      : n = 2 since there are 2 numbers, so all numbers are in the range [0,2]. 2 is the missing number in the range since it does not appear in nums.

  [3] Input    : nums = [9,6,4,2,3,5,7,0,1]
      Expected : 8
      Why      : n = 9 since there are 9 numbers, so all numbers are in the range [0,9]. 8 is the missing number in the range since it does not appear in nums.

FOLLOW UP
  Could you implement a solution using only O(1) extra space complexity
  and O(n) runtime complexity?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int missingNumber(vector<int>& nums);
