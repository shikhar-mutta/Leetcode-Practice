 2684. Maximum Number of Moves in a Grid
 Medium  |  Tags: Array, Dynamic Programming, Matrix
 https://leetcode.com/problems/maximum-number-of-moves-in-a-grid/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed m x n matrix grid consisting of positive
  integers.

  You can start at any cell in the first column of the matrix, and
  traverse the grid in the following way:

  - From a cell (row, col), you can move to any of the cells: (row - 1,
    col + 1), (row, col + 1) and (row + 1, col + 1) such that the value of
    the cell you move to, should be strictly bigger than the value of the
    current cell.

  Return the maximum number of moves that you can perform.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  2 <= m, n <= 1000
  4 <= m * n <= 10^5
  1 <= grid[i][j] <= 10^6

TEST CASES
  [1] Input    : grid = [[2,4,3,5],[5,4,9,3],[3,4,2,11],[10,9,13,15]]
      Expected : 3
      Why      : We can start at the cell (0, 0) and make the following moves:
                 - (0, 0) -> (0, 1).
                 - (0, 1) -> (1, 2).
                 … (2 more)

  [2] Input    : grid = [[3,2,4],[2,1,9],[1,1,7]]
      Expected : 0
      Why      : Starting from any cell in the first column we cannot perform any moves.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxMoves(vector<vector<int>>& grid);
