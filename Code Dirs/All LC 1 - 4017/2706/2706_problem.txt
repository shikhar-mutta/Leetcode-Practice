 2706. Buy Two Chocolates
 Easy  |  Tags: Array, Greedy, Sorting
 https://leetcode.com/problems/buy-two-chocolates/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array prices representing the prices of various
  chocolates in a store. You are also given a single integer money, which
  represents your initial amount of money.

  You must buy exactly two chocolates in such a way that you still have
  some non-negative leftover money. You would like to minimize the sum of
  the prices of the two chocolates you buy.

  Return the amount of money you will have leftover after buying the two
  chocolates. If there is no way for you to buy two chocolates without
  ending up in debt, return money. Note that the leftover must be non-
  negative.

CONSTRAINTS
  2 <= prices.length <= 50
  1 <= prices[i] <= 100
  1 <= money <= 100

TEST CASES
  [1] Input    : prices = [1,2,2], money = 3
      Expected : 0
      Why      : Purchase the chocolates priced at 1 and 2 units respectively. You will have 3 - 3 = 0 units of money afterwards. Thus, we return 0.

  [2] Input    : prices = [3,2,3], money = 3
      Expected : 3
      Why      : You cannot buy 2 chocolates without going in debt, so we return 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int buyChoco(vector<int>& prices, int money);
