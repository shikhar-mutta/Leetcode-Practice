 2710. Remove Trailing Zeros From a String
 Easy  |  Tags: String
 https://leetcode.com/problems/remove-trailing-zeros-from-a-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a positive integer num represented as a string, return the integer
  num without trailing zeros as a string.

CONSTRAINTS
  1 <= num.length <= 1000
  num consists of only digits.
  num doesn't have any leading zeros.

TEST CASES
  [1] Input    : num = "51230100"
      Expected : "512301"
      Why      : Integer "51230100" has 2 trailing zeros, we remove them and return integer "512301".

  [2] Input    : num = "123"
      Expected : "123"
      Why      : Integer "123" has no trailing zeros, we return integer "123".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string removeTrailingZeros(string num);

  edit : 2710.cpp
