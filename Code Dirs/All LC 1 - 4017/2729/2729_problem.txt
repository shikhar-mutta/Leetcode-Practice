 2729. Check if The Number is Fascinating
 Easy  |  Tags: Hash Table, Math
 https://leetcode.com/problems/check-if-the-number-is-fascinating/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n that consists of exactly 3 digits.

  We call the number n fascinating if, after the following modification,
  the resulting number contains all the digits from 1 to 9 exactly once
  and does not contain any 0's:

  - Concatenate n with the numbers 2 * n and 3 * n.

  Return true if n is fascinating, or false otherwise.

  Concatenating two numbers means joining them together. For example, the
  concatenation of 121 and 371 is 121371.

CONSTRAINTS
  100 <= n <= 999

TEST CASES
  [1] Input    : n = 192
      Expected : true
      Why      : We concatenate the numbers n = 192 and 2 * n = 384 and 3 * n = 576. The resulting number is 192384576. This number contains all the digits from 1 to 9 exactly once.

  [2] Input    : n = 100
      Expected : false
      Why      : We concatenate the numbers n = 100 and 2 * n = 200 and 3 * n = 300. The resulting number is 100200300. This number does not satisfy any of the conditions.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isFascinating(int n);
