 2746. Decremental String Concatenation
 Medium  |  Tags: Array, String, Dynamic Programming
 https://leetcode.com/problems/decremental-string-concatenation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array words containing n strings.

  Let's define a join operation join(x, y) between two strings x and y as
  concatenating them into xy. However, if the last character of x is equal
  to the first character of y, one of them is deleted.

  For example join("ab", "ba") = "aba" and join("ab", "cde") = "abcde".

  You are to perform n - 1 join operations. Let str0 = words[0]. Starting
  from i = 1 up to i = n - 1, for the i^th operation, you can do one of
  the following:

  - Make stri = join(stri - 1, words[i])

  - Make stri = join(words[i], stri - 1)

  Your task is to minimize the length of strn - 1.

  Return an integer denoting the minimum possible length of strn - 1.

CONSTRAINTS
  1 <= words.length <= 1000
  1 <= words[i].length <= 50
  Each character in words[i] is an English lowercase letter

TEST CASES
  [1] Input    : words = ["aa","ab","bc"]
      Expected : 4
      Why      : In this example, we can perform join operations in the following order to minimize the length of str2:
                 str0 = "aa"
                 str1 = join(str0, "ab") = "aab"
                 … (2 more)

  [2] Input    : words = ["ab","b"]
      Expected : 2
      Why      : In this example, str0 = "ab", there are two ways to get str1:
                 join(str0, "b") = "ab" or join("b", str0) = "bab".
                 The first string, "ab", has the minimum length. Hence, the answer is 2.

  [3] Input    : words = ["aaa","c","aba"]
      Expected : 6
      Why      : In this example, we can perform join operations in the following order to minimize the length of str2:
                 str0 = "aaa"
                 str1 = join(str0, "c") = "aaac"
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
