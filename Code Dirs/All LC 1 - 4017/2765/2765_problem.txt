 2765. Longest Alternating Subarray
 Easy  |  Tags: Array, Enumeration
 https://leetcode.com/problems/longest-alternating-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums. A subarray s of length m
  is called alternating if:

  - m is greater than 1.

  - s1 = s0 + 1.

  - The 0-indexed subarray s looks like [s0, s1, s0, s1,...,s(m-1) % 2].
    In other words, s1 - s0 = 1, s2 - s1 = -1, s3 - s2 = 1, s4 - s3 = -1,
    and so on up to s[m - 1] - s[m - 2] = (-1)^m.

  Return the maximum length of all alternating subarrays present in nums
  or -1 if no such subarray exists.

  A subarray is a contiguous non-empty sequence of elements within an
  array.

CONSTRAINTS
  2 <= nums.length <= 100
  1 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [2,3,4,3,4]
      Expected : 4
      Why      : The alternating subarrays are [2, 3], [3,4], [3,4,3], and [3,4,3,4]. The longest of these is [3,4,3,4], which is of length 4.

  [2] Input    : nums = [4,5,6]
      Expected : 2
      Why      : [4,5] and [5,6] are the only two alternating subarrays. They are both of length 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int alternatingSubarray(vector<int>& nums);
