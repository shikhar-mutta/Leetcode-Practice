 2779. Maximum Beauty of an Array After Applying Operation
 Medium  |  Tags: Array, Binary Search, Sliding Window, Sorting
 https://leetcode.com/problems/maximum-beauty-of-an-array-after-applying-operation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array nums and a non-negative integer k.

  In one operation, you can do the following:

  - Choose an index i that hasn't been chosen before from the range [0,
    nums.length - 1].

  - Replace nums[i] with any integer from the range [nums[i] - k, nums[i]
    + k].

  The beauty of the array is the length of the longest subsequence
  consisting of equal elements.

  Return the maximum possible beauty of the array nums after applying the
  operation any number of times.

  Note that you can apply the operation to each index only once.

  A subsequence of an array is a new array generated from the original
  array by deleting some elements (possibly none) without changing the
  order of the remaining elements.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= nums[i], k <= 10^5

TEST CASES
  [1] Input    : nums = [4,6,1,2], k = 2
      Expected : 3
      Why      : In this example, we apply the following operations:
                 - Choose index 1, replace it with 4 (from range [4,8]), nums = [4,4,1,2].
                 - Choose index 3, replace it with 4 (from range [0,4]), nums = [4,4,1,4].
                 … (2 more)

  [2] Input    : nums = [1,1,1,1], k = 10
      Expected : 4
      Why      : In this example we don't have to apply any operations.
                 The beauty of the array nums is 4 (whole array).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumBeauty(vector<int>& nums, int k);
