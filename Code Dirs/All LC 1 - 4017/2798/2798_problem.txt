 2798. Number of Employees Who Met the Target
 Easy  |  Tags: Array
 https://leetcode.com/problems/number-of-employees-who-met-the-target/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There are n employees in a company, numbered from 0 to n - 1. Each
  employee i has worked for hours[i] hours in the company.

  The company requires each employee to work for at least target hours.

  You are given a 0-indexed array of non-negative integers hours of length
  n and a non-negative integer target.

  Return the integer denoting the number of employees who worked at least
  target hours.

CONSTRAINTS
  1 <= n == hours.length <= 50
  0 <= hours[i], target <= 10^5

TEST CASES
  [1] Input    : hours = [0,1,2,3,4], target = 2
      Expected : 3
      Why      : The company wants each employee to work for at least 2 hours.
                 - Employee 0 worked for 0 hours and didn't meet the target.
                 - Employee 1 worked for 1 hours and didn't meet the target.
                 … (4 more)

  [2] Input    : hours = [5,1,4,2,2], target = 6
      Expected : 0
      Why      : The company wants each employee to work for at least 6 hours.
                 There are 0 employees who met the target.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfEmployeesWhoMetTarget(vector<int>& hours, int target);
