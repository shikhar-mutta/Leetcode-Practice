 2799. Count Complete Subarrays in an Array
 Medium  |  Tags: Array, Hash Table, Sliding Window
 https://leetcode.com/problems/count-complete-subarrays-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums consisting of positive integers.

  We call a subarray of an array complete if the following condition is
  satisfied:

  - The number of distinct elements in the subarray is equal to the number
    of distinct elements in the whole array.

  Return the number of complete subarrays.

  A subarray is a contiguous non-empty part of an array.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 2000

TEST CASES
  [1] Input    : nums = [1,3,1,2,2]
      Expected : 4
      Why      : The complete subarrays are the following: [1,3,1,2], [1,3,1,2,2], [3,1,2] and [3,1,2,2].

  [2] Input    : nums = [5,5,5,5]
      Expected : 10
      Why      : The array consists only of the integer 5, so any subarray is complete. The number of subarrays that we can choose is 10.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countCompleteSubarrays(vector<int>& nums);
