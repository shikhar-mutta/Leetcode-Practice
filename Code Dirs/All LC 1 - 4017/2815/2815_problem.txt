 2815. Max Pair Sum in an Array
 Easy  |  Tags: Array, Hash Table
 https://leetcode.com/problems/max-pair-sum-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. You have to find the maximum sum of
  a pair of numbers from nums such that the largest digit in both numbers
  is equal.

  For example, 2373 is made up of three distinct digits: 2, 3, and 7,
  where 7 is the largest among them.

  Return the maximum sum or -1 if no such pair exists.

CONSTRAINTS
  2 <= nums.length <= 100
  1 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [112,131,411]
      Expected : -1
      Why      : Each numbers largest digit in order is [2,3,4].

  [2] Input    : nums = [2536,1613,3366,162]
      Expected : 5902
      Why      : All the numbers have 6 as their largest digit, so the answer is 2536 + 3366 = 5902.

  [3] Input    : nums = [51,71,17,24,42]
      Expected : 88
      Why      : Each number's largest digit in order is [5,7,7,4,4].
                 So we have only two possible pairs, 71 + 17 = 88 and 24 + 42 = 66.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSum(vector<int>& nums);
