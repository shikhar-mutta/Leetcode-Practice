 2824. Count Pairs Whose Sum is Less than Target
 Easy  |  Tags: Array, Two Pointers, Binary Search, Sorting
 https://leetcode.com/problems/count-pairs-whose-sum-is-less-than-target/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 0-indexed integer array nums of length n and an integer target,
  return the number of pairs (i, j) where 0 <= i < j < n and nums[i] +
  nums[j] < target.

CONSTRAINTS
  1 <= nums.length == n <= 50
  -50 <= nums[i], target <= 50

TEST CASES
  [1] Input    : nums = [-1,1,2,3,1], target = 2
      Expected : 3
      Why      : There are 3 pairs of indices that satisfy the conditions in the statement:
                 - (0, 1) since 0 < 1 and nums[0] + nums[1] = 0 < target
                 - (0, 2) since 0 < 2 and nums[0] + nums[2] = 1 < target
                 … (2 more)

  [2] Input    : nums = [-6,2,5,-2,-7,-1,3], target = -2
      Expected : 10
      Why      : There are 10 pairs of indices that satisfy the conditions in the statement:
                 - (0, 1) since 0 < 1 and nums[0] + nums[1] = -4 < target
                 - (0, 3) since 0 < 3 and nums[0] + nums[3] = -8 < target
                 … (8 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPairs(vector<int>& nums, int target);
