 2826. Sorting Three Groups
 Medium  |  Tags: Array, Binary Search, Dynamic Programming
 https://leetcode.com/problems/sorting-three-groups/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. Each element in nums is 1, 2 or 3.
  In each operation, you can remove an element from nums. Return the
  minimum number of operations to make nums non-decreasing.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 3

TEST CASES
  [1] Input    : nums = [2,1,3,2,1]
      Expected : 3
      Why      : One of the optimal solutions is to remove nums[0], nums[2] and nums[3].

  [2] Input    : nums = [1,3,2,1,3,3]
      Expected : 2
      Why      : One of the optimal solutions is to remove nums[1] and nums[2].

  [3] Input    : nums = [2,2,2,2,3,3]
      Expected : 0
      Why      : nums is already non-decreasing.

FOLLOW UP
  Can you come up with an algorithm that runs in O(n) time complexity?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumOperations(vector<int>& nums);
