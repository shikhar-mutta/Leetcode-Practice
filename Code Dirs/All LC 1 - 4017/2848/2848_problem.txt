 2848. Points That Intersect With Cars
 Easy  |  Tags: Array, Hash Table, Prefix Sum
 https://leetcode.com/problems/points-that-intersect-with-cars/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed 2D integer array nums representing the
  coordinates of the cars parking on a number line. For any index i,
  nums[i] = [starti, endi] where starti is the starting point of the i^th
  car and endi is the ending point of the i^th car.

  Return the number of integer points on the line that are covered with
  any part of a car.

CONSTRAINTS
  1 <= nums.length <= 100
  nums[i].length == 2
  1 <= starti <= endi <= 100

TEST CASES
  [1] Input    : nums = [[3,6],[1,5],[4,7]]
      Expected : 7
      Why      : All the points from 1 to 7 intersect at least one car, therefore the answer would be 7.

  [2] Input    : nums = [[1,3],[5,8]]
      Expected : 7
      Why      : Points intersecting at least one car are 1, 2, 3, 5, 6, 7, 8. There are a total of 7 points, therefore the answer would be 7.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfPoints(vector<vector<int>>& nums);
