 2855. Minimum Right Shifts to Sort the Array
 Easy  |  Tags: Array
 https://leetcode.com/problems/minimum-right-shifts-to-sort-the-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array nums of length n containing distinct
  positive integers. Return the minimum number of right shifts required to
  sort nums and -1 if this is not possible.

  A right shift is defined as shifting the element at index i to index (i
  + 1) % n, for all indices.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100
  nums contains distinct integers.

TEST CASES
  [1] Input    : nums = [3,4,5,1,2]
      Expected : 2
      Why      : After the first right shift, nums = [2,3,4,5,1].
                 After the second right shift, nums = [1,2,3,4,5].
                 Now nums is sorted; therefore the answer is 2.

  [2] Input    : nums = [1,3,5]
      Expected : 0
      Why      : nums is already sorted therefore, the answer is 0.

  [3] Input    : nums = [2,1,4]
      Expected : -1
      Why      : It's impossible to sort the array using right shifts.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumRightShifts(vector<int>& nums);
