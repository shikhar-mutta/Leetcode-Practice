 2856. Minimum Array Length After Pair Removals
 Medium  |  Tags: Array, Hash Table, Two Pointers, Binary Search, Greedy, Counting
 https://leetcode.com/problems/minimum-array-length-after-pair-removals/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array num sorted in non-decreasing order.

  You can perform the following operation any number of times:

  - Choose two indices, i and j, where nums[i] < nums[j].

  - Then, remove the elements at indices i and j from nums. The remaining
    elements retain their original order, and the array is re-indexed.

  Return the minimum length of nums after applying the operation zero or
  more times.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9
  nums is sorted in non-decreasing order.

TEST CASES
  [1] Input    : nums = [1,2,3,4]
      Expected : 0

  [2] Input    : nums = [1,1,2,2,3,3]
      Expected : 0

  [3] Input    : nums = [1000000000,1000000000]
      Expected : 2
      Why      : Since both numbers are equal, they cannot be removed.

  [4] Input    : nums = [2,3,4,4,4]
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minLengthAfterRemovals(vector<int>& nums);
