 2865. Beautiful Towers I
 Medium  |  Tags: Array, Stack, Monotonic Stack
 https://leetcode.com/problems/beautiful-towers-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array heights of n integers representing the number of
  bricks in n consecutive towers. Your task is to remove some bricks to
  form a mountain-shaped tower arrangement. In this arrangement, the tower
  heights are non-decreasing, reaching a maximum peak value with one or
  multiple consecutive towers and then non-increasing.

  Return the maximum possible sum of heights of a mountain-shaped tower
  arrangement.

CONSTRAINTS
  1 <= n == heights.length <= 10^3
  1 <= heights[i] <= 10^9

TEST CASES
  [1] Input    : heights = [5,3,4,1,1]
      Expected : 13
      Why      : We remove some bricks to make heights = [5,3,3,1,1], the peak is at index 0.

  [2] Input    : heights = [6,5,3,9,2,7]
      Expected : 22
      Why      : We remove some bricks to make heights = [3,3,3,9,2,2], the peak is at index 3.

  [3] Input    : heights = [3,2,5,5,2,3]
      Expected : 18
      Why      : We remove some bricks to make heights = [2,2,5,5,2,2], the peak is at index 2 or 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maximumSumOfHeights(vector<int>& heights);
