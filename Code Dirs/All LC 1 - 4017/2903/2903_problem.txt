 2903. Find Indices With Index and Value Difference I
 Easy  |  Tags: Array, Two Pointers
 https://leetcode.com/problems/find-indices-with-index-and-value-difference-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer array nums having length n, an integer
  indexDifference, and an integer valueDifference.

  Your task is to find two indices i and j, both in the range [0, n - 1],
  that satisfy the following conditions:

  - abs(i - j) >= indexDifference, and

  - abs(nums[i] - nums[j]) >= valueDifference

  Return an integer array answer, where answer = [i, j] if there are two
  such indices, and answer = [-1, -1] otherwise. If there are multiple
  choices for the two indices, return any of them.

  Note: i and j may be equal.

CONSTRAINTS
  1 <= n == nums.length <= 100
  0 <= nums[i] <= 50
  0 <= indexDifference <= 100
  0 <= valueDifference <= 50

TEST CASES
  [1] Input    : nums = [5,1,4,1], indexDifference = 2, valueDifference = 4
      Expected : [0,3]
      Why      : In this example, i = 0 and j = 3 can be selected.
                 abs(0 - 3) >= 2 and abs(nums[0] - nums[3]) >= 4.
                 Hence, a valid answer is [0,3].
                 … (1 more)

  [2] Input    : nums = [2,1], indexDifference = 0, valueDifference = 0
      Expected : [0,0]
      Why      : In this example, i = 0 and j = 0 can be selected.
                 abs(0 - 0) >= 0 and abs(nums[0] - nums[0]) >= 0.
                 Hence, a valid answer is [0,0].
                 … (1 more)

  [3] Input    : nums = [1,2,3], indexDifference = 2, valueDifference = 4
      Expected : [-1,-1]
      Why      : In this example, it can be shown that it is impossible to find two indices that satisfy both conditions.
                 Hence, [-1,-1] is returned.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> findIndices(vector<int>& nums, int indexDifference, int valueDifference);
