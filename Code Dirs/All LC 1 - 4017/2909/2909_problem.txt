 2909. Minimum Sum of Mountain Triplets II
 Medium  |  Tags: Array, Prefix Sum
 https://leetcode.com/problems/minimum-sum-of-mountain-triplets-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array nums of integers.

  A triplet of indices (i, j, k) is a mountain if:

  - i < j < k

  - nums[i] < nums[j] and nums[k] < nums[j]

  Return the minimum possible sum of a mountain triplet of nums. If no
  such triplet exists, return -1.

CONSTRAINTS
  3 <= nums.length <= 10^5
  1 <= nums[i] <= 10^8

TEST CASES
  [1] Input    : nums = [8,6,1,5,3]
      Expected : 9
      Why      : Triplet (2, 3, 4) is a mountain triplet of sum 9 since:
                 - 2 < 3 < 4
                 - nums[2] < nums[3] and nums[4] < nums[3]
                 … (1 more)

  [2] Input    : nums = [5,4,8,7,10,2]
      Expected : 13
      Why      : Triplet (1, 3, 5) is a mountain triplet of sum 13 since:
                 - 1 < 3 < 5
                 - nums[1] < nums[3] and nums[5] < nums[3]
                 … (1 more)

  [3] Input    : nums = [6,5,4,3,4,5]
      Expected : -1
      Why      : It can be shown that there are no mountain triplets in nums.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumSum(vector<int>& nums);
