 2928. Distribute Candies Among Children I
 Easy  |  Tags: Math, Combinatorics, Enumeration
 https://leetcode.com/problems/distribute-candies-among-children-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two positive integers n and limit.

  Return the total number of ways to distribute n candies among 3 children
  such that no child gets more than limit candies.

CONSTRAINTS
  1 <= n <= 50
  1 <= limit <= 50

TEST CASES
  [1] Input    : n = 5, limit = 2
      Expected : 3
      Why      : There are 3 ways to distribute 5 candies such that no child gets more than 2 candies: (1, 2, 2), (2, 1, 2) and (2, 2, 1).

  [2] Input    : n = 3, limit = 3
      Expected : 10
      Why      : There are 10 ways to distribute 3 candies such that no child gets more than 3 candies: (0, 0, 3), (0, 1, 2), (0, 2, 1), (0, 3, 0), (1, 0, 2), (1, 1, 1), (1, 2, 0), (2, 0, 1), (2, 1, 0) and (3, 0, 0).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int distributeCandies(int n, int limit);
