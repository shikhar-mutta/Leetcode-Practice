 2942. Find Words Containing Character
 Easy  |  Tags: Array, String
 https://leetcode.com/problems/find-words-containing-character/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array of strings words and a character x.

  Return an array of indices representing the words that contain the
  character x.

  Note that the returned array may be in any order.

CONSTRAINTS
  1 <= words.length <= 50
  1 <= words[i].length <= 50
  x is a lowercase English letter.
  words[i] consists only of lowercase English letters.

TEST CASES
  [1] Input    : words = ["leet","code"], x = "e"
      Expected : [0,1]
      Why      : "e" occurs in both words: "leet", and "code". Hence, we return indices 0 and 1.

  [2] Input    : words = ["abc","bcd","aaaa","cbc"], x = "a"
      Expected : [0,2]
      Why      : "a" occurs in "abc", and "aaaa". Hence, we return indices 0 and 2.

  [3] Input    : words = ["abc","bcd","aaaa","cbc"], x = "z"
      Expected : []
      Why      : "z" does not occur in any of the words. Hence, we return an empty array.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> findWordsContaining(vector<string>& words, char x);
