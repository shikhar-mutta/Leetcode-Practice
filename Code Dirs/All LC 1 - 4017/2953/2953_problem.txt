 2953. Count Complete Substrings
 Hard  |  Tags: Hash Table, String, Sliding Window
 https://leetcode.com/problems/count-complete-substrings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string word and an integer k.

  A substring s of word is complete if:

  - Each character in s occurs exactly k times.

  - The difference between two adjacent characters is at most 2. That is,
    for any two adjacent characters c1 and c2 in s, the absolute
    difference in their positions in the alphabet is at most 2.

  Return the number of complete substrings of word.

  A substring is a non-empty contiguous sequence of characters in a
  string.

CONSTRAINTS
  1 <= word.length <= 10^5
  word consists only of lowercase English letters.
  1 <= k <= word.length

TEST CASES
  [1] Input    : word = "igigee", k = 2
      Expected : 3
      Why      : The complete substrings where each character appears exactly twice and the difference between adjacent characters is at most 2 are: igigee, igigee, igigee.

  [2] Input    : word = "aaabbbccc", k = 3
      Expected : 6
      Why      : The complete substrings where each character appears exactly three times and the difference between adjacent characters is at most 2 are: aaabbbccc, aaabbbccc, aaabbbccc, aaabbbccc, aaabbbccc, aaabbbccc.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countCompleteSubstrings(string word, int k);
