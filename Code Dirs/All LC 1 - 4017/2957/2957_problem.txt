 2957. Remove Adjacent Almost-Equal Characters
 Medium  |  Tags: String, Dynamic Programming, Greedy
 https://leetcode.com/problems/remove-adjacent-almost-equal-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed string word.

  In one operation, you can pick any index i of word and change word[i] to
  any lowercase English letter.

  Return the minimum number of operations needed to remove all adjacent
  almost-equal characters from word.

  Two characters a and b are almost-equal if a == b or a and b are
  adjacent in the alphabet.

CONSTRAINTS
  1 <= word.length <= 100
  word consists only of lowercase English letters.

TEST CASES
  [1] Input    : word = "aaaaa"
      Expected : 2
      Why      : We can change word into "acaca" which does not have any adjacent almost-equal characters.
                 It can be shown that the minimum number of operations needed to remove all adjacent almost-equal characters from word is 2.

  [2] Input    : word = "abddez"
      Expected : 2
      Why      : We can change word into "ybdoez" which does not have any adjacent almost-equal characters.
                 It can be shown that the minimum number of operations needed to remove all adjacent almost-equal characters from word is 2.

  [3] Input    : word = "zyxyxyz"
      Expected : 3
      Why      : We can change word into "zaxaxaz" which does not have any adjacent almost-equal characters.
                 It can be shown that the minimum number of operations needed to remove all adjacent almost-equal characters from word is 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int removeAlmostEqualCharacters(string word);
