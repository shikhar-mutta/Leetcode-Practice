 2962. Count Subarrays Where Max Element Appears at Least K Times
 Medium  |  Tags: Array, Sliding Window
 https://leetcode.com/problems/count-subarrays-where-max-element-appears-at-least-k-times/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and a positive integer k.

  Return the number of subarrays where the maximum element of nums appears
  at least k times in that subarray.

  A subarray is a contiguous sequence of elements within an array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^6
  1 <= k <= 10^5

TEST CASES
  [1] Input    : nums = [1,3,2,3,3], k = 2
      Expected : 6
      Why      : The subarrays that contain the element 3 at least 2 times are: [1,3,2,3], [1,3,2,3,3], [3,2,3], [3,2,3,3], [2,3,3] and [3,3].

  [2] Input    : nums = [1,4,2,1], k = 3
      Expected : 0
      Why      : No subarray contains the element 4 at least 3 times.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countSubarrays(vector<int>& nums, int k);
