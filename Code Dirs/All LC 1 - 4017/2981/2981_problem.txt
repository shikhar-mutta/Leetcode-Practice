 2981. Find Longest Special Substring That Occurs Thrice I
 Medium  |  Tags: Hash Table, String, Binary Search, Sliding Window, Counting
 https://leetcode.com/problems/find-longest-special-substring-that-occurs-thrice-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s that consists of lowercase English letters.

  A string is called special if it is made up of only a single character.
  For example, the string "abc" is not special, whereas the strings "ddd",
  "zz", and "f" are special.

  Return the length of the longest special substring of s which occurs at
  least thrice, or -1 if no special substring occurs at least thrice.

  A substring is a contiguous non-empty sequence of characters within a
  string.

CONSTRAINTS
  3 <= s.length <= 50
  s consists of only lowercase English letters.

TEST CASES
  [1] Input    : s = "aaaa"
      Expected : 2
      Why      : The longest special substring which occurs thrice is "aa": substrings "aaaa", "aaaa", and "aaaa".
                 It can be shown that the maximum length achievable is 2.

  [2] Input    : s = "abcdef"
      Expected : -1
      Why      : There exists no special substring which occurs at least thrice. Hence return -1.

  [3] Input    : s = "abcaba"
      Expected : 1
      Why      : The longest special substring which occurs thrice is "a": substrings "abcaba", "abcaba", and "abcaba".
                 It can be shown that the maximum length achievable is 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumLength(string s);
