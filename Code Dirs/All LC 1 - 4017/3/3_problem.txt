 3. Longest Substring Without Repeating Characters
 Medium  |  Tags: Hash Table, String, Sliding Window
 https://leetcode.com/problems/longest-substring-without-repeating-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, find the length of the longest substring without
  duplicate characters.

CONSTRAINTS
  0 <= s.length <= 10^5
  s consists of English letters, digits, symbols and spaces.

TEST CASES
  [1] Input    : s = "abcabcbb"
      Expected : 3
      Why      : The answer is "abc", with the length of 3. Note that "bca" and "cab" are also correct answers.

  [2] Input    : s = "bbbbb"
      Expected : 1
      Why      : The answer is "b", with the length of 1.

  [3] Input    : s = "pwwkew"
      Expected : 3
      Why      : The answer is "wke", with the length of 3.
                 Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int lengthOfLongestSubstring(string s);

FILES
  edit : 3.cpp
  test : lc run 3
