 3005. Count Elements With Maximum Frequency
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/count-elements-with-maximum-frequency/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums consisting of positive integers.

  Return the total frequencies of elements in nums such that those
  elements all have the maximum frequency.

  The frequency of an element is the number of occurrences of that element
  in the array.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,2,3,1,4]
      Expected : 4
      Why      : The elements 1 and 2 have a frequency of 2 which is the maximum frequency in the array.
                 So the number of elements in the array with maximum frequency is 4.

  [2] Input    : nums = [1,2,3,4,5]
      Expected : 5
      Why      : All elements of the array have a frequency of 1 which is the maximum.
                 So the number of elements in the array with maximum frequency is 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxFrequencyElements(vector<int>& nums);
