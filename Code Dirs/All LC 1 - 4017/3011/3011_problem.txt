 3011. Find if Array Can Be Sorted
 Medium  |  Tags: Array, Bit Manipulation, Sorting
 https://leetcode.com/problems/find-if-array-can-be-sorted/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array of positive integers nums.

  In one operation, you can swap any two adjacent elements if they have
  the same number of set bits. You are allowed to do this operation any
  number of times (including zero).

  Return true if you can sort the array in ascending order, else return
  false.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 2^8

TEST CASES
  [1] Input    : nums = [8,4,2,30,15]
      Expected : true
      Why      : Let's look at the binary representation of every element. The numbers 2, 4, and 8 have one set bit each with binary representation "10", "100", and "1000" respectively. The numbers 15 and 30 have four set bits each with binary representation "1111" and "11110".
                 We can sort the array using 4 operations:
                 - Swap nums[0] with nums[1]. This operation is valid because 8 and 4 have one set bit each. The array becomes [4,8,2,30,15].
                 … (5 more)

  [2] Input    : nums = [1,2,3,4,5]
      Expected : true
      Why      : The array is already sorted, hence we return true.

  [3] Input    : nums = [3,16,8,4,2]
      Expected : false
      Why      : It can be shown that it is not possible to sort the input array using any number of operations.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canSortArray(vector<int>& nums);
