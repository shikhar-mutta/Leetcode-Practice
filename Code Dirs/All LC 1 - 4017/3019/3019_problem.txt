 3019. Number of Changing Keys
 Easy  |  Tags: String
 https://leetcode.com/problems/number-of-changing-keys/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed string s typed by a user. Changing a key is
  defined as using a key different from the last used key. For example, s
  = "ab" has a change of a key while s = "bBBb" does not have any.

  Return the number of times the user had to change the key.

  Note: Modifiers like shift or caps lock won't be counted in changing the
  key that is if a user typed the letter 'a' and then the letter 'A' then
  it will not be considered as a changing of key.

CONSTRAINTS
  1 <= s.length <= 100
  s consists of only upper case and lower case English letters.

TEST CASES
  [1] Input    : s = "aAbBcC"
      Expected : 2
      Why      : From s[0] = 'a' to s[1] = 'A', there is no change of key as caps lock or shift is not counted.
                 From s[1] = 'A' to s[2] = 'b', there is a change of key.
                 From s[2] = 'b' to s[3] = 'B', there is no change of key as caps lock or shift is not counted.
                 … (2 more)

  [2] Input    : s = "AaAaAaaA"
      Expected : 0
      Why      : There is no change of key since only the letters 'a' and 'A' are pressed which does not require change of key.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countKeyChanges(string s);
