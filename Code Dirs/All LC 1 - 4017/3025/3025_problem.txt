 3025. Find the Number of Ways to Place People I
 Medium  |  Tags: Array, Math, Geometry, Sorting, Enumeration
 https://leetcode.com/problems/find-the-number-of-ways-to-place-people-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D array points of size n x 2 representing integer
  coordinates of some points on a 2D plane, where points[i] = [xi, yi].

  Count the number of pairs of points (A, B), where

  - A is on the upper left side of B, and

  - there are no other points in the rectangle (or line) they make
    (including the border), except for the points A and B.

  Return the count.

CONSTRAINTS
  2 <= n <= 50
  points[i].length == 2
  0 <= points[i][0], points[i][1] <= 50
  All points[i] are distinct.

TEST CASES
  [1] Input    : points = [[1,1],[2,2],[3,3]]
      Expected : 0
      Why      : There is no way to choose A and B such that A is on the upper left side of B.

  [2] Input    : points = [[6,2],[4,4],[2,6]]
      Expected : 2
      Why      : - The left one is the pair (points[1], points[0]), where points[1] is on the upper left side of points[0] and the rectangle is empty.
                 - The middle one is the pair (points[2], points[1]), same as the left one it is a valid pair.
                 - The right one is the pair (points[2], points[0]), where points[2] is on the upper left side of points[0], but points[1] is inside the rectangle so it's not a valid pair.

  [3] Input    : points = [[3,1],[1,3],[1,1]]
      Expected : 2
      Why      : - The left one is the pair (points[2], points[0]), where points[2] is on the upper left side of points[0] and there are no other points on the line they form. Note that it is a valid state when the two points form a line.
                 - The middle one is the pair (points[1], points[2]), it is a valid pair same as the left one.
                 - The right one is the pair (points[1], points[0]), it is not a valid pair as points[2] is on the border of the rectangle.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfPairs(vector<vector<int>>& points);
