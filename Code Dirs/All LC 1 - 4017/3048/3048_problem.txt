 3048. Earliest Second to Mark Indices I
 Medium  |  Tags: Array, Binary Search
 https://leetcode.com/problems/earliest-second-to-mark-indices-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two 1-indexed integer arrays, nums and, changeIndices,
  having lengths n and m, respectively.

  Initially, all indices in nums are unmarked. Your task is to mark all
  indices in nums.

  In each second, s, in order from 1 to m (inclusive), you can perform one
  of the following operations:

  - Choose an index i in the range [1, n] and decrement nums[i] by 1.

  - If nums[changeIndices[s]] is equal to 0, mark the index
    changeIndices[s].

  - Do nothing.

  Return an integer denoting the earliest second in the range [1, m] when
  all indices in nums can be marked by choosing operations optimally, or
  -1 if it is impossible.

CONSTRAINTS
  1 <= n == nums.length <= 2000
  0 <= nums[i] <= 10^9
  1 <= m == changeIndices.length <= 2000
  1 <= changeIndices[i] <= n

TEST CASES
  [1] Input    : nums = [2,2,0], changeIndices = [2,2,2,2,3,2,2,1]
      Expected : 8
      Why      : In this example, we have 8 seconds. The following operations can be performed to mark all indices:
                 Second 1: Choose index 1 and decrement nums[1] by one. nums becomes [1,2,0].
                 Second 2: Choose index 1 and decrement nums[1] by one. nums becomes [0,2,0].
                 … (9 more)

  [2] Input    : nums = [1,3], changeIndices = [1,1,1,2,1,1,1]
      Expected : 6
      Why      : In this example, we have 7 seconds. The following operations can be performed to mark all indices:
                 Second 1: Choose index 2 and decrement nums[2] by one. nums becomes [1,2].
                 Second 2: Choose index 2 and decrement nums[2] by one. nums becomes [1,1].
                 … (7 more)

  [3] Input    : nums = [0,1], changeIndices = [2,2,2]
      Expected : -1
      Why      : In this example, it is impossible to mark all indices because index 1 isn't in changeIndices.
                 Hence, the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int earliestSecondToMarkIndices(vector<int>& nums, vector<int>& changeIndices);
