 3070. Count Submatrices with Top-Left Element and Sum Less Than k
 Medium  |  Tags: Array, Matrix, Prefix Sum
 https://leetcode.com/problems/count-submatrices-with-top-left-element-and-sum-less-than-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed integer matrix grid and an integer k.

  Return the number of submatrices that contain the top-left element of
  the grid, and have a sum less than or equal to k.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  1 <= n, m <= 1000
  0 <= grid[i][j] <= 1000
  1 <= k <= 10^9

TEST CASES
  [1] Input    : grid = [[7,6,3],[6,6,1]], k = 18
      Expected : 4
      Why      : There are only 4 submatrices, shown in the image above, that contain the top-left element of grid, and have a sum less than or equal to 18.

  [2] Input    : grid = [[7,2,9],[1,5,0],[2,6,6]], k = 20
      Expected : 6
      Why      : There are only 6 submatrices, shown in the image above, that contain the top-left element of grid, and have a sum less than or equal to 20.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countSubmatrices(vector<vector<int>>& grid, int k);
