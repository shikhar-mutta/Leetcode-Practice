 3095. Shortest Subarray With OR at Least K I
 Easy  |  Tags: Array, Bit Manipulation, Sliding Window
 https://leetcode.com/problems/shortest-subarray-with-or-at-least-k-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums of non-negative integers and an integer k.

  An array is called special if the bitwise OR of all of its elements is
  at least k.

  Return the length of the shortest special non-empty subarray of nums, or
  return -1 if no special subarray exists.

CONSTRAINTS
  1 <= nums.length <= 50
  0 <= nums[i] <= 50
  0 <= k < 64

TEST CASES
  [1] Input    : nums = [1,2,3], k = 2
      Expected : 1
      Why      : The subarray [3] has OR value of 3. Hence, we return 1.
                 Note that [2] is also a special subarray.

  [2] Input    : nums = [2,1,8], k = 10
      Expected : 3
      Why      : The subarray [2,1,8] has OR value of 11. Hence, we return 3.

  [3] Input    : nums = [1,2], k = 0
      Expected : 1
      Why      : The subarray [1] has OR value of 1. Hence, we return 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumSubarrayLength(vector<int>& nums, int k);
