 3099. Harshad Number
 Easy  |  Tags: Math
 https://leetcode.com/problems/harshad-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An integer divisible by the sum of its digits is said to be a Harshad
  number. You are given an integer x. Return the sum of the digits of x if
  x is a Harshad number, otherwise, return -1.

CONSTRAINTS
  1 <= x <= 100

TEST CASES
  [1] Input    : x = 18
      Expected : 9
      Why      : The sum of digits of x is 9. 18 is divisible by 9. So 18 is a Harshad number and the answer is 9.

  [2] Input    : x = 23
      Expected : -1
      Why      : The sum of digits of x is 5. 23 is not divisible by 5. So 23 is not a Harshad number and the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumOfTheDigitsOfHarshadNumber(int x);
