 3115. Maximum Prime Difference
 Medium  |  Tags: Array, Math, Number Theory, Primality Test
 https://leetcode.com/problems/maximum-prime-difference/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Return an integer that is the maximum distance between the indices of
  two (not necessarily different) prime numbers in nums.

CONSTRAINTS
  1 <= nums.length <= 3 * 10^5
  1 <= nums[i] <= 100
  The input is generated such that the number of prime numbers in the nums is at least one.

TEST CASES
  [1] Input    : nums = [4,2,9,5,3]
      Expected : 3
      Why      : nums[1], nums[3], and nums[4] are prime. So the answer is |4 - 1| = 3.

  [2] Input    : nums = [4,8,2,8]
      Expected : 0
      Why      : nums[2] is prime. Because there is just one prime number, the answer is |2 - 2| = 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumPrimeDifference(vector<int>& nums);
