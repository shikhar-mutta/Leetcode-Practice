 3136. Valid Word
 Easy  |  Tags: String
 https://leetcode.com/problems/valid-word/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A word is considered valid if:

  - It contains a minimum of 3 characters.

  - It contains only digits (0-9), and English letters (uppercase and
    lowercase).

  - It includes at least one vowel.

  - It includes at least one consonant.

  You are given a string word.

  Return true if word is valid, otherwise, return false.

  Notes:

  - 'a', 'e', 'i', 'o', 'u', and their uppercases are vowels.

  - A consonant is an English letter that is not a vowel.

CONSTRAINTS
  1 <= word.length <= 20
  word consists of English uppercase and lowercase letters, digits, '@', '#', and '$'.

TEST CASES
  [1] Input    : word = "234Adas"
      Expected : true
      Why      : This word satisfies the conditions.

  [2] Input    : word = "b3"
      Expected : false
      Why      : The length of this word is fewer than 3, and does not have a vowel.

  [3] Input    : word = "a3$e"
      Expected : false
      Why      : This word contains a '$' character and does not have a consonant.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isValid(string word);
