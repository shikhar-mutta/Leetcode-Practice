 3138. Minimum Length of Anagram Concatenation
 Medium  |  Tags: Hash Table, String, Counting
 https://leetcode.com/problems/minimum-length-of-anagram-concatenation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s, which is known to be a concatenation of
  anagrams of some string t.

  Return the minimum possible length of the string t.

  An anagram is formed by rearranging the letters of a string. For
  example, "aab", "aba", and, "baa" are anagrams of "aab".

CONSTRAINTS
  1 <= s.length <= 10^5
  s consist only of lowercase English letters.

TEST CASES
  [1] Input    : s = "abba"
      Expected : 2
      Why      : One possible string t could be "ba".

  [2] Input    : s = "cdef"
      Expected : 4
      Why      : One possible string t could be "cdef", notice that t can be equal to s.

  [3] Input    : s = "abcbcacabbaccba"
      Expected : 3

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minAnagramLength(string s);
