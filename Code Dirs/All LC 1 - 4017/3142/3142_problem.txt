 3142. Check if Grid Satisfies Conditions
 Easy  |  Tags: Array, Matrix
 https://leetcode.com/problems/check-if-grid-satisfies-conditions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D matrix grid of size m x n. You need to check if each
  cell grid[i][j] is:

  - Equal to the cell below it, i.e. grid[i][j] == grid[i + 1][j] (if it
    exists).

  - Different from the cell to its right, i.e. grid[i][j] != grid[i][j +
    1] (if it exists).

  Return true if all the cells satisfy these conditions, otherwise, return
  false.

CONSTRAINTS
  1 <= n, m <= 10
  0 <= grid[i][j] <= 9

TEST CASES
  [1] Input    : grid = [[1,0,2],[1,0,2]]
      Expected : true
      Why      : All the cells in the grid satisfy the conditions.

  [2] Input    : grid = [[1,1,1],[0,0,0]]
      Expected : false
      Why      : All cells in the first row are equal.

  [3] Input    : grid = [[1],[2],[3]]
      Expected : false
      Why      : Cells in the first column have different values.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool satisfiesConditions(vector<vector<int>>& grid);
