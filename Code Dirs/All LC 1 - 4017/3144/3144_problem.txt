 3144. Minimum Substring Partition of Equal Character Frequency
 Medium  |  Tags: Hash Table, String, Dynamic Programming, Counting
 https://leetcode.com/problems/minimum-substring-partition-of-equal-character-frequency/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, you need to partition it into one or more balanced
  substrings. For example, if s == "ababcc" then ("abab", "c", "c"),
  ("ab", "abc", "c"), and ("ababcc") are all valid partitions, but ("a",
  "bab", "cc"), ("aba", "bc", "c"), and ("ab", "abcc") are not. The
  unbalanced substrings are bolded.

  Return the minimum number of substrings that you can partition s into.

  Note: A balanced string is a string where each character in the string
  occurs the same number of times.

CONSTRAINTS
  1 <= s.length <= 1000
  s consists only of English lowercase letters.

TEST CASES
  [1] Input    : s = "fabccddg"
      Expected : 3
      Why      : We can partition the string s into 3 substrings in one of the following ways: ("fab, "ccdd", "g"), or ("fabc", "cd", "dg").

  [2] Input    : s = "abababaccddb"
      Expected : 2
      Why      : We can partition the string s into 2 substrings like so: ("abab", "abaccddb").

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumSubstringsInPartition(string s);
