 315. Count of Smaller Numbers After Self
 Hard  |  Tags: Array, Binary Search, Divide and Conquer, Binary Indexed Tree, Segment Tree, Merge Sort, Ordered Set, Treap
 https://leetcode.com/problems/count-of-smaller-numbers-after-self/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return an integer array counts where
  counts[i] is the number of smaller elements to the right of nums[i].

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^4 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [5,2,6,1]
      Expected : [2,1,1,0]
      Why      : To the right of 5 there are 2 smaller elements (2 and 1).
                 To the right of 2 there is only 1 smaller element (1).
                 To the right of 6 there is 1 smaller element (1).
                 … (1 more)

  [2] Input    : nums = [-1]
      Expected : [0]

  [3] Input    : nums = [-1,-1]
      Expected : [0,0]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> countSmaller(vector<int>& nums);

FILES
  edit : 315.cpp
  test : lc run 315
