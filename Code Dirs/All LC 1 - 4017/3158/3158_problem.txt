 3158. Find the XOR of Numbers Which Appear Twice
 Easy  |  Tags: Array, Hash Table, Bit Manipulation
 https://leetcode.com/problems/find-the-xor-of-numbers-which-appear-twice/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums, where each number in the array appears
  either once or twice.

  Return the bitwise XOR of all the numbers that appear twice in the
  array, or 0 if no number appears twice.

CONSTRAINTS
  1 <= nums.length <= 50
  1 <= nums[i] <= 50
  Each number in nums appears either once or twice.

TEST CASES
  [1] Input    : nums = [1,2,1,3]
      Expected : 1
      Why      : The only number that appears twice in nums is 1.

  [2] Input    : nums = [1,2,3]
      Expected : 0
      Why      : No number appears twice in nums.

  [3] Input    : nums = [1,2,2,1]
      Expected : 3
      Why      : Numbers 1 and 2 appeared twice. 1 XOR 2 == 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int duplicateNumbersXOR(vector<int>& nums);
