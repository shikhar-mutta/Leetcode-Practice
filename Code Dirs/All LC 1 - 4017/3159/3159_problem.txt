 3159. Find Occurrences of an Element in an Array
 Medium  |  Tags: Array, Hash Table
 https://leetcode.com/problems/find-occurrences-of-an-element-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums, an integer array queries, and an
  integer x.

  For each queries[i], you need to find the index of the queries[i]^th
  occurrence of x in the nums array. If there are fewer than queries[i]
  occurrences of x, the answer should be -1 for that query.

  Return an integer array answer containing the answers to all queries.

CONSTRAINTS
  1 <= nums.length, queries.length <= 10^5
  1 <= queries[i] <= 10^5
  1 <= nums[i], x <= 10^4

TEST CASES
  [1] Input    : nums = [1,3,1,7], queries = [1,3,2,4], x = 1
      Expected : [0,-1,2,-1]
      Why      : - For the 1^st query, the first occurrence of 1 is at index 0.
                 - For the 2^nd query, there are only two occurrences of 1 in nums, so the answer is -1.
                 - For the 3^rd query, the second occurrence of 1 is at index 2.
                 … (1 more)

  [2] Input    : nums = [1,2,3], queries = [10], x = 5
      Expected : [-1]
      Why      : - For the 1^st query, 5 doesn't exist in nums, so the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> occurrencesOfElement(vector<int>& nums, vector<int>& queries, int x);
