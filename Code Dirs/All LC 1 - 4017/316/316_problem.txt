 316. Remove Duplicate Letters
 Medium  |  Tags: String, Stack, Greedy, Monotonic Stack
 https://leetcode.com/problems/remove-duplicate-letters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, remove duplicate letters so that every letter appears
  once and only once. You must make sure your result is the smallest in
  lexicographical order among all possible results.

CONSTRAINTS
  1 <= s.length <= 10^4
  s consists of lowercase English letters.

TEST CASES
  [1] Input    : s = "bcabc"
      Expected : "abc"

  [2] Input    : s = "cbacdcbc"
      Expected : "acdb"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string removeDuplicateLetters(string s);

FILES
  edit : 316.cpp
  test : lc run 316
