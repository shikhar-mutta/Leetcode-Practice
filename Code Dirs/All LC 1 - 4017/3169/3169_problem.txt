 3169. Count Days Without Meetings
 Medium  |  Tags: Array, Sorting
 https://leetcode.com/problems/count-days-without-meetings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer days representing the total number of
  days an employee is available for work (starting from day 1). You are
  also given a 2D array meetings of size n where, meetings[i] = [start_i,
  end_i] represents the starting and ending days of meeting i (inclusive).

  Return the count of days when the employee is available for work but no
  meetings are scheduled.

  Note: The meetings may overlap.

CONSTRAINTS
  1 <= days <= 10^9
  1 <= meetings.length <= 10^5
  meetings[i].length == 2
  1 <= meetings[i][0] <= meetings[i][1] <= days

TEST CASES
  [1] Input    : days = 10, meetings = [[5,7],[1,3],[9,10]]
      Expected : 2
      Why      : There is no meeting scheduled on the 4^th and 8^th days.

  [2] Input    : days = 5, meetings = [[2,4],[1,3]]
      Expected : 1
      Why      : There is no meeting scheduled on the 5^thday.

  [3] Input    : days = 6, meetings = [[1,6]]
      Expected : 0
      Why      : Meetings are scheduled for all working days.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countDays(int days, vector<vector<int>>& meetings);
