 318. Maximum Product of Word Lengths
 Medium  |  Tags: Array, String, Bit Manipulation
 https://leetcode.com/problems/maximum-product-of-word-lengths/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string array words, return the maximum value of length(word[i])
  * length(word[j]) where the two words do not share common letters. If no
  such two words exist, return 0.

CONSTRAINTS
  2 <= words.length <= 1000
  1 <= words[i].length <= 1000
  words[i] consists only of lowercase English letters.

TEST CASES
  [1] Input    : words = ["abcw","baz","foo","bar","xtfn","abcdef"]
      Expected : 16
      Why      : The two words can be "abcw", "xtfn".

  [2] Input    : words = ["a","ab","abc","d","cd","bcd","abcd"]
      Expected : 4
      Why      : The two words can be "ab", "cd".

  [3] Input    : words = ["a","aa","aaa","aaaa"]
      Expected : 0
      Why      : No such pair of words.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxProduct(vector<string>& words);
