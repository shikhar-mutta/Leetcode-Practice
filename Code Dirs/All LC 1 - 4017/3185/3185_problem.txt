 3185. Count Pairs That Form a Complete Day II
 Medium  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/count-pairs-that-form-a-complete-day-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array hours representing times in hours, return an
  integer denoting the number of pairs i, j where i < j and hours[i] +
  hours[j] forms a complete day.

  A complete day is defined as a time duration that is an exact multiple
  of 24 hours.

  For example, 1 day is 24 hours, 2 days is 48 hours, 3 days is 72 hours,
  and so on.

CONSTRAINTS
  1 <= hours.length <= 5 * 10^5
  1 <= hours[i] <= 10^9

TEST CASES
  [1] Input    : hours = [12,12,30,24,24]
      Expected : 2
      Why      : The pairs of indices that form a complete day are (0, 1) and (3, 4).

  [2] Input    : hours = [72,48,24,3]
      Expected : 3
      Why      : The pairs of indices that form a complete day are (0, 1), (0, 2), and (1, 2).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countCompleteDayPairs(vector<int>& hours);

FILES
  edit : 3185.cpp
