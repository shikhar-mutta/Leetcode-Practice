 3193. Count the Number of Inversions
 Hard  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/count-the-number-of-inversions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n and a 2D array requirements, where
  requirements[i] = [endi, cnti] represents the end index and the
  inversion count of each requirement.

  A pair of indices (i, j) from an integer array nums is called an
  inversion if:

  - i < j and nums[i] > nums[j]

  Return the number of permutations perm of [0, 1, 2, ..., n - 1] such
  that for all requirements[i], perm[0..endi] has exactly cnti inversions.

  Since the answer may be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  2 <= n <= 300
  1 <= requirements.length <= n
  requirements[i] = [endi, cnti]
  0 <= endi <= n - 1
  0 <= cnti <= 400
  The input is generated such that there is at least one i such that endi == n - 1.
  The input is generated such that all endi are unique.

TEST CASES
  [1] Input    : n = 3, requirements = [[2,2],[0,0]]
      Expected : 2
      Why      : The two permutations are:
                 - [2, 0, 1]
                 - Prefix [2, 0, 1] has inversions (0, 1) and (0, 2).
                 … (4 more)

  [2] Input    : n = 3, requirements = [[2,2],[1,1],[0,0]]
      Expected : 1
      Why      : The only satisfying permutation is [2, 0, 1]:
                 - Prefix [2, 0, 1] has inversions (0, 1) and (0, 2).
                 - Prefix [2, 0] has an inversion (0, 1).
                 … (1 more)

  [3] Input    : n = 2, requirements = [[0,0],[1,0]]
      Expected : 1
      Why      : The only satisfying permutation is [0, 1]:
                 - Prefix [0] has 0 inversions.
                 - Prefix [0, 1] has no inversions.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfPermutations(int n, vector<vector<int>>& requirements);
