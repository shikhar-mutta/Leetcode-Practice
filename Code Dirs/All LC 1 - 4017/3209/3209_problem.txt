 3209. Number of Subarrays With AND Value of K
 Hard  |  Tags: Array, Binary Search, Bit Manipulation, Segment Tree
 https://leetcode.com/problems/number-of-subarrays-with-and-value-of-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers nums and an integer k, return the number of
  subarrays of nums where the bitwise AND of the elements of the subarray
  equals k.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= nums[i], k <= 10^9

TEST CASES
  [1] Input    : nums = [1,1,1], k = 1
      Expected : 6
      Why      : All subarrays contain only 1's.

  [2] Input    : nums = [1,1,2], k = 1
      Expected : 3
      Why      : Subarrays having an AND value of 1 are: [1,1,2], [1,1,2], [1,1,2].

  [3] Input    : nums = [1,2,3], k = 2
      Expected : 2
      Why      : Subarrays having an AND value of 2 are: [1,2,3], [1,2,3].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countSubarrays(vector<int>& nums, int k);
