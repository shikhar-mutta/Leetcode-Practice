 3212. Count Submatrices With Equal Frequency of X and Y
 Medium  |  Tags: Array, Matrix, Prefix Sum
 https://leetcode.com/problems/count-submatrices-with-equal-frequency-of-x-and-y/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a 2D character matrix grid, where grid[i][j] is either 'X', 'Y',
  or '.', return the number of submatrices that contain:

  - grid[0][0]

  - an equal frequency of 'X' and 'Y'.

  - at least one 'X'.

CONSTRAINTS
  1 <= grid.length, grid[i].length <= 1000
  grid[i][j] is either 'X', 'Y', or '.'.

TEST CASES
  [1] Input    : grid = [["X","Y","."],["Y",".","."]]
      Expected : 3

  [2] Input    : grid = [["X","X"],["X","Y"]]
      Expected : 0
      Why      : No submatrix has an equal frequency of 'X' and 'Y'.

  [3] Input    : grid = [[".","."],[".","."]]
      Expected : 0
      Why      : No submatrix has at least one 'X'.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfSubmatrices(vector<vector<char>>& grid);
