 3226. Number of Bit Changes to Make Two Integers Equal
 Easy  |  Tags: Bit Manipulation
 https://leetcode.com/problems/number-of-bit-changes-to-make-two-integers-equal/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two positive integers n and k.

  You can choose any bit in the binary representation of n that is equal
  to 1 and change it to 0.

  Return the number of changes needed to make n equal to k. If it is
  impossible, return -1.

CONSTRAINTS
  1 <= n, k <= 10^6

TEST CASES
  [1] Input    : n = 13, k = 4
      Expected : 2
      Why      : Initially, the binary representations of n and k are n = (1101)2 and k = (0100)2.
                 We can change the first and fourth bits of n. The resulting integer is n = (0100)2 = k.

  [2] Input    : n = 21, k = 21
      Expected : 0
      Why      : n and k are already equal, so no changes are needed.

  [3] Input    : n = 14, k = 13
      Expected : -1
      Why      : It is not possible to make n equal to k.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minChanges(int n, int k);
