 3239. Minimum Number of Flips to Make Binary Grid Palindromic I
 Medium  |  Tags: Array, Two Pointers, Matrix
 https://leetcode.com/problems/minimum-number-of-flips-to-make-binary-grid-palindromic-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an m x n binary matrix grid.

  A row or column is considered palindromic if its values read the same
  forward and backward.

  You can flip any number of cells in grid from 0 to 1, or from 1 to 0.

  Return the minimum number of cells that need to be flipped to make
  either all rows palindromic or all columns palindromic.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  1 <= m * n <= 2 * 10^5
  0 <= grid[i][j] <= 1

TEST CASES
  [1] Input    : grid = [[1,0,0],[0,0,0],[0,0,1]]
      Expected : 2
      Why      : Flipping the highlighted cells makes all the rows palindromic.

  [2] Input    : grid = [[0,1],[0,1],[0,0]]
      Expected : 1
      Why      : Flipping the highlighted cell makes all the columns palindromic.

  [3] Input    : grid = [[1],[0]]
      Expected : 0
      Why      : All rows are already palindromic.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minFlips(vector<vector<int>>& grid);
