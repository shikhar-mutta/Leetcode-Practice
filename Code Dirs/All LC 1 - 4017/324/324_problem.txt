 324. Wiggle Sort II
 Medium  |  Tags: Array, Divide and Conquer, Greedy, Sorting, Quickselect
 https://leetcode.com/problems/wiggle-sort-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, reorder it such that nums[0] < nums[1] >
  nums[2] < nums[3]....

  You may assume the input array always has a valid answer.

CONSTRAINTS
  1 <= nums.length <= 5 * 10^4
  0 <= nums[i] <= 5000
  It is guaranteed that there will be an answer for the given input nums.

TEST CASES
  [1] Input    : nums = [1,5,1,1,6,4]
      Expected : [1,6,1,5,1,4]
      Why      : [1,4,1,5,1,6] is also accepted.

  [2] Input    : nums = [1,3,2,2,3,1]
      Expected : [2,3,1,3,1,2]

FOLLOW UP
  Can you do it in O(n) time and/or in-place with O(1) extra space?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  void wiggleSort(vector<int>& nums);

FILES
  edit : 324.cpp
  test : lc run 324
