 3249. Count the Number of Good Nodes
 Medium  |  Tags: Tree, Depth-First Search
 https://leetcode.com/problems/count-the-number-of-good-nodes/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is an undirected tree with n nodes labeled from 0 to n - 1, and
  rooted at node 0. You are given a 2D integer array edges of length n -
  1, where edges[i] = [ai, bi] indicates that there is an edge between
  nodes ai and bi in the tree.

  A node is good if all the subtrees rooted at its children have the same
  size.

  Return the number of good nodes in the given tree.

  A subtree of treeName is a tree consisting of a node in treeName and all
  of its descendants.

CONSTRAINTS
  2 <= n <= 10^5
  edges.length == n - 1
  edges[i].length == 2
  0 <= ai, bi < n
  The input is generated such that edges represents a valid tree.

TEST CASES
  [1] Input    : edges = [[0,1],[0,2],[1,3],[1,4],[2,5],[2,6]]
      Expected : 7
      Why      : All of the nodes of the given tree are good.

  [2] Input    : edges = [[0,1],[1,2],[1,3],[1,4],[0,5],[5,6],[6,7],[7,8],[0,9],[9,10],[9,12],[10,11]]
      Expected : 12
      Why      : All nodes except node 9 are good.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countGoodNodes(vector<vector<int>>& edges);
