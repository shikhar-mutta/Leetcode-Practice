 3255. Find the Power of K-Size Subarrays II
 Medium  |  Tags: Array, Sliding Window
 https://leetcode.com/problems/find-the-power-of-k-size-subarrays-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of integers nums of length n and a positive
  integer k.

  The power of an array is defined as:

  - Its maximum element if all of its elements are consecutive and sorted
    in ascending order.

  - -1 otherwise.

  You need to find the power of all subarrays of nums of size k.

  Return an integer array results of size n - k + 1, where results[i] is
  the power of nums[i..(i + k - 1)].

CONSTRAINTS
  1 <= n == nums.length <= 10^5
  1 <= nums[i] <= 10^6
  1 <= k <= n

TEST CASES
  [1] Input    : nums = [1,2,3,4,3,2,5], k = 3
      Expected : [3,4,-1,-1,-1]
      Why      : There are 5 subarrays of nums of size 3:
                 - [1, 2, 3] with the maximum element 3.
                 - [2, 3, 4] with the maximum element 4.
                 … (3 more)

  [2] Input    : nums = [2,2,2,2,2], k = 4
      Expected : [-1,-1]

  [3] Input    : nums = [3,2,3,2,3,2], k = 2
      Expected : [-1,3,-1,3,-1]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> resultsArray(vector<int>& nums, int k);
