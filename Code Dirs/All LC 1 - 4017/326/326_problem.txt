 326. Power of Three
 Easy  |  Tags: Math, Recursion
 https://leetcode.com/problems/power-of-three/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, return true if it is a power of three. Otherwise,
  return false.

  An integer n is a power of three, if there exists an integer x such that
  n == 3^x.

CONSTRAINTS
  -2^31 <= n <= 2^31 - 1

TEST CASES
  [1] Input    : n = 27
      Expected : true
      Why      : 27 = 3^3

  [2] Input    : n = 0
      Expected : false
      Why      : There is no x where 3^x = 0.

  [3] Input    : n = -1
      Expected : false
      Why      : There is no x where 3^x = (-1).

FOLLOW UP
  Could you solve it without loops/recursion?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isPowerOfThree(int n);

FILES
  edit : 326.cpp
  test : lc run 326
