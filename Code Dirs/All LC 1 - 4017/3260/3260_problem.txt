 3260. Find the Largest Palindrome Divisible by K
 Hard  |  Tags: Math, String, Dynamic Programming, Greedy, Number Theory
 https://leetcode.com/problems/find-the-largest-palindrome-divisible-by-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two positive integers n and k.

  An integer x is called k-palindromic if:

  - x is a palindrome.

  - x is divisible by k.

  Return the largest integer having n digits (as a string) that is
  k-palindromic.

  Note that the integer must not have leading zeros.

CONSTRAINTS
  1 <= n <= 10^5
  1 <= k <= 9

TEST CASES
  [1] Input    : n = 3, k = 5
      Expected : "595"
      Why      : 595 is the largest k-palindromic integer with 3 digits.

  [2] Input    : n = 1, k = 4
      Expected : "8"
      Why      : 4 and 8 are the only k-palindromic integers with 1 digit.

  [3] Input    : n = 5, k = 6
      Expected : "89898"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string largestPalindrome(int n, int k);
