 327. Count of Range Sum
 Hard  |  Tags: Array, Binary Search, Divide and Conquer, Binary Indexed Tree, Segment Tree, Merge Sort, Ordered Set, Treap
 https://leetcode.com/problems/count-of-range-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums and two integers lower and upper, return the
  number of range sums that lie in [lower, upper] inclusive.

  Range sum S(i, j) is defined as the sum of the elements in nums between
  indices i and j inclusive, where i <= j.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -2^31 <= nums[i] <= 2^31 - 1
  -10^5 <= lower <= upper <= 10^5
  The answer is guaranteed to fit in a 32-bit integer.

TEST CASES
  [1] Input    : nums = [-2,5,-1], lower = -2, upper = 2
      Expected : 3
      Why      : The three ranges are: [0,0], [2,2], and [0,2] and their respective sums are: -2, -1, 2.

  [2] Input    : nums = [0], lower = 0, upper = 0
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countRangeSum(vector<int>& nums, int lower, int upper);

  edit : 327.cpp
