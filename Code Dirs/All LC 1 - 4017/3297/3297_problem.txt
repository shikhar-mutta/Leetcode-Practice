 3297. Count Substrings That Can Be Rearranged to Contain a String I
 Medium  |  Tags: Hash Table, String, Sliding Window
 https://leetcode.com/problems/count-substrings-that-can-be-rearranged-to-contain-a-string-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two strings word1 and word2.

  A string x is called valid if x can be rearranged to have word2 as a
  prefix.

  Return the total number of valid substrings of word1.

CONSTRAINTS
  1 <= word1.length <= 10^5
  1 <= word2.length <= 10^4
  word1 and word2 consist only of lowercase English letters.

TEST CASES
  [1] Input    : word1 = "bcca", word2 = "abc"
      Expected : 1
      Why      : The only valid substring is "bcca" which can be rearranged to "abcc" having "abc" as a prefix.

  [2] Input    : word1 = "abcabc", word2 = "abc"
      Expected : 10
      Why      : All the substrings except substrings of size 1 and size 2 are valid.

  [3] Input    : word1 = "abcabc", word2 = "aaabc"
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long validSubstringCount(string word1, string word2);
