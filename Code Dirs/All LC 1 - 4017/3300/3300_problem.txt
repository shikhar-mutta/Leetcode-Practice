 3300. Minimum Element After Replacement With Digit Sum
 Easy  |  Tags: Array, Math
 https://leetcode.com/problems/minimum-element-after-replacement-with-digit-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  You replace each element in nums with the sum of its digits.

  Return the minimum element in nums after all replacements.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [10,12,13,14]
      Expected : 1
      Why      : nums becomes [1, 3, 4, 5] after all replacements, with minimum element 1.

  [2] Input    : nums = [1,2,3,4]
      Expected : 1
      Why      : nums becomes [1, 2, 3, 4] after all replacements, with minimum element 1.

  [3] Input    : nums = [999,19,199]
      Expected : 10
      Why      : nums becomes [27, 10, 19] after all replacements, with minimum element 10.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minElement(vector<int>& nums);
