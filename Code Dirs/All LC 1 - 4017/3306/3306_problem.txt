 3306. Count of Substrings Containing Every Vowel and K Consonants II
 Medium  |  Tags: Hash Table, String, Sliding Window
 https://leetcode.com/problems/count-of-substrings-containing-every-vowel-and-k-consonants-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string word and a non-negative integer k.

  Return the total number of substrings of word that contain every vowel
  ('a', 'e', 'i', 'o', and 'u') at least once and exactly k consonants.

CONSTRAINTS
  5 <= word.length <= 2 * 10^5
  word consists only of lowercase English letters.
  0 <= k <= word.length - 5

TEST CASES
  [1] Input    : word = "aeioqq", k = 1
      Expected : 0
      Why      : There is no substring with every vowel.

  [2] Input    : word = "aeiou", k = 0
      Expected : 1
      Why      : The only substring with every vowel and zero consonants is word[0..4], which is "aeiou".

  [3] Input    : word = "ieaouqqieaouqq", k = 1
      Expected : 3
      Why      : The substrings with every vowel and one consonant are:
                 - word[0..5], which is "ieaouq".
                 - word[6..11], which is "qieaou".
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countOfSubstrings(string word, int k);
