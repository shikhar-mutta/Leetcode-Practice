 3316. Find Maximum Removals From Source String
 Medium  |  Tags: Array, Hash Table, Two Pointers, String, Dynamic Programming
 https://leetcode.com/problems/find-maximum-removals-from-source-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string source of size n, a string pattern that is a
  subsequence of source, and a sorted integer array targetIndices that
  contains distinct numbers in the range [0, n - 1].

  We define an operation as removing a character at an index idx from
  source such that:

  - idx is an element of targetIndices.

  - pattern remains a subsequence of source after removing the character.

  Performing an operation does not change the indices of the other
  characters in source. For example, if you remove 'c' from "acb", the
  character at index 2 would still be 'b'.

  Return the maximum number of operations that can be performed.

CONSTRAINTS
  1 <= n == source.length <= 3 * 10^3
  1 <= pattern.length <= n
  1 <= targetIndices.length <= n
  targetIndices is sorted in ascending order.
  The input is generated such that targetIndices contains distinct elements in the range [0, n - 1].
  source and pattern consist only of lowercase English letters.
  The input is generated such that pattern appears as a subsequence in source.

TEST CASES
  [1] Input    : source = "abbaa", pattern = "aba", targetIndices = [0,1,2]
      Expected : 1
      Why      : We can't remove source[0] but we can do either of these two operations:
                 - Remove source[1], so that source becomes "a_baa".
                 - Remove source[2], so that source becomes "ab_aa".

  [2] Input    : source = "bcda", pattern = "d", targetIndices = [0,3]
      Expected : 2
      Why      : We can remove source[0] and source[3] in two operations.

  [3] Input    : source = "dda", pattern = "dda", targetIndices = [0,1,2]
      Expected : 0
      Why      : We can't remove any character from source.

  [4] Input    : source = "yeyeykyded", pattern = "yeyyd", targetIndices = [0,2,3,4]
      Expected : 2
      Why      : We can remove source[2] and source[3] in two operations.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxRemovals(string source, string pattern, vector<int>& targetIndices);
