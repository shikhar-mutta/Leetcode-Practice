 3334. Find the Maximum Factor Score of Array
 Medium  |  Tags: Array, Math, Number Theory, Least Common Multiple
 https://leetcode.com/problems/find-the-maximum-factor-score-of-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  The factor score of an array is defined as the product of the LCM and
  GCD of all elements of that array.

  Return the maximum factor score of nums after removing at most one
  element from it.

  Note that both the LCM and GCD of a single number are the number itself,
  and the factor score of an empty array is 0.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 30

TEST CASES
  [1] Input    : nums = [2,4,8,16]
      Expected : 64
      Why      : On removing 2, the GCD of the rest of the elements is 4 while the LCM is 16, which gives a maximum factor score of 4 * 16 = 64.

  [2] Input    : nums = [1,2,3,4,5]
      Expected : 60
      Why      : The maximum factor score of 60 can be obtained without removing any elements.

  [3] Input    : nums = [3]
      Expected : 9

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maxScore(vector<int>& nums);
