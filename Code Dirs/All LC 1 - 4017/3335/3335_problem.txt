 3335. Total Characters in String After Transformations I
 Medium  |  Tags: Hash Table, Math, String, Dynamic Programming, Counting
 https://leetcode.com/problems/total-characters-in-string-after-transformations-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s and an integer t, representing the number of
  transformations to perform. In one transformation, every character in s
  is replaced according to the following rules:

  - If the character is 'z', replace it with the string "ab".

  - Otherwise, replace it with the next character in the alphabet. For
    example, 'a' is replaced with 'b', 'b' is replaced with 'c', and so
    on.

  Return the length of the resulting string after exactly t
  transformations.

  Since the answer may be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= s.length <= 10^5
  s consists only of lowercase English letters.
  1 <= t <= 10^5

TEST CASES
  [1] Input    : s = "abcyy", t = 2
      Expected : 7
      Why      : - First Transformation (t = 1):
                 - 'a' becomes 'b'
                 - 'b' becomes 'c'
                 … (12 more)

  [2] Input    : s = "azbk", t = 1
      Expected : 5
      Why      : - First Transformation (t = 1):
                 - 'a' becomes 'b'
                 - 'z' becomes "ab"
                 … (4 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int lengthAfterTransformations(string s, int t);
