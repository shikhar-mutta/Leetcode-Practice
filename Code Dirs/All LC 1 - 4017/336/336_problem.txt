 336. Palindrome Pairs
 Hard  |  Tags: Array, Hash Table, String, Trie, Hash Function
 https://leetcode.com/problems/palindrome-pairs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 0-indexed array of unique strings words.

  A palindrome pair is a pair of integers (i, j) such that:

  - 0 <= i, j < words.length,

  - i != j, and

  - words[i] + words[j] (the concatenation of the two strings) is a
    palindrome.

  Return an array of all the palindrome pairs of words.

  You must write an algorithm with O(sum of words[i].length) runtime
  complexity.

CONSTRAINTS
  1 <= words.length <= 5000
  0 <= words[i].length <= 300
  words[i] consists of lowercase English letters.

TEST CASES
  [1] Input    : words = ["abcd","dcba","lls","s","sssll"]
      Expected : [[0,1],[1,0],[3,2],[2,4]]
      Why      : The palindromes are ["abcddcba","dcbaabcd","slls","llssssll"]

  [2] Input    : words = ["bat","tab","cat"]
      Expected : [[0,1],[1,0]]
      Why      : The palindromes are ["battab","tabbat"]

  [3] Input    : words = ["a",""]
      Expected : [[0,1],[1,0]]
      Why      : The palindromes are ["a","a"]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> palindromePairs(vector<string>& words);
