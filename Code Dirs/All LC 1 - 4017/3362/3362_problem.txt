 3362. Zero Array Transformation III
 Medium  |  Tags: Array, Two Pointers, Greedy, Sorting, Heap (Priority Queue), Prefix Sum
 https://leetcode.com/problems/zero-array-transformation-iii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of length n and a 2D array queries
  where queries[i] = [li, ri].

  Each queries[i] represents the following action on nums:

  - Decrement the value at each index in the range [li, ri] in nums by at
    most 1.

  - The amount by which the value is decremented can be chosen
    independently for each index.

  A Zero Array is an array with all its elements equal to 0.

  Return the maximum number of elements that can be removed from queries,
  such that nums can still be converted to a zero array using the
  remaining queries. If it is not possible to convert nums to a zero
  array, return -1.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= nums[i] <= 10^5
  1 <= queries.length <= 10^5
  queries[i].length == 2
  0 <= li <= ri < nums.length

TEST CASES
  [1] Input    : nums = [2,0,2], queries = [[0,2],[0,2],[1,1]]
      Expected : 1
      Why      : After removing queries[2], nums can still be converted to a zero array.
                 - Using queries[0], decrement nums[0] and nums[2] by 1 and nums[1] by 0.
                 - Using queries[1], decrement nums[0] and nums[2] by 1 and nums[1] by 0.

  [2] Input    : nums = [1,1,1,1], queries = [[1,3],[0,2],[1,3],[1,2]]
      Expected : 2
      Why      : We can remove queries[2] and queries[3].

  [3] Input    : nums = [1,2,3,4], queries = [[0,3]]
      Expected : -1
      Why      : nums cannot be converted to a zero array even after using all the queries.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxRemoval(vector<int>& nums, vector<vector<int>>& queries);
