 337. House Robber III
 Medium  |  Tags: Dynamic Programming, Tree, Depth-First Search, Binary Tree, DP on Trees
 https://leetcode.com/problems/house-robber-iii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The thief has found himself a new place for his thievery again. There is
  only one entrance to this area, called root.

  Besides the root, each house has one and only one parent house. After a
  tour, the smart thief realized that all houses in this place form a
  binary tree. It will automatically contact the police if two directly-
  linked houses were broken into on the same night.

  Given the root of the binary tree, return the maximum amount of money
  the thief can rob without alerting the police.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 10^4].
  0 <= Node.val <= 10^4

TEST CASES
  [1] Input    : root = [3,2,3,null,3,null,1]
      Expected : 7
      Why      : Maximum amount of money the thief can rob = 3 + 3 + 1 = 7.

  [2] Input    : root = [3,4,5,1,3,null,1]
      Expected : 9
      Why      : Maximum amount of money the thief can rob = 4 + 5 = 9.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int rob(TreeNode* root);
