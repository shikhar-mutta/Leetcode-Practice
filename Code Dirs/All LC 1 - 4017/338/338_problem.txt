 338. Counting Bits
 Easy  |  Tags: Dynamic Programming, Bit Manipulation
 https://leetcode.com/problems/counting-bits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, return an array ans of length n + 1 such that for
  each i (0 <= i <= n), ans[i] is the number of 1's in the binary
  representation of i.

  Do not solve it with built-in functions (i.e., like __builtin_popcount
  in C++).

CONSTRAINTS
  0 <= n <= 10^5

TEST CASES
  [1] Input    : n = 2
      Expected : [0,1,1]
      Why      : 0 --> 0
                 1 --> 1
                 2 --> 10

  [2] Input    : n = 5
      Expected : [0,1,1,2,1,2]
      Why      : 0 --> 0
                 1 --> 1
                 2 --> 10
                 … (3 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> countBits(int n);

FILES
  edit : 338.cpp
  test : lc run 338
