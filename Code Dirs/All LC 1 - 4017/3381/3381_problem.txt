 3381. Maximum Subarray Sum With Length Divisible by K
 Medium  |  Tags: Array, Hash Table, Prefix Sum
 https://leetcode.com/problems/maximum-subarray-sum-with-length-divisible-by-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of integers nums and an integer k.

  Return the maximum sum of a subarray of nums, such that the size of the
  subarray is divisible by k.

CONSTRAINTS
  1 <= k <= nums.length <= 2 * 10^5
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,2], k = 1
      Expected : 3
      Why      : The subarray [1, 2] with sum 3 has length equal to 2 which is divisible by 1.

  [2] Input    : nums = [-1,-2,-3,-4,-5], k = 4
      Expected : -10
      Why      : The maximum sum subarray is [-1, -2, -3, -4] which has length equal to 4 which is divisible by 4.

  [3] Input    : nums = [-5,1,2,-3,4], k = 2
      Expected : 4
      Why      : The maximum sum subarray is [1, 2, -3, 4] which has length equal to 4 which is divisible by 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maxSubarraySum(vector<int>& nums, int k);
