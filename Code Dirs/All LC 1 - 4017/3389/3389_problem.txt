 3389. Minimum Operations to Make Character Frequencies Equal
 Hard  |  Tags: Hash Table, String, Dynamic Programming, Counting, Enumeration
 https://leetcode.com/problems/minimum-operations-to-make-character-frequencies-equal/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s.

  A string t is called good if all characters of t occur the same number
  of times.

  You can perform the following operations any number of times:

  - Delete a character from s.

  - Insert a character in s.

  - Change a character in s to its next letter in the alphabet.

  Note that you cannot change 'z' to 'a' using the third operation.

  Return the minimum number of operations required to make s good.

CONSTRAINTS
  3 <= s.length <= 2 * 10^4
  s contains only lowercase English letters.

TEST CASES
  [1] Input    : s = "acab"
      Expected : 1
      Why      : We can make s good by deleting one occurrence of character 'a'.

  [2] Input    : s = "wddw"
      Expected : 0
      Why      : We do not need to perform any operations since s is initially good.

  [3] Input    : s = "aaabc"
      Expected : 2
      Why      : We can make s good by applying these operations:
                 - Change one occurrence of 'a' to 'b'
                 - Insert one occurrence of 'c' into s

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int makeStringGood(string s);
