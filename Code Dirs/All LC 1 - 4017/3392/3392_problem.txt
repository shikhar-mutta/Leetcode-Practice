 3392. Count Subarrays of Length Three With a Condition
 Easy  |  Tags: Array
 https://leetcode.com/problems/count-subarrays-of-length-three-with-a-condition/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the number of subarrays of length 3
  such that the sum of the first and third numbers equals exactly half of
  the second number.

CONSTRAINTS
  3 <= nums.length <= 100
  -100 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,1,4,1]
      Expected : 1
      Why      : Only the subarray [1,4,1] contains exactly 3 elements where the sum of the first and third numbers equals half the middle number.

  [2] Input    : nums = [1,1,1]
      Expected : 0
      Why      : [1,1,1] is the only subarray of length 3. However, its first and third numbers do not add to half the middle number.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countSubarrays(vector<int>& nums);
