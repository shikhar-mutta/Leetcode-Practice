 3402. Minimum Operations to Make Columns Strictly Increasing
 Easy  |  Tags: Array, Greedy, Matrix
 https://leetcode.com/problems/minimum-operations-to-make-columns-strictly-increasing/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a m x n matrix grid consisting of non-negative integers.

  In one operation, you can increment the value of any grid[i][j] by 1.

  Return the minimum number of operations needed to make all columns of
  grid strictly increasing.

CONSTRAINTS
  m == grid.length
  n == grid[i].length
  1 <= m, n <= 50
  0 <= grid[i][j] < 2500

TEST CASES
  [1] Input    : grid = [[3,2],[1,3],[3,4],[0,1]]
      Expected : 15
      Why      : - To make the 0^th column strictly increasing, we can apply 3 operations on grid[1][0], 2 operations on grid[2][0], and 6 operations on grid[3][0].
                 - To make the 1^st column strictly increasing, we can apply 4 operations on grid[3][1].

  [2] Input    : grid = [[3,2,1],[2,1,0],[1,2,3]]
      Expected : 12
      Why      : - To make the 0^th column strictly increasing, we can apply 2 operations on grid[1][0], and 4 operations on grid[2][0].
                 - To make the 1^st column strictly increasing, we can apply 2 operations on grid[1][1], and 2 operations on grid[2][1].
                 - To make the 2^nd column strictly increasing, we can apply 2 operations on grid[1][2].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumOperations(vector<vector<int>>& grid);
