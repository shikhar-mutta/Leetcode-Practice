 3405. Count the Number of Arrays with K Matching Adjacent Elements
 Hard  |  Tags: Math, Combinatorics, Fermat's Little Theorem
 https://leetcode.com/problems/count-the-number-of-arrays-with-k-matching-adjacent-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given three integers n, m, k. A good array arr of size n is
  defined as follows:

  - Each element in arr is in the inclusive range [1, m].

  - Exactly k indices i (where 1 <= i < n) satisfy the condition arr[i -
    1] == arr[i].

  Return the number of good arrays that can be formed.

  Since the answer may be very large, return it modulo 10^9+ 7.

CONSTRAINTS
  1 <= n <= 10^5
  1 <= m <= 10^5
  0 <= k <= n - 1

TEST CASES
  [1] Input    : n = 3, m = 2, k = 1
      Expected : 4
      Why      : - There are 4 good arrays. They are [1, 1, 2], [1, 2, 2], [2, 1, 1] and [2, 2, 1].
                 - Hence, the answer is 4.

  [2] Input    : n = 4, m = 2, k = 2
      Expected : 6
      Why      : - The good arrays are [1, 1, 1, 2], [1, 1, 2, 2], [1, 2, 2, 2], [2, 1, 1, 1], [2, 2, 1, 1] and [2, 2, 2, 1].
                 - Hence, the answer is 6.

  [3] Input    : n = 5, m = 2, k = 0
      Expected : 2
      Why      : - The good arrays are [1, 2, 1, 2, 1] and [2, 1, 2, 1, 2]. Hence, the answer is 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countGoodArrays(int n, int m, int k);
