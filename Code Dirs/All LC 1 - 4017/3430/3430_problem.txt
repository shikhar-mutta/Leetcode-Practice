 3430. Maximum and Minimum Sums of at Most Size K Subarrays
 Hard  |  Tags: Array, Math, Stack, Monotonic Stack
 https://leetcode.com/problems/maximum-and-minimum-sums-of-at-most-size-k-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and a positive integer k. Return the
  sum of the maximum and minimum elements of all subarrays with at most k
  elements.

CONSTRAINTS
  1 <= nums.length <= 80000
  1 <= k <= nums.length
  -10^6 <= nums[i] <= 10^6

TEST CASES
  [1] Input    : nums = [1,2,3], k = 2
      Expected : 20
      Why      : The subarrays of nums with at most 2 elements are:
                 Subarray
                 Minimum
                 … (25 more)

  [2] Input    : nums = [1,-3,1], k = 2
      Expected : -6
      Why      : The subarrays of nums with at most 2 elements are:
                 Subarray
                 Minimum
                 … (25 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long minMaxSubarraySum(vector<int>& nums, int k);
