 3444. Minimum Increments for Target Multiples in an Array
 Hard  |  Tags: Array, Math, Dynamic Programming, Bit Manipulation, Number Theory, Bitmask
 https://leetcode.com/problems/minimum-increments-for-target-multiples-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two arrays, nums and target.

  In a single operation, you may increment any element of nums by 1.

  Return the minimum number of operations required so that each element in
  target has at least one multiple in nums.

CONSTRAINTS
  1 <= nums.length <= 5 * 10^4
  1 <= target.length <= 4
  target.length <= nums.length
  1 <= nums[i], target[i] <= 10^4

TEST CASES
  [1] Input    : nums = [1,2,3], target = [4]
      Expected : 1
      Why      : The minimum number of operations required to satisfy the condition is 1.
                 - Increment 3 to 4 with just one operation, making 4 a multiple of itself.

  [2] Input    : nums = [8,4], target = [10,5]
      Expected : 2
      Why      : The minimum number of operations required to satisfy the condition is 2.
                 - Increment 8 to 10 with 2 operations, making 10 a multiple of both 5 and 10.

  [3] Input    : nums = [7,9,10], target = [7]
      Expected : 0
      Why      : Target 7 already has a multiple in nums, so no additional operations are needed.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumIncrements(vector<int>& nums, vector<int>& target);
