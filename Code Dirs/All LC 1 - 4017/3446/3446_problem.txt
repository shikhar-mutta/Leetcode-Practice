 3446. Sort Matrix by Diagonals
 Medium  |  Tags: Array, Sorting, Matrix
 https://leetcode.com/problems/sort-matrix-by-diagonals/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an n x n square matrix of integers grid. Return the matrix
  such that:

  - The diagonals in the bottom-left triangle (including the middle
    diagonal) are sorted in non-increasing order.

  - The diagonals in the top-right triangle are sorted in non-decreasing
    order.

CONSTRAINTS
  grid.length == grid[i].length == n
  1 <= n <= 10
  -10^5 <= grid[i][j] <= 10^5

TEST CASES
  [1] Input    : grid = [[1,7,3],[9,8,2],[4,5,6]]
      Expected : [[8,2,3],[9,6,7],[4,5,1]]
      Why      : The diagonals with a black arrow (bottom-left triangle) should be sorted in non-increasing order:
                 - [1, 8, 6] becomes [8, 6, 1].
                 - [9, 5] and [4] remain unchanged.
                 … (3 more)

  [2] Input    : grid = [[0,1],[1,2]]
      Expected : [[2,1],[1,0]]
      Why      : The diagonals with a black arrow must be non-increasing, so [0, 2] is changed to [2, 0]. The other diagonals are already in the correct order.

  [3] Input    : grid = [[1]]
      Expected : [[1]]
      Why      : Diagonals with exactly one element are already in order, so no changes are needed.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> sortMatrix(vector<vector<int>>& grid);
