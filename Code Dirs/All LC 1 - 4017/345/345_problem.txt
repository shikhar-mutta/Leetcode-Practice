 345. Reverse Vowels of a String
 Easy  |  Tags: Two Pointers, String
 https://leetcode.com/problems/reverse-vowels-of-a-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, reverse only all the vowels in the string and return
  it.

  The vowels are 'a', 'e', 'i', 'o', and 'u', and they can appear in both
  lower and upper cases, more than once.

CONSTRAINTS
  1 <= s.length <= 3 * 10^5
  s consist of printable ASCII characters.

TEST CASES
  [1] Input    : s = "IceCreAm"
      Expected : "AceCreIm"
      Why      : The vowels in s are ['I', 'e', 'e', 'A']. On reversing the vowels, s becomes "AceCreIm".

  [2] Input    : s = "leetcode"
      Expected : "leotcede"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string reverseVowels(string s);

FILES
  edit : 345.cpp
  test : lc run 345
