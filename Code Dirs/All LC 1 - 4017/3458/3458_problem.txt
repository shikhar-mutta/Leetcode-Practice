 3458. Select K Disjoint Special Substrings
 Medium  |  Tags: Hash Table, String, Dynamic Programming, Greedy, Sorting
 https://leetcode.com/problems/select-k-disjoint-special-substrings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s of length n and an integer k, determine whether it is
  possible to select k disjoint special substrings.

  A special substring is a substring where:

  - Any character present inside the substring should not appear outside
    it in the string.

  - The substring is not the entire string s.

  Note that all k substrings must be disjoint, meaning they cannot
  overlap.

  Return true if it is possible to select k such disjoint special
  substrings; otherwise, return false.

CONSTRAINTS
  2 <= n == s.length <= 5 * 10^4
  0 <= k <= 26
  s consists only of lowercase English letters.

TEST CASES
  [1] Input    : s = "abcdbaefab", k = 2
      Expected : true
      Why      : - We can select two disjoint special substrings: "cd" and "ef".
                 - "cd" contains the characters 'c' and 'd', which do not appear elsewhere in s.
                 - "ef" contains the characters 'e' and 'f', which do not appear elsewhere in s.

  [2] Input    : s = "cdefdc", k = 3
      Expected : false
      Why      : There can be at most 2 disjoint special substrings: "e" and "f". Since k = 3, the output is false.

  [3] Input    : s = "abeabe", k = 0
      Expected : true

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool maxSubstringLength(string s, int k);
