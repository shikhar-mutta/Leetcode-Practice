 3469. Find Minimum Cost to Remove Array Elements
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/find-minimum-cost-to-remove-array-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. Your task is to remove all elements
  from the array by performing one of the following operations at each
  step until nums is empty:

  - Choose any two elements from the first three elements of nums and
    remove them. The cost of this operation is the maximum of the two
    elements removed.

  - If fewer than three elements remain in nums, remove all the remaining
    elements in a single operation. The cost of this operation is the
    maximum of the remaining elements.

  Return the minimum cost required to remove all the elements.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 10^6

TEST CASES
  [1] Input    : nums = [6,2,8,4]
      Expected : 12
      Why      : Initially, nums = [6, 2, 8, 4].
                 - In the first operation, remove nums[0] = 6 and nums[2] = 8 with a cost of max(6, 8) = 8. Now, nums = [2, 4].
                 - In the second operation, remove the remaining elements with a cost of max(2, 4) = 4.
                 … (1 more)

  [2] Input    : nums = [2,1,3,3]
      Expected : 5
      Why      : Initially, nums = [2, 1, 3, 3].
                 - In the first operation, remove nums[0] = 2 and nums[1] = 1 with a cost of max(2, 1) = 2. Now, nums = [3, 3].
                 - In the second operation remove the remaining elements with a cost of max(3, 3) = 3.
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minCost(vector<int>& nums);
