 3470. Permutations IV
 Hard  |  Tags: Array, Math, Combinatorics, Enumeration
 https://leetcode.com/problems/permutations-iv/description/

PROBLEM
  Given two integers, n and k, an alternating permutation is a permutation
  of the first n positive integers such that no two adjacent elements are
  both odd or both even.

  Return the k-th alternating permutation sorted in lexicographical order.
  If there are fewer than k valid alternating permutations, return an
  empty list.

CONSTRAINTS
  1 <= n <= 100
  1 <= k <= 10^15

TEST CASES
  [1] Input    : n = 4, k = 6
      Expected : [3,4,1,2]
      Why      : The lexicographically-sorted alternating permutations of [1, 2, 3, 4] are:
                 - [1, 2, 3, 4]
                 - [1, 4, 3, 2]
                 … (7 more)

  [2] Input    : n = 3, k = 2
      Expected : [3,2,1]
      Why      : The lexicographically-sorted alternating permutations of [1, 2, 3] are:
                 - [1, 2, 3]
                 - [3, 2, 1] ← 2nd permutation
                 … (1 more)

  [3] Input    : n = 2, k = 3
      Expected : []
      Why      : The lexicographically-sorted alternating permutations of [1, 2] are:
                 - [1, 2]
                 - [2, 1]
                 … (1 more)
