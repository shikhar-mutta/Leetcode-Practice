 3471. Find the Largest Almost Missing Integer
 Easy  |  Tags: Array, Hash Table
 https://leetcode.com/problems/find-the-largest-almost-missing-integer/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer k.

  An integer x is almost missing from nums if x appears in exactly one
  subarray of size k within nums.

  Return the largest almost missing integer from nums. If no such integer
  exists, return -1.

  A subarray is a contiguous sequence of elements within an array.

CONSTRAINTS
  1 <= nums.length <= 50
  0 <= nums[i] <= 50
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [3,9,2,1,7], k = 3
      Expected : 7
      Why      : - 1 appears in 2 subarrays of size 3: [9, 2, 1] and [2, 1, 7].
                 - 2 appears in 3 subarrays of size 3: [3, 9, 2], [9, 2, 1], [2, 1, 7].
                 3 appears in 1 subarray of size 3: [3, 9, 2].
                 … (3 more)

  [2] Input    : nums = [3,9,7,2,1,7], k = 4
      Expected : 3
      Why      : - 1 appears in 2 subarrays of size 4: [9, 7, 2, 1], [7, 2, 1, 7].
                 - 2 appears in 3 subarrays of size 4: [3, 9, 7, 2], [9, 7, 2, 1], [7, 2, 1, 7].
                 - 3 appears in 1 subarray of size 4: [3, 9, 7, 2].
                 … (3 more)

  [3] Input    : nums = [0,0], k = 1
      Expected : -1
      Why      : There is no integer that appears in only one subarray of size 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestInteger(vector<int>& nums, int k);
