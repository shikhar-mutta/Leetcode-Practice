 3473. Sum of K Subarrays With Length at Least M
 Medium  |  Tags: Array, Dynamic Programming, Prefix Sum
 https://leetcode.com/problems/sum-of-k-subarrays-with-length-at-least-m/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and two integers, k and m.

  Return the maximum sum of k non-overlapping subarrays of nums, where
  each subarray has a length of at least m.

CONSTRAINTS
  1 <= nums.length <= 2000
  -10^4 <= nums[i] <= 10^4
  1 <= k <= floor(nums.length / m)
  1 <= m <= 3

TEST CASES
  [1] Input    : nums = [1,2,-1,3,3,4], k = 2, m = 2
      Expected : 13
      Why      : The optimal choice is:
                 - Subarray nums[3..5] with sum 3 + 3 + 4 = 10 (length is 3 >= m).
                 - Subarray nums[0..1] with sum 1 + 2 = 3 (length is 2 >= m).
                 … (1 more)

  [2] Input    : nums = [-10,3,-1,-2], k = 4, m = 1
      Expected : -10
      Why      : The optimal choice is choosing each element as a subarray. The output is (-10) + 3 + (-1) + (-2) = -10.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSum(vector<int>& nums, int k, int m);
