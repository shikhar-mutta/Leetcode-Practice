 3487. Maximum Unique Subarray Sum After Deletion
 Easy  |  Tags: Array, Hash Table, Greedy
 https://leetcode.com/problems/maximum-unique-subarray-sum-after-deletion/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  You are allowed to delete any number of elements from nums without
  making it empty. After performing the deletions, select a subarray of
  nums such that:

  - All elements in the subarray are unique.

  - The sum of the elements in the subarray is maximized.

  Return the maximum sum of such a subarray.

CONSTRAINTS
  1 <= nums.length <= 100
  -100 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,3,4,5]
      Expected : 15
      Why      : Select the entire array without deleting any element to obtain the maximum sum.

  [2] Input    : nums = [1,1,0,1,1]
      Expected : 1
      Why      : Delete the element nums[0] == 1, nums[1] == 1, nums[2] == 0, and nums[3] == 1. Select the entire array [1] to obtain the maximum sum.

  [3] Input    : nums = [1,2,-1,-2,1,0,-1]
      Expected : 3
      Why      : Delete the elements nums[2] == -1 and nums[3] == -2, and select the subarray [2, 1] from [1, 2, 1, 0, -1] to obtain the maximum sum.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSum(vector<int>& nums);
