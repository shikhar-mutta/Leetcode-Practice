 3514. Number of Unique XOR Triplets II
 Medium  |  Tags: Array, Math, Bit Manipulation, Enumeration
 https://leetcode.com/problems/number-of-unique-xor-triplets-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  A XOR triplet is defined as the XOR of three elements nums[i] XOR
  nums[j] XOR nums[k] where i <= j <= k.

  Return the number of unique XOR triplet values from all possible
  triplets (i, j, k).

CONSTRAINTS
  1 <= nums.length <= 1500
  1 <= nums[i] <= 1500

TEST CASES
  [1] Input    : nums = [1,3]
      Expected : 2
      Why      : The possible XOR triplet values are:
                 (0, 0, 0) → 1 XOR 1 XOR 1 = 1
                 (0, 0, 1) → 1 XOR 1 XOR 3 = 3
                 … (3 more)

  [2] Input    : nums = [6,7,8,9]
      Expected : 4
      Why      : The possible XOR triplet values are {6, 7, 8, 9}. Thus, the output is 4.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int uniqueXorTriplets(vector<int>& nums);
