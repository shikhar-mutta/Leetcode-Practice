 3517. Smallest Palindromic Rearrangement I
 Medium  |  Tags: String, Sorting, Counting Sort
 https://leetcode.com/problems/smallest-palindromic-rearrangement-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a palindromic string s.

  Return the lexicographically smallest palindromic permutation of s.

CONSTRAINTS
  1 <= s.length <= 10^5
  s consists of lowercase English letters.
  s is guaranteed to be palindromic.

TEST CASES
  [1] Input    : s = "z"
      Expected : "z"
      Why      : A string of only one character is already the lexicographically smallest palindrome.

  [2] Input    : s = "babab"
      Expected : "abbba"
      Why      : Rearranging "babab" → "abbba" gives the smallest lexicographic palindrome.

  [3] Input    : s = "daccad"
      Expected : "acddca"
      Why      : Rearranging "daccad" → "acddca" gives the smallest lexicographic palindrome.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string smallestPalindrome(string s);
