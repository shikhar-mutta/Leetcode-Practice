 3531. Count Covered Buildings
 Medium  |  Tags: Array, Hash Table, Sorting
 https://leetcode.com/problems/count-covered-buildings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer n, representing an n x n city. You are
  also given a 2D grid buildings, where buildings[i] = [x, y] denotes a
  unique building located at coordinates [x, y].

  A building is covered if there is at least one building in all four
  directions: left, right, above, and below.

  Return the number of covered buildings.

CONSTRAINTS
  2 <= n <= 10^5
  1 <= buildings.length <= 10^5
  buildings[i] = [x, y]
  1 <= x, y <= n
  All coordinates of buildings are unique.

TEST CASES
  [1] Input    : n = 3, buildings = [[1,2],[2,2],[3,2],[2,1],[2,3]]
      Expected : 1
      Why      : - Only building [2,2] is covered as it has at least one building:
                 - above ([1,2])
                 - below ([3,2])
                 … (3 more)

  [2] Input    : n = 3, buildings = [[1,1],[1,2],[2,1],[2,2]]
      Expected : 0
      Why      : - No building has at least one building in all four directions.

  [3] Input    : n = 5, buildings = [[1,3],[3,2],[3,3],[3,5],[5,3]]
      Expected : 1
      Why      : - Only building [3,3] is covered as it has at least one building:
                 - above ([1,3])
                 - below ([5,3])
                 … (3 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countCoveredBuildings(int n, vector<vector<int>>& buildings);
