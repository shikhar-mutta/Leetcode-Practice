 3536. Maximum Product of Two Digits
 Easy  |  Tags: Math, Sorting
 https://leetcode.com/problems/maximum-product-of-two-digits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer n.

  Return the maximum product of any two digits in n.

  Note: You may use the same digit twice if it appears more than once in
  n.

CONSTRAINTS
  10 <= n <= 10^9

TEST CASES
  [1] Input    : n = 31
      Expected : 3
      Why      : - The digits of n are [3, 1].
                 - The possible products of any two digits are: 3 * 1 = 3.
                 - The maximum product is 3.

  [2] Input    : n = 22
      Expected : 4
      Why      : - The digits of n are [2, 2].
                 - The possible products of any two digits are: 2 * 2 = 4.
                 - The maximum product is 4.

  [3] Input    : n = 124
      Expected : 8
      Why      : - The digits of n are [1, 2, 4].
                 - The possible products of any two digits are: 1 * 2 = 2, 1 * 4 = 4, 2 * 4 = 8.
                 - The maximum product is 8.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxProduct(int n);
