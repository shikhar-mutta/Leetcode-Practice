 354. Russian Doll Envelopes
 Hard  |  Tags: Array, Binary Search, Dynamic Programming, Sorting, Longest Increasing Subsequence
 https://leetcode.com/problems/russian-doll-envelopes/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D array of integers envelopes where envelopes[i] = [wi,
  hi] represents the width and the height of an envelope.

  One envelope can fit into another if and only if both the width and
  height of one envelope are greater than the other envelope's width and
  height.

  Return the maximum number of envelopes you can Russian doll (i.e., put
  one inside the other).

  Note: You cannot rotate an envelope.

CONSTRAINTS
  1 <= envelopes.length <= 10^5
  envelopes[i].length == 2
  1 <= wi, hi <= 10^5

TEST CASES
  [1] Input    : envelopes = [[5,4],[6,4],[6,7],[2,3]]
      Expected : 3
      Why      : The maximum number of envelopes you can Russian doll is 3 ([2,3] => [5,4] => [6,7]).

  [2] Input    : envelopes = [[1,1],[1,1],[1,1]]
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxEnvelopes(vector<vector<int>>& envelopes);
