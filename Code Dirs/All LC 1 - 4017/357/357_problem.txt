 357. Count Numbers with Unique Digits
 Medium  |  Tags: Math, Dynamic Programming, Backtracking
 https://leetcode.com/problems/count-numbers-with-unique-digits/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, return the count of all numbers with unique digits,
  x, where 0 <= x < 10^n.

CONSTRAINTS
  0 <= n <= 8

TEST CASES
  [1] Input    : n = 2
      Expected : 91
      Why      : The answer should be the total numbers in the range of 0 ≤ x < 100, excluding 11,22,33,44,55,66,77,88,99

  [2] Input    : n = 0
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countNumbersWithUniqueDigits(int n);

FILES
  edit : 357.cpp
  test : lc run 357
