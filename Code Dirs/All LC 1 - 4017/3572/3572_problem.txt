 3572. Maximize Y‑Sum by Picking a Triplet of Distinct X‑Values
 Medium  |  Tags: Array, Hash Table, Greedy, Sorting, Heap (Priority Queue)
 https://leetcode.com/problems/maximize-ysum-by-picking-a-triplet-of-distinct-xvalues/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integer arrays x and y, each of length n. You must
  choose three distinct indices i, j, and k such that:

  - x[i] != x[j]

  - x[j] != x[k]

  - x[k] != x[i]

  Your goal is to maximize the value of y[i] + y[j] + y[k] under these
  conditions. Return the maximum possible sum that can be obtained by
  choosing such a triplet of indices.

  If no such triplet exists, return -1.

CONSTRAINTS
  n == x.length == y.length
  3 <= n <= 10^5
  1 <= x[i], y[i] <= 10^6

TEST CASES
  [1] Input    : x = [1,2,1,3,2], y = [5,3,4,6,2]
      Expected : 14
      Why      : - Choose i = 0 (x[i] = 1, y[i] = 5), j = 1 (x[j] = 2, y[j] = 3), k = 3 (x[k] = 3, y[k] = 6).
                 - All three values chosen from x are distinct. 5 + 3 + 6 = 14 is the maximum we can obtain. Hence, the output is 14.

  [2] Input    : x = [1,2,1,2], y = [4,5,6,7]
      Expected : -1
      Why      : - There are only two distinct values in x. Hence, the output is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSumDistinctTriplet(vector<int>& x, vector<int>& y);
