 3587. Minimum Adjacent Swaps to Alternate Parity
 Medium  |  Tags: Array, Greedy
 https://leetcode.com/problems/minimum-adjacent-swaps-to-alternate-parity/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums of distinct integers.

  In one operation, you can swap any two adjacent elements in the array.

  An arrangement of the array is considered valid if the parity of
  adjacent elements alternates, meaning every pair of neighboring elements
  consists of one even and one odd number.

  Return the minimum number of adjacent swaps required to transform nums
  into any valid arrangement.

  If it is impossible to rearrange nums such that no two adjacent elements
  have the same parity, return -1.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9
  All elements in nums are distinct.

TEST CASES
  [1] Input    : nums = [2,4,6,5,7]
      Expected : 3
      Why      : Swapping 5 and 6, the array becomes [2,4,5,6,7]
                 Swapping 5 and 4, the array becomes [2,5,4,6,7]
                 Swapping 6 and 7, the array becomes [2,5,4,7,6]. The array is now a valid arrangement. Thus, the answer is 3.

  [2] Input    : nums = [2,4,5,7]
      Expected : 1
      Why      : By swapping 4 and 5, the array becomes [2,5,4,7], which is a valid arrangement. Thus, the answer is 1.

  [3] Input    : nums = [1,2,3]
      Expected : 0
      Why      : The array is already a valid arrangement. Thus, no operations are needed.

  [4] Input    : nums = [4,5,6,8]
      Expected : -1
      Why      : No valid arrangement is possible. Thus, the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minSwaps(vector<int>& nums);
