 3623. Count Number of Trapezoids I
 Medium  |  Tags: Array, Hash Table, Math, Geometry
 https://leetcode.com/problems/count-number-of-trapezoids-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array points, where points[i] = [xi, yi]
  represents the coordinates of the i^th point on the Cartesian plane.

  A horizontal trapezoid is a convex quadrilateral with at least one pair
  of horizontal sides (i.e. parallel to the x-axis). Two lines are
  parallel if and only if they have the same slope.

  Return the number of unique horizontal trapezoids that can be formed by
  choosing any four distinct points from points.

  Since the answer may be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  4 <= points.length <= 10^5
  –10^8 <= xi, yi <= 10^8
  All points are pairwise distinct.

TEST CASES
  [1] Input    : points = [[1,0],[2,0],[3,0],[2,2],[3,2]]
      Expected : 3
      Why      : There are three distinct ways to pick four points that form a horizontal trapezoid:
                 Using points [1,0], [2,0], [3,2], and [2,2].
                 Using points [2,0], [3,0], [3,2], and [2,2].
                 … (1 more)

  [2] Input    : points = [[0,0],[1,0],[0,1],[2,1]]
      Expected : 1
      Why      : There is only one horizontal trapezoid that can be formed.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countTrapezoids(vector<vector<int>>& points);
