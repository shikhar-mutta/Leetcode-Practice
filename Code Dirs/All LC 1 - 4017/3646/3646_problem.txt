 3646. Next Special Palindrome Number
 Hard  |  Tags: Backtracking, Bit Manipulation
 https://leetcode.com/problems/next-special-palindrome-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n.

  A number is called special if:

  - It is a palindrome.

  - Every digit k in the number appears exactly k times.

  Return the smallest special number strictly greater than n.

CONSTRAINTS
  0 <= n <= 10^15

TEST CASES
  [1] Input    : n = 2
      Expected : 22
      Why      : 22 is the smallest special number greater than 2, as it is a palindrome and the digit 2 appears exactly 2 times.

  [2] Input    : n = 33
      Expected : 212
      Why      : 212 is the smallest special number greater than 33, as it is a palindrome and the digits 1 and 2 appear exactly 1 and 2 times respectively.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long specialPalindrome(long long n);
