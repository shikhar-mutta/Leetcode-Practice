 3658. GCD of Odd and Even Sums
 Easy  |  Tags: Math, Number Theory
 https://leetcode.com/problems/gcd-of-odd-and-even-sums/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n. Your task is to compute the GCD (greatest
  common divisor) of two values:

  -
  sumOdd: the sum of the smallest n positive odd numbers.



  -
  sumEven: the sum of the smallest n positive even numbers.



  Return the GCD of sumOdd and sumEven.

CONSTRAINTS
  1 <= n <= 1000

TEST CASES
  [1] Input    : n = 4
      Expected : 4
      Why      : - Sum of the first 4 odd numbers sumOdd = 1 + 3 + 5 + 7 = 16
                 - Sum of the first 4 even numbers sumEven = 2 + 4 + 6 + 8 = 20
                 Hence, GCD(sumOdd, sumEven) = GCD(16, 20) = 4.

  [2] Input    : n = 5
      Expected : 5
      Why      : - Sum of the first 5 odd numbers sumOdd = 1 + 3 + 5 + 7 + 9 = 25
                 - Sum of the first 5 even numbers sumEven = 2 + 4 + 6 + 8 + 10 = 30
                 Hence, GCD(sumOdd, sumEven) = GCD(25, 30) = 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int gcdOfOddEvenSums(int n);
