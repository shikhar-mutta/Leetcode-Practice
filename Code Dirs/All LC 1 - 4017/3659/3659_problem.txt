 3659. Partition Array Into K-Distinct Groups
 Medium  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/partition-array-into-k-distinct-groups/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer k.

  Your task is to determine whether it is possible to partition all
  elements of nums into one or more groups such that:

  - Each group contains exactly k elements.

  - All elements in each group are distinct.

  - Each element in nums must be assigned to exactly one group.

  Return true if such a partition is possible, otherwise return false.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5
  ^1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [1,2,3,4], k = 2
      Expected : true
      Why      : One possible partition is to have 2 groups:
                 - Group 1: [1, 2]
                 - Group 2: [3, 4]
                 … (1 more)

  [2] Input    : nums = [3,5,2,2], k = 2
      Expected : true
      Why      : One possible partition is to have 2 groups:
                 - Group 1: [2, 3]
                 - Group 2: [2, 5]
                 … (1 more)

  [3] Input    : nums = [1,5,2,3], k = 3
      Expected : false
      Why      : We cannot form groups of k = 3 distinct elements using all values exactly once.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool partitionArray(vector<int>& nums, int k);
