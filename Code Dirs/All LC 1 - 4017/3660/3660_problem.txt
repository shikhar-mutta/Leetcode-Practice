 3660. Jump Game IX
 Medium  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/jump-game-ix/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  From any index i, you can jump to another index j under the following
  rules:

  - Jump to index j where j > i is allowed only if nums[j] < nums[i].

  - Jump to index j where j < i is allowed only if nums[j] > nums[i].

  For each index i, find the maximum value in nums that can be reached by
  following any sequence of valid jumps starting at i.

  Return an array ans where ans[i] is the maximum value reachable starting
  from index i.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [2,1,3]
      Expected : [2,2,3]
      Why      : - For i = 0: No jump increases the value.
                 - For i = 1: Jump to j = 0 as nums[j] = 2 is greater than nums[i].
                 - For i = 2: Since nums[2] = 3 is the maximum value in nums, no jump increases the value.
                 … (1 more)

  [2] Input    : nums = [2,3,1]
      Expected : [3,3,3]
      Why      : - For i = 0: Jump forward to j = 2 as nums[j] = 1 is less than nums[i] = 2, then from i = 2 jump to j = 1 as nums[j] = 3 is greater than nums[2].
                 - For i = 1: Since nums[1] = 3 is the maximum value in nums, no jump increases the value.
                 - For i = 2: Jump to j = 1 as nums[j] = 3 is greater than nums[2] = 1.
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> maxValue(vector<int>& nums);
