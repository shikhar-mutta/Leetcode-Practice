 3663. Find The Least Frequent Digit
 Easy  |  Tags: Array, Hash Table, Math, Counting
 https://leetcode.com/problems/find-the-least-frequent-digit/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, find the digit that occurs least frequently in its
  decimal representation. If multiple digits have the same frequency,
  choose the smallest digit.

  Return the chosen digit as an integer.

  The frequency of a digit x is the number of times it appears in the
  decimal representation of n.

CONSTRAINTS
  1 <= n <= 2^31 - 1

TEST CASES
  [1] Input    : n = 1553322
      Expected : 1
      Why      : The least frequent digit in n is 1, which appears only once. All other digits appear twice.

  [2] Input    : n = 723344511
      Expected : 2
      Why      : The least frequent digits in n are 7, 2, and 5; each appears only once.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int getLeastFrequentDigit(int n);
