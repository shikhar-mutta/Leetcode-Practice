 3666. Minimum Operations to Equalize Binary String
 Hard  |  Tags: Math, String, Breadth-First Search, Union-Find, Ordered Set
 https://leetcode.com/problems/minimum-operations-to-equalize-binary-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a binary string s, and an integer k.

  In one operation, you must choose exactly k different indices and flip
  each '0' to '1' and each '1' to '0'.

  Return the minimum number of operations required to make all characters
  in the string equal to '1'. If it is not possible, return -1.

CONSTRAINTS
  1 <= s.length <= 10^5
  s[i] is either '0' or '1'.
  1 <= k <= s.length

TEST CASES
  [1] Input    : s = "110", k = 1
      Expected : 1
      Why      : - There is one '0' in s.
                 - Since k = 1, we can flip it directly in one operation.

  [2] Input    : s = "0101", k = 3
      Expected : 2
      Why      : One optimal set of operations choosing k = 3 indices in each operation is:
                 - Operation 1: Flip indices [0, 1, 3]. s changes from "0101" to "1000".
                 - Operation 2: Flip indices [1, 2, 3]. s changes from "1000" to "1111".
                 … (1 more)

  [3] Input    : s = "101", k = 2
      Expected : -1
      Why      : Since k = 2 and s has only one '0', it is impossible to flip exactly k indices to make all '1'. Hence, the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minOperations(string s, int k);
