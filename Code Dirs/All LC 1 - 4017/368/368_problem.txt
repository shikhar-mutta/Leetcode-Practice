 368. Largest Divisible Subset
 Medium  |  Tags: Array, Math, Dynamic Programming, Sorting
 https://leetcode.com/problems/largest-divisible-subset/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a set of distinct positive integers nums, return the largest
  subset answer such that every pair (answer[i], answer[j]) of elements in
  this subset satisfies:

  - answer[i] % answer[j] == 0, or

  - answer[j] % answer[i] == 0

  If there are multiple solutions, return any of them.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 2 * 10^9
  All the integers in nums are unique.

TEST CASES
  [1] Input    : nums = [1,2,3]
      Expected : [1,2]
      Why      : [1,3] is also accepted.

  [2] Input    : nums = [1,2,4,8]
      Expected : [1,2,4,8]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> largestDivisibleSubset(vector<int>& nums);

FILES
  edit : 368.cpp
  test : lc run 368
