 3683. Earliest Time to Finish One Task
 Easy  |  Tags: Array
 https://leetcode.com/problems/earliest-time-to-finish-one-task/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array tasks where tasks[i] = [si, ti].

  Each [si, ti] in tasks represents a task with start time si that takes
  ti units of time to finish.

  Return the earliest time at which at least one task is finished.

CONSTRAINTS
  1 <= tasks.length <= 100
  tasks[i] = [si, ti]
  1 <= si, ti <= 100

TEST CASES
  [1] Input    : tasks = [[1,6],[2,3]]
      Expected : 5
      Why      : The first task starts at time t = 1 and finishes at time 1 + 6 = 7. The second task finishes at time 2 + 3 = 5. You can finish one task at time 5.

  [2] Input    : tasks = [[100,100],[100,100],[100,100]]
      Expected : 200
      Why      : All three tasks finish at time 100 + 100 = 200.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int earliestTime(vector<vector<int>>& tasks);
