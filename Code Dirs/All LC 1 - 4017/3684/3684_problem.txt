 3684. Maximize Sum of At Most K Distinct Elements
 Easy  |  Tags: Array, Hash Table, Greedy, Sorting
 https://leetcode.com/problems/maximize-sum-of-at-most-k-distinct-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer array nums and an integer k.

  Choose at most k elements from nums so that their sum is maximized.
  However, the chosen numbers must be distinct.

  Return an array containing the chosen numbers in strictly descending
  order.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 10^9
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [84,93,100,77,90], k = 3
      Expected : [100,93,90]
      Why      : The maximum sum is 283, which is attained by choosing 93, 100 and 90. We rearrange them in strictly descending order as [100, 93, 90].

  [2] Input    : nums = [84,93,100,77,93], k = 3
      Expected : [100,93,84]
      Why      : The maximum sum is 277, which is attained by choosing 84, 93 and 100. We rearrange them in strictly descending order as [100, 93, 84]. We cannot choose 93, 100 and 93 because the chosen numbers must be distinct.

  [3] Input    : nums = [1,1,1,2,2,2], k = 6
      Expected : [2,1]
      Why      : The maximum sum is 3, which is attained by choosing 1 and 2. We rearrange them in strictly descending order as [2, 1].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> maxKDistinct(vector<int>& nums, int k);
