 3686. Number of Stable Subsequences
 Hard  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/number-of-stable-subsequences/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  A subsequence is stable if it does not contain three consecutive
  elements with the same parity when the subsequence is read in order
  (i.e., consecutive inside the subsequence).

  Return the number of stable subsequences.

  Since the answer may be too large, return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [1,3,5]
      Expected : 6
      Why      : - Stable subsequences are [1], [3], [5], [1, 3], [1, 5], and [3, 5].
                 - Subsequence [1, 3, 5] is not stable because it contains three consecutive odd numbers. Thus, the answer is 6.

  [2] Input    : nums = [2,3,4,2]
      Expected : 14
      Why      : - The only subsequence that is not stable is [2, 4, 2], which contains three consecutive even numbers.
                 - All other subsequences are stable. Thus, the answer is 14.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countStableSubsequences(vector<int>& nums);
