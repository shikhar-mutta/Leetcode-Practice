 3688. Bitwise OR of Even Numbers in an Array
 Easy  |  Tags: Array, Bit Manipulation, Simulation
 https://leetcode.com/problems/bitwise-or-of-even-numbers-in-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Return the bitwise OR of all even numbers in the array.

  If there are no even numbers in nums, return 0.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,3,4,5,6]
      Expected : 6
      Why      : The even numbers are 2, 4, and 6. Their bitwise OR equals 6.

  [2] Input    : nums = [7,9,11]
      Expected : 0
      Why      : There are no even numbers, so the result is 0.

  [3] Input    : nums = [1,8,16]
      Expected : 24
      Why      : The even numbers are 8 and 16. Their bitwise OR equals 24.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int evenNumberBitwiseORs(vector<int>& nums);
