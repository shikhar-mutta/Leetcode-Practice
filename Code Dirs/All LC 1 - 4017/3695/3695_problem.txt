 3695. Maximize Alternating Sum Using Swaps
 Hard  |  Tags: Array, Greedy, Union-Find, Sorting
 https://leetcode.com/problems/maximize-alternating-sum-using-swaps/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  You want to maximize the alternating sum of nums, which is defined as
  the value obtained by adding elements at even indices and subtracting
  elements at odd indices. That is, nums[0] - nums[1] + nums[2] -
  nums[3]...

  You are also given a 2D integer array swaps where swaps[i] = [pi, qi].
  For each pair [pi, qi] in swaps, you are allowed to swap the elements at
  indices pi and qi. These swaps can be performed any number of times and
  in any order.

  Return the maximum possible alternating sum of nums.

CONSTRAINTS
  2 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9
  0 <= swaps.length <= 10^5
  swaps[i] = [pi, qi]
  0 <= pi < qi <= nums.length - 1
  [pi, qi] != [pj, qj]

TEST CASES
  [1] Input    : nums = [1,2,3], swaps = [[0,2],[1,2]]
      Expected : 4
      Why      : The maximum alternating sum is achieved when nums is [2, 1, 3] or [3, 1, 2]. As an example, you can obtain nums = [2, 1, 3] as follows.
                 - Swap nums[0] and nums[2]. nums is now [3, 2, 1].
                 - Swap nums[1] and nums[2]. nums is now [3, 1, 2].
                 … (1 more)

  [2] Input    : nums = [1,2,3], swaps = [[1,2]]
      Expected : 2
      Why      : The maximum alternating sum is achieved by not performing any swaps.

  [3] Input    : nums = [1,1000000000,1,1000000000,1,1000000000], swaps = []
      Expected : -2999999997
      Why      : Since we cannot perform any swaps, the maximum alternating sum is achieved by not performing any swaps.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maxAlternatingSum(vector<int>& nums, vector<vector<int>>& swaps);
