 3701. Compute Alternating Sum
 Easy  |  Tags: Array, Simulation
 https://leetcode.com/problems/compute-alternating-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  The alternating sum of nums is the value obtained by adding elements at
  even indices and subtracting elements at odd indices. That is, nums[0] -
  nums[1] + nums[2] - nums[3]...

  Return an integer denoting the alternating sum of nums.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,3,5,7]
      Expected : -4
      Why      : - Elements at even indices are nums[0] = 1 and nums[2] = 5 because 0 and 2 are even numbers.
                 - Elements at odd indices are nums[1] = 3 and nums[3] = 7 because 1 and 3 are odd numbers.
                 - The alternating sum is nums[0] - nums[1] + nums[2] - nums[3] = 1 - 3 + 5 - 7 = -4.

  [2] Input    : nums = [100]
      Expected : 100
      Why      : - The only element at even indices is nums[0] = 100 because 0 is an even number.
                 - There are no elements on odd indices.
                 - The alternating sum is nums[0] = 100.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int alternatingSum(vector<int>& nums);
