 3704. Count No-Zero Pairs That Sum to N
 Hard  |  Tags: Math, Dynamic Programming
 https://leetcode.com/problems/count-no-zero-pairs-that-sum-to-n/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A no-zero integer is a positive integer that does not contain the digit
  0 in its decimal representation.

  Given an integer n, count the number of pairs (a, b) where:

  - a and b are no-zero integers.

  - a + b = n

  Return an integer denoting the number of such pairs.

CONSTRAINTS
  2 <= n <= 10^15

TEST CASES
  [1] Input    : n = 2
      Expected : 1
      Why      : The only pair is (1, 1).

  [2] Input    : n = 3
      Expected : 2
      Why      : The pairs are (1, 2) and (2, 1).

  [3] Input    : n = 11
      Expected : 8
      Why      : The pairs are (2, 9), (3, 8), (4, 7), (5, 6), (6, 5), (7, 4), (8, 3), and (9, 2). Note that (1, 10) and (10, 1) do not satisfy the conditions because 10 contains 0 in its decimal representation.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countNoZeroPairs(long long n);
