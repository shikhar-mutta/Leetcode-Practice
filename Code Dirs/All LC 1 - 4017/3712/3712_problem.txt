 3712. Sum of Elements With Frequency Divisible by K
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/sum-of-elements-with-frequency-divisible-by-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer k.

  Return an integer denoting the sum of all elements in nums whose
  frequency is divisible by k, or 0 if there are no such elements.

  Note: An element is included in the sum exactly as many times as it
  appears in the array if its total frequency is divisible by k.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100
  1 <= k <= 100

TEST CASES
  [1] Input    : nums = [1,2,2,3,3,3,3,4], k = 2
      Expected : 16
      Why      : - The number 1 appears once (odd frequency).
                 - The number 2 appears twice (even frequency).
                 - The number 3 appears four times (even frequency).
                 … (2 more)

  [2] Input    : nums = [1,2,3,4,5], k = 2
      Expected : 0
      Why      : There are no elements that appear an even number of times, so the total sum is 0.

  [3] Input    : nums = [4,4,4,1,2,3], k = 3
      Expected : 12
      Why      : - The number 1 appears once.
                 - The number 2 appears once.
                 - The number 3 appears once.
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumDivisibleByK(vector<int>& nums, int k);
