 3718. Smallest Missing Multiple of K
 Easy  |  Tags: Array, Hash Table
 https://leetcode.com/problems/smallest-missing-multiple-of-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums and an integer k, return the smallest
  positive multiple of k that is missing from nums.

  A multiple of k is any positive integer divisible by k.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100
  1 <= k <= 100

TEST CASES
  [1] Input    : nums = [8,2,3,4,6], k = 2
      Expected : 10
      Why      : The multiples of k = 2 are 2, 4, 6, 8, 10, 12... and the smallest multiple missing from nums is 10.

  [2] Input    : nums = [1,4,7,10,15], k = 5
      Expected : 5
      Why      : The multiples of k = 5 are 5, 10, 15, 20... and the smallest multiple missing from nums is 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int missingMultiple(vector<int>& nums, int k);
