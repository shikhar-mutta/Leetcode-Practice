 3739. Count Subarrays With Majority Element II
 Hard  |  Tags: Array, Hash Table, Divide and Conquer, Segment Tree, Merge Sort, Prefix Sum
 https://leetcode.com/problems/count-subarrays-with-majority-element-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer target.

  Return the number of subarrays of nums in which target is the majority
  element.

  The majority element of a subarray is the element that appears strictly
  more than half of the times in that subarray.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9
  1 <= target <= 10^9

TEST CASES
  [1] Input    : nums = [1,2,2,3], target = 2
      Expected : 5
      Why      : Valid subarrays with target = 2 as the majority element:
                 - nums[1..1] = [2]
                 - nums[2..2] = [2]
                 … (4 more)

  [2] Input    : nums = [1,1,1,1], target = 1
      Expected : 10
      Why      : All 10 subarrays have 1 as the majority element.

  [3] Input    : nums = [1,2,3], target = 4
      Expected : 0
      Why      : target = 4 does not appear in nums at all. Therefore, there cannot be any subarray where 4 is the majority element. Hence the answer is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countMajoritySubarrays(vector<int>& nums, int target);
