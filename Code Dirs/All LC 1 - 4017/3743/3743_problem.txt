 3743. Maximize Cyclic Partition Score
 Hard  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/maximize-cyclic-partition-score/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a cyclic array nums and an integer k.

  Partition nums into at most k subarrays. As nums is cyclic, these
  subarrays may wrap around from the end of the array back to the
  beginning.

  The range of a subarray is the difference between its maximum and
  minimum values. The score of a partition is the sum of subarray ranges.

  Return the maximum possible score among all cyclic partitions.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 10^9
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [1,2,3,3], k = 2
      Expected : 3
      Why      : - Partition nums into [2, 3] and [3, 1] (wrapped around).
                 - The range of [2, 3] is max(2, 3) - min(2, 3) = 3 - 2 = 1.
                 - The range of [3, 1] is max(3, 1) - min(3, 1) = 3 - 1 = 2.
                 … (1 more)

  [2] Input    : nums = [1,2,3,3], k = 1
      Expected : 2
      Why      : - Partition nums into [1, 2, 3, 3].
                 - The range of [1, 2, 3, 3] is max(1, 2, 3, 3) - min(1, 2, 3, 3) = 3 - 1 = 2.
                 - The score is 2.

  [3] Input    : nums = [1,2,3,3], k = 4
      Expected : 3
      Why      : Identical to Example 1, we partition nums into [2, 3] and [3, 1]. Note that nums may be partitioned into fewer than k subarrays.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maximumScore(vector<int>& nums, int k);
