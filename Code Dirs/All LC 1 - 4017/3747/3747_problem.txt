 3747. Count Distinct Integers After Removing Zeros
 Medium  |  Tags: Math, Dynamic Programming
 https://leetcode.com/problems/count-distinct-integers-after-removing-zeros/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer n.

  For every integer x from 1 to n, we write down the integer obtained by
  removing all zeros from the decimal representation of x.

  Return an integer denoting the number of distinct integers written down.

CONSTRAINTS
  1 <= n <= 10^15

TEST CASES
  [1] Input    : n = 10
      Expected : 9
      Why      : The integers we wrote down are 1, 2, 3, 4, 5, 6, 7, 8, 9, 1. There are 9 distinct integers (1, 2, 3, 4, 5, 6, 7, 8, 9).

  [2] Input    : n = 3
      Expected : 3
      Why      : The integers we wrote down are 1, 2, 3. There are 3 distinct integers (1, 2, 3).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countDistinct(long long n);

  edit : 3747.cpp
