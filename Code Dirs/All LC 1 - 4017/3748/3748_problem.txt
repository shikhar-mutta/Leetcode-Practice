 3748. Count Stable Subarrays
 Hard  |  Tags: Array, Binary Search, Prefix Sum
 https://leetcode.com/problems/count-stable-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  A subarray of nums is called stable if it contains no inversions, i.e.,
  there is no pair of indices i < j such that nums[i] > nums[j].

  You are also given a 2D integer array queries of length q, where each
  queries[i] = [li, ri] represents a query. For each query [li, ri],
  compute the number of stable subarrays that lie entirely within the
  segment nums[li..ri].

  Return an integer array ans of length q, where ans[i] is the answer to
  the i^th query.

  Note:

  - A single element subarray is considered stable.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5
  1 <= queries.length <= 10^5
  queries[i] = [li, ri]
  0 <= li <= ri <= nums.length - 1

TEST CASES
  [1] Input    : nums = [3,1,2], queries = [[0,1],[1,2],[0,2]]
      Expected : [2,3,4]
      Why      : - For queries[0] = [0, 1], the subarray is [nums[0], nums[1]] = [3, 1].
                 - The stable subarrays are [3] and [1]. The total number of stable subarrays is 2.
                 - For queries[1] = [1, 2], the subarray is [nums[1], nums[2]] = [1, 2].
                 … (4 more)

  [2] Input    : nums = [2,2], queries = [[0,1],[0,0]]
      Expected : [3,1]
      Why      : - For queries[0] = [0, 1], the subarray is [nums[0], nums[1]] = [2, 2].
                 - The stable subarrays are [2], [2], and [2, 2]. The total number of stable subarrays is 3.
                 - For queries[1] = [0, 0], the subarray is [nums[0]] = [2].
                 … (2 more)
