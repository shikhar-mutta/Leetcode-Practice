 375. Guess Number Higher or Lower II
 Medium  |  Tags: Math, Dynamic Programming, Minimax, Game Theory
 https://leetcode.com/problems/guess-number-higher-or-lower-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  We are playing the Guessing Game. The game will work as follows:

  - I pick a number between 1 and n.

  - You guess a number.

  - If you guess the right number, you win the game.

  - If you guess the wrong number, then I will tell you whether the number
    I picked is higher or lower, and you will continue guessing.

  - Every time you guess a wrong number x, you will pay x dollars. If you
    run out of money, you lose the game.

  Given a particular n, return the minimum amount of money you need to
  guarantee a win regardless of what number I pick.

CONSTRAINTS
  1 <= n <= 200

TEST CASES
  [1] Input    : n = 10
      Expected : 16
      Why      : The winning strategy is as follows:
                 - The range is [1,10]. Guess 7.
                 - If this is my number, your total is $0. Otherwise, you pay $7.
                 … (14 more)

  [2] Input    : n = 1
      Expected : 0
      Why      : There is only one possible number, so you can guess 1 and not have to pay anything.

  [3] Input    : n = 2
      Expected : 1
      Why      : There are two possible numbers, 1 and 2.
                 - Guess 1.
                 - If this is my number, your total is $0. Otherwise, you pay $1.
                 … (2 more)

SIGNATURE
