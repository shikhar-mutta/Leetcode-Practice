 3753. Total Waviness of Numbers in Range II
 Hard  |  Tags: Math, Dynamic Programming
 https://leetcode.com/problems/total-waviness-of-numbers-in-range-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integers num1 and num2 representing an inclusive range
  [num1, num2].

  The waviness of a number is defined as the total count of its peaks and
  valleys:

  - A digit is a peak if it is strictly greater than both of its immediate
    neighbors.

  - A digit is a valley if it is strictly less than both of its immediate
    neighbors.

  - The first and last digits of a number cannot be peaks or valleys.

  - Any number with fewer than 3 digits has a waviness of 0.

  Return the total sum of waviness for all numbers in the range [num1,
  num2].

CONSTRAINTS
  1 <= num1 <= num2 <= 10^15

TEST CASES
  [1] Input    : num1 = 120, num2 = 130
      Expected : 3
      Why      : In the range [120, 130]:
                 - 120: middle digit 2 is a peak, waviness = 1.
                 - 121: middle digit 2 is a peak, waviness = 1.
                 … (3 more)

  [2] Input    : num1 = 198, num2 = 202
      Expected : 3
      Why      : In the range [198, 202]:
                 - 198: middle digit 9 is a peak, waviness = 1.
                 - 201: middle digit 0 is a valley, waviness = 1.
                 … (3 more)

  [3] Input    : num1 = 4848, num2 = 4848
      Expected : 2
      Why      : Number 4848: the second digit 8 is a peak, and the third digit 4 is a valley, giving a waviness of 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long totalWaviness(long long num1, long long num2);
