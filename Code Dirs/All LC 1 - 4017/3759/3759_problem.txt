 3759. Count Elements With at Least K Greater Values
 Medium  |  Tags: Array, Binary Search, Divide and Conquer, Sorting, Quickselect
 https://leetcode.com/problems/count-elements-with-at-least-k-greater-values/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of length n and an integer k.

  An element in nums is said to be qualified if there exist at least k
  elements in the array that are strictly greater than it.

  Return an integer denoting the total number of qualified elements in
  nums.

CONSTRAINTS
  1 <= n == nums.length <= 10^5
  1 <= nums[i] <= 10^9
  0 <= k < n

TEST CASES
  [1] Input    : nums = [3,1,2], k = 1
      Expected : 2
      Why      : The elements 1 and 2 each have at least k = 1 element greater than themselves.
                 No element is greater than 3. Therefore, the answer is 2.

  [2] Input    : nums = [5,5,5], k = 2
      Expected : 0
      Why      : Since all elements are equal to 5, no element is greater than the other. Therefore, the answer is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countElements(vector<int>& nums, int k);
