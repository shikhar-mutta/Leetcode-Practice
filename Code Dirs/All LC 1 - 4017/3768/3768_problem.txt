 3768. Minimum Inversion Count in Subarrays of Fixed Length
 Hard  |  Tags: Array, Segment Tree, Sliding Window
 https://leetcode.com/problems/minimum-inversion-count-in-subarrays-of-fixed-length/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of length n and an integer k.

  An inversion is a pair of indices (i, j) from nums such that i < j and
  nums[i] > nums[j].

  The inversion count of a subarray is the number of inversions within it.

  Return the minimum inversion count among all subarrays of nums with
  length k.

CONSTRAINTS
  1 <= n == nums.length <= 10^5
  1 <= nums[i] <= 10^9
  1 <= k <= n

TEST CASES
  [1] Input    : nums = [3,1,2,5,4], k = 3
      Expected : 0
      Why      : We consider all subarrays of length k = 3 (indices below are relative to each subarray):
                 - [3, 1, 2] has 2 inversions: (0, 1) and (0, 2).
                 - [1, 2, 5] has 0 inversions.
                 … (2 more)

  [2] Input    : nums = [5,3,2,1], k = 4
      Expected : 6
      Why      : There is only one subarray of length k = 4: [5, 3, 2, 1].
                 Within this subarray, the inversions are: (0, 1), (0, 2), (0, 3), (1, 2), (1, 3), and (2, 3).
                 Total inversions is 6, so the minimum inversion count is 6.

  [3] Input    : nums = [2,1], k = 1
      Expected : 0
      Why      : All subarrays of length k = 1 contain only one element, so no inversions are possible.
                 The minimum inversion count is therefore 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long minInversionCount(vector<int>& nums, int k);
