 3770. Largest Prime from Consecutive Prime Sum
 Medium  |  Tags: Array, Math, Number Theory
 https://leetcode.com/problems/largest-prime-from-consecutive-prime-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n.

  Return the largest prime number less than or equal to n that can be
  expressed as the sum of one or more consecutive prime numbers starting
  from 2. If no such number exists, return 0.

CONSTRAINTS
  1 <= n <= 5 * 10^5

TEST CASES
  [1] Input    : n = 20
      Expected : 17
      Why      : The prime numbers less than or equal to n = 20 which are consecutive prime sums are:
                 -
                 2 = 2
                 … (5 more)

  [2] Input    : n = 2
      Expected : 2
      Why      : The only consecutive prime sum less than or equal to 2 is 2 itself.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestPrime(int n);
