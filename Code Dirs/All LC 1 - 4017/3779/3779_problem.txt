 3779. Minimum Number of Operations to Have Distinct Elements
 Medium  |  Tags: Array, Hash Table
 https://leetcode.com/problems/minimum-number-of-operations-to-have-distinct-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  In one operation, you remove the first three elements of the current
  array. If there are fewer than three elements remaining, all remaining
  elements are removed.

  Repeat this operation until the array is empty or contains no duplicate
  values.

  Return an integer denoting the number of operations required.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [3,8,3,6,5,8]
      Expected : 1
      Why      : In the first operation, we remove the first three elements. The remaining elements [6, 5, 8] are all distinct, so we stop. Only one operation is needed.

  [2] Input    : nums = [2,2]
      Expected : 1
      Why      : After one operation, the array becomes empty, which meets the stopping condition.

  [3] Input    : nums = [4,3,5,1,2]
      Expected : 0
      Why      : All elements in the array are distinct, therefore no operations are needed.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minOperations(vector<int>& nums);
