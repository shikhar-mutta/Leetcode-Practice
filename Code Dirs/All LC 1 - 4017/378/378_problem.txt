 378. Kth Smallest Element in a Sorted Matrix
 Medium  |  Tags: Array, Binary Search, Sorting, Heap (Priority Queue), Matrix
 https://leetcode.com/problems/kth-smallest-element-in-a-sorted-matrix/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an n x n matrix where each of the rows and columns is sorted in
  ascending order, return the k^th smallest element in the matrix.

  Note that it is the k^th smallest element in the sorted order, not the
  k^th distinct element.

  You must find a solution with a memory complexity better than O(n^2).

CONSTRAINTS
  n == matrix.length == matrix[i].length
  1 <= n <= 300
  -10^9 <= matrix[i][j] <= 10^9
  All the rows and columns of matrix are guaranteed to be sorted in non-decreasing order.
  1 <= k <= n^2

TEST CASES
  [1] Input    : matrix = [[1,5,9],[10,11,13],[12,13,15]], k = 8
      Expected : 13
      Why      : The elements in the matrix are [1,5,9,10,11,12,13,13,15], and the 8^th smallest number is 13

  [2] Input    : matrix = [[-5]], k = 1
      Expected : -5

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int kthSmallest(vector<vector<int>>& matrix, int k);
