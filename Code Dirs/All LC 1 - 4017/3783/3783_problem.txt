 3783. Mirror Distance of an Integer
 Easy  |  Tags: Math
 https://leetcode.com/problems/mirror-distance-of-an-integer/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n.

  Define its mirror distance as: abs(n - reverse(n)) where reverse(n) is
  the integer formed by reversing the digits of n.

  Return an integer denoting the mirror distance of n.

  abs(x) denotes the absolute value of x.

CONSTRAINTS
  1 <= n <= 10^9

TEST CASES
  [1] Input    : n = 25
      Expected : 27
      Why      : - reverse(25) = 52.
                 - Thus, the answer is abs(25 - 52) = 27.

  [2] Input    : n = 10
      Expected : 9
      Why      : - reverse(10) = 01 which is 1.
                 - Thus, the answer is abs(10 - 1) = 9.

  [3] Input    : n = 7
      Expected : 0
      Why      : - reverse(7) = 7.
                 - Thus, the answer is abs(7 - 7) = 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int mirrorDistance(int n);
