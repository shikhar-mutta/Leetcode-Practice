 3784. Minimum Deletion Cost to Make All Characters Equal
 Medium  |  Tags: Array, Hash Table, String, Enumeration
 https://leetcode.com/problems/minimum-deletion-cost-to-make-all-characters-equal/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s of length n and an integer array cost of the
  same length, where cost[i] is the cost to delete the i^th character of
  s.

  You may delete any number of characters from s (possibly none), such
  that the resulting string is non-empty and consists of equal characters.

  Return an integer denoting the minimum total deletion cost required.

CONSTRAINTS
  n == s.length == cost.length
  1 <= n <= 10^5
  1 <= cost[i] <= 10^9
  s consists of lowercase English letters.

TEST CASES
  [1] Input    : s = "aabaac", cost = [1,2,3,4,1,10]
      Expected : 11
      Why      : Deleting the characters at indices 0, 1, 2, 3, 4 results in the string "c", which consists of equal characters, and the total cost is cost[0] + cost[1] + cost[2] + cost[3] + cost[4] = 1 + 2 + 3 + 4 + 1 = 11.

  [2] Input    : s = "abc", cost = [10,5,8]
      Expected : 13
      Why      : Deleting the characters at indices 1 and 2 results in the string "a", which consists of equal characters, and the total cost is cost[1] + cost[2] = 5 + 8 = 13.

  [3] Input    : s = "zzzzz", cost = [67,67,67,67,67]
      Expected : 0
      Why      : All characters in s are equal, so the deletion cost is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long minCost(string s, vector<int>& cost);
