 3785. Minimum Swaps to Avoid Forbidden Values
 Hard  |  Tags: Array, Hash Table, Greedy, Counting
 https://leetcode.com/problems/minimum-swaps-to-avoid-forbidden-values/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integer arrays, nums and forbidden, each of length n.

  You may perform the following operation any number of times (including
  zero):

  - Choose two distinct indices i and j, and swap nums[i] with nums[j].

  Return the minimum number of swaps required such that, for every index
  i, the value of nums[i] is not equal to forbidden[i]. If no amount of
  swaps can ensure that every index avoids its forbidden value, return -1.

CONSTRAINTS
  1 <= n == nums.length == forbidden.length <= 10^5
  1 <= nums[i], forbidden[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,2,3], forbidden = [3,2,1]
      Expected : 1
      Why      : One optimal set of swaps:
                 - Select indices i = 0 and j = 1 in nums and swap them, resulting in nums = [2, 1, 3].
                 - After this swap, for every index i, nums[i] is not equal to forbidden[i].

  [2] Input    : nums = [4,6,6,5], forbidden = [4,6,5,5]
      Expected : 2
      Why      : One optimal set of swaps:
                 - Select indices i = 0 and j = 2 in nums and swap them, resulting in nums = [6, 6, 4, 5].
                 - Select indices i = 1 and j = 3 in nums and swap them, resulting in nums = [6, 5, 4, 6].
                 … (1 more)

  [3] Input    : nums = [7,7], forbidden = [8,7]
      Expected : -1
      Why      : It is not possible to make nums[i] different from forbidden[i] for all indices.

  [4] Input    : nums = [1,2], forbidden = [2,1]
      Expected : 0
      Why      : No swaps are required because nums[i] is already different from forbidden[i] for all indices, so the answer is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minSwaps(vector<int>& nums, vector<int>& forbidden);
