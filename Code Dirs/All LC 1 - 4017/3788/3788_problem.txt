 3788. Maximum Score of a Split
 Medium  |  Tags: Array, Prefix Sum
 https://leetcode.com/problems/maximum-score-of-a-split/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of length n.

  Choose an index i such that 0 <= i < n - 1.

  For a chosen split index i:

  - Let prefixSum(i) be the sum of nums[0] + nums[1] + ... + nums[i].

  - Let suffixMin(i) be the minimum value among nums[i + 1], nums[i + 2],
    ..., nums[n - 1].

  The score of a split at index i is defined as:

  score(i) = prefixSum(i) - suffixMin(i)

  Return an integer denoting the maximum score over all valid split
  indices.

CONSTRAINTS
  2 <= nums.length <= 10^5
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [10,-1,3,-4,-5]
      Expected : 17
      Why      : The optimal split is at i = 2, score(2) = prefixSum(2) - suffixMin(2) = (10 + (-1) + 3) - (-5) = 17.

  [2] Input    : nums = [-7,-5,3]
      Expected : -2
      Why      : The optimal split is at i = 0, score(0) = prefixSum(0) - suffixMin(0) = (-7) - (-5) = -2.

  [3] Input    : nums = [1,1]
      Expected : 0
      Why      : The only valid split is at i = 0, score(0) = prefixSum(0) - suffixMin(0) = 1 - 1 = 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long maximumScore(vector<int>& nums);
