 3790. Smallest All-Ones Multiple
 Medium  |  Tags: Hash Table, Math
 https://leetcode.com/problems/smallest-all-ones-multiple/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer k.

  Find the smallest integer n divisible by k that consists of only the
  digit 1 in its decimal representation (e.g., 1, 11, 111, ...).

  Return an integer denoting the number of digits in the decimal
  representation of n. If no such n exists, return -1.

CONSTRAINTS
  2 <= k <= 10^5

TEST CASES
  [1] Input    : k = 3
      Expected : 3
      Why      : n = 111 because 111 is divisible by 3, but 1 and 11 are not. The length of n = 111 is 3.

  [2] Input    : k = 7
      Expected : 6
      Why      : n = 111111. The length of n = 111111 is 6.

  [3] Input    : k = 2
      Expected : -1
      Why      : There does not exist a valid n that is a multiple of 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minAllOneMultiple(int k);
