 3794. Reverse String Prefix
 Easy  |  Tags: Two Pointers, String
 https://leetcode.com/problems/reverse-string-prefix/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s and an integer k.

  Reverse the first k characters of s and return the resulting string.

CONSTRAINTS
  1 <= s.length <= 100
  s consists of lowercase English letters.
  1 <= k <= s.length

TEST CASES
  [1] Input    : s = "abcd", k = 2
      Expected : "bacd"
      Why      : The first k = 2 characters "ab" are reversed to "ba". The final resulting string is "bacd".

  [2] Input    : s = "xyz", k = 3
      Expected : "zyx"
      Why      : The first k = 3 characters "xyz" are reversed to "zyx". The final resulting string is "zyx".

  [3] Input    : s = "hey", k = 1
      Expected : "hey"
      Why      : The first k = 1 character "h" remains unchanged on reversal. The final resulting string is "hey".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string reversePrefix(string s, int k);
