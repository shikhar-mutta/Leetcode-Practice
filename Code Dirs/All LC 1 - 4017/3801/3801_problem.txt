 3801. Minimum Cost to Merge Sorted Lists
 Hard  |  Tags: Array, Two Pointers, Binary Search, Dynamic Programming, Bit Manipulation
 https://leetcode.com/problems/minimum-cost-to-merge-sorted-lists/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array lists, where each lists[i] is a non-
  empty array of integers sorted in non-decreasing order.

  You may repeatedly choose two lists a = lists[i] and b = lists[j], where
  i != j, and merge them. The cost to merge a and b is:

  len(a) + len(b) + abs(median(a) - median(b)), where len and median
  denote the list length and median, respectively.

  After merging a and b, remove both a and b from lists and insert the new
  merged sorted list in any position. Repeat merges until only one list
  remains.

  Return an integer denoting the minimum total cost required to merge all
  lists into one single sorted list.

  The median of an array is the middle element after sorting it in non-
  decreasing order. If the array has an even number of elements, the
  median is the left middle element.

CONSTRAINTS
  2 <= lists.length <= 12
  1 <= lists[i].length <= 500
  -10^9 <= lists[i][j] <= 10^9
  lists[i] is sorted in non-decreasing order.
  The sum of lists[i].length will not exceed 2000.

TEST CASES
  [1] Input    : lists = [[1,3,5],[2,4],[6,7,8]]
      Expected : 18
      Why      : Merge a = [1, 3, 5] and b = [2, 4]:
                 - len(a) = 3 and len(b) = 2
                 - median(a) = 3 and median(b) = 2
                 … (7 more)

  [2] Input    : lists = [[1,1,5],[1,4,7,8]]
      Expected : 10
      Why      : Merge a = [1, 1, 5] and b = [1, 4, 7, 8]:
                 - len(a) = 3 and len(b) = 4
                 - median(a) = 1 and median(b) = 4
                 … (2 more)

  [3] Input    : lists = [[1],[3]]
      Expected : 4
      Why      : Merge a = [1] and b = [3]:
                 - len(a) = 1 and len(b) = 1
                 - median(a) = 1 and median(b) = 3
                 … (2 more)

  [4] Input    : lists = [[1],[1]]
      Expected : 2
      Why      : The total cost is len(a) + len(b) + abs(median(a) - median(b)) = 1 + 1 + abs(1 - 1) = 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long minMergeCost(vector<vector<int>>& lists);
