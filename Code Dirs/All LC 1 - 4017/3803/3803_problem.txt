 3803. Count Residue Prefixes
 Easy  |  Tags: Hash Table, String
 https://leetcode.com/problems/count-residue-prefixes/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s consisting only of lowercase English letters.

  A prefix of s is called a residue if the number of distinct characters
  in the prefix is equal to len(prefix) % 3.

  Return the count of residue prefixes in s.

  A prefix of a string is a non-empty substring that starts from the
  beginning of the string and extends to any point within it.

CONSTRAINTS
  1 <= s.length <= 100
  s contains only lowercase English letters.

TEST CASES
  [1] Input    : s = "abc"
      Expected : 2
      Why      : - Prefix "a" has 1 distinct character and length modulo 3 is 1, so it is a residue.
                 - Prefix "ab" has 2 distinct characters and length modulo 3 is 2, so it is a residue.
                 - Prefix "abc" does not satisfy the condition. Thus, the answer is 2.

  [2] Input    : s = "dd"
      Expected : 1
      Why      : - Prefix "d" has 1 distinct character and length modulo 3 is 1, so it is a residue.
                 - Prefix "dd" has 1 distinct character but length modulo 3 is 2, so it is not a residue. Thus, the answer is 1.

  [3] Input    : s = "bob"
      Expected : 2
      Why      : - Prefix "b" has 1 distinct character and length modulo 3 is 1, so it is a residue.
                 - Prefix "bo" has 2 distinct characters and length mod 3 is 2, so it is a residue. Thus, the answer is 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int residuePrefixes(string s);
