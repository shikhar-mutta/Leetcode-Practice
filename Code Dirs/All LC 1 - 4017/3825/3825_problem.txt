 3825. Longest Strictly Increasing Subsequence With Non-Zero Bitwise AND
 Medium  |  Tags: Array, Binary Search, Bit Manipulation, Enumeration
 https://leetcode.com/problems/longest-strictly-increasing-subsequence-with-non-zero-bitwise-and/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Return the length of the longest strictly increasing subsequence in nums
  whose bitwise AND is non-zero. If no such subsequence exists, return 0.

CONSTRAINTS
  1 <= nums.length <= 10^5
  0 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [5,4,7]
      Expected : 2
      Why      : One longest strictly increasing subsequence is [5, 7]. The bitwise AND is 5 AND 7 = 5, which is non-zero.

  [2] Input    : nums = [2,3,6]
      Expected : 3
      Why      : The longest strictly increasing subsequence is [2, 3, 6]. The bitwise AND is 2 AND 3 AND 6 = 2, which is non-zero.

  [3] Input    : nums = [0,1]
      Expected : 1
      Why      : One longest strictly increasing subsequence is [1]. The bitwise AND is 1, which is non-zero.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestSubsequence(vector<int>& nums);
