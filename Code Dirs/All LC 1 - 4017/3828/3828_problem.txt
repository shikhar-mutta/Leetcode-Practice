 3828. Final Element After Subarray Deletions
 Medium  |  Tags: Array, Math, Brainteaser, Game Theory
 https://leetcode.com/problems/final-element-after-subarray-deletions/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Two players, Alice and Bob, play a game in turns, with Alice playing
  first.

  - In each turn, the current player chooses any subarray nums[l..r] such
    that r - l + 1 < m, where m is the current length of the array.

  - The selected subarray is removed, and the remaining elements are
    concatenated to form the new array.

  - The game continues until only one element remains.

  Alice aims to maximize the final element, while Bob aims to minimize it.
  Assuming both play optimally, return the value of the final remaining
  element.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [1,5,2]
      Expected : 2
      Why      : One valid optimal strategy:
                 - Alice removes [1], array becomes [5, 2].
                 - Bob removes [5], array becomes [2]. Thus, the answer is 2.

  [2] Input    : nums = [3,7]
      Expected : 7
      Why      : Alice removes [3], leaving the array [7]. Since Bob cannot play a turn now, the answer is 7.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int finalElement(vector<int>& nums);
