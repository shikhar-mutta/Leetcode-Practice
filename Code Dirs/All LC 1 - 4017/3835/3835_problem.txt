 3835. Count Subarrays With Cost Less Than or Equal to K
 Medium  |  Tags: Array, Queue, Monotonic Queue
 https://leetcode.com/problems/count-subarrays-with-cost-less-than-or-equal-to-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums, and an integer k.

  For any subarray nums[l..r], define its cost as:

  cost = (max(nums[l..r]) - min(nums[l..r])) * (r - l + 1).

  Return an integer denoting the number of subarrays of nums whose cost is
  less than or equal to k.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9
  0 <= k <= 10^15

TEST CASES
  [1] Input    : nums = [1,3,2], k = 4
      Expected : 5
      Why      : We consider all subarrays of nums:
                 - nums[0..0]: cost = (1 - 1) * 1 = 0
                 - nums[0..1]: cost = (3 - 1) * 2 = 4
                 … (5 more)

  [2] Input    : nums = [5,5,5,5], k = 0
      Expected : 10
      Why      : For any subarray of nums, the maximum and minimum values are the same, so the cost is always 0.
                 As a result, every subarray of nums has cost less than or equal to 0.
                 For an array of length 4, the total number of subarrays is (4 * 5) / 2 = 10.

  [3] Input    : nums = [1,2,3], k = 0
      Expected : 3
      Why      : The only subarrays of nums with cost 0 are the single-element subarrays, and there are 3 of them.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long countSubarrays(vector<int>& nums, long long k);
