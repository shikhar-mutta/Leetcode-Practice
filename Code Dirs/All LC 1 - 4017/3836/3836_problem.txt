 3836. Maximum Score Using Exactly K Pairs
 Hard  |  Tags: Array, Dynamic Programming
 https://leetcode.com/problems/maximum-score-using-exactly-k-pairs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integer arrays nums1 and nums2 of lengths n and m
  respectively, and an integer k.

  You must choose exactly k pairs of indices (i1, j1), (i2, j2), ..., (ik,
  jk) such that:

  - 0 <= i1 < i2 < ... < ik < n

  - 0 <= j1 < j2 < ... < jk < m

  For each chosen pair (i, j), you gain a score of nums1[i] * nums2[j].

  The total score is the sum of the products of all selected pairs.

  Return an integer representing the maximum achievable total score.

CONSTRAINTS
  1 <= n == nums1.length <= 100
  1 <= m == nums2.length <= 100
  -10^6 <= nums1[i], nums2[i] <= 10^6
  1 <= k <= min(n, m)

TEST CASES
  [1] Input    : nums1 = [1,3,2], nums2 = [4,5,1], k = 2
      Expected : 22
      Why      : One optimal choice of index pairs is:
                 - (i1, j1) = (1, 0) which scores 3 * 4 = 12
                 - (i2, j2) = (2, 1) which scores 2 * 5 = 10
                 … (1 more)

  [2] Input    : nums1 = [-2,0,5], nums2 = [-3,4,-1,2], k = 2
      Expected : 26
      Why      : One optimal choice of index pairs is:
                 - (i1, j1) = (0, 0) which scores -2 * -3 = 6
                 - (i2, j2) = (2, 1) which scores 5 * 4 = 20
                 … (1 more)

  [3] Input    : nums1 = [-3,-2], nums2 = [1,2], k = 2
      Expected : -7
      Why      : The optimal choice of index pairs is:
                 - (i1, j1) = (0, 0) which scores -3 * 1 = -3
                 - (i2, j2) = (1, 1) which scores -2 * 2 = -4
                 … (1 more)
