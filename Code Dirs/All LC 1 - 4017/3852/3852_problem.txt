 3852. Smallest Pair With Different Frequencies
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/smallest-pair-with-different-frequencies/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Consider all pairs of distinct values x and y from nums such that:

  - x < y

  - x and y have different frequencies in nums.

  Among all such pairs:

  - Choose the pair with the smallest possible value of x.

  - If multiple pairs have the same x, choose the one with the smallest
    possible value of y.

  Return an integer array [x, y]. If no valid pair exists, return [-1,
  -1].

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,1,2,2,3,4]
      Expected : [1,3]
      Why      : The smallest value is 1 with a frequency of 2, and the smallest value greater than 1 that has a different frequency from 1 is 3 with a frequency of 1. Thus, the answer is [1, 3].

  [2] Input    : nums = [1,5]
      Expected : [-1,-1]
      Why      : Both values have the same frequency, so no valid pair exists. Return [-1, -1].

  [3] Input    : nums = [7]
      Expected : [-1,-1]
      Why      : There is only one value in the array, so no valid pair exists. Return [-1, -1].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> minDistinctFreqPair(vector<int>& nums);
