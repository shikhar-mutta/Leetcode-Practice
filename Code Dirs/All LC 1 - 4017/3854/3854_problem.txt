 3854. Minimum Operations to Make Array Parity Alternating
 Medium  |  Tags: Array, Greedy
 https://leetcode.com/problems/minimum-operations-to-make-array-parity-alternating/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  An array is called parity alternating if for every index i where 0 <= i
  < n - 1, nums[i] and nums[i + 1] have different parity (one is even and
  the other is odd).

  In one operation, you may choose any index i and either increase nums[i]
  by 1 or decrease nums[i] by 1.

  Return an integer array answer of length 2 where:

  - answer[0] is the minimum number of operations required to make the
    array parity alternating.

  - answer[1] is the minimum possible value of max(nums) - min(nums) taken
    over all arrays that are parity alternating and can be obtained by
    performing exactly answer[0] operations.

  An array of length 1 is considered parity alternating.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [-2,-3,1,4]
      Expected : [2,6]
      Why      : Applying the following operations:
                 - Increase nums[2] by 1, resulting in nums = [-2, -3, 2, 4].
                 - Decrease nums[3] by 1, resulting in nums = [-2, -3, 2, 3].
                 … (1 more)

  [2] Input    : nums = [0,2,-2]
      Expected : [1,3]
      Why      : Applying the following operation:
                 - Decrease nums[1] by 1, resulting in nums = [0, 1, -2].
                 The resulting array is parity alternating, and the value of max(nums) - min(nums) = 1 - (-2) = 3 is the minimum possible among all parity alternating arrays obtainable using exactly 1 operation.

  [3] Input    : nums = [7]
      Expected : [0,0]
      Why      : No operations are required. The array is already parity alternating, and the value of max(nums) - min(nums) = 7 - 7 = 0, which is the minimum possible.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> makeParityAlternating(vector<int>& nums);
