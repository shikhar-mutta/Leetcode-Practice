 3855. Sum of K-Digit Numbers in a Range
 Hard  |  Tags: Math, Divide and Conquer, Combinatorics, Number Theory
 https://leetcode.com/problems/sum-of-k-digit-numbers-in-a-range/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given three integers l, r, and k.

  Consider all possible integers consisting of exactly k digits, where
  each digit is chosen independently from the integer range [l, r]
  (inclusive). If 0 is included in the range, leading zeros are allowed.

  Return an integer representing the sum of all such numbers. Since the
  answer may be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  0 <= l <= r <= 9
  1 <= k <= 10^9

TEST CASES
  [1] Input    : l = 1, r = 2, k = 2
      Expected : 66
      Why      : - All numbers formed using k = 2 digits in the range [1, 2] are 11, 12, 21, 22.
                 - The total sum is 11 + 12 + 21 + 22 = 66.

  [2] Input    : l = 0, r = 1, k = 3
      Expected : 444
      Why      : - All numbers formed using k = 3 digits in the range [0, 1] are 000, 001, 010, 011, 100, 101, 110, 111.
                 - These numbers without leading zeros are 0, 1, 10, 11, 100, 101, 110, 111.
                 - The total sum is 444.

  [3] Input    : l = 5, r = 5, k = 10
      Expected : 555555520
      Why      : - 5555555555 is the only valid number consisting of k = 10 digits in the range [5, 5].
                 - The total sum is 5555555555 % (10^9 + 7) = 555555520.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumOfNumbers(int l, int r, int k);
