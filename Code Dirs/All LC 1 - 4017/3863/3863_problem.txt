 3863. Minimum Operations to Sort a String
 Medium  |  Tags: String
 https://leetcode.com/problems/minimum-operations-to-sort-a-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s consisting of lowercase English letters.

  In one operation, you can select any substring of s that is not the
  entire string and sort it in non-descending alphabetical order.

  Return the minimum number of operations required to make s sorted in
  non-descending order. If it is not possible, return -1.

CONSTRAINTS
  1 <= s.length <= 10^5
  s consists of only lowercase English letters.

TEST CASES
  [1] Input    : s = "dog"
      Expected : 1
      Why      : - Sort substring "og" to "go".
                 - Now, s = "dgo", which is sorted in ascending order. Thus, the answer is 1.

  [2] Input    : s = "card"
      Expected : 2
      Why      : - Sort substring "car" to "acr", so s = "acrd".
                 - Sort substring "rd" to "dr", making s = "acdr", which is sorted in ascending order. Thus, the answer is 2.

  [3] Input    : s = "gf"
      Expected : -1
      Why      : - It is impossible to sort s under the given constraints. Thus, the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minOperations(string s);
