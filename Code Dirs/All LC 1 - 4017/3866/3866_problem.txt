 3866. First Unique Even Element
 Easy  |  Tags: Array, Hash Table, Counting
 https://leetcode.com/problems/first-unique-even-element/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Return an integer denoting the first even integer (earliest by array
  index) that appears exactly once in nums. If no such integer exists,
  return -1.

  An integer x is considered even if it is divisible by 2.

CONSTRAINTS
  1 <= nums.length <= 100
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [3,4,2,5,4,6]
      Expected : 2
      Why      : Both 2 and 6 are even and they appear exactly once. Since 2 occurs first in the array, the answer is 2.

  [2] Input    : nums = [4,4]
      Expected : -1
      Why      : No even integer appears exactly once, so return -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int firstUniqueEven(vector<int>& nums);
