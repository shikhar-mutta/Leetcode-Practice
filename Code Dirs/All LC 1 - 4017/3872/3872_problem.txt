 3872. Longest Arithmetic Sequence After Changing At Most One Element
 Medium  |  Tags: Array, Enumeration
 https://leetcode.com/problems/longest-arithmetic-sequence-after-changing-at-most-one-element/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  A subarray is arithmetic if the difference between consecutive elements
  in the subarray is constant.

  You can replace at most one element in nums with any integer. Then, you
  select an arithmetic subarray from nums.

  Return an integer denoting the maximum length of the arithmetic subarray
  you can select.

CONSTRAINTS
  4 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [9,7,5,10,1]
      Expected : 5
      Why      : - Replace nums[3] = 10 with 3. The array becomes [9, 7, 5, 3, 1].
                 - Select the subarray [9, 7, 5, 3, 1], which is arithmetic because consecutive elements have a common difference of -2.

  [2] Input    : nums = [1,2,6,7]
      Expected : 3
      Why      : - Replace nums[0] = 1 with -2. The array becomes [-2, 2, 6, 7].
                 - Select the subarray [-2, 2, 6, 7], which is arithmetic because consecutive elements have a common difference of 4.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestArithmetic(vector<int>& nums);
