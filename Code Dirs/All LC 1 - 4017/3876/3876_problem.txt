 3876. Construct Uniform Parity Array II
 Medium  |  Tags: Array, Math
 https://leetcode.com/problems/construct-uniform-parity-array-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array nums1 of n distinct integers.

  You want to construct another array nums2 of length n such that the
  elements in nums2 are either all odd or all even.

  For each index i, you must choose exactly one of the following (in any
  order):

  - nums2[i] = nums1[i]

  - nums2[i] = nums1[i] - nums1[j], for an index j != i, such that
    nums1[i] - nums1[j] >= 1

  Return true if it is possible to construct such an array, otherwise
  return false.

CONSTRAINTS
  1 <= n == nums1.length <= 10^5
  1 <= nums1[i] <= 10^9
  nums1 consists of distinct integers.

TEST CASES
  [1] Input    : nums1 = [1,4,7]
      Expected : true
      Why      : - Set nums2[0] = nums1[0] = 1.
                 - Set nums2[1] = nums1[1] - nums1[0] = 4 - 1 = 3.
                 - Set nums2[2] = nums1[2] = 7.
                 … (1 more)

  [2] Input    : nums1 = [2,3]
      Expected : false
      Why      : It is not possible to construct nums2 such that all elements have the same parity. Thus, the answer is false.

  [3] Input    : nums1 = [4,6]
      Expected : true
      Why      : - Set nums2[0] = nums1[0] = 4.
                 - Set nums2[1] = nums1[1] = 6.
                 - nums2 = [4, 6], and all elements are even. Thus, the answer is true.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool uniformArray(vector<int>& nums1);
