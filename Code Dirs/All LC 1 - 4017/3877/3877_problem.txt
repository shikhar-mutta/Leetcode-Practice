 3877. Minimum Removals to Achieve Target XOR
 Medium  |  Tags: Array, Dynamic Programming, Bit Manipulation
 https://leetcode.com/problems/minimum-removals-to-achieve-target-xor/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer target.

  You may remove any number of elements from nums (possibly zero).

  Return the minimum number of removals required so that the bitwise XOR
  of the remaining elements equals target. If it is impossible to achieve
  target, return -1.

  The bitwise XOR of an empty array is 0.

CONSTRAINTS
  1 <= nums.length <= 40
  0 <= nums[i] <= 10^4
  0 <= target <= 10^4

TEST CASES
  [1] Input    : nums = [1,2,3], target = 2
      Expected : 1
      Why      : - Removing nums[1] = 2 leaves [nums[0], nums[2]] = [1, 3].
                 - The XOR of [1, 3] is 2, which equals target.
                 - It is not possible to achieve XOR = 2 in less than one removal, therefore the answer is 1.

  [2] Input    : nums = [2,4], target = 1
      Expected : -1
      Why      : It is impossible to remove elements to achieve target. Thus, the answer is -1.

  [3] Input    : nums = [7], target = 7
      Expected : 0
      Why      : The XOR of all elements is nums[0] = 7, which equals target. Thus, no removal is needed.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minRemovals(vector<int>& nums, int target);
