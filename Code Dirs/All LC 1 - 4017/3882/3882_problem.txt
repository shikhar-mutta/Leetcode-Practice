 3882. Minimum XOR Path in a Grid
 Medium  |  Tags: Array, Dynamic Programming, Bit Manipulation, Matrix
 https://leetcode.com/problems/minimum-xor-path-in-a-grid/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a 2D integer array grid of size m * n.

  You start at the top-left cell (0, 0) and want to reach the bottom-right
  cell (m - 1, n - 1).

  At each step, you may move either right or down.

  The cost of a path is defined as the bitwise XOR of all the values in
  the cells along that path, including the start and end cells.

  Return the minimum possible XOR value among all valid paths from (0, 0)
  to (m - 1, n - 1).

CONSTRAINTS
  1 <= m == grid.length <= 1000
  1 <= n == grid[i].length <= 1000
  m * n <= 1000
  0 <= grid[i][j] <= 1023

TEST CASES
  [1] Input    : grid = [[1,2],[3,4]]
      Expected : 6
      Why      : There are two valid paths:
                 - (0, 0) → (0, 1) → (1, 1) with XOR: 1 XOR 2 XOR 4 = 7
                 - (0, 0) → (1, 0) → (1, 1) with XOR: 1 XOR 3 XOR 4 = 6
                 … (1 more)

  [2] Input    : grid = [[6,7],[5,8]]
      Expected : 9
      Why      : There are two valid paths:
                 - (0, 0) → (0, 1) → (1, 1) with XOR: 6 XOR 7 XOR 8 = 9
                 - (0, 0) → (1, 0) → (1, 1) with XOR: 6 XOR 5 XOR 8 = 11
                 … (1 more)

  [3] Input    : grid = [[2,7,5]]
      Expected : 0
      Why      : There is only one valid path:
                 - (0, 0) → (0, 1) → (0, 2) with XOR: 2 XOR 7 XOR 5 = 0
                 The XOR value of this path is 0, which is the minimum possible.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
