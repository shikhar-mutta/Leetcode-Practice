 3883. Count Non Decreasing Arrays With Given Digit Sums
 Hard  |  Tags: Array, Dynamic Programming, Prefix Sum
 https://leetcode.com/problems/count-non-decreasing-arrays-with-given-digit-sums/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array digitSum of length n.

  An array arr of length n is considered valid if:

  - 0 <= arr[i] <= 5000

  - it is non-decreasing.

  - the sum of the digits of arr[i] equals digitSum[i].

  Return an integer denoting the number of distinct valid arrays. Since
  the answer may be large, return it modulo 10^9 + 7.

  An array is said to be non-decreasing if each element is greater than or
  equal to the previous element, if it exists.

CONSTRAINTS
  1 <= digitSum.length <= 1000
  0 <= digitSum[i] <= 50

TEST CASES
  [1] Input    : digitSum = [25,1]
      Expected : 6
      Why      : Numbers whose sum of digits is 25 are 799, 889, 898, 979, 988, and 997.
                 The only number whose sum of digits is 1 that can appear after these values while keeping the array non-decreasing is 1000.
                 Thus, the valid arrays are [799, 1000], [889, 1000], [898, 1000], [979, 1000], [988, 1000], and [997, 1000].
                 … (1 more)

  [2] Input    : digitSum = [1]
      Expected : 4
      Why      : The valid arrays are [1], [10], [100], and [1000].
                 Thus, the answer is 4.

  [3] Input    : digitSum = [2,49,23]
      Expected : 0
      Why      : There is no integer in the range [0, 5000] whose sum of digits is 49. Thus, the answer is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countArrays(vector<int>& digitSum);
