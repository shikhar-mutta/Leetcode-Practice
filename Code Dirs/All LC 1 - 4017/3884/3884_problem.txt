 3884. First Matching Character From Both Ends
 Easy  |  Tags: Two Pointers, String
 https://leetcode.com/problems/first-matching-character-from-both-ends/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s of length n consisting of lowercase English
  letters.

  Return the smallest index i such that s[i] == s[n - i - 1].

  If no such index exists, return -1.

CONSTRAINTS
  1 <= n == s.length <= 100
  s consists of lowercase English letters.

TEST CASES
  [1] Input    : s = "abcacbd"
      Expected : 1
      Why      : At index i = 1, s[1] and s[5] are both 'b'.
                 No smaller index satisfies the condition, so the answer is 1.

  [2] Input    : s = "abc"
      Expected : 1
      Why      : At index i = 1, the two compared positions coincide, so both characters are 'b'.
                 No smaller index satisfies the condition, so the answer is 1.

  [3] Input    : s = "abcdab"
      Expected : -1
      Why      : For every index i, the characters at positions i and n - i - 1 are different.
                 Therefore, no valid index exists, so the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int firstMatchingIndex(string s);
