 3885. Design Event Manager
 Medium  |  Tags: Array, Hash Table, Design, Heap (Priority Queue), Ordered Set
 https://leetcode.com/problems/design-event-manager/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an initial list of events, where each event has a unique
  eventId and a priority.

  Implement the EventManager class:

  - EventManager(int[][] events) Initializes the manager with the given
    events, where events[i] = [eventIdi, priorityi].

  - void updatePriority(int eventId, int newPriority) Updates the priority
    of the active event with id eventId to newPriority.

  - int pollHighest() Removes and returns the eventId of the active event
    with the highest priority. If multiple active events have the same
    priority, return the smallest eventId among them. If there are no
    active events, return -1.

  An event is called active if it has not been removed by pollHighest().

CONSTRAINTS
  1 <= events.length <= 10^5
  events[i] = [eventId, priority]
  1 <= eventId <= 10^9
  1 <= priority <= 10^9
  All the values of eventId in events are unique.
  1 <= newPriority <= 10^9
  For every call to updatePriority, eventId refers to an active event.
  At most 10^5 calls in total will be made to updatePriority and pollHighest.

TEST CASES
  [1] Input    : ["EventManager", "pollHighest", "updatePriority", "pollHighest", "pollHighest"]

                 eventManager.updatePriority(9, 7); // event 9 now has priority 7

      Why      : EventManager eventManager = new EventManager([[4,1], [7,2]]); // Initializes the manager with two events
                 eventManager.pollHighest(); // return 7
