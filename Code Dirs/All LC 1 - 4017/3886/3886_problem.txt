 3886. Sum of Sortable Integers
 Hard  |  Tags: Array, Math, Sorting, Enumeration
 https://leetcode.com/problems/sum-of-sortable-integers/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of length n.

  An integer k is called sortable if k divides n and you can sort nums in
  non-decreasing order by sequentially performing the following
  operations:

  - Partition nums into consecutive subarrays of length k.

  - Cyclically rotate each subarray independently any number of times to
    the left or to the right.

  Return an integer denoting the sum of all possible sortable integers k.

CONSTRAINTS
  1 <= n == nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [3,1,2]
      Expected : 3
      Why      : - For n = 3, possible divisors are 1 and 3.
                 - For k = 1: each subarray has one element. No rotation can sort the array.
                 - For k = 3: the single subarray [3, 1, 2] can be rotated once to produce [1, 2, 3], which is sorted.
                 … (1 more)

  [2] Input    : nums = [7,6,5]
      Expected : 0
      Why      : - For n = 3, possible divisors are 1 and 3.
                 - For k = 1: each subarray has one element. No rotation can sort the array.
                 - For k = 3: the single subarray [7, 6, 5] cannot be rotated into non-decreasing order.
                 … (1 more)

  [3] Input    : nums = [5,8]
      Expected : 3
      Why      : - For n = 2, possible divisors are 1 and 2.
                 - Since [5, 8] is already sorted, every divisor is sortable. Hence, the answer is 1 + 2 = 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sortableIntegers(vector<int>& nums);
