 3890. Integers With Multiple Sum of Two Cubes
 Medium  |  Tags: Hash Table, Sorting, Counting, Enumeration
 https://leetcode.com/problems/integers-with-multiple-sum-of-two-cubes/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n.

  An integer x is considered good if there exist at least two distinct
  pairs (a, b) such that:

  - a and b are positive integers.

  - a <= b

  - x = a^3 + b^3

  Return an array containing all good integers less than or equal to n,
  sorted in ascending order.

CONSTRAINTS
  1 <= n <= 10^9

TEST CASES
  [1] Input    : n = 4104
      Expected : [1729,4104]
      Why      : Among integers less than or equal to 4104, the good integers are:
                 - 1729: 1^3 + 12^3 = 1729 and 9^3 + 10^3 = 1729.
                 - 4104: 2^3 + 16^3 = 4104 and 9^3 + 15^3 = 4104.
                 … (1 more)

  [2] Input    : n = 578
      Expected : []
      Why      : There are no good integers less than or equal to 578, so the answer is an empty array.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> findGoodIntegers(int n);

  edit : 3890.cpp
