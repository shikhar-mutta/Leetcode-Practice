 3895. Count Digit Appearances
 Medium  |  Tags: Array, Math
 https://leetcode.com/problems/count-digit-appearances/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer digit.

  Return the total number of times digit appears in the decimal
  representation of all elements in nums.

CONSTRAINTS
  1 <= nums.length <= 1000
  1 <= nums[i] <= 10^6
  0 <= digit <= 9

TEST CASES
  [1] Input    : nums = [12,54,32,22], digit = 2
      Expected : 4
      Why      : The digit 2 appears once in 12 and 32, and twice in 22. Thus, the total number of times digit 2 appears is 4.

  [2] Input    : nums = [1,34,7], digit = 9
      Expected : 0
      Why      : The digit 9 does not appear in the decimal representation of any element in nums, so the total number of times digit 9 appears is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countDigitOccurrences(vector<int>& nums, int digit);
