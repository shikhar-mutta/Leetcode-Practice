 3899. Angles of a Triangle
 Medium  |  Tags: Array, Math, Geometry
 https://leetcode.com/problems/angles-of-a-triangle/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a positive integer array sides of length 3.

  Determine if there exists a triangle with positive area whose three side
  lengths are given by the elements of sides.

  If such a triangle exists, return an array of three floating-point
  numbers representing its internal angles (in degrees), sorted in non-
  decreasing order. Otherwise, return an empty array.

  Answers within 10^-5 of the actual answer will be accepted.

CONSTRAINTS
  sides.length == 3
  1 <= sides[i] <= 1000

TEST CASES
  [1] Input    : sides = [3,4,5]
      Expected : [36.86990,53.13010,90.00000]
      Why      : You can form a right-angled triangle with side lengths 3, 4, and 5. The internal angles of this triangle are approximately 36.869897646, 53.130102354, and 90 degrees respectively.

  [2] Input    : sides = [2,4,2]
      Expected : []
      Why      : You cannot form a triangle with positive area using side lengths 2, 4, and 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<double> internalAngles(vector<int>& sides);
