 3908. Valid Digit Number
 Easy  |  Tags: Math
 https://leetcode.com/problems/valid-digit-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n and a digit x.

  A number is considered valid if:

  - It contains at least one occurrence of digit x, and

  - It does not start with digit x.

  Return true if n is valid, otherwise return false.

CONSTRAINTS
  0 <= n <= 10^5
  0 <= x <= 9

TEST CASES
  [1] Input    : n = 101, x = 0
      Expected : true
      Why      : The number contains digit 0 at index 1. It does not start with 0, so it satisfies both conditions. Thus, the answer is true.

  [2] Input    : n = 232, x = 2
      Expected : false
      Why      : The number starts with 2, which violates the condition. Thus, the answer is false.

  [3] Input    : n = 5, x = 1
      Expected : false
      Why      : The number does not contain digit 1. Thus, the answer is false.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool validDigit(int n, int x);
