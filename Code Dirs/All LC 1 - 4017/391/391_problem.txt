 391. Perfect Rectangle
 Hard  |  Tags: Array, Hash Table, Math, Geometry, Sweep Line
 https://leetcode.com/problems/perfect-rectangle/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array rectangles where rectangles[i] = [xi, yi, ai, bi]
  represents an axis-aligned rectangle. The bottom-left point of the
  rectangle is (xi, yi) and the top-right point of it is (ai, bi).

  Return true if all the rectangles together form an exact cover of a
  rectangular region.

CONSTRAINTS
  1 <= rectangles.length <= 2 * 10^4
  rectangles[i].length == 4
  -10^5 <= xi < ai <= 10^5
  -10^5 <= yi < bi <= 10^5

TEST CASES
  [1] Input    : rectangles = [[1,1,3,3],[3,1,4,2],[3,2,4,4],[1,3,2,4],[2,3,3,4]]
      Expected : true
      Why      : All 5 rectangles together form an exact cover of a rectangular region.

  [2] Input    : rectangles = [[1,1,2,3],[1,3,2,4],[3,1,4,2],[3,2,4,4]]
      Expected : false
      Why      : Because there is a gap between the two rectangular regions.

  [3] Input    : rectangles = [[1,1,3,3],[3,1,4,2],[1,3,2,4],[2,2,4,4]]
      Expected : false
      Why      : Because two of the rectangles overlap with each other.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isRectangleCover(vector<vector<int>>& rectangles);
