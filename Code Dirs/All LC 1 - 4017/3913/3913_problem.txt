 3913. Sort Vowels by Frequency
 Medium  |  Tags: String, Sorting, Counting
 https://leetcode.com/problems/sort-vowels-by-frequency/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s consisting of lowercase English characters.

  Rearrange only the vowels in the string so that they appear in non-
  increasing order of their frequency.

  If multiple vowels have the same frequency, order them by the position
  of their first occurrence in s.

  Return the modified string.

  Vowels are 'a', 'e', 'i', 'o', and 'u'.

  The frequency of a letter is the number of times it occurs in the
  string.

CONSTRAINTS
  1 <= s.length <= 10^5
  s consists of lowercase English letters

TEST CASES
  [1] Input    : s = "leetcode"
      Expected : "leetcedo"
      Why      : - Vowels in the string are ['e', 'e', 'o', 'e'] with frequencies: e = 3, o = 1.
                 - Sorting in non-increasing order of frequency and placing them back into the vowel positions results in "leetcedo".

  [2] Input    : s = "aeiaaioooa"
      Expected : "aaaaoooiie"
      Why      : - Vowels in the string are ['a', 'e', 'i', 'a', 'a', 'i', 'o', 'o', 'o', 'a'] with frequencies: a = 4, o = 3, i = 2, e = 1.
                 - Sorting them in non-increasing order of frequency and placing them back into the vowel positions results in "aaaaoooiie".

  [3] Input    : s = "baeiou"
      Expected : "baeiou"
      Why      : - Each vowel appears exactly once, so all have the same frequency.
                 - Thus, they retain their relative order based on first occurrence, and the string remains unchanged.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string sortVowels(string s);
