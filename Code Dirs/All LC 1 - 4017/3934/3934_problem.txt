 3934. Smallest Unique Subarray
 Hard  |  Tags: Array, Hash Table, Binary Search, Rolling Hash, Suffix Array, Hash Function
 https://leetcode.com/problems/smallest-unique-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Find the minimum length of a subarray that is not identical to any other
  subarray in nums.

  Return an integer denoting the minimum possible length of such a
  subarray.

  Two subarrays are considered identical if they have the same length and
  the same elements in corresponding positions.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [3,3,3]
      Expected : 3
      Why      : - Subarrays of length 1: [3] → appears 3 times
                 - Subarrays of length 2: [3, 3] → appears 2 times
                 - Subarrays of length 3: [3, 3, 3] → appears once
                 … (1 more)

  [2] Input    : nums = [2,1,2,3,3]
      Expected : 1
      Why      : Subarrays of length 1:
                 - [2] → appears 2 times
                 - [1] → appears once
                 … (2 more)

  [3] Input    : nums = [1,1,2,2,1]
      Expected : 2
      Why      : Subarrays of length 1:
                 - [1] → appears 3 times
                 - [2] → appears 2 times
                 … (6 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int smallestUniqueSubarray(vector<int>& nums);
