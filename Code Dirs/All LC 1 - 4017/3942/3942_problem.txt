 3942. Minimum Operations to Sort a Permutation
 Medium  |  Tags: Array
 https://leetcode.com/problems/minimum-operations-to-sort-a-permutation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of length n, where nums is a
  permutation of the integers from 0 to n - 1.

  You may perform only the following operations:

  - Reverse the entire array.

  - Rotate Left by One: Move the first element to the end of the array,
    and rest elements to left by one position.

  Return an integer denoting the minimum number of operations required to
  sort the array in increasing order. If it is not possible to sort the
  array using only the given operations, return -1.

CONSTRAINTS
  1 <= n == nums.length <= 10^5
  0 <= nums[i] <= n - 1
  nums is a permutation of integers from 0 to n - 1.

TEST CASES
  [1] Input    : nums = [0,2,1]
      Expected : 2
      Why      : - Rotate Left by one: [2, 1, 0]
                 - Reverse the array: [0, 1, 2]
                 The array becomes sorted in 2 operations, which is minimal

  [2] Input    : nums = [1,0,2]
      Expected : 2
      Why      : - Reverse the array: [2, 0, 1]
                 - Rotate Left by one: [0, 1, 2]
                 The array becomes sorted in 2 operations, which is minimal.

  [3] Input    : nums = [2,0,1,3]
      Expected : -1
      Why      : It is impossible to reach [2, 0, 1, 3]. Thus, the answer is -1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minOperations(vector<int>& nums);
