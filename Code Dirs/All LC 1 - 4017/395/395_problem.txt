 395. Longest Substring with At Least K Repeating Characters
 Medium  |  Tags: Hash Table, String, Divide and Conquer, Sliding Window
 https://leetcode.com/problems/longest-substring-with-at-least-k-repeating-characters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s and an integer k, return the length of the longest
  substring of s such that the frequency of each character in this
  substring is greater than or equal to k.

  if no such substring exists, return 0.

CONSTRAINTS
  1 <= s.length <= 10^4
  s consists of only lowercase English letters.
  1 <= k <= 10^5

TEST CASES
  [1] Input    : s = "aaabb", k = 3
      Expected : 3
      Why      : The longest substring is "aaa", as 'a' is repeated 3 times.

  [2] Input    : s = "ababbc", k = 2
      Expected : 5
      Why      : The longest substring is "ababb", as 'a' is repeated 2 times and 'b' is repeated 3 times.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int longestSubstring(string s, int k);

FILES
  edit : 395.cpp
  test : lc run 395
