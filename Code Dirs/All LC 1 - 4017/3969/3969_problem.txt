 3969. Valid Subarrays With Matching Sum Digits I
 Medium  |  Tags: Array, Hash Table, Sliding Window, Enumeration, Prefix Sum
 https://leetcode.com/problems/valid-subarrays-with-matching-sum-digits-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer digit x.

  A subarray nums[l..r] is considered valid if the sum of its elements
  satisfies both of the following conditions:

  - The first digit of the sum is equal to x.

  - The last digit of the sum is equal to x.

  Return the number of valid subarrays.

CONSTRAINTS
  1 <= nums.length <= 1500
  1 <= nums[i] <= 10^9
  1 <= x <= 9

TEST CASES
  [1] Input    : nums = [1,100,1], x = 1
      Expected : 4
      Why      : The valid subarrays are:
                 - nums[0..0]: sum = 1
                 - nums[0..1]: sum = 1 + 100 = 101
                 … (3 more)

  [2] Input    : nums = [1], x = 2
      Expected : 0
      Why      : The only subarray is nums[0..0] with a sum of 1, which does not satisfy the conditions.
                 Thus, the answer is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countValidSubarrays(vector<int>& nums, int x);
