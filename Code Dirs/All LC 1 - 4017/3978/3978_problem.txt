 3978. Unique Middle Element
 Easy  |  Tags: Array, Counting
 https://leetcode.com/problems/unique-middle-element/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums of odd length n.

  Return true if the middle element of nums appears exactly once in the
  array. Otherwise return false.

CONSTRAINTS
  1 <= n == nums.length <= 100
  n is odd.
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,2,3]
      Expected : true
      Why      : The middle element of nums is 2, which appears exactly once.
                 Thus, the answer is true.

  [2] Input    : nums = [1,2,2]
      Expected : false
      Why      : The middle element of nums is 2, which appears twice.
                 Thus, the answer is false.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isMiddleElementUnique(vector<int>& nums);
