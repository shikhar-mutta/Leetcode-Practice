 3983. Subsequence After One Replacement
 Medium  |  Tags: Two Pointers, String
 https://leetcode.com/problems/subsequence-after-one-replacement/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two strings s and t consisting of lowercase English
  letters.

  You may choose at most one index in s and replace the character at that
  index with any lowercase English letter.

  Return true if it is possible to make s a subsequence of t; otherwise,
  return false.

CONSTRAINTS
  1 <= s.length, t.length <= 10^5
  s and t consist only of lowercase English letters.

TEST CASES
  [1] Input    : s = "cat", t = "chat"
      Expected : true
      Why      : - Replace s[1] from 'a' to 'h'. The resulting string is "cht".
                 - "cht" is a subsequence of "chat" because we can match 'c', 'h', and 't' in order.

  [2] Input    : s = "plane", t = "apple"
      Expected : false
      Why      : - The characters 'p', 'l', and 'e' can be matched in t, but the remaining characters cannot be matched while preserving the required order.
                 - Even after replacing any one character in s, it is impossible to make s a subsequence of t.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canMakeSubsequence(string s, string t);
