 3985. Palindromic Subarray Sum
 Hard  |  Tags: Array, Binary Search, Hash Function, Prefix Sum
 https://leetcode.com/problems/palindromic-subarray-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  Return the maximum possible sum of a subarray of nums that is a
  palindrome.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [10,10]
      Expected : 20
      Why      : The whole array [10,10] is a palindrome. Therefore, the maximum sum is 10 + 10 = 20.

  [2] Input    : nums = [1,2,3,2,1,5,6]
      Expected : 9
      Why      : The contiguous subarray [1,2,3,2,1] is a palindrome. Its sum is 1 + 2 + 3 + 2 + 1 = 9 and it is the maximum sum.

  [3] Input    : nums = [7,1,2,1,7,3,4,3,4]
      Expected : 18
      Why      : The contiguous subarray [7,1,2,1,7] is a palindrome. Its sum is 7 + 1 + 2 + 1 + 7 = 18 and it is the maximum sum.

  [4] Input    : nums = [1,2,3,4,5]
      Expected : 5
      Why      : No subarray with length greater than 1 is a palindrome. The largest element in the array is 5. Therefore, the answer is 5.

  [5] Input    : nums = [1000]
      Expected : 1000
      Why      : The subarray with only one element is a palindrome. Therefore, the answer is 1000.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  long long getSum(vector<int>& nums);
