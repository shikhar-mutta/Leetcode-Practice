 4. Median of Two Sorted Arrays
 Hard  |  Tags: Array, Binary Search, Divide and Conquer
 https://leetcode.com/problems/median-of-two-sorted-arrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two sorted arrays nums1 and nums2 of size m and n respectively,
  return the median of the two sorted arrays.

  The overall run time complexity should be O(log (m+n)).

CONSTRAINTS
  nums1.length == m
  nums2.length == n
  0 <= m <= 1000
  0 <= n <= 1000
  1 <= m + n <= 2000
  -10^6 <= nums1[i], nums2[i] <= 10^6

TEST CASES
  [1] Input    : nums1 = [1,3], nums2 = [2]
      Expected : 2.00000
      Why      : merged array = [1,2,3] and median is 2.

  [2] Input    : nums1 = [1,2], nums2 = [3,4]
      Expected : 2.50000
      Why      : merged array = [1,2,3,4] and median is (2 + 3) / 2 = 2.5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2);

FILES
  edit : 4.cpp
  test : lc run 4
