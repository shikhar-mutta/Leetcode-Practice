 4002. Count Valid Sequences
 Medium  |  Tags: Math, Combinatorics
 https://leetcode.com/problems/count-valid-sequences/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two positive integers n and k.

  A valid sequence is a sequence of k positive integers such that:

  - The sum of all integers in the sequence is equal to n.

  - The product of all integers in the sequence is even.

  Return the number of valid sequences. Since the answer may be very
  large, return it modulo 10^9 + 7.

  Two sequences are considered different if they differ at any index. For
  example, [1, 1, 2] and [1, 2, 1] are considered different sequences.

CONSTRAINTS
  1 <= n <= 5 * 10^5
  1 <= k <= n

TEST CASES
  [1] Input    : n = 5, k = 3
      Expected : 3
      Why      : The sequences of length k = 3 whose sum is 5 are:
                 Sequence
                 Product
                 … (20 more)

  [2] Input    : n = 3, k = 2
      Expected : 2
      Why      : The sequences of length k = 2 whose sum is 3 are:
                 Sequence
                 Product
                 … (8 more)

  [3] Input    : n = 5, k = 5
      Expected : 0
      Why      : The only possible sequence of length k = 5 whose sum is 5 is [1, 1, 1, 1, 1], which has an odd product. Thus, the answer is 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countValidSequences(int n, int k);
