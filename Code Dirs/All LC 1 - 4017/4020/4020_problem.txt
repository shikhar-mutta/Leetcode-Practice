 4020. Elevator Requests I
 Easy  |  Tags: Array, Simulation
 https://leetcode.com/problems/elevator-requests-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer n denoting the number of floors in a building,
  where the floors are numbered from 0 to n - 1.

  You are also given an integer array requests, where requests represents
  the sequence of floor requests.

  An elevator starts at floor 0 and follows these rules:

  - The elevator moves one floor per second.

  - The elevator serves requests in the given order.

  - If the elevator is already on the requested floor, no movement is
    needed.

  - After serving a request, the elevator immediately starts moving toward
    the next request.

  Return the total time in seconds required to serve all requests.

CONSTRAINTS
  1 <= n <= 100
  1 <= requests.length <= 100
  0 <= requests[i] <= n - 1

TEST CASES
  [1] Input    : n = 5, requests = [2,1,4,3]
      Expected : 7
      Why      : - requests[0] = 2: Moving from floor 0 to floor 2 takes 2 seconds.
                 - requests[1] = 1: Moving from floor 2 to floor 1 takes 1 second.
                 - requests[2] = 4: Moving from floor 1 to floor 4 takes 3 seconds.
                 … (2 more)

  [2] Input    : n = 3, requests = [2,0,0]
      Expected : 4
      Why      : - requests[0] = 2: Moving from floor 0 to floor 2 takes 2 seconds.
                 - requests[1] = 0: Moving from floor 2 to floor 0 takes 2 seconds.
                 - requests[2] = 0: No movement is needed.
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int elevatorRequests(int n, vector<int>& requests);
