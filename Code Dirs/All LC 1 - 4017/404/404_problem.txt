 404. Sum of Left Leaves
 Easy  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/sum-of-left-leaves/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, return the sum of all left leaves.

  A leaf is a node with no children. A left leaf is a leaf that is the
  left child of another node.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 1000].
  -1000 <= Node.val <= 1000

TEST CASES
  [1] Input    : root = [3,9,20,null,null,15,7]
      Expected : 24
      Why      : There are two left leaves in the binary tree, with values 9 and 15 respectively.

  [2] Input    : root = [1]
      Expected : 0

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int sumOfLeftLeaves(TreeNode* root);
