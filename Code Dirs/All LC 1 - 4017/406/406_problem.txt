 406. Queue Reconstruction by Height
 Medium  |  Tags: Array, Binary Indexed Tree, Segment Tree, Sorting
 https://leetcode.com/problems/queue-reconstruction-by-height/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of people, people, which are the attributes of
  some people in a queue (not necessarily in order). Each people[i] = [hi,
  ki] represents the i^th person of height hi with exactly ki other people
  in front who have a height greater than or equal to hi.

  Reconstruct and return the queue that is represented by the input array
  people. The returned queue should be formatted as an array queue, where
  queue[j] = [hj, kj] is the attributes of the j^th person in the queue
  (queue[0] is the person at the front of the queue).

CONSTRAINTS
  1 <= people.length <= 2000
  0 <= hi <= 10^6
  0 <= ki < people.length
  It is guaranteed that the queue can be reconstructed.

TEST CASES
  [1] Input    : people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
      Expected : [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
      Why      : Person 0 has height 5 with no other people taller or the same height in front.
                 Person 1 has height 7 with no other people taller or the same height in front.
                 Person 2 has height 5 with two persons taller or the same height in front, which is person 0 and 1.
                 … (4 more)

  [2] Input    : people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]
      Expected : [[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> reconstructQueue(vector<vector<int>>& people);

FILES
  edit : 406.cpp
