 41. First Missing Positive
 Hard  |  Tags: Array, Hash Table
 https://leetcode.com/problems/first-missing-positive/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an unsorted integer array nums. Return the smallest positive
  integer that is not present in nums.

  You must implement an algorithm that runs in O(n) time and uses O(1)
  auxiliary space.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -2^31 <= nums[i] <= 2^31 - 1

TEST CASES
  [1] Input    : nums = [1,2,0]
      Expected : 3
      Why      : The numbers in the range [1,2] are all in the array.

  [2] Input    : nums = [3,4,-1,1]
      Expected : 2
      Why      : 1 is in the array but 2 is missing.

  [3] Input    : nums = [7,8,9,11,12]
      Expected : 1
      Why      : The smallest positive integer 1 is missing.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int firstMissingPositive(vector<int>& nums);

FILES
