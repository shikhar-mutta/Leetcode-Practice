 413. Arithmetic Slices
 Medium  |  Tags: Array, Dynamic Programming, Sliding Window
 https://leetcode.com/problems/arithmetic-slices/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An integer array is called arithmetic if it consists of at least three
  elements and if the difference between any two consecutive elements is
  the same.

  - For example, [1,3,5,7,9], [7,7,7,7], and [3,-1,-5,-9] are arithmetic
    sequences.

  Given an integer array nums, return the number of arithmetic subarrays
  of nums.

  A subarray is a contiguous subsequence of the array.

CONSTRAINTS
  1 <= nums.length <= 5000
  -1000 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [1,2,3,4]
      Expected : 3
      Why      : We have 3 arithmetic slices in nums: [1, 2, 3], [2, 3, 4] and [1,2,3,4] itself.

  [2] Input    : nums = [1]
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfArithmeticSlices(vector<int>& nums);

FILES
  edit : 413.cpp
  test : lc run 413
