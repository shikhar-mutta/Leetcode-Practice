 415. Add Strings
 Easy  |  Tags: Math, String, Simulation
 https://leetcode.com/problems/add-strings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two non-negative integers, num1 and num2 represented as string,
  return the sum of num1 and num2 as a string.

  You must solve the problem without using any built-in library for
  handling large integers (such as BigInteger). You must also not convert
  the inputs to integers directly.

CONSTRAINTS
  1 <= num1.length, num2.length <= 10^4
  num1 and num2 consist of only digits.
  num1 and num2 don't have any leading zeros except for the zero itself.

TEST CASES
  [1] Input    : num1 = "11", num2 = "123"
      Expected : "134"

  [2] Input    : num1 = "456", num2 = "77"
      Expected : "533"

  [3] Input    : num1 = "0", num2 = "0"
      Expected : "0"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string addStrings(string num1, string num2);

FILES
  edit : 415.cpp
  test : lc run 415
