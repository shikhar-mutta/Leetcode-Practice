 416. Partition Equal Subset Sum
 Medium  |  Tags: Array, Dynamic Programming, Knapsack Problem, 0-1 Knapsack
 https://leetcode.com/problems/partition-equal-subset-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return true if you can partition the array
  into two subsets such that the sum of the elements in both subsets is
  equal or false otherwise.

CONSTRAINTS
  1 <= nums.length <= 200
  1 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [1,5,11,5]
      Expected : true
      Why      : The array can be partitioned as [1, 5, 5] and [11].

  [2] Input    : nums = [1,2,3,5]
      Expected : false
      Why      : The array cannot be partitioned into equal sum subsets.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canPartition(vector<int>& nums);

FILES
  edit : 416.cpp
  test : lc run 416
