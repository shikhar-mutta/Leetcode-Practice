 435. Non-overlapping Intervals
 Medium  |  Tags: Array, Dynamic Programming, Greedy, Sorting
 https://leetcode.com/problems/non-overlapping-intervals/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of intervals intervals where intervals[i] = [starti,
  endi], return the minimum number of intervals you need to remove to make
  the rest of the intervals non-overlapping.

  Note that intervals which only touch at a point are non-overlapping. For
  example, [1, 2] and [2, 3] are non-overlapping.

CONSTRAINTS
  1 <= intervals.length <= 10^5
  intervals[i].length == 2
  -5 * 10^4 <= starti < endi <= 5 * 10^4

TEST CASES
  [1] Input    : intervals = [[1,2],[2,3],[3,4],[1,3]]
      Expected : 1
      Why      : [1,3] can be removed and the rest of the intervals are non-overlapping.

  [2] Input    : intervals = [[1,2],[1,2],[1,2]]
      Expected : 2
      Why      : You need to remove two [1,2] to make the rest of the intervals non-overlapping.

  [3] Input    : intervals = [[1,2],[2,3]]
      Expected : 0
      Why      : You don't need to remove any of the intervals since they're already non-overlapping.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int eraseOverlapIntervals(vector<vector<int>>& intervals);
