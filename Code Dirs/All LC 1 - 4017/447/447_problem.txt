 447. Number of Boomerangs
 Medium  |  Tags: Array, Hash Table, Math
 https://leetcode.com/problems/number-of-boomerangs/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given n points in the plane that are all distinct, where
  points[i] = [xi, yi]. A boomerang is a tuple of points (i, j, k) such
  that the distance between i and j equals the distance between i and k
  (the order of the tuple matters).

  Return the number of boomerangs.

CONSTRAINTS
  n == points.length
  1 <= n <= 500
  points[i].length == 2
  -10^4 <= xi, yi <= 10^4
  All the points are unique.

TEST CASES
  [1] Input    : points = [[0,0],[1,0],[2,0]]
      Expected : 2
      Why      : The two boomerangs are [[1,0],[0,0],[2,0]] and [[1,0],[2,0],[0,0]].

  [2] Input    : points = [[1,1],[2,2],[3,3]]
      Expected : 2

  [3] Input    : points = [[1,1]]
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numberOfBoomerangs(vector<vector<int>>& points);

FILES
  edit : 447.cpp
  test : lc run 447
