 453. Minimum Moves to Equal Array Elements
 Medium  |  Tags: Array, Math
 https://leetcode.com/problems/minimum-moves-to-equal-array-elements/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums of size n, return the minimum number of
  moves required to make all array elements equal.

  In one move, you can increment n - 1 elements of the array by 1.

CONSTRAINTS
  n == nums.length
  1 <= nums.length <= 10^5
  -10^9 <= nums[i] <= 10^9
  The answer is guaranteed to fit in a 32-bit integer.

TEST CASES
  [1] Input    : nums = [1,2,3]
      Expected : 3
      Why      : Only three moves are needed (remember each move increments two elements):
                 [1,2,3] => [2,3,3] => [3,4,3] => [4,4,4]

  [2] Input    : nums = [1,1,1]
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minMoves(vector<int>& nums);

FILES
  edit : 453.cpp
  test : lc run 453
