 462. Minimum Moves to Equal Array Elements II
 Medium  |  Tags: Array, Math, Sorting
 https://leetcode.com/problems/minimum-moves-to-equal-array-elements-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums of size n, return the minimum number of
  moves required to make all array elements equal.

  In one move, you can increment or decrement an element of the array by
  1.

  Test cases are designed so that the answer will fit in a 32-bit integer.

CONSTRAINTS
  n == nums.length
  1 <= nums.length <= 10^5
  -10^9 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,2,3]
      Expected : 2
      Why      : Only two moves are needed (remember each move increments or decrements one element):
                 [1,2,3] => [2,2,3] => [2,2,2]

  [2] Input    : nums = [1,10,2,9]
      Expected : 16

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minMoves2(vector<int>& nums);

FILES
  edit : 462.cpp
  test : lc run 462
