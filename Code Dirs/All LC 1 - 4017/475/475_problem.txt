 475. Heaters
 Medium  |  Tags: Array, Two Pointers, Binary Search, Sorting
 https://leetcode.com/problems/heaters/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Winter is coming! During the contest, your first job is to design a
  standard heater with a fixed warm radius to warm all the houses.

  Every house can be warmed, as long as the house is within the heater's
  warm radius range.

  Given the positions of houses and heaters on a horizontal line, return
  the minimum radius standard of heaters so that those heaters could cover
  all houses.

  Notice that all the heaters follow your radius standard, and the warm
  radius will be the same.

CONSTRAINTS
  1 <= houses.length, heaters.length <= 3 * 10^4
  1 <= houses[i], heaters[i] <= 10^9

TEST CASES
  [1] Input    : houses = [1,2,3], heaters = [2]
      Expected : 1
      Why      : The only heater was placed in the position 2, and if we use the radius 1 standard, then all the houses can be warmed.

  [2] Input    : houses = [1,2,3,4], heaters = [1,4]
      Expected : 1
      Why      : The two heaters were placed at positions 1 and 4. We need to use a radius 1 standard, then all the houses can be warmed.

  [3] Input    : houses = [1,5], heaters = [2]
      Expected : 3

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findRadius(vector<int>& houses, vector<int>& heaters);
