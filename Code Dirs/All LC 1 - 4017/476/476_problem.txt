 476. Number Complement
 Easy  |  Tags: Bit Manipulation
 https://leetcode.com/problems/number-complement/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The complement of an integer is the integer you get when you flip all
  the 0's to 1's and all the 1's to 0's in its binary representation.

  - For example, The integer 5 is "101" in binary and its complement is
    "010" which is the integer 2.

  Given an integer num, return its complement.

CONSTRAINTS
  1 <= num < 2^31

TEST CASES
  [1] Input    : num = 5
      Expected : 2
      Why      : The binary representation of 5 is 101 (no leading zero bits), and its complement is 010. So you need to output 2.

  [2] Input    : num = 1
      Expected : 0
      Why      : The binary representation of 1 is 1 (no leading zero bits), and its complement is 0. So you need to output 0.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findComplement(int num);

FILES
  edit : 476.cpp
  test : lc run 476
