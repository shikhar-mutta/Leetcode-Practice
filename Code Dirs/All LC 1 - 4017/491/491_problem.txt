 491. Non-decreasing Subsequences
 Medium  |  Tags: Array, Hash Table, Backtracking, Bit Manipulation
 https://leetcode.com/problems/non-decreasing-subsequences/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return all the different possible non-
  decreasing subsequences of the given array with at least two elements.
  You may return the answer in any order.

CONSTRAINTS
  1 <= nums.length <= 15
  -100 <= nums[i] <= 100

TEST CASES
  [1] Input    : nums = [4,6,7,7]
      Expected : [[4,6],[4,6,7],[4,6,7,7],[4,7],[4,7,7],[6,7],[6,7,7],[7,7]]

  [2] Input    : nums = [4,4,3,2,1]
      Expected : [[4,4]]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> findSubsequences(vector<int>& nums);

FILES
  edit : 491.cpp
  test : lc run 491
