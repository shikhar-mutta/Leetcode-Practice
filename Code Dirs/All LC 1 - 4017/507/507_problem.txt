 507. Perfect Number
 Easy  |  Tags: Math
 https://leetcode.com/problems/perfect-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A perfect number is a positive integer that is equal to the sum of its
  positive divisors, excluding the number itself. A divisor of an integer
  x is an integer that can divide x evenly.

  Given an integer n, return true if n is a perfect number, otherwise
  return false.

CONSTRAINTS
  1 <= num <= 10^8

TEST CASES
  [1] Input    : num = 28
      Expected : true
      Why      : 28 = 1 + 2 + 4 + 7 + 14
                 1, 2, 4, 7, and 14 are all divisors of 28.

  [2] Input    : num = 7
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool checkPerfectNumber(int num);

FILES
  edit : 507.cpp
  test : lc run 507
