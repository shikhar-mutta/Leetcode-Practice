 508. Most Frequent Subtree Sum
 Medium  |  Tags: Hash Table, Tree, Depth-First Search, Binary Tree, DP on Trees
 https://leetcode.com/problems/most-frequent-subtree-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, return the most frequent subtree sum.
  If there is a tie, return all the values with the highest frequency in
  any order.

  The subtree sum of a node is defined as the sum of all the node values
  formed by the subtree rooted at that node (including the node itself).

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 10^4].
  -10^5 <= Node.val <= 10^5

TEST CASES
  [1] Input    : root = [5,2,-3]
      Expected : [2,-3,4]

  [2] Input    : root = [5,2,-5]
      Expected : [2]

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  vector<int> findFrequentTreeSum(TreeNode* root);
