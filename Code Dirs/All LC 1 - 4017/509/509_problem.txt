 509. Fibonacci Number
 Easy  |  Tags: Math, Dynamic Programming, Recursion, Memoization
 https://leetcode.com/problems/fibonacci-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The Fibonacci numbers, commonly denoted F(n) form a sequence, called the
  Fibonacci sequence, such that each number is the sum of the two
  preceding ones, starting from 0 and 1. That is,

  F(0) = 0, F(1) = 1
  F(n) = F(n - 1) + F(n - 2), for n > 1.

  Given n, calculate F(n).

CONSTRAINTS
  0 <= n <= 30

TEST CASES
  [1] Input    : n = 2
      Expected : 1
      Why      : F(2) = F(1) + F(0) = 1 + 0 = 1.

  [2] Input    : n = 3
      Expected : 2
      Why      : F(3) = F(2) + F(1) = 1 + 1 = 2.

  [3] Input    : n = 4
      Expected : 3
      Why      : F(4) = F(3) + F(2) = 2 + 1 = 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int fib(int n);
