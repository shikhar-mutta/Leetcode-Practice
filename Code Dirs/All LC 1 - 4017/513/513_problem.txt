 513. Find Bottom Left Tree Value
 Medium  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/find-bottom-left-tree-value/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the root of a binary tree.

  Return the leftmost value in the last row of the tree.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 10^4].
  -2^31 <= Node.val <= 2^31 - 1

TEST CASES
  [1] Input    : root = [2,1,3]
      Expected : 1
      Why      : The last row is [1,3], so the leftmost value is 1.

  [2] Input    : root = [1,2,3,4,null,5,6,null,null,7]
      Expected : 7
      Why      : The last row contains only the node 7.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int findBottomLeftValue(TreeNode* root);
