 515. Find Largest Value in Each Tree Row
 Medium  |  Tags: Tree, Depth-First Search, Breadth-First Search, Binary Tree
 https://leetcode.com/problems/find-largest-value-in-each-tree-row/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, return an array of the largest value in
  each row of the tree (0-indexed).

CONSTRAINTS
  The number of nodes in the tree will be in the range [0, 10^4].
  -2^31 <= Node.val <= 2^31 - 1

TEST CASES
  [1] Input    : root = [1,3,2,5,3,null,9]
      Expected : [1,3,9]

  [2] Input    : root = [1,2,3]
      Expected : [1,3]

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  vector<int> largestValues(TreeNode* root);

  edit : 515.cpp
  test : lc run 515
