 52. N-Queens II
 Hard  |  Tags: Backtracking, Algorithm X
 https://leetcode.com/problems/n-queens-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The n-queens puzzle is the problem of placing n queens on an n x n
  chessboard such that no two queens attack each other.

  Given an integer n, return the number of distinct solutions to the
  n-queens puzzle.

CONSTRAINTS
  1 <= n <= 9

TEST CASES
  [1] Input    : n = 4
      Expected : 2
      Why      : There are two distinct solutions to the 4-queens puzzle as shown.

  [2] Input    : n = 1
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int totalNQueens(int n);

FILES
  edit : 52.cpp
  test : lc run 52
