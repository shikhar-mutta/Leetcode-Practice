 525. Contiguous Array
 Medium  |  Tags: Array, Hash Table, Prefix Sum
 https://leetcode.com/problems/contiguous-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a binary array nums, return the maximum length of a contiguous
  subarray with an equal number of 0 and 1.

CONSTRAINTS
  1 <= nums.length <= 10^5
  nums[i] is either 0 or 1.

TEST CASES
  [1] Input    : nums = [0,1]
      Expected : 2
      Why      : [0, 1] is the longest contiguous subarray with an equal number of 0 and 1.

  [2] Input    : nums = [0,1,0]
      Expected : 2
      Why      : [0, 1] (or [1, 0]) is a longest contiguous subarray with equal number of 0 and 1.

  [3] Input    : nums = [0,1,1,1,1,1,0,0,0]
      Expected : 6
      Why      : [1,1,1,0,0,0] is the longest contiguous subarray with equal number of 0 and 1.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findMaxLength(vector<int>& nums);
