 526. Beautiful Arrangement
 Medium  |  Tags: Array, Dynamic Programming, Backtracking, Bit Manipulation, Bitmask
 https://leetcode.com/problems/beautiful-arrangement/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Suppose you have n integers labeled 1 through n. A permutation of those
  n integers perm (1-indexed) is considered a beautiful arrangement if for
  every i (1 <= i <= n), either of the following is true:

  - perm[i] is divisible by i.

  - i is divisible by perm[i].

  Given an integer n, return the number of the beautiful arrangements that
  you can construct.

CONSTRAINTS
  1 <= n <= 15

TEST CASES
  [1] Input    : n = 2
      Expected : 2
      Why      : The first beautiful arrangement is [1,2]:
                 - perm[1] = 1 is divisible by i = 1
                 - perm[2] = 2 is divisible by i = 2
                 … (3 more)

  [2] Input    : n = 1
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countArrangement(int n);
