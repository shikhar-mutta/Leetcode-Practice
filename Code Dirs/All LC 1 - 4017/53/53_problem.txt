 53. Maximum Subarray
 Medium  |  Tags: Array, Divide and Conquer, Dynamic Programming
 https://leetcode.com/problems/maximum-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, find the subarray with the largest sum, and
  return its sum.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^4 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [-2,1,-3,4,-1,2,1,-5,4]
      Expected : 6
      Why      : The subarray [4,-1,2,1] has the largest sum 6.

  [2] Input    : nums = [1]
      Expected : 1
      Why      : The subarray [1] has the largest sum 1.

  [3] Input    : nums = [5,4,-1,7,8]
      Expected : 23
      Why      : The subarray [5,4,-1,7,8] has the largest sum 23.

FOLLOW UP
  If you have figured out the O(n) solution, try coding another solution
  using the divide and conquer approach, which is more subtle.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSubArray(vector<int>& nums);

FILES
