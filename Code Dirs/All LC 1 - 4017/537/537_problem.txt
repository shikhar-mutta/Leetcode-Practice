 537. Complex Number Multiplication
 Medium  |  Tags: Math, String, Simulation
 https://leetcode.com/problems/complex-number-multiplication/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A complex number can be represented as a string on the form
  "real+imaginaryi" where:

  - real is the real part and is an integer in the range [-100, 100].

  - imaginary is the imaginary part and is an integer in the range [-100,
    100].

  - i^2 == -1.

  Given two complex numbers num1 and num2 as strings, return a string of
  the complex number that represents their multiplications.

CONSTRAINTS
  num1 and num2 are valid complex numbers.

TEST CASES
  [1] Input    : num1 = "1+1i", num2 = "1+1i"
      Expected : "0+2i"
      Why      : (1 + i) * (1 + i) = 1 + i2 + 2 * i = 2i, and you need convert it to the form of 0+2i.

  [2] Input    : num1 = "1+-1i", num2 = "1+-1i"
      Expected : "0+-2i"
      Why      : (1 - i) * (1 - i) = 1 + i2 - 2 * i = -2i, and you need convert it to the form of 0+-2i.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string complexNumberMultiply(string num1, string num2);
