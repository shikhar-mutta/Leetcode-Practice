 56. Merge Intervals
 Medium  |  Tags: Array, Sorting, Quicksort
 https://leetcode.com/problems/merge-intervals/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of intervals where intervals[i] = [starti, endi], merge
  all overlapping intervals, and return an array of the non-overlapping
  intervals that cover all the intervals in the input.

CONSTRAINTS
  1 <= intervals.length <= 10^4
  intervals[i].length == 2
  0 <= starti <= endi <= 10^4

TEST CASES
  [1] Input    : intervals = [[1,3],[2,6],[8,10],[15,18]]
      Expected : [[1,6],[8,10],[15,18]]
      Why      : Since intervals [1,3] and [2,6] overlap, merge them into [1,6].

  [2] Input    : intervals = [[1,4],[4,5]]
      Expected : [[1,5]]
      Why      : Intervals [1,4] and [4,5] are considered overlapping.

  [3] Input    : intervals = [[4,7],[1,4]]
      Expected : [[1,7]]
      Why      : Intervals [1,4] and [4,7] are considered overlapping.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<vector<int>> merge(vector<vector<int>>& intervals);
