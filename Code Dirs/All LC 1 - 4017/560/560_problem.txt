 560. Subarray Sum Equals K
 Medium  |  Tags: Array, Hash Table, Prefix Sum
 https://leetcode.com/problems/subarray-sum-equals-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers nums and an integer k, return the total
  number of subarrays whose sum equals to k.

  A subarray is a contiguous non-empty sequence of elements within an
  array.

CONSTRAINTS
  1 <= nums.length <= 2 * 10^4
  -1000 <= nums[i] <= 1000
  -10^7 <= k <= 10^7

TEST CASES
  [1] Input    : nums = [1,1,1], k = 2
      Expected : 2

  [2] Input    : nums = [1,2,3], k = 3
      Expected : 2

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int subarraySum(vector<int>& nums, int k);

FILES
  edit : 560.cpp
  test : lc run 560
