 561. Array Partition
 Easy  |  Tags: Array, Greedy, Sorting, Counting Sort
 https://leetcode.com/problems/array-partition/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums of 2n integers, group these integers into n
  pairs (a1, b1), (a2, b2), ..., (an, bn) such that the sum of min(ai, bi)
  for all i is maximized. Return the maximized sum.

CONSTRAINTS
  1 <= n <= 10^4
  nums.length == 2 * n
  -10^4 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [1,4,3,2]
      Expected : 4
      Why      : All possible pairings (ignoring the ordering of elements) are:
                 1. (1, 4), (2, 3) -> min(1, 4) + min(2, 3) = 1 + 2 = 3
                 2. (1, 3), (2, 4) -> min(1, 3) + min(2, 4) = 1 + 2 = 3
                 … (2 more)

  [2] Input    : nums = [6,2,6,5,1,2]
      Expected : 9
      Why      : The optimal pairing is (2, 1), (2, 5), (6, 6). min(2, 1) + min(2, 5) + min(6, 6) = 1 + 2 + 6 = 9.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int arrayPairSum(vector<int>& nums);
