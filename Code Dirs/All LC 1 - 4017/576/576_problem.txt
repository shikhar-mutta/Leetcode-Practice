 576. Out of Boundary Paths
 Medium  |  Tags: Dynamic Programming
 https://leetcode.com/problems/out-of-boundary-paths/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is an m x n grid with a ball. The ball is initially at the
  position [startRow, startColumn]. You are allowed to move the ball to
  one of the four adjacent cells in the grid (possibly out of the grid
  crossing the grid boundary). You can apply at most maxMove moves to the
  ball.

  Given the five integers m, n, maxMove, startRow, startColumn, return the
  number of paths to move the ball out of the grid boundary. Since the
  answer can be very large, return it modulo 10^9 + 7.

CONSTRAINTS
  1 <= m, n <= 50
  0 <= maxMove <= 50
  0 <= startRow < m
  0 <= startColumn < n

TEST CASES
  [1] Input    : m = 2, n = 2, maxMove = 2, startRow = 0, startColumn = 0
      Expected : 6

  [2] Input    : m = 1, n = 3, maxMove = 3, startRow = 0, startColumn = 1
      Expected : 12

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findPaths(int m, int n, int maxMove, int startRow, int startColumn);

FILES
  edit : 576.cpp
  test : lc run 576
