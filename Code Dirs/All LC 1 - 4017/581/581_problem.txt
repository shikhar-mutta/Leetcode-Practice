 581. Shortest Unsorted Continuous Subarray
 Medium  |  Tags: Array, Two Pointers, Stack, Greedy, Sorting, Monotonic Stack
 https://leetcode.com/problems/shortest-unsorted-continuous-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, you need to find one continuous subarray
  such that if you only sort this subarray in non-decreasing order, then
  the whole array will be sorted in non-decreasing order.

  Return the shortest such subarray and output its length.

CONSTRAINTS
  1 <= nums.length <= 10^4
  -10^5 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [2,6,4,8,10,9,15]
      Expected : 5
      Why      : You need to sort [6, 4, 8, 10, 9] in ascending order to make the whole array sorted in ascending order.

  [2] Input    : nums = [1,2,3,4]
      Expected : 0

  [3] Input    : nums = [1]
      Expected : 0

FOLLOW UP
  Can you solve it in O(n) time complexity?

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findUnsortedSubarray(vector<int>& nums);

FILES
  edit : 581.cpp
