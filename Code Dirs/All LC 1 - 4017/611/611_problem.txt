 611. Valid Triangle Number
 Medium  |  Tags: Array, Two Pointers, Binary Search, Greedy, Sorting
 https://leetcode.com/problems/valid-triangle-number/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the number of triplets chosen from
  the array that can make triangles if we take them as side lengths of a
  triangle.

CONSTRAINTS
  1 <= nums.length <= 1000
  0 <= nums[i] <= 1000

TEST CASES
  [1] Input    : nums = [2,2,3,4]
      Expected : 3
      Why      : Valid combinations are:
                 2,3,4 (using the first 2)
                 2,3,4 (using the second 2)
                 … (1 more)

  [2] Input    : nums = [4,2,3,4]
      Expected : 4

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int triangleNumber(vector<int>& nums);

FILES
  edit : 611.cpp
  test : lc run 611
