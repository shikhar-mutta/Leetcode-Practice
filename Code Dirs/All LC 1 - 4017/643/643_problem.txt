 643. Maximum Average Subarray I
 Easy  |  Tags: Array, Sliding Window
 https://leetcode.com/problems/maximum-average-subarray-i/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums consisting of n elements, and an
  integer k.

  Find a contiguous subarray whose length is equal to k that has the
  maximum average value and return this value. Any answer with a
  calculation error less than 10^-5 will be accepted.

CONSTRAINTS
  n == nums.length
  1 <= k <= n <= 10^5
  -10^4 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [1,12,-5,-6,50,3], k = 4
      Expected : 12.75000
      Why      : Maximum average is (12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75

  [2] Input    : nums = [5], k = 1
      Expected : 5.00000

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  double findMaxAverage(vector<int>& nums, int k);
