 650. 2 Keys Keyboard
 Medium  |  Tags: Math, Dynamic Programming
 https://leetcode.com/problems/2-keys-keyboard/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is only one character 'A' on the screen of a notepad. You can
  perform one of two operations on this notepad for each step:

  - Copy All: You can copy all the characters present on the screen (a
    partial copy is not allowed).

  - Paste: You can paste the characters which are copied last time.

  Given an integer n, return the minimum number of operations to get the
  character 'A' exactly n times on the screen.

CONSTRAINTS
  1 <= n <= 1000

TEST CASES
  [1] Input    : n = 3
      Expected : 3
      Why      : Initially, we have one character 'A'.
                 In step 1, we use Copy All operation.
                 In step 2, we use Paste operation to get 'AA'.
                 … (1 more)

  [2] Input    : n = 1
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minSteps(int n);

  edit : 650.cpp
  test : lc run 650
