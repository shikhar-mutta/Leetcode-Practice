 652. Find Duplicate Subtrees
 Medium  |  Tags: Hash Table, Tree, Depth-First Search, Binary Tree
 https://leetcode.com/problems/find-duplicate-subtrees/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, return all duplicate subtrees.

  For each kind of duplicate subtrees, you only need to return the root
  node of any one of them.

  Two trees are duplicate if they have the same structure with the same
  node values.

CONSTRAINTS
  The number of the nodes in the tree will be in the range [1, 5000]
  -200 <= Node.val <= 200

TEST CASES
  [1] Input    : root = [1,2,3,4,null,2,4,null,null,4]
      Expected : [[2,4],[4]]

  [2] Input    : root = [2,1,1]
      Expected : [[1]]

  [3] Input    : root = [2,2,2,3,null,3,null]
      Expected : [[2,3],[3]]

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  vector<TreeNode*> findDuplicateSubtrees(TreeNode* root);
