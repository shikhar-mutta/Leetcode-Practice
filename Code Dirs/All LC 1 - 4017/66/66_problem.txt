 66. Plus One
 Easy  |  Tags: Array, Math
 https://leetcode.com/problems/plus-one/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a large integer represented as an integer array digits,
  where each digits[i] is the i^th digit of the integer. The digits are
  ordered from most significant to least significant in left-to-right
  order. The large integer does not contain any leading 0's.

  Increment the large integer by one and return the resulting array of
  digits.

CONSTRAINTS
  1 <= digits.length <= 100
  0 <= digits[i] <= 9
  digits does not contain any leading 0's.

TEST CASES
  [1] Input    : digits = [1,2,3]
      Expected : [1,2,4]
      Why      : The array represents the integer 123.
                 Incrementing by one gives 123 + 1 = 124.
                 Thus, the result should be [1,2,4].

  [2] Input    : digits = [4,3,2,1]
      Expected : [4,3,2,2]
      Why      : The array represents the integer 4321.
                 Incrementing by one gives 4321 + 1 = 4322.
                 Thus, the result should be [4,3,2,2].

  [3] Input    : digits = [9]
      Expected : [1,0]
      Why      : The array represents the integer 9.
                 Incrementing by one gives 9 + 1 = 10.
                 Thus, the result should be [1,0].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> plusOne(vector<int>& digits);
