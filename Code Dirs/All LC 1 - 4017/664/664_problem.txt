 664. Strange Printer
 Hard  |  Tags: String, Dynamic Programming
 https://leetcode.com/problems/strange-printer/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is a strange printer with the following two special properties:

  - The printer can only print a sequence of the same character each time.

  - At each turn, the printer can print new characters starting from and
    ending at any place and will cover the original existing characters.

  Given a string s, return the minimum number of turns the printer needed
  to print it.

CONSTRAINTS
  1 <= s.length <= 100
  s consists of lowercase English letters.

TEST CASES
  [1] Input    : s = "aaabbb"
      Expected : 2
      Why      : Print "aaa" first and then print "bbb".

  [2] Input    : s = "aba"
      Expected : 2
      Why      : Print "aaa" first and then print "b" from the second place of the string, which will cover the existing character 'a'.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int strangePrinter(string s);
