 665. Non-decreasing Array
 Medium  |  Tags: Array
 https://leetcode.com/problems/non-decreasing-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array nums with n integers, your task is to check if it could
  become non-decreasing by modifying at most one element.

  We define an array is non-decreasing if nums[i] <= nums[i + 1] holds for
  every i (0-based) such that (0 <= i <= n - 2).

CONSTRAINTS
  n == nums.length
  1 <= n <= 10^4
  -10^5 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [4,2,3]
      Expected : true
      Why      : You could modify the first 4 to 1 to get a non-decreasing array.

  [2] Input    : nums = [4,2,1]
      Expected : false
      Why      : You cannot get a non-decreasing array by modifying at most one element.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool checkPossibility(vector<int>& nums);
