 667. Beautiful Arrangement II
 Medium  |  Tags: Array, Math
 https://leetcode.com/problems/beautiful-arrangement-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integers n and k, construct a list answer that contains n
  different positive integers ranging from 1 to n and obeys the following
  requirement:

  - Suppose this list is answer = [a1, a2, a3, ... , an], then the list
    [|a1 - a2|, |a2 - a3|, |a3 - a4|, ... , |an-1 - an|] has exactly k
    distinct integers.

  Return the list answer. If there multiple valid answers, return any of
  them.

CONSTRAINTS
  1 <= k < n <= 10^4

TEST CASES
  [1] Input    : n = 3, k = 1
      Expected : [1,2,3]
      Why      : The [1,2,3] has three different positive integers ranging from 1 to 3, and the [1,1] has exactly 1 distinct integer: 1

  [2] Input    : n = 3, k = 2
      Expected : [1,3,2]
      Why      : The [1,3,2] has three different positive integers ranging from 1 to 3, and the [2,1] has exactly 2 distinct integers: 1 and 2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> constructArray(int n, int k);

FILES
  edit : 667.cpp
