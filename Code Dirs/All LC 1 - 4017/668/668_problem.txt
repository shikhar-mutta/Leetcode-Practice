 668. Kth Smallest Number in Multiplication Table
 Hard  |  Tags: Math, Binary Search
 https://leetcode.com/problems/kth-smallest-number-in-multiplication-table/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Nearly everyone has used the Multiplication Table. The multiplication
  table of size m x n is an integer matrix mat where mat[i][j] == i * j
  (1-indexed).

  Given three integers m, n, and k, return the k^th smallest element in
  the m x n multiplication table.

CONSTRAINTS
  1 <= m, n <= 3 * 10^4
  1 <= k <= m * n

TEST CASES
  [1] Input    : m = 3, n = 3, k = 5
      Expected : 3
      Why      : The 5^th smallest number is 3.

  [2] Input    : m = 2, n = 3, k = 6
      Expected : 6
      Why      : The 6^th smallest number is 6.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findKthNumber(int m, int n, int k);

FILES
  edit : 668.cpp
  test : lc run 668
