 670. Maximum Swap
 Medium  |  Tags: Math, Greedy
 https://leetcode.com/problems/maximum-swap/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer num. You can swap two digits at most once to
  get the maximum valued number.

  Return the maximum valued number you can get.

CONSTRAINTS
  0 <= num <= 10^8

TEST CASES
  [1] Input    : num = 2736
      Expected : 7236
      Why      : Swap the number 2 and the number 7.

  [2] Input    : num = 9973
      Expected : 9973
      Why      : No swap.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maximumSwap(int num);

FILES
  edit : 670.cpp
  test : lc run 670
