 673. Number of Longest Increasing Subsequence
 Medium  |  Tags: Array, Dynamic Programming, Binary Indexed Tree, Segment Tree, Longest Increasing Subsequence
 https://leetcode.com/problems/number-of-longest-increasing-subsequence/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the number of longest increasing
  subsequences.

  Notice that the sequence has to be strictly increasing.

CONSTRAINTS
  1 <= nums.length <= 2000
  -10^6 <= nums[i] <= 10^6
  The answer is guaranteed to fit inside a 32-bit integer.

TEST CASES
  [1] Input    : nums = [1,3,5,4,7]
      Expected : 2
      Why      : The two longest increasing subsequences are [1, 3, 4, 7] and [1, 3, 5, 7].

  [2] Input    : nums = [2,2,2,2,2]
      Expected : 5
      Why      : The length of the longest increasing subsequence is 1, and there are 5 increasing subsequences of length 1, so output 5.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findNumberOfLIS(vector<int>& nums);
