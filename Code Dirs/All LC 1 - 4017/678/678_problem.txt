 678. Valid Parenthesis String
 Medium  |  Tags: String, Dynamic Programming, Stack, Greedy, Bracket Sequences
 https://leetcode.com/problems/valid-parenthesis-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s containing only three types of characters: '(', ')' and
  '*', return true if s is valid.

  The following rules define a valid string:

  - Any left parenthesis '(' must have a corresponding right parenthesis
    ')'.

  - Any right parenthesis ')' must have a corresponding left parenthesis
    '('.

  - Left parenthesis '(' must go before the corresponding right
    parenthesis ')'.

  - '*' could be treated as a single right parenthesis ')' or a single
    left parenthesis '(' or an empty string "".

CONSTRAINTS
  1 <= s.length <= 100
  s[i] is '(', ')' or '*'.

TEST CASES
  [1] Input    : s = "()"
      Expected : true

  [2] Input    : s = "(*)"
      Expected : true

  [3] Input    : s = "(*))"
      Expected : true

  [4] Input    : s = "("
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool checkValidString(string s);
