 69. Sqrt(x)
 Easy  |  Tags: Math, Binary Search, Newton's Method
 https://leetcode.com/problems/sqrtx/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a non-negative integer x, return the square root of x rounded down
  to the nearest integer. The returned integer should be non-negative as
  well.

  You must not use any built-in exponent function or operator.

  - For example, do not use pow(x, 0.5) in c++ or x ** 0.5 in python.

CONSTRAINTS
  0 <= x <= 2^31 - 1

TEST CASES
  [1] Input    : x = 4
      Expected : 2
      Why      : The square root of 4 is 2, so we return 2.

  [2] Input    : x = 8
      Expected : 2
      Why      : The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int mySqrt(int x);

FILES
  edit : 69.cpp
  test : lc run 69
