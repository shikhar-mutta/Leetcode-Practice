 697. Degree of an Array
 Easy  |  Tags: Array, Hash Table
 https://leetcode.com/problems/degree-of-an-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a non-empty array of non-negative integers nums, the degree of
  this array is defined as the maximum frequency of any one of its
  elements.

  Your task is to find the smallest possible length of a (contiguous)
  subarray of nums, that has the same degree as nums.

CONSTRAINTS
  nums.length will be between 1 and 50,000.
  nums[i] will be an integer between 0 and 49,999.

TEST CASES
  [1] Input    : nums = [1,2,2,3,1]
      Expected : 2
      Why      : The input array has a degree of 2 because both elements 1 and 2 appear twice.
                 Of the subarrays that have the same degree:
                 [1, 2, 2, 3, 1], [1, 2, 2, 3], [2, 2, 3, 1], [1, 2, 2], [2, 2, 3], [2, 2]
                 … (1 more)

  [2] Input    : nums = [1,2,2,3,1,4,2]
      Expected : 6
      Why      : The degree is 3 because the element 2 is repeated 3 times.
                 So [2,2,3,1,4,2] is the shortest subarray, therefore returning 6.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findShortestSubArray(vector<int>& nums);
