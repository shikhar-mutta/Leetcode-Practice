 700. Search in a Binary Search Tree
 Easy  |  Tags: Tree, Binary Search Tree, Binary Tree
 https://leetcode.com/problems/search-in-a-binary-search-tree/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given the root of a binary search tree (BST) and an integer val.

  Find the node in the BST that the node's value equals val and return the
  subtree rooted with that node. If such a node does not exist, return
  null.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 5000].
  1 <= Node.val <= 10^7
  root is a binary search tree.
  1 <= val <= 10^7

TEST CASES
  [1] Input    : root = [4,2,7,1,3], val = 2
      Expected : [2,1,3]

  [2] Input    : root = [4,2,7,1,3], val = 5
      Expected : []

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  TreeNode* searchBST(TreeNode* root, int val);
