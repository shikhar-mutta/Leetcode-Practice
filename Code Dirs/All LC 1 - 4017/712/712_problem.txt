 712. Minimum ASCII Delete Sum for Two Strings
 Medium  |  Tags: String, Dynamic Programming, Longest Common Subsequence
 https://leetcode.com/problems/minimum-ascii-delete-sum-for-two-strings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two strings s1 and s2, return the lowest ASCII sum of deleted
  characters to make two strings equal.

CONSTRAINTS
  1 <= s1.length, s2.length <= 1000
  s1 and s2 consist of lowercase English letters.

TEST CASES
  [1] Input    : s1 = "sea", s2 = "eat"
      Expected : 231
      Why      : Deleting "s" from "sea" adds the ASCII value of "s" (115) to the sum.
                 Deleting "t" from "eat" adds 116 to the sum.
                 At the end, both strings are equal, and 115 + 116 = 231 is the minimum sum possible to achieve this.

  [2] Input    : s1 = "delete", s2 = "leet"
      Expected : 403
      Why      : Deleting "dee" from "delete" to turn the string into "let",
                 adds 100[d] + 101[e] + 101[e] to the sum.
                 Deleting "e" from "leet" adds 101[e] to the sum.
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minimumDeleteSum(string s1, string s2);
