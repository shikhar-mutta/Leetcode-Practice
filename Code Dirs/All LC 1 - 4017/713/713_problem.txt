 713. Subarray Product Less Than K
 Medium  |  Tags: Array, Binary Search, Sliding Window, Prefix Sum
 https://leetcode.com/problems/subarray-product-less-than-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an array of integers nums and an integer k.

  Return the number of contiguous subarrays where the product of all the
  elements in the subarray is strictly less than k.

CONSTRAINTS
  1 <= nums.length <= 3 * 10^4
  1 <= nums[i] <= 1000
  0 <= k <= 10^6

TEST CASES
  [1] Input    : nums = [10,5,2,6], k = 100
      Expected : 8
      Why      : The 8 subarrays that have product less than 100 are:
                 [10], [5], [2], [6], [10, 5], [5, 2], [2, 6], [5, 2, 6]
                 Note that [10, 5, 2] is not included as the product of 100 is not strictly less than k.

  [2] Input    : nums = [1,2,3], k = 0
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numSubarrayProductLessThanK(vector<int>& nums, int k);
