 718. Maximum Length of Repeated Subarray
 Medium  |  Tags: Array, Binary Search, Dynamic Programming, Sliding Window, Rolling Hash, Hash Function
 https://leetcode.com/problems/maximum-length-of-repeated-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integer arrays nums1 and nums2, return the maximum length of a
  subarray that appears in both arrays.

CONSTRAINTS
  1 <= nums1.length, nums2.length <= 1000
  0 <= nums1[i], nums2[i] <= 100

TEST CASES
  [1] Input    : nums1 = [1,2,3,2,1], nums2 = [3,2,1,4,7]
      Expected : 3
      Why      : The repeated subarray with maximum length is [3,2,1].

  [2] Input    : nums1 = [0,0,0,0,0], nums2 = [0,0,0,0,0]
      Expected : 5
      Why      : The repeated subarray with maximum length is [0,0,0,0,0].

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int findLength(vector<int>& nums1, vector<int>& nums2);
