 719. Find K-th Smallest Pair Distance
 Hard  |  Tags: Array, Two Pointers, Binary Search, Sorting
 https://leetcode.com/problems/find-k-th-smallest-pair-distance/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  The distance of a pair of integers a and b is defined as the absolute
  difference between a and b.

  Given an integer array nums and an integer k, return the k^th smallest
  distance among all the pairs nums[i] and nums[j] where 0 <= i < j <
  nums.length.

CONSTRAINTS
  n == nums.length
  2 <= n <= 10^4
  0 <= nums[i] <= 10^6
  1 <= k <= n * (n - 1) / 2

TEST CASES
  [1] Input    : nums = [1,3,1], k = 1
      Expected : 0
      Why      : Here are all the pairs:
                 (1,3) -> 2
                 (1,1) -> 0
                 … (2 more)

  [2] Input    : nums = [1,1,1], k = 2
      Expected : 0

  [3] Input    : nums = [1,6,1], k = 3
      Expected : 5

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int smallestDistancePair(vector<int>& nums, int k);
