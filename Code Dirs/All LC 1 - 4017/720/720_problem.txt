 720. Longest Word in Dictionary
 Medium  |  Tags: Array, Hash Table, String, Trie, Sorting
 https://leetcode.com/problems/longest-word-in-dictionary/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of strings words representing an English Dictionary,
  return the longest word in words that can be built one character at a
  time by other words in words.

  If there is more than one possible answer, return the longest word with
  the smallest lexicographical order. If there is no answer, return the
  empty string.

  Note that the word should be built from left to right with each
  additional character being added to the end of a previous word.

CONSTRAINTS
  1 <= words.length <= 1000
  1 <= words[i].length <= 30
  words[i] consists of lowercase English letters.

TEST CASES
  [1] Input    : words = ["w","wo","wor","worl","world"]
      Expected : "world"
      Why      : The word "world" can be built one character at a time by "w", "wo", "wor", and "worl".

  [2] Input    : words = ["a","banana","app","appl","ap","apply","apple"]
      Expected : "apple"
      Why      : Both "apply" and "apple" can be built from other words in the dictionary. However, "apple" is lexicographically smaller than "apply".

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string longestWord(vector<string>& words);

FILES
  edit : 720.cpp
