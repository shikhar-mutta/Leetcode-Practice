 730. Count Different Palindromic Subsequences
 Hard  |  Tags: String, Dynamic Programming
 https://leetcode.com/problems/count-different-palindromic-subsequences/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, return the number of different non-empty palindromic
  subsequences in s. Since the answer may be very large, return it modulo
  10^9 + 7.

  A subsequence of a string is obtained by deleting zero or more
  characters from the string.

  A sequence is palindromic if it is equal to the sequence reversed.

  Two sequences a1, a2, ... and b1, b2, ... are different if there is some
  i for which ai != bi.

CONSTRAINTS
  1 <= s.length <= 1000
  s[i] is either 'a', 'b', 'c', or 'd'.

TEST CASES
  [1] Input    : s = "bccb"
      Expected : 6
      Why      : The 6 different non-empty palindromic subsequences are 'b', 'c', 'bb', 'cc', 'bcb', 'bccb'.
                 Note that 'bcb' is counted only once, even though it occurs twice.

  [2] Input    : s = "abcdabcdabcdabcdabcdabcdabcdabcddcbadcbadcbadcbadcbadcbadcbadcba"
      Expected : 104860361
      Why      : There are 3104860382 different non-empty palindromic subsequences, which is 104860361 modulo 10^9 + 7.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPalindromicSubsequences(string s);
