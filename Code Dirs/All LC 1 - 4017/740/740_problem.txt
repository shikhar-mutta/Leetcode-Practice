 740. Delete and Earn
 Medium  |  Tags: Array, Hash Table, Dynamic Programming
 https://leetcode.com/problems/delete-and-earn/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums. You want to maximize the number of
  points you get by performing the following operation any number of
  times:

  - Pick any nums[i] and delete it to earn nums[i] points. Afterwards, you
    must delete every element equal to nums[i] - 1 and every element equal
    to nums[i] + 1.

  Return the maximum number of points you can earn by applying the above
  operation some number of times.

CONSTRAINTS
  1 <= nums.length <= 2 * 10^4
  1 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [3,4,2]
      Expected : 6
      Why      : You can perform the following operations:
                 - Delete 4 to earn 4 points. Consequently, 3 is also deleted. nums = [2].
                 - Delete 2 to earn 2 points. nums = [].
                 … (1 more)

  [2] Input    : nums = [2,2,3,3,3,4]
      Expected : 9
      Why      : You can perform the following operations:
                 - Delete a 3 to earn 3 points. All 2's and 4's are also deleted. nums = [3,3].
                 - Delete a 3 again to earn 3 points. nums = [3].
                 … (2 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int deleteAndEarn(vector<int>& nums);
