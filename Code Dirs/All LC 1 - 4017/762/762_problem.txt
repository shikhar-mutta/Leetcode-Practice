 762. Prime Number of Set Bits in Binary Representation
 Easy  |  Tags: Math, Bit Manipulation, Primality Test
 https://leetcode.com/problems/prime-number-of-set-bits-in-binary-representation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integers left and right, return the count of numbers in the
  inclusive range [left, right] having a prime number of set bits in their
  binary representation.

  Recall that the number of set bits an integer has is the number of 1's
  present when written in binary.

  - For example, 21 written in binary is 10101, which has 3 set bits.

CONSTRAINTS
  1 <= left <= right <= 10^6
  0 <= right - left <= 10^4

TEST CASES
  [1] Input    : left = 6, right = 10
      Expected : 4
      Why      : 6 -> 110 (2 set bits, 2 is prime)
                 7 -> 111 (3 set bits, 3 is prime)
                 8 -> 1000 (1 set bit, 1 is not prime)
                 … (3 more)

  [2] Input    : left = 10, right = 15
      Expected : 5
      Why      : 10 -> 1010 (2 set bits, 2 is prime)
                 11 -> 1011 (3 set bits, 3 is prime)
                 12 -> 1100 (2 set bits, 2 is prime)
                 … (4 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countPrimeSetBits(int left, int right);
