 763. Partition Labels
 Medium  |  Tags: Hash Table, Two Pointers, String, Greedy
 https://leetcode.com/problems/partition-labels/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s. We want to partition the string into as many
  parts as possible so that each letter appears in at most one part. For
  example, the string "ababcc" can be partitioned into ["abab", "cc"], but
  partitions such as ["aba", "bcc"] or ["ab", "ab", "cc"] are invalid.

  Note that the partition is done so that after concatenating all the
  parts in order, the resultant string should be s.

  Return a list of integers representing the size of these parts.

CONSTRAINTS
  1 <= s.length <= 500
  s consists of lowercase English letters.

TEST CASES
  [1] Input    : s = "ababcbacadefegdehijhklij"
      Expected : [9,7,8]
      Why      : The partition is "ababcbaca", "defegde", "hijhklij".
                 This is a partition so that each letter appears in at most one part.
                 A partition like "ababcbacadefegde", "hijhklij" is incorrect, because it splits s into less parts.

  [2] Input    : s = "eccbbbbdec"
      Expected : [10]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> partitionLabels(string s);
