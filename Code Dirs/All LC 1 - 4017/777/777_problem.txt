 777. Swap Adjacent in LR String
 Medium  |  Tags: Two Pointers, String
 https://leetcode.com/problems/swap-adjacent-in-lr-string/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  In a string composed of 'L', 'R', and 'X' characters, like "RXXLRXRXL",
  a move consists of either replacing one occurrence of "XL" with "LX", or
  replacing one occurrence of "RX" with "XR". Given the starting string
  start and the ending string result, return True if and only if there
  exists a sequence of moves to transform start to result.

CONSTRAINTS
  1 <= start.length <= 10^4
  start.length == result.length
  Both start and result will only consist of characters in 'L', 'R', and 'X'.

TEST CASES
  [1] Input    : start = "RXXLRXRXL", result = "XRLXXRRLX"
      Expected : true
      Why      : We can transform start to result following these steps:
                 RXXLRXRXL ->
                 XRXLRXRXL ->
                 … (3 more)

  [2] Input    : start = "X", result = "L"
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool canTransform(string start, string result);

FILES
  edit : 777.cpp
  test : lc run 777
