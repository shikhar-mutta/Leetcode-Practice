 784. Letter Case Permutation
 Medium  |  Tags: String, Backtracking, Bit Manipulation
 https://leetcode.com/problems/letter-case-permutation/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s, you can transform every letter individually to be
  lowercase or uppercase to create another string.

  Return a list of all possible strings we could create. Return the output
  in any order.

CONSTRAINTS
  1 <= s.length <= 12
  s consists of lowercase English letters, uppercase English letters, and digits.

TEST CASES
  [1] Input    : s = "a1b2"
      Expected : ["a1b2","a1B2","A1b2","A1B2"]

  [2] Input    : s = "3z4"
      Expected : ["3z4","3Z4"]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<string> letterCasePermutation(string s);

FILES
  edit : 784.cpp
  test : lc run 784
