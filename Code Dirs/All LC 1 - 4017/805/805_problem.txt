 805. Split Array With Same Average
 Hard  |  Tags: Array, Hash Table, Math, Dynamic Programming, Bit Manipulation, Meet in the Middle, Bitmask
 https://leetcode.com/problems/split-array-with-same-average/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums.

  You should move each element of nums into one of the two arrays A and B
  such that A and B are non-empty, and average(A) == average(B).

  Return true if it is possible to achieve that and false otherwise.

  Note that for an array arr, average(arr) is the sum of all the elements
  of arr over the length of arr.

CONSTRAINTS
  1 <= nums.length <= 30
  0 <= nums[i] <= 10^4

TEST CASES
  [1] Input    : nums = [1,2,3,4,5,6,7,8]
      Expected : true
      Why      : We can split the array into [1,4,5,8] and [2,3,6,7], and both of them have an average of 4.5.

  [2] Input    : nums = [3,1]
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool splitArraySameAverage(vector<int>& nums);

FILES
  edit : 805.cpp
  test : lc run 805
