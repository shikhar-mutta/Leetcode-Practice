 812. Largest Triangle Area
 Easy  |  Tags: Array, Math, Geometry, Polygons
 https://leetcode.com/problems/largest-triangle-area/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of points on the X-Y plane points where points[i] = [xi,
  yi], return the area of the largest triangle that can be formed by any
  three different points. Answers within 10^-5 of the actual answer will
  be accepted.

CONSTRAINTS
  3 <= points.length <= 50
  -50 <= xi, yi <= 50
  All the given points are unique.

TEST CASES
  [1] Input    : points = [[0,0],[0,1],[1,0],[0,2],[2,0]]
      Expected : 2.00000
      Why      : The five points are shown in the above figure. The red triangle is the largest.

  [2] Input    : points = [[1,0],[0,0],[0,1]]
      Expected : 0.50000

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  double largestTriangleArea(vector<vector<int>>& points);
