 814. Binary Tree Pruning
 Medium  |  Tags: Tree, Depth-First Search, Binary Tree
 https://leetcode.com/problems/binary-tree-pruning/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root of a binary tree, return the same tree where every
  subtree (of the given tree) not containing a 1 has been removed.

  A subtree of a node node is node plus every node that is a descendant of
  node.

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 200].
  Node.val is either 0 or 1.

TEST CASES
  [1] Input    : root = [1,null,0,0,1]
      Expected : [1,null,0,null,1]
      Why      : Only the red nodes satisfy the property "every subtree not containing a 1".
                 The diagram on the right represents the answer.

  [2] Input    : root = [1,0,1,0,0,0,1]
      Expected : [1,null,1,null,1]

  [3] Input    : root = [1,1,0,1,1,0,1,0]
      Expected : [1,1,0,1,1,null,1]

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  TreeNode* pruneTree(TreeNode* root);
