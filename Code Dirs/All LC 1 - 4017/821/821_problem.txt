 821. Shortest Distance to a Character
 Easy  |  Tags: Array, Two Pointers, String
 https://leetcode.com/problems/shortest-distance-to-a-character/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a string s and a character c that occurs in s, return an array of
  integers answer where answer.length == s.length and answer[i] is the
  distance from index i to the closest occurrence of character c in s.

  The distance between two indices i and j is abs(i - j), where abs is the
  absolute value function.

CONSTRAINTS
  1 <= s.length <= 10^4
  s[i] and c are lowercase English letters.
  It is guaranteed that c occurs at least once in s.

TEST CASES
  [1] Input    : s = "loveleetcode", c = "e"
      Expected : [3,2,1,0,1,0,0,1,2,2,1,0]
      Why      : The character 'e' appears at indices 3, 5, 6, and 11 (0-indexed).
                 The closest occurrence of 'e' for index 0 is at index 3, so the distance is abs(0 - 3) = 3.
                 The closest occurrence of 'e' for index 1 is at index 3, so the distance is abs(1 - 3) = 2.
                 … (2 more)

  [2] Input    : s = "aaab", c = "b"
      Expected : [3,2,1,0]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> shortestToChar(string s, char c);
