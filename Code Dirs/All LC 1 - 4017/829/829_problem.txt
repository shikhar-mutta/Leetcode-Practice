 829. Consecutive Numbers Sum
 Hard  |  Tags: Math, Enumeration
 https://leetcode.com/problems/consecutive-numbers-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer n, return the number of ways you can write n as the sum
  of consecutive positive integers.

CONSTRAINTS
  1 <= n <= 10^9

TEST CASES
  [1] Input    : n = 5
      Expected : 2
      Why      : 5 = 2 + 3

  [2] Input    : n = 9
      Expected : 3
      Why      : 9 = 4 + 5 = 2 + 3 + 4

  [3] Input    : n = 15
      Expected : 4
      Why      : 15 = 8 + 7 = 4 + 5 + 6 = 1 + 2 + 3 + 4 + 5

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int consecutiveNumbersSum(int n);

FILES
  edit : 829.cpp
  test : lc run 829
