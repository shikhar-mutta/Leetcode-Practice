 84. Largest Rectangle in Histogram
 Hard  |  Tags: Array, Stack, Monotonic Stack, Range Minimum/Maximum Query
 https://leetcode.com/problems/largest-rectangle-in-histogram/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers heights representing the histogram's bar
  height where the width of each bar is 1, return the area of the largest
  rectangle in the histogram.

CONSTRAINTS
  1 <= heights.length <= 10^5
  0 <= heights[i] <= 10^4

TEST CASES
  [1] Input    : heights = [2,1,5,6,2,3]
      Expected : 10
      Why      : The above is a histogram where width of each bar is 1.
                 The largest rectangle is shown in the red area, which has an area = 10 units.

  [2] Input    : heights = [2,4]
      Expected : 4

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestRectangleArea(vector<int>& heights);

FILES
  edit : 84.cpp
  test : lc run 84
