 852. Peak Index in a Mountain Array
 Medium  |  Tags: Array, Binary Search, Ternary Search
 https://leetcode.com/problems/peak-index-in-a-mountain-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer mountain array arr of length n where the values
  increase to a peak element and then decrease.

  Return the index of the peak element.

  Your task is to solve it in O(log(n)) time complexity.

CONSTRAINTS
  3 <= arr.length <= 10^5
  0 <= arr[i] <= 10^6
  arr is guaranteed to be a mountain array.

TEST CASES
  [1] Input    : arr = [0,1,0]
      Expected : 1

  [2] Input    : arr = [0,2,1,0]
      Expected : 1

  [3] Input    : arr = [0,10,5,2]
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int peakIndexInMountainArray(vector<int>& arr);

FILES
  edit : 852.cpp
  test : lc run 852
