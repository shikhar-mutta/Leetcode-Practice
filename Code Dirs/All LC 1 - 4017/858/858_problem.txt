 858. Mirror Reflection
 Medium  |  Tags: Math, Geometry, Number Theory, Least Common Multiple, Greatest Common Divisor
 https://leetcode.com/problems/mirror-reflection/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  There is a special square room with mirrors on each of the four walls.
  Except for the southwest corner, there are receptors on each of the
  remaining corners, numbered 0, 1, and 2.

  The square room has walls of length p and a laser ray from the southwest
  corner first meets the east wall at a distance q from the 0^th receptor.

  Given the two integers p and q, return the number of the receptor that
  the ray meets first.

  The test cases are guaranteed so that the ray will meet a receptor
  eventually.

CONSTRAINTS
  1 <= q <= p <= 1000

TEST CASES
  [1] Input    : p = 2, q = 1
      Expected : 2
      Why      : The ray meets receptor 2 the first time it gets reflected back to the left wall.

  [2] Input    : p = 3, q = 1
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int mirrorReflection(int p, int q);
