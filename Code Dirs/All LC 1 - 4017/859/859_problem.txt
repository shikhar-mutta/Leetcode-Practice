 859. Buddy Strings
 Easy  |  Tags: Hash Table, String
 https://leetcode.com/problems/buddy-strings/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two strings s and goal, return true if you can swap two letters in
  s so the result is equal to goal, otherwise, return false.

  Swapping letters is defined as taking two indices i and j (0-indexed)
  such that i != j and swapping the characters at s[i] and s[j].

  - For example, swapping at indices 0 and 2 in "abcd" results in "cbad".

CONSTRAINTS
  1 <= s.length, goal.length <= 2 * 10^4
  s and goal consist of lowercase letters.

TEST CASES
  [1] Input    : s = "ab", goal = "ba"
      Expected : true
      Why      : You can swap s[0] = 'a' and s[1] = 'b' to get "ba", which is equal to goal.

  [2] Input    : s = "ab", goal = "ab"
      Expected : false
      Why      : The only letters you can swap are s[0] = 'a' and s[1] = 'b', which results in "ba" != goal.

  [3] Input    : s = "aa", goal = "aa"
      Expected : true
      Why      : You can swap s[0] = 'a' and s[1] = 'a' to get "aa", which is equal to goal.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool buddyStrings(string s, string goal);
