 86. Partition List
 Medium  |  Tags: Linked List, Two Pointers
 https://leetcode.com/problems/partition-list/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the head of a linked list and a value x, partition it such that
  all nodes less than x come before nodes greater than or equal to x.

  You should preserve the original relative order of the nodes in each of
  the two partitions.

CONSTRAINTS
  The number of nodes in the list is in the range [0, 200].
  -100 <= Node.val <= 100
  -200 <= x <= 200

TEST CASES
  [1] Input    : head = [1,4,3,2,5,2], x = 3
      Expected : [1,2,2,4,3,5]

  [2] Input    : head = [2,1], x = 2
      Expected : [1,2]

CODE TYPE
  function · linked list
    driver: one Solution call per test case
    linked list: ListNode* — values in order, e.g. [1,2,3,4]

SIGNATURE
  ListNode* partition(ListNode* head, int x);

FILES
  edit : 86.cpp
