 870. Advantage Shuffle
 Medium  |  Tags: Array, Two Pointers, Greedy, Sorting
 https://leetcode.com/problems/advantage-shuffle/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given two integer arrays nums1 and nums2 both of the same
  length. The advantage of nums1 with respect to nums2 is the number of
  indices i for which nums1[i] > nums2[i].

  Return any permutation of nums1 that maximizes its advantage with
  respect to nums2.

CONSTRAINTS
  1 <= nums1.length <= 10^5
  nums2.length == nums1.length
  0 <= nums1[i], nums2[i] <= 10^9

TEST CASES
  [1] Input    : nums1 = [2,7,11,15], nums2 = [1,10,4,11]
      Expected : [2,11,7,15]

  [2] Input    : nums1 = [12,24,8,32], nums2 = [13,25,32,11]
      Expected : [24,32,8,12]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> advantageCount(vector<int>& nums1, vector<int>& nums2);
