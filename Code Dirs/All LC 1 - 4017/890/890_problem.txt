 890. Find and Replace Pattern
 Medium  |  Tags: Array, Hash Table, String
 https://leetcode.com/problems/find-and-replace-pattern/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a list of strings words and a string pattern, return a list of
  words[i] that match pattern. You may return the answer in any order.

  A word matches the pattern if there exists a permutation of letters p so
  that after replacing every letter x in the pattern with p(x), we get the
  desired word.

  Recall that a permutation of letters is a bijection from letters to
  letters: every letter maps to another letter, and no two letters map to
  the same letter.

CONSTRAINTS
  1 <= pattern.length <= 20
  1 <= words.length <= 50
  words[i].length == pattern.length
  pattern and words[i] are lowercase English letters.

TEST CASES
  [1] Input    : words = ["abc","deq","mee","aqq","dkd","ccc"], pattern = "abb"
      Expected : ["mee","aqq"]
      Why      : "mee" matches the pattern because there is a permutation {a -> m, b -> e, ...}.
                 "ccc" does not match the pattern because {a -> c, b -> c, ...} is not a permutation, since a and b map to the same letter.

  [2] Input    : words = ["a","b","c"], pattern = "a"
      Expected : ["a","b","c"]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<string> findAndReplacePattern(vector<string>& words, string pattern);
