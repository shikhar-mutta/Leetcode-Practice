 896. Monotonic Array
 Easy  |  Tags: Array
 https://leetcode.com/problems/monotonic-array/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An array is monotonic if it is either monotone increasing or monotone
  decreasing.

  An array nums is monotone increasing if for all i <= j, nums[i] <=
  nums[j]. An array nums is monotone decreasing if for all i <= j, nums[i]
  >= nums[j].

  Given an integer array nums, return true if the given array is
  monotonic, or false otherwise.

CONSTRAINTS
  1 <= nums.length <= 10^5
  -10^5 <= nums[i] <= 10^5

TEST CASES
  [1] Input    : nums = [1,2,2,3]
      Expected : true

  [2] Input    : nums = [6,5,4,4]
      Expected : true

  [3] Input    : nums = [1,3,2]
      Expected : false

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isMonotonic(vector<int>& nums);
