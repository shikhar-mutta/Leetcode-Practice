 898. Bitwise ORs of Subarrays
 Medium  |  Tags: Array, Dynamic Programming, Bit Manipulation
 https://leetcode.com/problems/bitwise-ors-of-subarrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array arr, return the number of distinct bitwise ORs of
  all the non-empty subarrays of arr.

  The bitwise OR of a subarray is the bitwise OR of each integer in the
  subarray. The bitwise OR of a subarray of one integer is that integer.

  A subarray is a contiguous non-empty sequence of elements within an
  array.

CONSTRAINTS
  1 <= arr.length <= 5 * 10^4
  0 <= arr[i] <= 10^9

TEST CASES
  [1] Input    : arr = [0]
      Expected : 1
      Why      : There is only one possible result: 0.

  [2] Input    : arr = [1,1,2]
      Expected : 3
      Why      : The possible subarrays are [1], [1], [2], [1, 1], [1, 2], [1, 1, 2].
                 These yield the results 1, 1, 2, 1, 3, 3.
                 There are 3 unique values, so the answer is 3.

  [3] Input    : arr = [1,2,4]
      Expected : 6
      Why      : The possible results are 1, 2, 3, 4, 6, and 7.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int subarrayBitwiseORs(vector<int>& arr);
