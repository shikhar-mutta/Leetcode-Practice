 902. Numbers At Most N Given Digit Set
 Hard  |  Tags: Array, Math, String, Binary Search, Dynamic Programming
 https://leetcode.com/problems/numbers-at-most-n-given-digit-set/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of digits which is sorted in non-decreasing order. You
  can write numbers using each digits[i] as many times as we want. For
  example, if digits = ['1','3','5'], we may write numbers such as '13',
  '551', and '1351315'.

  Return the number of positive integers that can be generated that are
  less than or equal to a given integer n.

CONSTRAINTS
  1 <= digits.length <= 9
  digits[i].length == 1
  digits[i] is a digit from '1' to '9'.
  All the values in digits are unique.
  digits is sorted in non-decreasing order.
  1 <= n <= 10^9

TEST CASES
  [1] Input    : digits = ["1","3","5","7"], n = 100
      Expected : 20
      Why      : The 20 numbers that can be written are:
                 1, 3, 5, 7, 11, 13, 15, 17, 31, 33, 35, 37, 51, 53, 55, 57, 71, 73, 75, 77.

  [2] Input    : digits = ["1","4","9"], n = 1000000000
      Expected : 29523
      Why      : We can write 3 one digit numbers, 9 two digit numbers, 27 three digit numbers,
                 81 four digit numbers, 243 five digit numbers, 729 six digit numbers,
                 2187 seven digit numbers, 6561 eight digit numbers, and 19683 nine digit numbers.
                 … (1 more)

  [3] Input    : digits = ["7"], n = 8
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int atMostNGivenDigitSet(vector<string>& digits, int n);
