 903. Valid Permutations for DI Sequence
 Hard  |  Tags: String, Dynamic Programming, Prefix Sum
 https://leetcode.com/problems/valid-permutations-for-di-sequence/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a string s of length n where s[i] is either:

  - 'D' means decreasing, or

  - 'I' means increasing.

  A permutation perm of n + 1 integers of all the integers in the range
  [0, n] is called a valid permutation if for all valid i:

  - If s[i] == 'D', then perm[i] > perm[i + 1], and

  - If s[i] == 'I', then perm[i] < perm[i + 1].

  Return the number of valid permutations perm. Since the answer may be
  large, return it modulo 10^9 + 7.

CONSTRAINTS
  n == s.length
  1 <= n <= 200
  s[i] is either 'I' or 'D'.

TEST CASES
  [1] Input    : s = "DID"
      Expected : 5
      Why      : The 5 valid permutations of (0, 1, 2, 3) are:
                 (1, 0, 3, 2)
                 (2, 0, 3, 1)
                 … (3 more)

  [2] Input    : s = "D"
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numPermsDISequence(string s);
