 905. Sort Array By Parity
 Easy  |  Tags: Array, Two Pointers, Sorting
 https://leetcode.com/problems/sort-array-by-parity/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, move all the even integers at the beginning
  of the array followed by all the odd integers.

  Return any array that satisfies this condition.

CONSTRAINTS
  1 <= nums.length <= 5000
  0 <= nums[i] <= 5000

TEST CASES
  [1] Input    : nums = [3,1,2,4]
      Expected : [2,4,3,1]
      Why      : The outputs [4,2,3,1], [2,4,1,3], and [4,2,1,3] would also be accepted.

  [2] Input    : nums = [0]
      Expected : [0]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> sortArrayByParity(vector<int>& nums);

FILES
  edit : 905.cpp
  test : lc run 905
