 907. Sum of Subarray Minimums
 Medium  |  Tags: Array, Dynamic Programming, Stack, Monotonic Stack
 https://leetcode.com/problems/sum-of-subarray-minimums/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of integers arr, find the sum of min(b), where b ranges
  over every (contiguous) subarray of arr. Since the answer may be large,
  return the answer modulo 10^9 + 7.

CONSTRAINTS
  1 <= arr.length <= 3 * 10^4
  1 <= arr[i] <= 3 * 10^4

TEST CASES
  [1] Input    : arr = [3,1,2,4]
      Expected : 17
      Why      : Subarrays are [3], [1], [2], [4], [3,1], [1,2], [2,4], [3,1,2], [1,2,4], [3,1,2,4].
                 Minimums are 3, 1, 2, 4, 1, 1, 2, 1, 1, 1.
                 Sum is 17.

  [2] Input    : arr = [11,81,94,43,3]
      Expected : 444

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int sumSubarrayMins(vector<int>& arr);
