 910. Smallest Range II
 Medium  |  Tags: Array, Math, Greedy, Sorting
 https://leetcode.com/problems/smallest-range-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an integer k.

  For each index i where 0 <= i < nums.length, change nums[i] to be either
  nums[i] + k or nums[i] - k.

  The score of nums is the difference between the maximum and minimum
  elements in nums.

  Return the minimum score of nums after changing the values at each
  index.

CONSTRAINTS
  1 <= nums.length <= 10^4
  0 <= nums[i] <= 10^4
  0 <= k <= 10^4

TEST CASES
  [1] Input    : nums = [1], k = 0
      Expected : 0
      Why      : The score is max(nums) - min(nums) = 1 - 1 = 0.

  [2] Input    : nums = [0,10], k = 2
      Expected : 6
      Why      : Change nums to be [2, 8]. The score is max(nums) - min(nums) = 8 - 2 = 6.

  [3] Input    : nums = [1,3,6], k = 3
      Expected : 3
      Why      : Change nums to be [4, 6, 3]. The score is max(nums) - min(nums) = 6 - 3 = 3.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int smallestRangeII(vector<int>& nums, int k);
