 918. Maximum Sum Circular Subarray
 Medium  |  Tags: Array, Divide and Conquer, Dynamic Programming, Queue, Monotonic Queue
 https://leetcode.com/problems/maximum-sum-circular-subarray/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a circular integer array nums of length n, return the maximum
  possible sum of a non-empty subarray of nums.

  A circular array means the end of the array connects to the beginning of
  the array. Formally, the next element of nums[i] is nums[(i + 1) % n]
  and the previous element of nums[i] is nums[(i - 1 + n) % n].

  A subarray may only include each element of the fixed buffer nums at
  most once. Formally, for a subarray nums[i], nums[i + 1], ..., nums[j],
  there does not exist i <= k1, k2 <= j with k1 % n == k2 % n.

CONSTRAINTS
  n == nums.length
  1 <= n <= 3 * 10^4
  -3 * 10^4 <= nums[i] <= 3 * 10^4

TEST CASES
  [1] Input    : nums = [1,-2,3,-2]
      Expected : 3
      Why      : Subarray [3] has maximum sum 3.

  [2] Input    : nums = [5,-3,5]
      Expected : 10
      Why      : Subarray [5,5] has maximum sum 5 + 5 = 10.

  [3] Input    : nums = [-3,-2,-3]
      Expected : -2
      Why      : Subarray [-2] has maximum sum -2.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int maxSubarraySumCircular(vector<int>& nums);
