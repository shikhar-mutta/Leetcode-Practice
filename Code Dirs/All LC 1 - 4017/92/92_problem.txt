 92. Reverse Linked List II
 Medium  |  Tags: Linked List
 https://leetcode.com/problems/reverse-linked-list-ii/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the head of a singly linked list and two integers left and right
  where left <= right, reverse the nodes of the list from position left to
  position right, and return the reversed list.

CONSTRAINTS
  The number of nodes in the list is n.
  1 <= n <= 500
  -500 <= Node.val <= 500
  1 <= left <= right <= n

TEST CASES
  [1] Input    : head = [1,2,3,4,5], left = 2, right = 4
      Expected : [1,4,3,2,5]

  [2] Input    : head = [5], left = 1, right = 1
      Expected : [5]

FOLLOW UP
  Could you do it in one pass?

CODE TYPE
  function · linked list
    driver: one Solution call per test case
    linked list: ListNode* — values in order, e.g. [1,2,3,4]

SIGNATURE
  ListNode* reverseBetween(ListNode* head, int left, int right);
