 926. Flip String to Monotone Increasing
 Medium  |  Tags: String, Dynamic Programming
 https://leetcode.com/problems/flip-string-to-monotone-increasing/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  A binary string is monotone increasing if it consists of some number of
  0's (possibly none), followed by some number of 1's (also possibly
  none).

  You are given a binary string s. You can flip s[i] changing it from 0 to
  1 or from 1 to 0.

  Return the minimum number of flips to make s monotone increasing.

CONSTRAINTS
  1 <= s.length <= 10^5
  s[i] is either '0' or '1'.

TEST CASES
  [1] Input    : s = "00110"
      Expected : 1
      Why      : We flip the last digit to get 00111.

  [2] Input    : s = "010110"
      Expected : 2
      Why      : We flip to get 011111, or alternatively 000111.

  [3] Input    : s = "00011000"
      Expected : 2
      Why      : We flip to get 00000000.

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minFlipsMonoIncr(string s);
