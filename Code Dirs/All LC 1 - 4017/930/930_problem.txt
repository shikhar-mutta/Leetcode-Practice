 930. Binary Subarrays With Sum
 Medium  |  Tags: Array, Hash Table, Sliding Window, Prefix Sum
 https://leetcode.com/problems/binary-subarrays-with-sum/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given a binary array nums and an integer goal, return the number of non-
  empty subarrays with a sum goal.

  A subarray is a contiguous part of the array.

CONSTRAINTS
  1 <= nums.length <= 3 * 10^4
  nums[i] is either 0 or 1.
  0 <= goal <= nums.length

TEST CASES
  [1] Input    : nums = [1,0,1,0,1], goal = 2
      Expected : 4
      Why      : The 4 subarrays are bolded and underlined below:
                 [1,0,1,0,1]
                 [1,0,1,0,1]
                 … (2 more)

  [2] Input    : nums = [0,0,0,0,0], goal = 0
      Expected : 15

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numSubarraysWithSum(vector<int>& nums, int goal);
