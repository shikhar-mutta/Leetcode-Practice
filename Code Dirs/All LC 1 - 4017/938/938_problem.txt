 938. Range Sum of BST
 Easy  |  Tags: Tree, Depth-First Search, Binary Search Tree, Binary Tree
 https://leetcode.com/problems/range-sum-of-bst/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given the root node of a binary search tree and two integers low and
  high, return the sum of values of all nodes with a value in the
  inclusive range [low, high].

CONSTRAINTS
  The number of nodes in the tree is in the range [1, 2 * 10^4].
  1 <= Node.val <= 10^5
  1 <= low <= high <= 10^5
  All Node.val are unique.

TEST CASES
  [1] Input    : root = [10,5,15,3,7,null,18], low = 7, high = 15
      Expected : 32
      Why      : Nodes 7, 10, and 15 are in the range [7, 15]. 7 + 10 + 15 = 32.

  [2] Input    : root = [10,5,15,3,7,13,18,1,null,6], low = 6, high = 10
      Expected : 23
      Why      : Nodes 6, 7, and 10 are in the range [6, 10]. 6 + 7 + 10 = 23.

CODE TYPE
  function · tree
    driver: one Solution call per test case
    tree: TreeNode* — level order, e.g. [3,9,20,null,null,15,7]

SIGNATURE
  int rangeSumBST(TreeNode* root, int low, int high);
