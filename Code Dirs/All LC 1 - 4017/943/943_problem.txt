 943. Find the Shortest Superstring
 Hard  |  Tags: Array, String, Dynamic Programming, Bit Manipulation, Bitmask, Hamiltonian Path
 https://leetcode.com/problems/find-the-shortest-superstring/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an array of strings words, return the smallest string that
  contains each string in words as a substring. If there are multiple
  valid strings of the smallest length, return any of them.

  You may assume that no string in words is a substring of another string
  in words.

CONSTRAINTS
  1 <= words.length <= 12
  1 <= words[i].length <= 20
  words[i] consists of lowercase English letters.
  All the strings of words are unique.

TEST CASES
  [1] Input    : words = ["alex","loves","leetcode"]
      Expected : "alexlovesleetcode"
      Why      : All permutations of "alex","loves","leetcode" would also be accepted.

  [2] Input    : words = ["catg","ctaagt","gcta","ttca","atgcatc"]
      Expected : "gctaagttcatgcatc"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string shortestSuperstring(vector<string>& words);
