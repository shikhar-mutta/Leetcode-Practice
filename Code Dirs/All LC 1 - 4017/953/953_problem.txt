 953. Verifying an Alien Dictionary
 Easy  |  Tags: Array, Hash Table, String
 https://leetcode.com/problems/verifying-an-alien-dictionary/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  In an alien language, surprisingly, they also use English lowercase
  letters, but possibly in a different order. The order of the alphabet is
  some permutation of lowercase letters.

  Given a sequence of words written in the alien language, and the order
  of the alphabet, return true if and only if the given words are sorted
  lexicographically in this alien language.

CONSTRAINTS
  1 <= words.length <= 100
  1 <= words[i].length <= 20
  order.length == 26
  All characters in words[i] and order are English lowercase letters.

TEST CASES
  [1] Input    : words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"
      Expected : true
      Why      : As 'h' comes before 'l' in this language, then the sequence is sorted.

  [2] Input    : words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"
      Expected : false
      Why      : As 'd' comes after 'l' in this language, then words[0] > words[1], hence the sequence is unsorted.

  [3] Input    : words = ["apple","app"], order = "abcdefghijklmnopqrstuvwxyz"
      Expected : false
      Why      : The first three characters "app" match, and the second string is shorter (in size.) According to lexicographical rules "apple" > "app", because 'l' > '∅', where '∅' is defined as the blank character which is less than any other character (More info).

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  bool isAlienSorted(vector<string>& words, string order);
