 970. Powerful Integers
 Medium  |  Tags: Hash Table, Math, Enumeration
 https://leetcode.com/problems/powerful-integers/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given three integers x, y, and bound, return a list of all the powerful
  integers that have a value less than or equal to bound.

  An integer is powerful if it can be represented as x^i + y^j for some
  integers i >= 0 and j >= 0.

  You may return the answer in any order. In your answer, each value
  should occur at most once.

CONSTRAINTS
  1 <= x, y <= 100
  0 <= bound <= 10^6

TEST CASES
  [1] Input    : x = 2, y = 3, bound = 10
      Expected : [2,3,4,5,7,9,10]
      Why      : 2 = 2^0 + 3^0
                 3 = 2^1 + 3^0
                 4 = 2^0 + 3^1
                 … (4 more)

  [2] Input    : x = 3, y = 5, bound = 15
      Expected : [2,4,6,8,10,14]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> powerfulIntegers(int x, int y, int bound);
