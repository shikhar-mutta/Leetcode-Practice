 974. Subarray Sums Divisible by K
 Medium  |  Tags: Array, Hash Table, Prefix Sum
 https://leetcode.com/problems/subarray-sums-divisible-by-k/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums and an integer k, return the number of non-
  empty subarrays that have a sum divisible by k.

  A subarray is a contiguous part of an array.

CONSTRAINTS
  1 <= nums.length <= 3 * 10^4
  -10^4 <= nums[i] <= 10^4
  2 <= k <= 10^4

TEST CASES
  [1] Input    : nums = [4,5,0,-2,-3,1], k = 5
      Expected : 7
      Why      : There are 7 subarrays with a sum divisible by k = 5:
                 [4, 5, 0, -2, -3, 1], [5], [5, 0], [5, 0, -2, -3], [0], [0, -2, -3], [-2, -3]

  [2] Input    : nums = [5], k = 9
      Expected : 0

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int subarraysDivByK(vector<int>& nums, int k);
