 976. Largest Perimeter Triangle
 Easy  |  Tags: Array, Math, Greedy, Sorting, Quicksort, Polygons
 https://leetcode.com/problems/largest-perimeter-triangle/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the largest perimeter of a triangle
  with a non-zero area, formed from three of these lengths. If it is
  impossible to form any triangle of a non-zero area, return 0.

CONSTRAINTS
  3 <= nums.length <= 10^4
  1 <= nums[i] <= 10^6

TEST CASES
  [1] Input    : nums = [2,1,2]
      Expected : 5
      Why      : You can form a triangle with three side lengths: 1, 2, and 2.

  [2] Input    : nums = [1,2,1,10]
      Expected : 0
      Why      : You cannot use the side lengths 1, 1, and 2 to form a triangle.
                 You cannot use the side lengths 1, 1, and 10 to form a triangle.
                 You cannot use the side lengths 1, 2, and 10 to form a triangle.
                 … (1 more)

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int largestPerimeter(vector<int>& nums);
