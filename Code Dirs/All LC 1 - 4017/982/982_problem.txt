 982. Triples with Bitwise AND Equal To Zero
 Hard  |  Tags: Array, Hash Table, Bit Manipulation
 https://leetcode.com/problems/triples-with-bitwise-and-equal-to-zero/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given an integer array nums, return the number of AND triples.

  An AND triple is a triple of indices (i, j, k) such that:

  - 0 <= i < nums.length

  - 0 <= j < nums.length

  - 0 <= k < nums.length

  - nums[i] & nums[j] & nums[k] == 0, where & represents the bitwise-AND
    operator.

CONSTRAINTS
  1 <= nums.length <= 1000
  0 <= nums[i] < 2^16

TEST CASES
  [1] Input    : nums = [2,1,3]
      Expected : 12
      Why      : We could choose the following i, j, k triples:
                 (i=0, j=0, k=1) : 2 & 2 & 1
                 (i=0, j=1, k=0) : 2 & 1 & 2
                 … (10 more)

  [2] Input    : nums = [0,0,0]
      Expected : 27

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int countTriplets(vector<int>& nums);
