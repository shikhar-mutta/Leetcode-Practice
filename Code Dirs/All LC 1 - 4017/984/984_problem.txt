 984. String Without AAA or BBB
 Medium  |  Tags: String, Greedy
 https://leetcode.com/problems/string-without-aaa-or-bbb/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  Given two integers a and b, return any string s such that:

  - s has length a + b and contains exactly a 'a' letters, and exactly b
    'b' letters,

  - The substring 'aaa' does not occur in s, and

  - The substring 'bbb' does not occur in s.

CONSTRAINTS
  0 <= a, b <= 100
  It is guaranteed such an s exists for the given a and b.

TEST CASES
  [1] Input    : a = 1, b = 2
      Expected : "abb"
      Why      : "abb", "bab" and "bba" are all correct answers.

  [2] Input    : a = 4, b = 1
      Expected : "aabaa"

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  string strWithout3a3b(int a, int b);
