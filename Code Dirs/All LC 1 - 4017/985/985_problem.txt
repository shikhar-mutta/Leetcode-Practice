 985. Sum of Even Numbers After Queries
 Medium  |  Tags: Array, Simulation
 https://leetcode.com/problems/sum-of-even-numbers-after-queries/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given an integer array nums and an array queries where
  queries[i] = [vali, indexi].

  For each query i, first, apply nums[indexi] = nums[indexi] + vali, then
  print the sum of the even values of nums.

  Return an integer array answer where answer[i] is the answer to the i^th
  query.

CONSTRAINTS
  1 <= nums.length <= 10^4
  -10^4 <= nums[i] <= 10^4
  1 <= queries.length <= 10^4
  -10^4 <= vali <= 10^4
  0 <= indexi < nums.length

TEST CASES
  [1] Input    : nums = [1,2,3,4], queries = [[1,0],[-3,1],[-4,0],[2,3]]
      Expected : [8,6,2,4]
      Why      : At the beginning, the array is [1,2,3,4].
                 After adding 1 to nums[0], the array is [2,2,3,4], and the sum of even values is 2 + 2 + 4 = 8.
                 After adding -3 to nums[1], the array is [2,-1,3,4], and the sum of even values is 2 + 4 = 6.
                 … (2 more)

  [2] Input    : nums = [1], queries = [[4,0]]
      Expected : [0]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  vector<int> sumEvenAfterQueries(vector<int>& nums, vector<vector<int>>& queries);
