 995. Minimum Number of K Consecutive Bit Flips
 Hard  |  Tags: Array, Bit Manipulation, Queue, Sliding Window, Prefix Sum, Brute-Force Search
 https://leetcode.com/problems/minimum-number-of-k-consecutive-bit-flips/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  You are given a binary array nums and an integer k.

  A k-bit flip is choosing a subarray of length k from nums and
  simultaneously changing every 0 in the subarray to 1, and every 1 in the
  subarray to 0.

  Return the minimum number of k-bit flips required so that there is no 0
  in the array. If it is not possible, return -1.

  A subarray is a contiguous part of an array.

CONSTRAINTS
  1 <= nums.length <= 10^5
  1 <= k <= nums.length

TEST CASES
  [1] Input    : nums = [0,1,0], k = 1
      Expected : 2
      Why      : Flip nums[0], then flip nums[2].

  [2] Input    : nums = [1,1,0], k = 2
      Expected : -1
      Why      : No matter how we flip subarrays of size 2, we cannot make the array become [1,1,1].

  [3] Input    : nums = [0,0,0,1,0,1,1,0], k = 3
      Expected : 3
      Why      : Flip nums[0],nums[1],nums[2]: nums becomes [1,1,1,1,0,1,1,0]
                 Flip nums[4],nums[5],nums[6]: nums becomes [1,1,1,1,1,0,0,0]
                 Flip nums[5],nums[6],nums[7]: nums becomes [1,1,1,1,1,1,1,1]

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int minKBitFlips(vector<int>& nums, int k);
