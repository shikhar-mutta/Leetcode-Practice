 996. Number of Squareful Arrays
 Hard  |  Tags: Array, Hash Table, Math, Dynamic Programming, Backtracking, Bit Manipulation, Bitmask
 https://leetcode.com/problems/number-of-squareful-arrays/description/
══════════════════════════════════════════════════════════════════════════

PROBLEM
  An array is squareful if the sum of every pair of adjacent elements is a
  perfect square.

  Given an integer array nums, return the number of permutations of nums
  that are squareful.

  Two permutations perm1 and perm2 are different if there is some index i
  such that perm1[i] != perm2[i].

CONSTRAINTS
  1 <= nums.length <= 12
  0 <= nums[i] <= 10^9

TEST CASES
  [1] Input    : nums = [1,17,8]
      Expected : 2
      Why      : [1,8,17] and [17,8,1] are the valid permutations.

  [2] Input    : nums = [2,2,2]
      Expected : 1

CODE TYPE
  function
    driver: one Solution call per test case

SIGNATURE
  int numSquarefulPerms(vector<int>& nums);
